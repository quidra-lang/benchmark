## Evidence and language semantics

Dictionaries hold shared copy objects. `pop(0)` chooses the oldest reservation; deleting `member["loans"]`/`member["holds"]` changes membership without destroying the copy, which release mutates and assigns to the next member. DAY walks each integer day. The queue is already populated in the question, so no RESERVE setup is required. The excerpt traces the valid RETURN path through validation, late fine/ledger/history and closure, then RETURN before HOLD. The new hold computes first-open(current day + 3), stores that date, and prints it. The requested local policy replacement is +3 to +5 only at this creation site. An already stored expiry E is not recomputed: DAY E retains the hold, DAY E+1 charges its previous owner, prints EXPIRED, and releases/reassigns it via the same helper. Closed-day adjustment belongs to creation; expiry processing uses the stored date, including an expiry+1 date that itself is closed.
