## Evidence and language semantics

The existing implementation accepts only positive steps and ascending endpoints. The proposed analysis changes the step guard to step == 0, then rejects a step whose sign disagrees with a nonzero to-from difference. Equal endpoints admit either nonzero sign and produce one point. Compute K = floor(abs(to-from)/abs(step)) + 1 in exact rational arithmetic; use signed from + k*step for k=0,...,K-1, not a rounded floating-point loop. Keep dispatch/argument checks, element existence, parsing from then to then step, node existence, zero-step, direction/range, K>20, resistance positivity, and structural checks in that order. Thus an unknown node still precedes a zero step, a direction error precedes the point limit, and too many points precedes nonpositive resistance. For a resistor, checking only from is insufficient for descending sweeps: before any sample is applied, require the minimum of from and from+(K-1)*step to be positive. Use actual sampled endpoints; from=5,to=0,step=-2 applies 5,3,1, so an unsampled zero bound alone does not make a resistance nonpositive. Retain the no-nodes, first floating-node and first voltage-source-loop checks before matrix solving. A concrete valid netlist is R1 n1 0 1; I1 0 n1 1; G1 n1 0 n1 0 1, followed by .SWEEP G1 1 -2 -1 n1 and .END (one statement per line). R1 grounds n1, G1 may have negative gain, and there is no ideal voltage-source loop. The matrix is the single equation (1+g)*V(n1)=1. The proposed K=4 sequence g=1,0,-1,-2 therefore emits, in order, G1 = 1: V(n1) = 1/2 (0.500000); G1 = 0: V(n1) = 1 (1.000000); G1 = -1: singular matrix; G1 = -2: V(n1) = -1 (-1.000000). Singularity is a per-point result, not a command-validation error: continue to the final point. Original G1 remains 1 afterward, whether preservation is implemented by a trial copy, an override map or explicit save/restore. Keep the reduced fraction and signed six-place truncation used by the existing formatter. These outputs and boundary cases are source deductions for the requested modification, not executed tests or implemented changes.

rational and element are value structs; append([]element(nil), c.elements...) allocates an independent element slice before any sample assignment. Changing temporary.elements[index].value cannot alter the original slice. K and the sample index are int64, whereas node indexes are int. build reads the temporary value into fresh matrix/RHS data. solve returns nil for the singular point and emit continues the loop. Command validation uses a distinct commandError panic recovered by process; it precedes the temporary sampling and does not replace the per-point nil handling. String/value formatting and fmt output retain exact fractions and six-place truncation.

## Minimization and alternatives

Only the guards omit input/value semantics, precedence, signed sample application, singular continuation, formatting and state preservation. The selected slice retains exact arithmetic and custom helper definitions needed for that path and for the required structural checks. Unrelated analysis commands, network reduction, current/power reporting, and separable stamps for unused element kinds are omitted. Required shared type, class, branch and dispatch context is retained; each complete source line appears unchanged and at most once.
