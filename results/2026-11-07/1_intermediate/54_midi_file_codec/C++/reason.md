## Evidence and language semantics

The requested change belongs in the event transformation, after target selection and signed pitch addition and before the payload assignment. Replace the range-failure removal path with a lower/upper bound clamp. Every selected event must reach the retained-event path exactly once; leave tick, status/channel, second data byte and track order untouched. Equal resulting pitches are separate sequence entries, including entries at the same tick; no set, grouping or note-pair operation is required. The transposed count includes those now clamped, including a zero shift; dropped becomes zero and its detail loop receives no events. DECODE already formats the stored payload in track order. ENCODE already uses each retained absolute tick minus the previous retained tick, so preserving events preserves the original delta sequence, including zero deltas; the shortest base-128 encoding and channel payload emission remain applicable. Existing running-status compression only suppresses status bytes, while NOTE_OFF ZERO changes status/velocity at encoding time and keeps the pitch. Neither operation coalesces events. Kind is an ordered enum beginning with NoteOff, NoteOn and PolyPressure, so the <= PolyPressure predicate selects precisely those three. typeNames maps their enum indices to displayed names. fields[0] is formatted as pitch and all fields are emitted in the encoder, while tick is a distinct int64_t field. The new track vector receives each Event by value then is moved back; std::vector push_back retains multiplicity and order even for identical field values. Song& binds the stored map value, so the replacement persists without an additional store. argument validates the shift before the optional channel and only after command membership and song lookup; fail throws runtime_error handled with the existing error: prefix. encode takes const Song&, which prevents mutation through that reference; the local fields copy implements NOTE_OFF ZERO without altering stored pitch. No custom helper body is included merely to re-establish the standard vector, move, find or const-reference rules.
