## Evidence and language semantics

The requested change belongs in the event transformation, after target selection and signed pitch addition and before the payload assignment. Replace the range-failure removal path with a lower/upper bound clamp. Every selected event must reach the retained-event path exactly once; leave tick, status/channel, second data byte and track order untouched. Equal resulting pitches are separate sequence entries, including entries at the same tick; no set, grouping or note-pair operation is required. The transposed count includes those now clamped, including a zero shift; dropped becomes zero and its detail loop receives no events. DECODE already formats the stored payload in track order. ENCODE already uses each retained absolute tick minus the previous retained tick, so preserving events preserves the original delta sequence, including zero deltas; the shortest base-128 encoding and channel payload emission remain applicable. Existing running-status compression only suppresses status bytes, while NOTE_OFF ZERO changes status/velocity at encoding time and keeps the pitch. Neither operation coalesces events. Lua note payloads use index 1, not zero; notes[p] is deliberately keyed from 0 through 127. Status high nibbles 8..10 identify the three channels through eventType/channels, while low bits plus one select a supplied channel. The new tables are sequence tables traversed with ipairs and appended at #new+1: keep both target and non-target append paths, with clamped targets taking the former exactly once. No pitch-keyed table is introduced. song is the held table, and replacing song.tracks[i] persists its row. range converts and checks the arguments; requireThat raises with level 0 and pcall formats error:. The unknown-command check precedes the held-song check and the TRANSPOSE argument check. append is custom and is included because its loop is necessary to establish sequence concatenation in both eventLine and encode; copy is included to establish a separate encoding data table for NOTE_OFF ZERO. Integer division in vlq and table.insert at 1 produce the shortest delta representation.
