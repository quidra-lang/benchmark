## Evidence and language semantics

The requested change belongs in the event transformation, after target selection and signed pitch addition and before the payload assignment. Replace the range-failure removal path with a lower/upper bound clamp. Every selected event must reach the retained-event path exactly once; leave tick, status/channel, second data byte and track order untouched. Equal resulting pitches are separate sequence entries, including entries at the same tick; no set, grouping or note-pair operation is required. The transposed count includes those now clamped, including a zero shift; dropped becomes zero and its detail loop receives no events. DECODE already formats the stored payload in track order. ENCODE already uses each retained absolute tick minus the previous retained tick, so preserving events preserves the original delta sequence, including zero deltas; the shortest base-128 encoding and channel payload emission remain applicable. Existing running-status compression only suppresses status bytes, while NOTE_OFF ZERO changes status/velocity at encoding time and keeps the pitch. Neither operation coalesces events. Zig pitch computation explicitly widens the byte to signed I before adding; clamp must precede byte()/@intCast, which does not saturate. clone duplicates payload bytes and tracks; mutation occurs on the copied song, then songs.items[at].song commits it. Replacing each track with kept preserves event order and tick positions and retains equal clamped notes as separate Event values. code/16 and channel identify the three kinds and optional channel; standard ArrayList append does not merge entries. The encoder reads the committed song and the unchanged tick delta; running status and NOTE_OFF ZERO alter only status/velocity. Lookup and valid checks precede transformation; Host.line supplies newline and existing error representation.

The relevant event/list types, selected formatting branches, VLQ code, encoder traversal, command guards and persistent-state write are retained. Custom helper bodies appear only where they determine a required behavior; ordinary collection/ownership rules are stated in the evidence. Source declarations and branch guards needed to identify selected definitions are retained even when a smaller candidate omitted them.
