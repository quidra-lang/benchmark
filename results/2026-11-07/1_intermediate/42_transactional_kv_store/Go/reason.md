## Evidence and language semantics

The same bare-token scenario is used across languages: SET k v EX 5; BEGIN; BEGIN; SET keep inner; COMMIT; SNAPSHOT s; RESTORE s; TICK 6; ROLLBACK; GET k; RESTORE s; GET keep; GET k. It distinguishes an outer transaction copy, an inner commit, and a retained named snapshot. The clock starts at zero; the TTL deadline is five; at clock six restoring either saved database removes k. The outer rollback removes keep from the current database but the named snapshot s still supplies it. Go maps are reference-bearing values, so merely assigning the map would not create a snapshot. cloneDatabase allocates a fresh map and clones each stored value; textValue is an immutable string and expiration is a copied struct. The saved map installed by rollback is removed from the stack, whereas named RESTORE clones the saved map and retains the registry entry. Store time is independent and defaults to zero; restoration assigns only database and invokes purge, so absolute expiries <= the advanced clock disappear again. Scanner, command registration and dispatch, and reply formatting determine the visible trace.

## Minimization and alternatives

Bare arguments avoid the quoted/escaped-token branch. Only the successful command routes needed by the scenario are retained; unrelated data structures and commands are excluded. SET with EX was compared with SET plus EXPIRE: the chosen SET path already shows value creation and its absolute TTL and avoids a second command path. Copy implementations are included only where the language does not itself guarantee independence. Output primitives are retained because their formatting is observable. Restoring only the database field, while time and snapshot/transaction storage are distinct, establishes the unchanged clock and surviving named snapshots without selecting unrelated commands. Each retained declaration, branch, assignment and call supplies a required dependency; necessary internal control boundaries are retained; redundant outer declaration frames and extra context are omitted when they add no fact. The final excerpt was reviewed independently against all common requirements. Whitespace-only lines outside source literals and explicit line continuations are omitted: they contribute tokens but no evidence for the answer. Literal content is preserved, and files with ambiguous quote or multiline-literal syntax are left unchanged by this step. The bare-token loop ends before the completed argument list is returned. Necessary option-loop, command-arm, transaction/TICK and main input/error boundaries preserve subsequent command reachability and reply order. A brace or end on its own is retained when it establishes such a boundary; Python and Quidra retain the corresponding indentation. The quoted-token path, unrelated commands and outer declaration framing remain excluded.
