## Evidence and language semantics

The same bare-token scenario is used across languages: SET k v EX 5; BEGIN; BEGIN; SET keep inner; COMMIT; SNAPSHOT s; RESTORE s; TICK 6; ROLLBACK; GET k; RESTORE s; GET keep; GET k. It distinguishes an outer transaction copy, an inner commit, and a retained named snapshot. The clock starts at zero; the TTL deadline is five; at clock six restoring either saved database removes k. The outer rollback removes keep from the current database but the named snapshot s still supplies it. C pointer assignment is not a snapshot. allocate/copy_string/copy_record/copy_database show independent heap storage for records, keys and string payloads, including copied absolute expiry. free_database/free_record and delete_key show what COMMIT and purge release, without releasing the independent snapshot. stack is a separate LIFO pointer array; rollback transfers its newest owned database after freeing the current one. Named restore copies rather than consumes saved storage. Static current_time starts at zero and is not part of Database. The complete parallel enum/format declarations are needed because name-to-handler mapping is positional. SET expiry, expiration count, GET and main establish the trace without selecting unrelated value commands.

## Minimization and alternatives

Bare arguments avoid the quoted/escaped-token branch. Only the successful command routes needed by the scenario are retained; unrelated data structures and commands are excluded. SET with EX was compared with SET plus EXPIRE: the chosen SET path already shows value creation and its absolute TTL and avoids a second command path. Copy implementations are included only where the language does not itself guarantee independence. Output primitives are retained because their formatting is observable. Restoring only the database field, while time and snapshot/transaction storage are distinct, establishes the unchanged clock and surviving named snapshots without selecting unrelated commands. Each retained declaration, branch, assignment and call supplies a required dependency; standalone closing delimiters and extra context are omitted when they add no fact.
