## Evidence and language semantics

The input loop and execute split command and args; command dispatches the eight selected cases. Player initializes rounds/records/calculation and constructor identity/index fields. GolfRound captures previousIndex, records.length and previousCalculation before building adjusted scores/diff. update replaces calculation objects, so storing the earlier object reference safely preserves that calculation; array length truncation in REMOVE removes the newer dated records. low filters the half-open day window and sorts index then date. Spread sorting and reverse keep HISTORY in chronological order while newest tied differentials count first. Standard Number, Math.floor, array sort/map/slice/filter, object reference and Map semantics suffice for selected helpers; event processing is unrelated.

Independent excerpt-only check: register a course c with eighteen par-4 holes and stroke indexes 1..18, tee t with rating 720 and slope 113, and player p with index 180. Record all-5 rounds on days 1, 2 and 3. Each has AGS 90 and differential 180 (18.0); none is exceptional. The first two rounds retain index 180 and have no calculation; each appends (day,180). The third selects the newest tied differential, averages 180 and applies -20, giving index 160 (16.0), low 180, and calculation k=1/average=180/adjustment=-20 with no caps. INDEX reports rounds 3 and that calculation; HISTORY has three 18.0 differentials with only round 3 starred; LOWINDEX at day 4 is 16.0 on day 3. REMOVE restores index 180, the absent calculation and record length 2. The next INDEX is 18.0/rounds 2 without calculation, HISTORY has two unstarred entries, and LOWINDEX at day 4 is 18.0 on day 1.
