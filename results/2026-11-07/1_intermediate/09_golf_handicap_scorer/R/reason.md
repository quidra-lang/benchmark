## Evidence and language semantics

registry/object create reference environments for the registered Course and Player, while score rounds, calculation metadata and dated records are ordinary lists/vectors with R value semantics. execute uses strsplit then parses numeric vectors and markers; ROUND captures before_index/before_records/before_calculation before mutating the Player environment. REMOVE restores those saved values and list prefixes using seq_len, including zero-length restoration. Counting orders adjusted values then negative round numbers; low_index tests day-365 <= record day < day and breaks index ties by earlier date. The selected score_number helper is necessary for score normalization; pmin, sum, order, fd rounding and formatting helpers support the output. The input loop prints the returned output vector. Environment/list semantics explain both intentional player mutation and preserved historical snapshots.

Independent excerpt-only check: register a course c with eighteen par-4 holes and stroke indexes 1..18, tee t with rating 720 and slope 113, and player p with index 180. Record all-5 rounds on days 1, 2 and 3. Each has AGS 90 and differential 180 (18.0); none is exceptional. The first two rounds retain index 180 and have no calculation; each appends (day,180). The third selects the newest tied differential, averages 180 and applies -20, giving index 160 (16.0), low 180, and calculation k=1/average=180/adjustment=-20 with no caps. INDEX reports rounds 3 and that calculation; HISTORY has three 18.0 differentials with only round 3 starred; LOWINDEX at day 4 is 16.0 on day 3. REMOVE restores index 180, the absent calculation and record length 2. The next INDEX is 18.0/rounds 2 without calculation, HISTORY has two unstarred entries, and LOWINDEX at day 4 is 18.0 on day 1. The same selected capture/restore paths also preserve an absent initial index or an earlier nonempty calculation.
