## Evidence and language semantics

Matches hold both typed key/index paths and separate position vectors. jsonEncode(path) gives deduplication identity and the comparator explicitly reverses ordinal order. Rename rebuilds a parent Map from entries on candidate, preserving order. A QueryFailure bypasses history.add/document assignment and is caught by run, so no earlier candidate edit escapes. Equal keys and empty targets still commit and report selected.length. UNDO clones and removes the last history value, reporting the remaining length; LOAD counts all preorder matches and path depth.
