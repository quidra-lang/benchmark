## Evidence and language semantics

The common scenario is specified in the shared requirements; profile arrays contain exactly24 repeated values and the sole hourly override replaces hour1 load300 by400. The input is within all Task A ranges. Initial500Wh and reserve200Wh leave300Wh available in the ordinary SELF run: hour0 uses300Wh and the grid supplies the remaining7000Wh for0.70 plus1.00 fixed. SET INITIAL100 affects the active configuration only. OUTAGE1/0/1 replays the saved INITIAL50 configuration, starts at500Wh (there is no preceding hour), drops its lower SOC bound to0 inside the inclusive window and leaves200Wh unserved at hour1. The other22hours import6600Wh costing0.66, so the trial bill is1.66 and served percentage is floor(10000*500/700)/100=71.42. BILL after OUTAGE reads the original1.70 result. Hash#dup detaches settings and prices, whose entries are immutable integers; sharing the input data and strategy strings does not share mutable simulator SOC. attr_reader declarations expose the retained result/record values used by report methods. OUTAGE stores a newly simulated result in a local variable, and the current instance variable is only installed by the selected RUN route. Ruby integer division and Range inclusion supply the numeric/outage rules; first.zero? selects start_soc rather than the language-valid negative-index access.

## Minimization and alternatives

SELF was chosen over parameterized/arbitrage strategies to avoid their validation, tariff-ranking and export-policy dependencies. A single period and zero PV avoid tariff ties and nonzero charging cases; the shared arithmetic/flow lines remain when needed to establish those zeros and the import/shortfall fields. SET INITIAL was chosen over PRICE because the changed initial charge makes saved-versus-active configuration observable exactly at the required day1/hour0 boundary; including both mutations would add a redundant command route. One overridden hour demonstrates hourly input replacement and a partially served outage. Retain only reached parser/command paths, flow and billing dependencies, copied configuration ownership and output fields; exclude reports, additional strategies and unrelated statistics. Whole routines were considered and rejected in favor of individually required complete lines, including guards where they select the SELF path. Delimiter-only lines and unrelated result fields are omitted. The final excerpt was reviewed on its own against the same five requirements; Task A conformance is assumed and programs were not executed.
