## Evidence and language semantics

Events are expanded and processed sequentially. Validation/finished checks precede acceptance of each event; an error exits the current iteration/command without removing the already accepted prefix. UNDO removes one successful event, even when it was in a multi-event command and even when it ended the match. Empty history is rejected. The saved record contains old values only for changed state-array cells plus the previous completed-set list length. Undo restores those cells and truncates that list. The done/winner cells and statistics occupy the same array, so they are restored with scores rather than updated independently. Java int[].clone copies primitive elements. ArrayDeque is used as a stack; changed cells are saved from before and pop returns one record. Source bytes and each selected original line were verified against the current develop checkout before inheritance; the excerpt was then independently reviewed. Additional selected error helpers establish actual nonlocal failure; selected scalar/array/frame declarations establish restoration semantics where needed.
