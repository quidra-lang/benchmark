## Evidence and language semantics

Common concrete input: 1; CHART exact; state a; on a done / log "prefix"; on a done.state.a / log "exact"; on a * / log "wild"; RUN; event done.state.a; event done; event other; dump; END (each semicolon separates an input line). Original logs are prefix, prefix, wild; after removing the prefix alternative from the descriptor predicate they are exact, prefix, wild. The first event is a valid externally supplied name, also the spelling used for completion events; generated completions still enter the same event queue but use the revised exact-name rule. The only active state remains a at time zero. No guard, target, entry/exit action, timer or variable is declared; absent guards are true and every selected transition is internal. Quidra class field initializers establish empty transition/action arrays, zero clock, false configuration flags and empty Expression.nodes for absent expressions. The array of flags is indexed by numeric state IDs, while ordered transition_ids preserve registration. transition_scope returns -1 for the absent target; exits_for therefore yields false flags, and the target < 0 guard skips entry seeds. Empty expression nodes make guards true and literal log actions bypass evaluation. Remove only item.name.starts_with(descriptor+"."); equality/wildcard and explicit always/timer branches remain. Named Event values from raise/final completion enter the FIFO queue and ordinary event selection; reservations retain timer IDs. The custom cut_once, state lookup, construction, close_entries and emit paths establish the valid chart, three log strings and dump indentation.

Boundary review: The optional-guard if header is retained before the already selected guard-text assignments. The tick branch and its while header place the already selected reservation operations under timer dispatch, separately from the preceding event branch. Existing dedentation places target/action construction and the transition return outside the optional parsing branches.

## Minimization and alternatives

A single atomic state and targetless transitions minimize state-entry/exit/history dependencies while still exercising parsing, ordered transition priority, default guards, conflict filtering, action logs and dump output. A chart with guarded arithmetic or changing targets would require expression evaluation and target/history closure without adding a fact needed to locate this matching change. Queue/completion creation and separate timer/eventless dispatch anchors are retained to delimit the modification; their scheduling algorithms are not changed. Only the successful branches and custom helpers needed for this trace are retained, plus the match alternatives that distinguish old/new behavior. Each selected complete line was reviewed for necessity; the excerpt alone was checked against the common requirements. Internal boundaries needed to establish the scope of later selected operations are retained. Independent outer declaration frames and unrelated command bodies are omitted where they provide no evidence.
