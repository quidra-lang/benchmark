Original logs are prefix, prefix, wild; after removing the prefix alternative from the descriptor predicate they are exact, prefix, wild. The first event is a valid externally supplied name, also the spelling used for completion events; generated completions still enter the same event queue but use the revised exact-name rule. The only active state remains a at time zero. No guard, target, entry/exit action, timer or variable is declared; absent guards are true and every selected transition is internal. Typed nullable target/guard defaults and discriminated trigger kinds make the three dispatch modes explicit, but runtime Map/Set identities still determine priority and deduplication. The current prefix test is the final some disjunct; deleting it leaves wildcard and identical-event comparison intact. An internal Choice contains scope null and an empty Set, so conflict processing admits it and microstep does not expand targets. The existing FIFO queue receives completion names and action-raised events; timer identity and always-kind paths do not use event spelling.

Boundary review: The guard and target parsing branches close before transitionParts returns. The quoted-log object closes before its if branches, and the multiline ancestor-search for loop closes before candidate deduplication. Other selected internal control boundaries preserve action, entry and dispatch scope; the independent select method closing frame is omitted.

A chart with guarded arithmetic or changing targets would require expression evaluation and target/history closure without adding a fact needed to locate this matching change. Queue/completion creation and separate timer/eventless dispatch anchors are retained to delimit the modification; their scheduling algorithms are not changed. Only the successful branches and custom helpers needed for this trace are retained, plus the match alternatives that distinguish old/new behavior.
