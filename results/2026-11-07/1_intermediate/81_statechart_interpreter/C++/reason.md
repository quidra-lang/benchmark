## Evidence and language semantics

Common concrete input: 1; CHART exact; state a; on a done / log "prefix"; on a done.state.a / log "exact"; on a * / log "wild"; RUN; event done.state.a; event done; event other; dump; END (each semicolon separates an input line). Original logs are prefix, prefix, wild; after removing the prefix alternative from the descriptor predicate they are exact, prefix, wild. The first event is a valid externally supplied name, also the spelling used for completion events; generated completions still enter the same event queue but use the revised exact-name rule. The only active state remains a at time zero. No guard, target, entry/exit action, timer or variable is declared; absent guards are true and every selected transition is internal. Default-constructed shared_ptr expression trees are null and vectors/strings empty; vector<bool>(n) creates false flags. Those guarantees establish no guard/value work and empty internal exit sets. Integer IDs in ordered vectors preserve candidate registration; set<int> is used only for deduplication. Removing the rfind(descriptor+".",0)==0 disjunct retains equality and wildcard. The timer case includes both kind and identity and the eventless case remains unchanged. deque front/pop_front preserves queued raised/completion events. Internal mode yields scope -1 and skips entry seeding; active a therefore persists. Custom words, reference checks, initialization and cout formatting supply the input-to-output chain.

Boundary review: Internal braces separate literal-log parsing and optional target parsing from their following returns, and end the selected definition, transition-choice, entry and event-command loops before later operations. Else headers are copied only as part of the complete original boundary lines.

## Minimization and alternatives

A single atomic state and targetless transitions minimize state-entry/exit/history dependencies while still exercising parsing, ordered transition priority, default guards, conflict filtering, action logs and dump output. A chart with guarded arithmetic or changing targets would require expression evaluation and target/history closure without adding a fact needed to locate this matching change. Queue/completion creation and separate timer/eventless dispatch anchors are retained to delimit the modification; their scheduling algorithms are not changed. Only the successful branches and custom helpers needed for this trace are retained, plus the match alternatives that distinguish old/new behavior. Each selected complete line was reviewed for necessity; the excerpt alone was checked against the common requirements. Internal boundaries needed to establish the scope of later selected operations are retained. Independent outer declaration frames and unrelated command bodies are omitted where they provide no evidence. Whitespace-only lines outside source literals and explicit line continuations are omitted: they contribute tokens but no evidence for the answer. Literal content is preserved, and files with ambiguous quote or multiline-literal syntax are left unchanged by this step.
