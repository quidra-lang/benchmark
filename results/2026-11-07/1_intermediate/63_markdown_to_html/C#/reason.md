## Evidence and language semantics

Use [TOC], a blank line, # Parent {#foo}, a blank line, > ## Foo, then @@END@@. The TOC is recognized before either heading; the quoted line is stripped of > and recursively parsed as a level-2 heading. The explicit heading reserves foo and removes {#foo} from the display source. The nested automatic heading uses raw Foo to form foo, finds it occupied, then chooses and reserves foo-1. Ordinary inline characters are escaped and assembled into the heading HTML; tag stripping that rendered HTML supplies the TOC labels Parent and Foo. Automatic slugging receives raw heading source, before inline rendering. The same final IDs are recorded for both heading attributes and TOC links. The heading-level tree makes the level-2 Foo a child of level-1 Parent. The earlier TOC placeholder is replaced only after the heading traversal, so the leading nav links #foo and #foo-1 agree with h1 id=foo and the quoted h2 id=foo-1. C# Block.Number carries the ATX level, and the Heading class maps constructor arguments to Level, Id and Label and owns a Children list. A single Renderer owns HashSet<string> usedIds and List<Heading> headings; quote rendering calls its own RenderBlocks, so nested headings participate in the same ordered reservation and collection. Document first finishes RenderBlocks, then obtains TableOfContents for Replace. No global pre-reservation of later explicit IDs is inferred.
