## Evidence and language semantics

Use [TOC], a blank line, # Parent {#foo}, a blank line, > ## Foo, then @@END@@. The TOC is recognized before either heading; the quoted line is stripped of > and recursively parsed as a level-2 heading. The explicit heading reserves foo and removes {#foo} from the display source. The nested automatic heading uses raw Foo to form foo, finds it occupied, then chooses and reserves foo-1. Ordinary inline characters are escaped and assembled into the heading HTML; tag stripping that rendered HTML supplies the TOC labels Parent and Foo. Automatic slugging receives raw heading source, before inline rendering. The same final IDs are recorded for both heading attributes and TOC links. The heading-level tree makes the level-2 Foo a child of level-1 Parent. The earlier TOC placeholder is replaced only after the heading traversal, so the leading nav links #foo and #foo-1 agree with h1 id=foo and the quoted h2 id=foo-1. PHP object methods retain the same Renderer state throughout recursive block rendering. Arrays hold value records, so tableOfContents stores integer indices and explicitly appends children through $this->headings[parent][children]; it does not depend on foreach $entry mutating the original record. The usedIds array is tested with isset and populated before recording the HTML label. document first renders all blocks, then passes the completed tableOfContents to str_replace. Ordinary string pieces use is_string and concatenation. Reservation follows render order; later explicit IDs are not claimed to be globally pre-reserved. The shown delimiter-character test guards the else branch that emits ordinary letters as escaped strings.

## Minimization and alternatives

Selected the ordinary-character inline path for this valid minimal witness. More elaborate emphasis, links, footnotes, tables, lists, code fences, other heading syntaxes, and error handling do not establish an additional answer requirement. A witness with only top-level headings would shorten the excerpt but would not demonstrate nested-block collection. An allocation-only excerpt loses forward references and raw-versus-rendered provenance.
