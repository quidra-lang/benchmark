## Evidence and language semantics

Use [TOC], a blank line, # Parent {#foo}, a blank line, > ## Foo, then @@END@@. The TOC is recognized before either heading; the quoted line is stripped of > and recursively parsed as a level-2 heading. The explicit heading reserves foo and removes {#foo} from the display source. The nested automatic heading uses raw Foo to form foo, finds it occupied, then chooses and reserves foo-1. Ordinary inline characters are escaped and assembled into the heading HTML; tag stripping that rendered HTML supplies the TOC labels Parent and Foo. Automatic slugging receives raw heading source, before inline rendering. The same final IDs are recorded for both heading attributes and TOC links. The heading-level tree makes the level-2 Foo a child of level-1 Parent. The earlier TOC placeholder is replaced only after the heading traversal, so the leading nav links #foo and #foo-1 agree with h1 id=foo and the quoted h2 id=foo-1. Quidra stores parsed blocks in Parser.blocks, appends each block with add, and returns numeric indices; quote children therefore refer to the same block table through their indices. Renderer reads the finished block table from parser.blocks and follows sequence/render calls on the same receiver; the trace relies on indices and explicit assignments, not on array aliasing. The dot-prefixed mutating calls update the receiver; append results are explicitly assigned back to headings, while distinct.has/add provides occupied-ID testing and reservation. TOC nesting uses a separate integer parent array and does not require aliasing Heading values. Piece defaults keep ordinary text on the non-delimiter output branch. String interpolation constants DQ/NL/HT supply quotes, newlines, and the deferred marker; doubled braces in source represent the explicit-ID braces. The empty notes array returns an empty footnote suffix.

## Minimization and alternatives
