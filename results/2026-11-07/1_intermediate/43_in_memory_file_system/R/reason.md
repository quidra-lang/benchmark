## Evidence and language semantics

The resolution list defaults node and parent to NULL. A link-target call clears original, and a missing target result returns without acquiring the original suffix creation location. A missing ordinary final name returns its containing directory and that name. A missing link target returns the same displayed missing-entry reason without that creation payload; the failure escapes before the remaining original path can be treated as creatable. Absolute targets start at root; relative targets start at the containing directory. The excerpt alone supplies traversal, the original/recursive flag transition, return payload, and touch acceptance/error branches. Standard splitting, map lookup, optional/null, and branch semantics require no library implementation.

Other commands, node size/content operations, allocation internals, and command parsing are irrelevant to this routine question. Constructors are retained only where needed to interpret omitted/default result fields; error-format mappings are retained where the same displayed message is indirect. Pure block delimiters, blank lines, expansion-limit checks, and unrelated successful-action work were omitted where the selected conditions and indentation preserve the required scope. A full resolver including loop-limit handling would cost more tokens without affecting the stipulated missing-path comparison; no proposed source change is made.
