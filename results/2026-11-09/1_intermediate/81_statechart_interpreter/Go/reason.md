## Evidence and language semantics

Common concrete input: 1; CHART exact; state a; on a done / log "prefix"; on a done.state.a / log "exact"; on a * / log "wild"; RUN; event done.state.a; event done; event other; dump; END (each semicolon separates an input line). Original logs are prefix, prefix, wild; after removing the prefix alternative from the descriptor predicate they are exact, prefix, wild. The first event is a valid externally supplied name, also the spelling used for completion events; generated completions still enter the same event queue but use the revised exact-name rule. The only active state remains a at time zero. No guard, target, entry/exit action, timer or variable is declared; absent guards are true and every selected transition is internal. Go zero values initialize nil guards/action expressions, empty slices, zero time and false activity; make([]bool,n) creates the empty exit/entry bitsets. State IDs index those sets, while pointer identity identifies transitions for timer equality and deduplication. Slice range order gives document and registration priority. The selected transitionSet internal early return and conflict loop prove that no state is exited. Remove strings.HasPrefix(event,descriptor+".") only; exact/wildcard and the kind/timer tests remain. enqueue and final completion preserve ordinary event names; reservation dispatch retains timer pointers. The literal parser and fmt output directly establish three log lines and unchanged a at dump time0.

Boundary review: Internal braces close optional transition parsing and definition loops before registration continues, and close action, selection, entry, macrostep, script and input loops before their following operations. These are control boundaries inside retained routines, not restored outer function frames.

## Minimization and alternatives

A single atomic state and targetless transitions minimize state-entry/exit/history dependencies while still exercising parsing, ordered transition priority, default guards, conflict filtering, action logs and dump output. A chart with guarded arithmetic or changing targets would require expression evaluation and target/history closure without adding a fact needed to locate this matching change. Queue/completion creation and separate timer/eventless dispatch anchors are retained to delimit the modification; their scheduling algorithms are not changed. Only the successful branches and custom helpers needed for this trace are retained, plus the match alternatives that distinguish old/new behavior. Each selected complete line was reviewed for necessity; the excerpt alone was checked against the common requirements. Internal boundaries needed to establish the scope of later selected operations are retained. Independent outer declaration frames and unrelated command bodies are omitted where they provide no evidence. Whitespace-only lines outside source literals and explicit line continuations are omitted: they contribute tokens but no evidence for the answer. Literal content is preserved, and files with ambiguous quote or multiline-literal syntax are left unchanged by this step.
