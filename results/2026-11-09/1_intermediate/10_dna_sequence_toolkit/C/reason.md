## Evidence and language semantics

Integer division in percentage truncates 10000*part/whole before fixed splits hundredths into two digits. GC and GCWINDOW share percentage. Change only GC's conversion call, using a specialized conversion or local rounded scaled value; leave the window call and base counters intact. For nonnegative GC count g and positive length n, the new integer hundredths value is floor((20000*g+n)/(2*n)); this is exact half-up rounding before the same two-digit rendering. Integer quotient/remainder rounding with 2*remainder>=n is an equivalent option.
