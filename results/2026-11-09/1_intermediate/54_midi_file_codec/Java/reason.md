## Evidence and language semantics

The requested change belongs in the event transformation, after target selection and signed pitch addition and before the payload assignment. Replace the range-failure removal path with a lower/upper bound clamp. Every selected event must reach the retained-event path exactly once; leave tick, status/channel, second data byte and track order untouched. Equal resulting pitches are separate sequence entries, including entries at the same tick; no set, grouping or note-pair operation is required. The transposed count includes those now clamped, including a zero shift; dropped becomes zero and its detail loop receives no events. DECODE already formats the stored payload in track order. ENCODE already uses each retained absolute tick minus the previous retained tick, so preserving events preserves the original delta sequence, including zero deltas; the shortest base-128 encoding and channel payload emission remain applicable. Existing running-status compression only suppresses status bytes, while NOTE_OFF ZERO changes status/velocity at encoding time and keeps the pitch. Neither operation coalesces events. The Java Event reference keeps long tick separate from integer code and a mutable List<Integer> payload. channel validates the channel-code interval, and kind/CHANNEL map high nibbles 8..10 to the affected event names. The signed long addition must be clamped before narrowing to int in data.set. track.add and s.tracks.set retain one reference per original event and preserve its position; Java Lists allow repeated/equal entries, and songs.get returns the stored Song object. The selected validation switch and range helper establish the unchanged shift and optional-channel bounds after command/song checks. fail throws Failure, caught with the existing error: prefix. eventText formats data[0] via noteName; encode uses its per-track tick differences and VLQ, emits each payload, and keeps a separate replacement payload for NOTE_OFF ZERO. ArrayList/addAll and ordinary reference semantics supply the ordering/persistence facts without additional implementation source.
