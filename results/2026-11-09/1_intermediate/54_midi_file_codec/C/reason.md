## Evidence and language semantics

The requested change belongs in the event transformation, after target selection and signed pitch addition and before the payload assignment. Replace the range-failure removal path with a lower/upper bound clamp. Every selected event must reach the retained-event path exactly once; leave tick, status/channel, second data byte and track order untouched. Equal resulting pitches are separate sequence entries, including entries at the same tick; no set, grouping or note-pair operation is required. The transposed count includes those now clamped, including a zero shift; dropped becomes zero and its detail loop receives no events. DECODE already formats the stored payload in track order. ENCODE already uses each retained absolute tick minus the previous retained tick, so preserving events preserves the original delta sequence, including zero deltas; the shortest base-128 encoding and channel payload emission remain applicable. Existing running-status compression only suppresses status bytes, while NOTE_OFF ZERO changes status/velocity at encoding time and keeps the pitch. Neither operation coalesces events. C stores events in counted arrays: the write index and t->count implement stable compaction. Remove the out-of-range continue and removed-record append; keep every e in the same write slot sequence, with a clamped unsigned-char payload value. The signed Integer typedef must be used for the addition before narrowing; a cast to unsigned char does not implement clamping. Event struct assignment preserves tick and status, while the data pointer gives the deliberate payload update; find_song returns the held Song pointer and does not copy it. Both helper implementations and the pointer lookup are included because C signatures alone would not establish them. byte appends one output byte by incrementing the buffer count, and var reverses the seven-bit groups, establishing shortest delta encoding. fail formats a reason and longjmps; setjmp/execute and its error printf show the existing error order and result representation. No freed-event path remains reachable after the clamp change.
