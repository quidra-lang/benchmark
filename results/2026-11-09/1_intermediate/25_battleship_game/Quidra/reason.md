## Evidence and language semantics

Normalize only the parsed command name SHOT to FIRE (or bind SHOT to exactly the existing FIRE handler), before all name-based routing, leaving argument positions and the ordered batch intact. Do not loop by dispatching separate FIRE commands: that would repeat validation/allowance and finish turns independently. The excerpt separates batch validation from action and retains the original per-shot and completion calls. An error in a later command does not undo already accepted state; an invalid later cell in the current batch is discovered during its preflight before any shot. Exceptions/early returns bypass completion. Repeated cells reach the unchanged shot operation in order, so its existing ALREADY behavior remains; victory still stops remaining shots. AI and TORPEDO keep their own operands, handlers, output and action rules. Quidra reads op before player_commands and turn-command membership, so canonicalize that name at the start while retaining every token after it. Empty strategy preserves supplied cells; AI passes its strategy token, and TORPEDO keeps its separate row/side helper and used check. FIRE preflights before shooting_turn. shoot updates the statistics and explicitly assigns attacker/defender back, then shooting_turn aggregates hit and calls finish_turn once. command explicitly writes game back to program after accepted turn/automatic stages. An error return precedes those stages, and the outer union match only emits ERROR; preceding accepted program state is retained. These conclusions use the explicit write-back sites, without assuming an implicit rollback or deep-copy guarantee.

Dispatch alone would identify an alias entry but not prove preservation of batch validation, failure boundaries, action order or completion; the FIRE body alone would miss the original name-resolution and AI/TORPEDO separation. Adding all helpers or the full dispatcher would add independently unnecessary lines. Separate aliases in every downstream name test are a larger and error-prone alternative to canonicalizing the single input command token; global replacement of SHOT output text is not a command alias.
