## Evidence and language semantics

Use [TOC], a blank line, # Parent {#foo}, a blank line, > ## Foo, then @@END@@. The TOC is recognized before either heading; the quoted line is stripped of > and recursively parsed as a level-2 heading. The explicit heading reserves foo and removes {#foo} from the display source. The nested automatic heading uses raw Foo to form foo, finds it occupied, then chooses and reserves foo-1. Ordinary inline characters are escaped and assembled into the heading HTML; tag stripping that rendered HTML supplies the TOC labels Parent and Foo. Automatic slugging receives raw heading source, before inline rendering. The same final IDs are recorded for both heading attributes and TOC links. The heading-level tree makes the level-2 Foo a child of level-1 Parent. The earlier TOC placeholder is replaced only after the heading traversal, so the leading nav links #foo and #foo-1 agree with h1 id=foo and the quoted h2 id=foo-1. J uses globally assigned boxed arrays (=:), initialized empty, for UsedIds and the parallel heading levels/IDs/labels; recursive rendering therefore appends to the same recorded state. Parsed blocks live in global Blocks, with setBlock explicitly amending the stored boxed record by index; quote children are indices into that table. A normal piece boxes html with count/opens/closes zero, so emphasis concatenates its HTML. Membership of boxed IDs drives the suffix loop. TOC construction computes integer parent indices from HeadingLevels, then tocList retrieves labels and IDs at matching indices. Local variable assignment (=.) and array values do not imply shared mutable copies. All headings are rendered before the marker substitution loop. Empty NoteNames proves the appended footnote output is empty for this witness.
