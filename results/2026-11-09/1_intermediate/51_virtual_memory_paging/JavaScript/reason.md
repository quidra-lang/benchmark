Class fields initialize empty maps, counters and flags; constructor creates settings.frames null entries and independent TLB lists. SYSTEM replaces the old simulation and outputs keys from fresh settings. Change only the frames/frame_count default from4 to8. All explicit frames values remain subject to the existing1..16 validation and overwrite that default; the tlb/sets divisibility rule is unchanged. Since parsing and construction start afresh on each SYSTEM, SYSTEM frames=2 still allocates2 frames, and a later SYSTEM with frames omitted allocates8 rather than inheriting2.
