## Evidence and language semantics

Events are expanded and processed sequentially. Validation/finished checks precede acceptance of each event; an error exits the current iteration/command without removing the already accepted prefix. UNDO removes one successful event, even when it was in a multi-event command and even when it ended the match. Empty history is rejected. POINT stores its old score/server/run/completed-list values plus flags describing statistics increments. Undo decrements those exact statistics, restores score/run values, truncates completed units and clears the winner. ROLL/THROW instead retain the old state and restore that entire state. The history therefore records one event, not one input command. The custom recursive clone is included because Lua tables otherwise alias. pack/unpack preserves the integer delta record, and table.remove without an index pops the last history entry. Source bytes and each selected original line were verified against the current develop checkout before inheritance; the excerpt was then independently reviewed. Additional selected error helpers establish actual nonlocal failure; selected scalar/array/frame declarations establish restoration semantics where needed.
