C: For the single accepted block in the shared scenario, defaults are copied into a per-graph settings value, later valid OPTION records replace only that copy, and comments/empty input lines are skipped. A node must be declared before accepting an edge; self-loops and duplicate directed edges are discarded and counted. Nodes are normalized by increasing numeric ID while accepted edge order is retained. Cycle removal computes a node sequence; each original edge keeps its original endpoints and obtains forward DAG upper/lower endpoints by the sequence rank. With reduction off, every accepted edge remains drawn. LONGEST assigns each node one more than its maximum successor height, or0 at a sink; promotion off bypasses the height mutation. Heights are inverted/renumbered into top-down layers. Every long DAG edge gains one dummy in each intermediate layer, and consecutive chain vertices produce gap segments and upper/lower adjacency. DFS in node-number order follows the constructed lower adjacency and appends each vertex once, establishing the actual initial layer orders. The seeded MINSTD state is initialized once per graph and carried across runs; restarts2 means runs0,1,2, each beginning from a separate copy of the same initial order, with Fisher-Yates shuffling in later runs. Nine is an upper bound on sweeps, with earlier zero-crossing or equal-order two-step recurrence termination. Alternating down/up sweeps use reference positions from the current adjacent layer, leave vertices with no references fixed, stably order the others by twice their median, then apply strict-improvement adjacent swaps. The moved count is captured before those swaps; crossing records describe the post-swap order. Each run saves its initial snapshot/count at sweep0 and replaces its best only on a strict smaller count, retaining the earliest best sweep on ties. Global strict improvement likewise retains the earliest best run; the run’s saved best snapshot is adopted, not its last working order or the last CSV record. A later sweep or restart can finish worse without replacing that saved result. Sifting starts from the adopted order: remove each vertex, try every insertion, preserve the original position if tied for minimum, otherwise choose the first minimum; repeat through a zero-move round. The saved swept count/run/sweep fields remain unchanged. Final total/brute crossing counts and per-edge crossing counts are independently evaluated on the sifted order. Sifting can strictly lower the final count relative to the saved sweep count; retaining the original position on equal cost prevents tie-only moves. Coordinates receive that same adopted/sifted order and dummy adjacency. Routing and canvas construction use the resulting x positions and chain segments; original edge endpoints still label the result. Reversed edges reverse the reported chain and route and place a backward arrow at the DAG upper endpoint, restoring original direction; in TB these are ^ for reversed and v for unreversed. layout.txt records sweep/best/sift history plus final layer/vertex/edge geometry, crossings.csv serializes attempted sweep counts, stats.txt places saved swept/run/sweep beside separately recomputed final/brute and geometry summaries, and drawings.txt serializes the final canvas. No PATH is supplied, so path search and highlighting bodies are excluded. Numeric coordinate/track placement, SCC analysis and alternative layering/promotion/reduction implementations are unnecessary for this adoption trace. Orders contains arrays of IntList structs with owned data pointers. A struct assignment alone would alias those row buffers, so orders_copy calls int_copy for every layer; int_copy allocates new storage and memcpy copies integer elements. The independent initial/run_order/history copies preserve earlier orders while active sweeps mutate theirs. When a run wins, adopted=run_order transfers those row pointers and resets run_order to an empty aggregate before freeing the remainder. Sifting’s shallow trial copies are safe because only one candidate row is replaced and positions/crossing functions read the other rows. allocate uses calloc, which supplies the false/zero/null initial state for blocks, transitive flags, layout counters and canvas cells. Saved Sweep/Sift records are value structs, so appending a record cannot change prior values. Recount occurs at the end of reduce_crossings before the coordinate and geometry calls; coordinate output mutates vertex x, while the order used by the recount is the adopted layout->orders. The route is physically reversed before drawing chooses its final endpoint and the direction/reversed arrow table. Pixel box/arrow/line precedence then supplies the serialized drawing.
