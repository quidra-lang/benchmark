## Evidence and source semantics

`graph_io.DEFAULTS`, `read_defaults`, `Graph.__init__`, `Graph.accept` and `read_graphs` bind params.txt → a per-GRAPH `defaults.copy()` → OPTION assignments → accepted integer-ID NODE/EDGE records. Settings contain only immutable strings/integers, so the shallow dictionary copy isolates these values. Edge sets reject duplicates, self-loops are counted separately, and `GraphLayout.__init__` sorts numeric node IDs before converting original endpoints into dense indices. The Graph, Edge, GraphLayout and Canvas class headers retain the identity of the selected methods; the main imports retain their actual module bindings.

`prepare_dag` computes acyclic order and changes only `upper/lower` and `reversed`; `source/target` retain original identity. Its complete reduce guard and the unconditional `self.drawn` assignment show that reduce=off retains every normalized edge. Longest layering retains the method guard/else, recurrence and returned heights; promotion's guard and the return delimit the omitted inactive body. Layer renumbering, dummy insertion, segment adjacency and DFS initial order all remain. A cycle can therefore reverse a working edge; an edge spanning more than one layer gets one dummy per intermediate layer and adjacent-layer segments.

`order_snapshot` constructs a tuple of fresh tuples, whose integer elements are immutable. `copy_order` constructs fresh layer lists. `starting_order` copies the same initial order for each run; run>0 shuffles only within layers using the continuing seeded generator. With restarts=2, `range(restarts+1)` permits runs 0, 1 and 2. `perform_sweep` alternates down/up, median sorting is stable on equal keys, and adjacent swaps require a strict crossing improvement. `run_sweeps` records the initial and every attempted sweep before saving independent snapshots. `count < best_count` preserves the first best sweep; the global strict comparison preserves the earlier run on ties. Its adopted `self.orders = copy_order(best_order)` uses the saved snapshot, even if the last active order/count is worse. The zero-count, nine-sweep and independent history[-1]/history[-3] guards may stop a run early.

Sifting runs only after all run adoptions. It retains the original position when tied at the minimum, otherwise the first minimum, and mutates `self.orders` while leaving `best_crossings/best_run/best_sweep` intact. `finish_crossing_counts` recomputes gap, final, brute and per-edge crossings from that order. The crossing implementations retain both the batched segment count and independent inversion test needed to explain those counts. Thus saved swept best, last attempted sweep and post-sifting final counts are separate values; crossings.csv contains recorded attempts rather than a synthetic final row.

`process` passes `self.orders` and dummy adjacency into `coordinates.assign`; its actual `namedtuple` Result declaration binds x/left/right/aligned/block/width/conflict fields, and the return plus `self.x = self.coordinates.x` bind geometry to that result. The assign wrapper remains; its numerical mark_conflicts/alignment/compact helper internals are outside the coordinate-free answer requirement. Geometry builds tracks/bands and canvas extents from those coordinates; drawing consumes the same chain segments. `draw_lines_and_arrows` places a reversed edge's backward arrow at its upper endpoint. `build_routes` reverses its route and `edge_line` reverses its displayed chain, while `edge_name` and edge output use original source/target IDs. No PATH is present: `find_path` returns immediately, `self.path` remains None, the selected box loop receives an empty on_path set, and unrelated highlighting is omitted.

`layout_lines` retains its sweep-record loop header, best/sift records, adopted layer/vertex order, edge paths and coordinate summaries through `return lines`. `statistics_lines` retains initialization, adopted-layer maxima, saved swept versus final/brute fields, canvas crossing-cell query and its end/return; unrelated original-component/span/route-summary fields are omitted. `csv_lines` consumes the entire sweep_records list, and `drawing_lines` serializes the final canvas. The accepted-graph main branch binds one processed layout to all four accumulators; the actual output loop and separate drawings writer bind them to layout.txt, stats.txt, crossings.csv and drawings.txt. The entry-point guard calls main. Aggregates across other graphs and rejection details are outside this one-valid-graph scenario.
