## Answer and source evidence

shifts starts at 0 for the current insertion. In the while block an existing entry is copied from j to j+1 and shifts increments once for that rightward move; j then moves left. After the loop, assigning the extracted value into j+1 has no shifts increment. Thus at i=1 the one moved existing value counts once and reinsertion does not count.
