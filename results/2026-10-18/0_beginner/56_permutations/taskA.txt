Write a program that enumerates all 24 permutations obtained by rearranging the 4 characters of the string ABCD, using recursive backtracking. Starting from the first position, choose one not-yet-used character at a time, trying them in the order A, B, C, D, and place it; when all 4 characters have been placed, print that permutation, then go back to the previous position and try the next character. Enumerating in this order lists the permutations in lexicographic order. Do not use built-in language features or library facilities that generate permutations (for example Python's itertools.permutations, C++'s std::next_permutation or J's A.).

Output format:
Print one line per permutation, in the order of enumeration, in the format "k: PERM". k is a sequence number starting at 1 (a decimal integer without extra leading zeros), and PERM is the 4 characters of the permutation (ASCII uppercase letters). All other parts are ASCII characters exactly as written, with one ASCII space after ":". Print only these 24 lines, with no trailing whitespace at the end of any line, and end every line with a newline. The example output below is for the string XYZ.

Example output (the numbers are illustrative and differ from the actual answer):
1: XYZ
2: XZY
3: YXZ
4: YZX
5: ZXY
6: ZYX
