Sort the integer array (8 elements) whose values are 27, 64, 13, 88, 41, 5, 72, 36, in that order, into increasing order with bubble sort. Positions in the array are numbered 0 to 7, with the first element at position 0. Perform at most 7 passes, in order from pass 1; in pass p, for j = 0, 1, ..., 7-p in this order, compare the value at position j with the value at position j+1, and swap the two values if the value at position j is larger (do not swap when they are equal). If a pass performs no swap at all, that pass is the last one and the sort ends. If swaps keep occurring, the sort ends after pass 7.

Output format:
After each pass, output one line: the ASCII "pass p:" (p is the pass number, pass 1 being 1), followed by the 8 values of the array at the end of that pass, from position 0 in order. If the sort ends because no swap occurred, also output the line for that last pass. After all passes, output as the last line the ASCII "swaps:" and one ASCII space, followed by the total number of swaps over all passes. Put exactly one ASCII space between "pass" and p, after ":", and between adjacent values. Write every number as a decimal integer without extra leading zeros. Output only these lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for sorting a different array, 38, 15, 62, 9, 47, 23, 71, 54.

Example output (the numbers are illustrative and differ from the actual answer):
pass 1: 15 38 9 47 23 62 54 71
pass 2: 15 9 38 23 47 54 62 71
pass 3: 9 15 23 38 47 54 62 71
pass 4: 9 15 23 38 47 54 62 71
swaps: 10
