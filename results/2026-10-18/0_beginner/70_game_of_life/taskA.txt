On a board of 8 rows by 8 columns, run Conway's Game of Life up to generation 4. The initial state of the board (generation 0) is given by the following 8 lines of strings. Each line represents one row of the board (from top to bottom), and each character represents one cell (from left to right); "#" is a live cell and "." is a dead cell.
.#......
..#.....
###.....
........
........
........
.....###
........
The neighbors of a cell are the 8 cells above, below, left, right and diagonal to it. Any neighbor that lies outside the board is always treated as dead. The board of the next generation is determined for all cells simultaneously, based only on the board of the current generation. A dead cell becomes a live cell if it has exactly 3 live neighbors; otherwise it stays dead. A live cell stays alive if it has 2 or 3 live neighbors; otherwise it becomes a dead cell.

Output format:
For each generation, in order from generation 0 to generation 4, first print the line "generation g" (g is the generation number), followed by 8 lines showing the board of that generation in the same representation as the initial state. As the last line, print the number N of live cells in generation 4 in the form "alive: N" (46 lines in total). Put exactly one ASCII space between "generation" and g, and after ":"; write everything else in ASCII lowercase exactly as shown. Write every number as a decimal integer with no extra leading zeros. Do not put blank lines between generations. Print only these lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for a different initial state computed only up to generation 1, and its last line is the number of live cells in generation 1 (the actual output goes up to generation 4).

.##.....

....#...
