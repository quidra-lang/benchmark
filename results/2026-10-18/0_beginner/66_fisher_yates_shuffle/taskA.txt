Shuffle a deck of 52 playing cards using the Fisher-Yates method.
A card is written as 2 characters: one character for the rank followed by one character for the suit. The ranks are A, 2, 3, 4, 5, 6, 7, 8, 9, T, J, Q, K (T stands for 10), and the suits are S, H, D, C (for example, the ace of spades is AS and the 10 of diamonds is TD).
Before shuffling, the deck is arranged with the suits in the order S, H, D, C, and within each suit the ranks in the order A, 2, ..., 9, T, J, Q, K. Numbering the positions in the deck from 0 to 51, the cards from position 0 onward are AS, 2S, ..., KS, AH, ..., KH, AD, ..., KD, AC, ..., KC.
For random numbers, use the linear congruential generator called MINSTD, given by the following formula.
x <- (48271 * x) mod 2147483647
The initial value (seed) of x is 2026. Each time a random number is taken, first update x with the formula above, and use the updated x as that random number. Therefore the first random number is 48271 * 2026 mod 2147483647. Note that the intermediate product 48271 * x can be as large as about 1.04*10^14, which does not fit in a 32-bit integer.
The shuffle is performed, for i = 51, 50, ..., 1 in this order, by taking one random number x, computing j = x mod (i + 1), and swapping the card at position i with the card at position j (when i = j, nothing changes).

Output format:
Print the shuffled deck from position 0 onward, split into 4 lines of 13 cards each, 4 lines in total. Line 1 holds the cards at positions 0-12, line 2 positions 13-25, line 3 positions 26-38, and line 4 positions 39-51. On each line, write the cards in the 2-character notation above, separated by one space each. Do not put trailing whitespace at the end of any line, and end every line, including the last one, with a newline.
