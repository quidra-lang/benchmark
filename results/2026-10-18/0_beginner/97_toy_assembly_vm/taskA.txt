Write a program that runs the following program of 17 instructions (each line is a string representing one instruction) on a simple virtual machine.
SET A 1
SET B 1
SET D 8
MUL A B
PRINT A
ADD B 1
SUB D 1
JNZ D -4
SET A 1071
SET B 462
SET C A
MOD C B
SET A B
SET B C
JNZ B -4
PRINT A
HALT
The virtual machine has 4 registers A, B, C, D, each holding one integer, all initially 0. The instructions are numbered 0, 1, 2, ... from the top, and the program counter pc (the number of the next instruction to execute) is initially 0. Each instruction is interpreted by splitting it at ASCII spaces, and the first part is the instruction name. Below, r is a register name, x is a register name or an integer literal >= 0 (a register name denotes the value of that register, and an integer literal denotes that number), and off is an integer literal (with a leading "-" when negative).
SET r x: assign the value of x to r.
ADD r x: add the value of x to r.
SUB r x: subtract the value of x from r.
MUL r x: multiply r by the value of x.
MOD r x: assign to r the remainder of dividing r by the value of x.
JNZ x off: if the value of x is not 0, add off to pc; if it is 0, add 1 to pc.
PRINT x: output the value of x.
HALT: end execution.
Every instruction other than JNZ adds 1 to pc each time it is executed. Execution ends when HALT is executed or when pc goes outside the range of instruction numbers.
This program uses a loop with a counter to output the factorial of n for n = 1, 2, ..., 8 in order, and then uses a loop of the Euclidean algorithm with remainders to find and output the greatest common divisor of 1071 and 462. Do not compute the factorials or the greatest common divisor directly; interpret and execute the instruction strings one by one. During execution, every register value is >= 0 and less than 2 to the 31st power, and MOD never divides by 0.

Output format:
Each time PRINT is executed, output its value on one line.
After execution ends, output as the last line, in the format "executed: N", the total number N of instructions executed (including the HALT executed last). Put exactly one ASCII space after ":".
Write every number as a decimal integer without a sign or extra leading zeros. Output only the lines from PRINT and the last line; no line has trailing spaces, and every line ends with a newline. The example output below is for a different program.

Example output (the numbers are illustrative and differ from the actual answer):
3
10
36
executed: 25
