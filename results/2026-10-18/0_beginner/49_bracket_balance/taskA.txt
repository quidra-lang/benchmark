Write a program that, for the following 7 strings containing the brackets ( ) [ ] { } together with letters, digits, spaces, operators and so on (each line is one string, with no leading or trailing spaces), checks in this order whether the brackets match, using a stack.
(a + b) * [c - d]
{x = [1, 2, (3 + 4)]}
f(a[i] + g(b)}
(1 + 2)) * 3
if (a < b) { c = d[0]; }
((a + b] * c
[{(x * y) - z}
Scan the string one character at a time from the beginning, and push each opening bracket ( [ { onto the stack. When a closing bracket ) ] } appears, if the stack is empty or the opening bracket on top of the stack is not of the matching kind (( with ), [ with ], { with }), take the position of that closing bracket as the error position and stop checking that string. If it is of the matching kind, pop the top opening bracket from the stack. Ignore all characters other than brackets.
If the scan reaches the end without an error and opening brackets remain on the stack, the error position is the length of the string (its number of characters). If none remain, the brackets match.
Positions are counted with the first character as 0, and spaces count as one character each.

Output format:
Print one line per string, in the given order.
If the brackets match, use the format "S -> balanced"; on an error, use the format "S -> error at index i".
S is the string written exactly as given, and i is a decimal integer giving the error position. Put exactly one space before and after "->" and after each of "error", "at" and "index".
Print only these 7 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
[x + (y * 2)] -> balanced
a + b) -> error at index 5
{(c - d) -> error at index 8
