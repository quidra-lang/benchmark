Write a program that, for the following 6 digit strings representing membership numbers (each line is one membership number), determines in this order whether each is a valid number using the Luhn algorithm.
688126340316
0128469655154
92181914514156
177332430060552
7982377590420309
9884593615513906
Membership numbers have 12 to 16 digits; treat each as a string, exactly as the given sequence of digits, including any leading 0 (converting to an integer would lose leading zeros and, depending on the number of digits, might not represent the value exactly).
The check works as follows. Counting digits from the right with the rightmost digit as the 1st, double each digit in an even position (2nd, 4th, ...), and if the doubled result is greater than 9, subtract 9 from it. Digits in odd positions keep their value. If the sum of all digit values obtained this way is divisible by 10, the number is valid; otherwise it is invalid.
For each invalid number, find the digit d (exactly one of 0-9 qualifies) such that replacing only the rightmost digit (the check digit) with d makes the number valid.

Output format:
Print one line per membership number, in the given order.
For a valid number use the format "N: valid", and for an invalid number use the format "N: invalid (expected check digit d)".
N is the membership number written exactly as given (including any leading 0), and d is the single digit found. Put exactly one space after ":", after "invalid", and after each of "expected", "check" and "digit", and write the parentheses as ASCII characters.
Print only these 6 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
123456789015: valid
5012345678903: invalid (expected check digit 8)
