Write a program that draws a diamond shape of size n = 5 using the ASCII asterisk "*" and spaces. The shape consists of 2n-1 = 9 lines. First, for i = 1, 2, ..., n in this order, output a line made of n-i spaces followed by 2i-1 "*" characters; after that, for i = n-1, n-2, ..., 1 in this order, output the lines made by the same rule.

Output format:
Each line consists only of n-i leading spaces followed by 2i-1 "*" characters, with no whitespace after the "*" characters. Output only these 9 lines, and end every line with a newline. The example output below is for the case n = 3.

Example output (the numbers are illustrative and differ from the actual answer):
  *
 ***
*****
 ***
  *
