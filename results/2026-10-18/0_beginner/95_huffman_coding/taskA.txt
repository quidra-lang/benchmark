Write a program that encodes the following string with a Huffman code. The string consists of 37 characters, lowercase English letters and ASCII spaces, and each gap between words is exactly one ASCII space (there is no space at the beginning or end).
she sells sea shells by the sea shore
First, count the number of occurrences of each symbol (lowercase English letter or ASCII space) appearing in the string, and for each symbol create one tree whose only leaf is that symbol. The weight of a tree is the sum of the occurrence counts of the symbols it contains.
Next, repeat the following operation until only one tree remains. Take out the highest-priority tree among all trees, then take out another highest-priority tree among the remaining trees, create a new tree with the first one as the left child and the second one as the right child, and add it to the remaining trees. Tree priority: the tree with the smaller weight comes first; when weights are equal, compare the smallest ASCII code among the symbols contained in each tree, and the tree with the smaller such code comes first (the code of the ASCII space is smaller than the code of any lowercase English letter).
Trace the finished tree from the root to the leaf of each symbol, writing 0 each time you move to a left child and 1 each time you move to a right child; the resulting sequence is the code of that symbol.

Output format:
For each symbol appearing in the string, in increasing order of ASCII code, output one line in the format "'c' freq=F code=BITS". c is the symbol itself (for the ASCII space, write one ASCII space between the quotes, as in "' '"), F is the number of occurrences, and BITS is the sequence of 0s and 1s that is the code. The quotes are ASCII single quotes (').
Next, output in the format "encoded bits: N" the number of bits N needed to represent the whole string with this code (the sum, over all symbols, of the occurrence count times the code length).
Finally, output in the format "fixed 8-bit: M" the number of bits M when every character is represented with 8 bits per character (number of characters * 8).
Put exactly one ASCII space after "'c'", after F, and after each of "encoded", "bits:", "fixed", "8-bit:", and put no space before or after "=". Write numbers as decimal integers without a sign or extra leading zeros.
Output only the per-symbol lines and the last 2 lines; no line has trailing spaces, and every line ends with a newline. The example output below is for a different string, "go go gophers".
