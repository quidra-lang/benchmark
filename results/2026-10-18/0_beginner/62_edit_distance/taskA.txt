For each of the following 5 pairs of English words (all in lowercase ASCII letters), compute the edit distance (Levenshtein distance) for transforming word a of the pair into word b. Each pair is listed in the order "word a, word b".
Pair 1: kitten, sitting
Pair 2: flaw, lawn
Pair 3: listen, silent
Pair 4: intention, execution
Pair 5: algorithm, altruistic
The edit distance is the minimum number of operations needed to transform word a into word b, where each of the 3 kinds of operations, inserting one character, deleting one character, and replacing one character with a different character, costs 1. Compute it by dynamic programming that records, in a table (a two-dimensional array), the minimum number of operations to transform the first i characters of word a into the first j characters of word b, for every i and j.

Output format:
Print 5 lines in total, one line per pair, in the order of the pairs above. Each line consists of, in this order: word a, one space, "->", one space, word b, ":", one space, and the edit distance. Write the edit distance as a decimal integer. Do not put trailing whitespace at the end of any line, and end every line, including the last one, with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
book -> back: 2
orange -> range: 1
coffee -> toffee: 1
