Sort an integer array (10 elements, all values distinct) whose values are 47, 12, 85, 33, 6, 71, 29, 58, 90 and 14 into ascending order with a top-down merge sort, and at the same time count the number of inversions. Array positions are numbered 0 to 9, with the first element at position 0. The procedure for sorting the range from position l to position r (both ends inclusive) is as follows. If l = r, do nothing. If l < r, let m be the quotient of (l + r) divided by 2 (fractional part truncated); first sort the left range (position l to position m) with the same procedure, then sort the right range (position m+1 to position r) with the same procedure, and then merge the two ranges into one and write it back to positions l to r. In the merge, repeatedly compare the first remaining values of the left side and the right side and take out the smaller one, placing the values in the order they were taken out. When one side becomes empty, append the rest of the other side in its existing order. When taking out a value from the right side, if values still remain on the left side, add the number of those remaining values to the inversion count. The inversion count starts at 0, and this procedure is performed once on the whole array (position 0 to position 9).

Output format:
Print one line per merge, in the order the merges are performed. Each line is "merge [l..r]:" followed by the values at positions l to r, in order, at the moment that merge has finished. l and r are the positions of the two ends of the merged range, and ".." is two ASCII periods. After all merges, print a line with "sorted:" followed by the 10 values of the sorted array in order from position 0, and then the line "inversions: K" (K is the inversion count), in this order (11 lines in total). Put exactly one ASCII space between "merge" and "[", after each ":", and between values, and put no whitespace anywhere else. Write every number as a decimal integer with no extra leading zeros. Print only these 11 lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for sorting a different array 8, 3, 5, 1, 9 (5 elements).

Example output (the numbers are illustrative and differ from the actual answer):
merge [0..1]: 3 8
merge [0..2]: 3 5 8
merge [3..4]: 1 9
merge [0..4]: 1 3 5 8 9
sorted: 1 3 5 8 9
inversions: 5
