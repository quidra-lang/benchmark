Find 6 words in the following board of uppercase English letters with 10 rows and 10 columns. The rows of the board are row 0 to row 9 from top to bottom, and in each row's string the leftmost character is column 0 and the rightmost character is column 9.
Row 0: MMONKENBIR
Row 1: PMTIGERJPL
Row 2: TGREJEDUZI
Row 3: SPYUTEJDEC
Row 4: WKAPSIDLBN
Row 5: KUVNGSBPRO
Row 6: RIBSDACBAM
Row 7: YWVAUAPKAH
Row 8: KYCGTHHESR
Row 9: OCCALAOKKR
The words to find are the 6 words TIGER, ZEBRA, MONKEY, PANDA, KOALA and RABBIT.
A word "is found from the cell at row r, column c in direction d" when the characters of the consecutive cells reached by moving one cell at a time in direction d, starting from the cell at row r, column c, match all characters of the word in order from its first character to its last character, without leaving the board. There are the following 8 directions; row numbers increase downward.
E: right (the column number increases by 1)
SE: down-right (both the row number and the column number increase by 1)
S: down (the row number increases by 1)
SW: down-left (the row number increases by 1 and the column number decreases by 1)
W: left (the column number decreases by 1)
NW: up-left (both the row number and the column number decrease by 1)
N: up (the row number decreases by 1)
NE: up-right (the row number decreases by 1 and the column number increases by 1)
For each word, examine the starting cells in the order row 0 column 0, row 0 column 1, ..., row 0 column 9, row 1 column 0, ..., row 9 column 9 (row-major order), and at each starting cell examine the directions in the order E, SE, S, SW, W, NW, N, NE; report the starting cell and direction found first. If the word is not found from any starting cell in any direction, report that it was not found.

Output format:
Print 6 lines in total, one line per word, in the order of the words to find above.
The line for a word that was found consists of, in this order: the word, ":", one space, "(", the row number of the starting cell, ",", one space, the column number of the starting cell, ")", one space, and the direction abbreviation (one of E, SE, S, SW, W, NW, N, NE).
The line for a word that was not found consists of, in this order: the word, ":", one space, and "not found" (with one space between not and found).
Write row and column numbers as 0-based decimal integers. Do not put trailing whitespace at the end of any line, and end every line, including the last one, with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
LION: (4, 0) E
BEAR: not found
WOLF: (7, 3) N
