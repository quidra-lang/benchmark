Sort the integer array (8 elements) whose values are 52, 17, 38, 9, 61, 38, 24, 45, in that order, into increasing order with a stable insertion sort. Positions in the array are numbered 0 to 7, with the first element at position 0. For i = 1, 2, ..., 7 in this order, take out the value v at position i; among the values in the sorted part at positions 0 to i-1, shift every value strictly greater than v (values equal to v are not included) one position to the right, keeping their order, and put v into the vacated position.

Output format:
For i = 1 through i = 7 in order, output one line each (7 lines in total): the ASCII "i=I shifts=K:", followed by the 8 values of the array at the end of that step, from position 0 in order. I is the value of i, and K is the number of values shifted right in that step. Finally, as line 8, output the ASCII "total shifts:" and one ASCII space, followed by the total number of values shifted over the 7 steps. Put exactly one ASCII space after I, between "total" and "shifts", after ":", and between adjacent values, and put no spaces before or after "=". Write every number as a decimal integer without extra leading zeros. Output only these 8 lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for sorting a different array, 31, 8, 45, 19, 8, 62, 27, 50.
