Write a program that solves the following sudoku puzzle by backtracking (depth-first search using recursion). The puzzle is given as the 9x9 board, one row per line from the top row down, with each row written as a string of the digits of its 9 cells from left to right; 0 represents an empty cell. This puzzle has exactly one solution.
800025000
070080005
260400070
000001900
010000040
600200000
900010000
700000004
020000036
Fill the empty cells so that each row, each column, and each of the 9 blocks obtained by dividing the board into 3x3 sections contains each of the digits 1 to 9 exactly once.
Search as follows. Among the empty cells, choose the one that appears first when scanning the rows from the top down and each row from left to right, and try the digits 1, 2, ..., 9 in this order in that cell. To try a digit d, check whether d already appears in the same row, the same column, or the same block as that cell; only if it appears in none of them, write d into the cell and continue the same search for the next empty cell. If the search gets stuck further on, return the cell to empty and try the next digit. If no progress is possible after trying all 9 digits, go back to the cell where a digit was written just before. The solution is considered found at the moment no empty cells remain, and the search ends there.

Output format:
First, output the solved board in 9 lines from the top row down. Each line contains the 9 digits of that row from left to right, separated by exactly one ASCII space.
Then, as the last line, output the total number N of times a digit was written into a cell during the search, in the format "placements: N". N includes writes that were later returned to empty, and does not include the digits given in the puzzle from the start. Put exactly one ASCII space after ":", and write N as a decimal integer without a sign or extra leading zeros.
Output only these 10 lines; no line has trailing spaces, and every line ends with a newline.
