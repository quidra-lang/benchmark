Write a program that uses a priority queue to process the following 16 operations (each line is a string representing one operation) in order from top to bottom.
add email 3
add backup 5
add deploy 1
run
add report 3
add test 2
add lint 3
run
run
add cleanup 5
add review 2
run
add build 1
add docs 4
run
run
Each operation is interpreted by splitting it at ASCII spaces. "add NAME PRIORITY" adds a task named NAME with priority PRIORITY (a positive integer) to the queue. All task names are distinct words of lowercase English letters. "run" removes from the queue the one task with the smallest priority value and executes it. Among tasks with equal priority values, the task that was added earlier is removed first. In this data, the queue is never empty when a run is performed.
You may implement a binary heap yourself or use the priority queue in your language's standard library, but the order for equal priority values must always follow the rule above.

Output format:
Each time a run is processed, output the removed task on one line in the format "run: NAME (priority p)". NAME is the task name and p is its priority.
After all operations have been processed, output as the last line, in the format "remaining: NAME1 NAME2 ...", the names of the tasks remaining in the queue, listed in the order in which they would be removed if run were repeated afterwards.
Put exactly one ASCII space after ":", after NAME, after "priority", and between consecutive remaining task names, and put no space after "(" or before ")". Write numbers as decimal integers without a sign or extra leading zeros.
Output only these 7 lines (6 lines from run and 1 remaining line); no line has trailing spaces, and every line ends with a newline. The example output below is for a different sequence of operations with 3 runs.

Example output (the numbers are illustrative and differ from the actual answer):
run: sync (priority 1)
run: mail (priority 2)
run: index (priority 2)
remaining: print scan
