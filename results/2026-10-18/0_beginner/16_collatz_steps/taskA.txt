For the 5 positive integers with starting values 1, 6, 27, 97 and 871, write a program that computes the number of steps of the Collatz operation and the maximum value reached along the way. The Collatz operation replaces n with n/2 if n is even, and with 3n+1 if n is odd; it is repeated until n becomes 1. The step count K is the number of operations performed until 1 is reached (0 if the starting value is 1), and the maximum M is the largest of the values that appear along the way, including the starting value itself.

Output format:
For each starting value, in the given order, output one line in the form "n: steps=K max=M". n is the starting value, K is the step count and M is the maximum, all written as decimal integers with no extra leading zeros. All other parts are the ASCII characters exactly as written; put a single space after ":" and a single space before "max", and put no whitespace before or after "=". Output only these 5 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
3: steps=7 max=16
7: steps=16 max=52
