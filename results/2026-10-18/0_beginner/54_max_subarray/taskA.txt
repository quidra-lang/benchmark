Write a program that, for each of the following 3 integer arrays, finds the contiguous subarray (a contiguous range of the array containing at least one element) with the largest sum, using Kadane's algorithm.
Array 1: the array with the values 3, -5, 8, -2, 6, -9, 4, 1, -7, 5, -3, 2 (12 elements)
Array 2: the array with the values -4, 7, -1, 3, -8, 10, -2, 5, -6, -2, 9, -12, 4, -1 (14 elements)
Array 3: the array with the values -6, -3, 5, -1, -4, 3, -9, 2, 3, -1, 4, -5, 1, 6, -2 (15 elements)
Kadane's algorithm scans the array exactly once from the beginning. At each position, it updates the maximum sum of a contiguous subarray ending at that position as the larger of the maximum at the previous position plus the current element, and the current element alone (starting over), and keeps a record of the largest sum seen so far and its range. Every array contains at least one positive element, and the contiguous subarray with the largest sum is unique.

Output format:
Print one line per array, in the given order, in the format "max sum S at [i, j]". S is the largest sum, and i and j are the positions of the first and last elements of that contiguous subarray (numbered with the first element as 0; the i-th and j-th elements are included in the range); all are decimal integers without extra leading zeros. All other parts are ASCII characters exactly as written, with one ASCII space between "max", "sum", S, "at" and "[" and after ",", and no whitespace after "[" or before "]". Print only these 3 lines, with no trailing whitespace at the end of any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
max sum 9 at [3, 6]
max sum 21 at [0, 11]
