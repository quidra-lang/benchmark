Starting from an edit buffer (a string) that is initially empty, execute the following 14 commands in order from top to bottom. Each line is one command.
undo
type hello world
delete 5
type there
undo
undo
redo
type friend
redo
delete 20
undo
redo
redo
type see you
The meaning of each command is as follows.
"type TEXT" appends TEXT to the end of the buffer. TEXT is the entire remainder of the command after "type " (type followed by one ASCII space); it consists only of lowercase English letters and ASCII spaces, and it does not begin or end with a space.
"delete N" deletes N characters (N is a positive integer) from the end of the buffer. If the buffer has fewer than N characters, it deletes all characters.
"undo" undoes the most recently executed type or delete that has not yet been undone, restoring the buffer to its contents just before that command was executed.
"redo" redoes the most recently undone command among the commands that can be redone, restoring the buffer to its contents just after that command was executed. A command undone by undo becomes redoable, and a command redone by redo becomes undoable by undo again.
Executing type or delete makes every command that is redoable at that moment no longer redoable.
An undo when there is no command that can be undone, and a redo when there is no command that can be redone, do nothing and leave the buffer unchanged.

Output format:
Print one line per command, in the order executed (14 lines in total). Each line consists of the command string written as is, one ASCII space, "=>", one ASCII space, followed by the contents of the buffer after executing that command, enclosed in ASCII double quotes ("). If the buffer is empty, write "" (two double quotes). Inside the double quotes, write the buffer contents as is, and do not omit anything even if the buffer ends with a space. However, the line for an undo when there is no command that can be undone is "undo => nothing to undo", and the line for a redo when there is no command that can be redone is "redo => nothing to redo" (without double quotes). Print only these 14 lines, with no trailing whitespace at the end of any line (outside the double quotes), and end every line with a newline. The example output below is for executing a different command sequence: type abc, undo, undo, redo, delete 1, redo.

Example output (the numbers are illustrative and differ from the actual answer):
type abc => "abc"
undo => ""
undo => nothing to undo
redo => "abc"
delete 1 => "ab"
redo => nothing to redo
