Solve the following two systems of linear equations in double-precision real numbers, using Gaussian elimination with partial pivoting followed by back substitution.
Each system is given as an augmented matrix. Each parenthesized tuple represents one equation a1 * x1 + a2 * x2 + ... + an * xn = b and lists the coefficients a1, a2, ..., an and the right-hand side b in this order.
System 1 (3 unknowns): (2, -1, 3, 7), (4, 1, -2, 3), (-3, 5, 1, -4)
System 2 (4 unknowns): (1, 3, -2, 4, 6), (5, -2, 1, 3, -7), (-2, 4, 6, -1, 9), (3, 1, -4, 2, 5)
Both systems have exactly one solution.
Let n be the number of unknowns and a[i][j] the entry in row i, column j of the augmented matrix (rows and columns are both counted from 1, and column n+1 is the right-hand side). Perform all computations in double-precision real numbers with the following procedure.
- Forward elimination: for k = 1, 2, ..., n in this order, do the following. Among rows k through n, take as the pivot row the row whose entry in column k has the largest absolute value (if several rows share the largest, take the topmost of them), and if it is not row k, swap it with row k. Then, for each row i = k+1, k+2, ..., n, let f = a[i][k] / a[k][k], and for j = k, k+1, ..., n+1 in this order replace a[i][j] with a[i][j] - f * a[k][j].
- Back substitution: for i = n, n-1, ..., 1 in this order, start with s = a[i][n+1], replace s with s - a[i][j] * xj for j = i+1, i+2, ..., n in this order, and finally set xi = s / a[i][i].
In this data, at every pivot selection the difference between the largest and the second largest absolute values is sufficiently large, and no solution value is 0 or close to a rounding boundary for rounding to 4 decimal places.

Output format:
For each system, in the given order, first print the line "system k:", and then one line per unknown, starting from x1, in the format "xi = V".
k is the system number (1 or 2), and i is the number of the unknown, starting from 1. V is the value of that unknown rounded half up at the 5th decimal place and written with exactly 4 digits after the decimal point, with a leading "-" for a negative number, and with a single 0 before the decimal point when the integer part is 0, as in "0.1234".
"system" and "x" are lowercase ASCII letters. Put one ASCII space between "system" and k, one ASCII space before and after "=", and no whitespace anywhere else. Print only these 1 + 3 + 1 + 4 = 9 lines, with no trailing whitespace on any line, and end every line with a newline.

system 1:
x1 = 2.5000
x2 = -0.3333
x3 = 1.1667
system 2:
x1 = 0.1250
x2 = -4.0000
x3 = 3.7143
