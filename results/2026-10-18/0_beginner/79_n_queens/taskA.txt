For each board size n = 4, 5, 6, 7, 8, use backtracking to find the number of ways to place n queens on an n x n board so that no two queens are on the same row, the same column or the same diagonal line. Rows are numbered 0 to n-1 from top to bottom, and columns are numbered 0 to n-1 from left to right. Place one queen per row, in order starting from row 0; in each row, try the columns in increasing order starting from column 0, trying only columns that are neither in the same column nor on the same diagonal line as any queen already placed. After placing a queen in a row, move on to the next row, and when queens have been placed in all n rows, count that as one solution. When a row has no more columns to try, go back to the previous row and try the next column in that row, continuing until all possibilities have been examined. Also find the first solution found when n = 8.

Output format:
Print one line for each n in order from n = 4 to n = 8, in the form "N=n: S solutions". The leading "N=" is an ASCII uppercase N and "=" written as is, n is the board size, and S is the number of solutions. Put no whitespace before or after "=", and put one ASCII space after ":" and after S. Then print the first solution found when n = 8 as 8 lines, starting from row 0. Each line represents the cells of that row, starting from column 0, with one character per cell: a cell with a queen is an ASCII uppercase "Q", and every other cell is "." (13 lines in total). Write every number as a decimal integer with no extra leading zeros. Print only these 13 lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for board sizes n = 9 and n = 10, followed by the first solution found when n = 10.
