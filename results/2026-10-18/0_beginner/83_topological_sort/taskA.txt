For each of the following two lists of course prerequisites, find an order in which the courses can be taken, using topological sorting by Kahn's algorithm.
Every course name is a single word consisting only of lowercase ASCII letters, and no two courses in the same list have the same name. "X -> Y" means that course X must be taken before course Y can be taken (X is a prerequisite of Y).
List 1: the 8 courses are physics, algebra, graphics, programming, statistics, calculus, databases, algorithms, and the 9 prerequisite pairs are calculus -> physics, algebra -> calculus, programming -> algorithms, algebra -> statistics, algorithms -> databases, statistics -> databases, calculus -> graphics, algorithms -> graphics, physics -> graphics.
List 2: the 6 courses are music, ecology, art, geology, biology, chemistry, and the 6 prerequisite pairs are music -> art, art -> ecology, biology -> chemistry, chemistry -> ecology, ecology -> geology, geology -> chemistry.
For each list, start with all courses untaken, and repeat the following operation until no such course remains: among the untaken courses whose prerequisites have all been taken (including courses with no prerequisites), choose the one that comes first in alphabetical order and take it.
Alphabetical order compares two course names character by character from the beginning, and the first pair of differing characters decides the order by their alphabetical order (in this data, no course name is a prefix of another course name).
List 2 contains a cycle of prerequisites, so some courses are never taken.

Output format:
Print the following 3 lines in this order.
Line 1 is the result for list 1: "order:" followed by the names of the taken courses in the order in which they were taken, separated by "->".
Line 2 is the result for list 2, in the same format as line 1.
Line 3 shows the courses that were never taken in list 2: "cycle:" followed by the names of those courses in alphabetical order.
Put one ASCII space after "order:" and after "cycle:". "->" is an ASCII hyphen followed by a greater-than sign, with one ASCII space before and after it. The course names on the "cycle:" line are separated by single ASCII spaces. Print only these 3 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
order: drama -> history -> art -> literature -> music
order: chess -> poetry
cycle: dance film
