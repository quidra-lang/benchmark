Evaluate the following 7 integer expressions written in Reverse Polish Notation (postfix notation), in the given order, using a stack. Each expression is a sequence of tokens separated by single ASCII spaces.
Expression 1: 3 4 + 2 *
Expression 2: -17 5 / 4 -3 * -
Expression 3: 1 2 + * 3
Expression 4: 15 7 1 1 + - / 3 * 2 1 1 + + -
Expression 5: 4 2 5 * + 1 3 2 * - 5 + /
Expression 6: 2 3 4 + 5
Expression 7: 46341 46339 * -2 /
A token is either a single character that is one of the operators "+", "-", "*" and "/", or an integer (a sequence of one or more digits, immediately preceded by "-" when the number is negative; example: -3). Therefore a token consisting of "-" alone is the subtraction operator, and a token in which "-" is immediately followed by digits is a negative integer.
Evaluation starts with an empty stack and processes the tokens one at a time from left to right. An integer is pushed onto the stack. An operator pops two values from the stack (call the value popped first b and the value popped second a) and pushes the result of the operation on a and b ("+" gives a + b, "-" gives a - b, "*" gives a * b, "/" gives a / b). "/" is integer division that discards the fractional part of the quotient, rounding toward zero (examples: 7 / 2 is 3, -7 / 2 is -3, 7 / -2 is -3).
The following cases are errors; the evaluation of that expression stops at that point (the remaining tokens are not processed).
- When an operator is about to be processed and the stack holds fewer than 2 values: stack underflow
- When "/" is processed and b is 0: division by zero
- When all tokens have been processed and the stack does not hold exactly 1 value: leftover operands
If there is no error, the single value left on the stack at the end is the result. In this data, the absolute values of all intermediate values and of the results are less than 2^31.

Output format:
For each expression, in the given order, print one line in the format "EXPR => V" if there is no error, or "EXPR => error: MESSAGE" if there is an error.
EXPR is the given expression itself (its tokens separated by single ASCII spaces). V is the result, written as a decimal integer without extra leading zeros, with a leading "-" for a negative number. MESSAGE is the English message for the error shown above (one of stack underflow, division by zero and leftover operands).
"=>" is an ASCII equals sign followed by a greater-than sign. Put one ASCII space before and after it, and one ASCII space after the ":" of "error:". Print only these 7 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
5 -2 3 * - => 11
8 2 2 - / => error: division by zero
4 + => error: stack underflow
1 2 => error: leftover operands
