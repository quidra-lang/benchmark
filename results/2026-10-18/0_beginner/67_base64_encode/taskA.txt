Encode each of the following 5 strings in Base64. The double quotes only mark the boundaries and are not part of the strings. The third string is the empty string (a string of length 0).
String 1: "Man"
String 2: "Hello, World!"
String 3: ""
String 4: "<b>bold</b>"
String 5: "a+b=c?"
All strings consist of ASCII letters, digits, symbols and spaces, and contain no double quote character ("). Treat each character as one byte whose value is its ASCII code (an integer in the range 32-126). For the encoding, use the standard alphabet "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/" defined in RFC 4648 and padding with "=". Do not use a Base64 library or any other ready-made encoding facility; compute the result with arithmetic or bitwise operations according to the following steps.
Step 1: Split the string into groups of 3 bytes from the beginning, and regard each group of 3 bytes as a 24-bit value with the first byte as the most significant.
Step 2: Divide those 24 bits into 4 groups of 6 bits from the most significant end, replace each 6-bit value v (0-63) with the v-th character of the alphabet above (the first character "A" is the 0th), and append those 4 characters in order to the end of the encoded result.
Step 3: If 1 byte remains at the end, append 2 bytes of value 0 after it to make 24 bits, append only the first 2 characters from the most significant end, and then append "==". If 2 bytes remain, append 1 byte of value 0 to make 24 bits, append only the first 3 characters from the most significant end, and then append "=". If no bytes remain, append nothing.
The result of encoding the empty string is the empty string.

Output format:
Print 5 lines in total, one line per string, in the order of the strings above. Each line consists of, in this order: a double quote ("), the original string, a double quote ("), one space, "->", one space, a double quote ("), the encoded result, and a double quote ("). When the string or the encoded result is empty, write nothing between the two double quotes ("). Do not put trailing whitespace at the end of any line, and end every line, including the last one, with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
"Cat" -> "Q2F0"
"Hello" -> "SGVsbG8="
"Base 64" -> "QmFzZSA2NA=="
