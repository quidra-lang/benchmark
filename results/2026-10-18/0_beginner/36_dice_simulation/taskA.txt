Using the random number generator MINSTD, perform 1000 trials of rolling 2 dice and examine the distribution of the sum of the rolled values. MINSTD keeps an integer x as its state and repeatedly updates it by setting the new x to the remainder of x multiplied by 48271, divided by 2147483647. The initial value (seed) of x is 12345. Each time one random number is used, update x once and use the updated x (the first value used is the seed 12345 updated once). In each trial, use one random number for the first die and then one for the second die, in that order, and the value of a die is "the remainder of x divided by 6, plus 1". For each of the 1000 trials, compute the sum of the 2 values (from 2 to 12 inclusive), and count the number of occurrences of each sum. Note that the product of 48271 and x can greatly exceed 2^31, so compute it without overflow or rounding error.

Output format:
First, for the sums S = 2, 3, ..., 12, output one line each in increasing order in the format "S: C" (11 lines). C is the number of times that sum occurred; do not omit sums that occurred 0 times. Then, on the last line, output the ASCII "most frequent:" and one ASCII space, followed by the sum with the largest number of occurrences. If several sums share the largest number of occurrences, output the smallest of them. All other parts are ASCII characters exactly as written; put exactly one ASCII space after ":" and between "most" and "frequent". Write every number as a decimal integer without extra leading zeros. Output only these 12 lines, with no trailing whitespace on any line, and end every line with a newline.

3: 52

most frequent: 6
