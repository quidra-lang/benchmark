Parse the following 4 URL query strings, in this order. Each line is one string, and each consists only of ASCII alphanumeric characters and symbols.
name=Alice+Smith&age=30&city=New%20York
q=c%2B%2B+tutorial&page=2&sort=desc&page=3
msg=50%25+off%21&debug&lang=en&ref=&lang=ja
redirect=https%3a%2f%2fexample.com%2Fhome&token=abc==&item10=pen&item2=fish%26chips
First split each string at "&" into items. Split each item at the position of the first "=" that appears in it: the part before it is the key and the part after it is the value (the value may contain further "=" characters). For an item that does not contain "=", the whole item is the key and the value is the empty string. Then decode the key and the value separately. Decoding reads the string once from beginning to end, replaces "+" with one ASCII space, replaces each "%" together with the 2 hexadecimal digits that follow it (letters may be uppercase or lowercase), 3 characters in all, with the single ASCII character whose character code is that hexadecimal number, and leaves every other character unchanged. Characters produced by decoding are not decoded again (for example, "%2B" becomes "+" and does not then become a space). Every "%" is always followed by 2 hexadecimal digits. A decoded key consists only of lowercase English letters and digits, and a decoded value consists only of printable ASCII characters (character codes 0x20 to 0x7E) other than the double quote ("). If the same key appears more than once in one string, record all values of that key in the order they appear.

Output format:
For each string, in the given order, first print the line "query k:" (k is the string number, with the first string being 1), followed by one line for each distinct key that appears in that string, in ascending order of keys. Ascending order of keys means lexicographic order comparing one character at a time by character code (smaller first); digits come before lowercase English letters, and a string comes before any longer string that begins with it. A key line consists of two ASCII spaces, the key, ":", one ASCII space, followed by the values of that key in the order they appeared, each enclosed in ASCII double quotes (") and separated by "," and one ASCII space. An empty-string value is written as "". Put one ASCII space between "query" and k. Print only these lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for parsing two different strings, q=hello+world&tag=a&tag=b%2Fc&empty=&flag and x2=%41%42&x1=1+2%3D3.

Example output (the numbers are illustrative and differ from the actual answer):
query 1:
  empty: ""
  flag: ""
  q: "hello world"
  tag: "a", "b/c"
query 2:
  x1: "1 2=3"
  x2: "AB"
