Compute the 12 rows of Pascal's triangle from row 0 through row 11. Row 0 consists of the single value 1. For n = 1, 2, ..., 11, row n consists of n+1 values, and the values at both ends are 1. Every other value, that is, the k-th value from the left (k = 1, 2, ..., n-1), counting the leftmost value as the 0th, is the sum of the (k-1)-th value and the k-th value of row n-1. Build the rows in order, each one from the previous row in this way.

Output format:
Output one line per row, from row 0 through row 11 in row-number order (12 lines in total). On each line, list the values of that row from left to right, separated by exactly one ASCII space; do not add leading spaces to shape a triangle or spaces to align digits. Write every number as a decimal integer without extra leading zeros. Output only these 12 lines, with no trailing whitespace on any line, and end every line with a newline. The example output below shows only the first 4 lines, with altered values, to illustrate the format.

Example output (the numbers are illustrative and differ from the actual answer):
2
2 2
2 4 2
2 6 6 2
