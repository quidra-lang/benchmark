Write a program that computes the matrix product C = AB of the following integer matrix A with 3 rows and 4 columns and integer matrix B with 4 rows and 2 columns. The element in row i, column j of C is the sum of the products of each element of row i of A and the corresponding element of column j of B.
Matrix A:
Row 1: 3, -2, 5, 1
Row 2: -4, 7, 0, 6
Row 3: 2, 9, -8, -3
Matrix B:
Row 1: 1, 4
Row 2: -5, 2
Row 3: 6, -1
Row 4: 0, 7

Output format:
Output the rows of C one per line from top to bottom, 3 lines in total. Each line contains the 2 elements of that row from left to right, each right-aligned in a field 5 characters wide (padded with spaces on the left), placed one after another with no separator. Negative numbers are written as decimal integers with a leading "-". Therefore each line is 10 characters long. End every line, including the last one, with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
   12   -7
    0  105
 -248   36
