For each integer n from 0 to 12, compute the factorial n! of n. 0! is 1, and for n >= 1, n! = 1 * 2 * ... * n. Every value fits in the range of a 32-bit signed integer.

Output format:
Print one line per n, for n from 0 to 12 in order, 13 lines in total.
Each line consists of, in this order: n immediately followed by "!", one ASCII space, "=", one ASCII space, the value of n!.
Write every number as a decimal integer with no extra leading zeros. Print only these 13 lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for n from 13 to 15.

Example output (the numbers are illustrative and differ from the actual answer):
13! = 6227020800
14! = 87178291200
15! = 1307674368000
