Write a program that computes the determinants of the following 3 integer square matrices by recursively applying cofactor expansion (Laplace expansion) along the first row. Each matrix is shown row by row starting from the first row, with the entries of each row listed from left to right.
Matrix 1 (3 rows, 3 columns): (2, -3, 1), (5, 4, -2), (-1, 6, 3)
Matrix 2 (4 rows, 4 columns): (3, 0, -2, 5), (1, 4, 7, -3), (-6, 2, 1, 8), (9, -5, 3, 2)
Matrix 3 (5 rows, 5 columns): (4, -1, 7, 0, -3), (2, 8, -5, 6, 1), (-9, 3, 2, -4, 5), (6, 0, -7, 3, -2), (1, -6, 4, 9, 8)
The determinant of an n-by-n matrix is its only entry when n = 1. When n is 2 or more, for j = 1, 2, ..., n, compute the j-th entry from the left in the first row multiplied by the determinant of the (n-1)-by-(n-1) matrix (minor) obtained by removing the first row and the j-th column from the original matrix, and sum these values, adding those with odd j and subtracting those with even j. Perform all computations with integers (every intermediate value and every result has an absolute value less than 2 to the power 31). Do not use built-in language features or library facilities that compute determinants (for example R's det, Julia's LinearAlgebra.det or J's -/ .*).

Output format:
Print one line per matrix, in the given order, in the format "det(NxN) = D". N is the number of rows of the matrix (equal to the number of columns) and D is the value of the determinant; both are decimal integers without extra leading zeros (when D is negative, it is preceded by an ASCII "-"). The "x" between the two Ns is an ASCII lowercase letter x. All other parts are ASCII characters exactly as written, with one ASCII space before and after "=" and no whitespace anywhere else. Print only these 3 lines, with no trailing whitespace at the end of any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
det(3x3) = -12
det(4x4) = 205
det(5x5) = 3480
