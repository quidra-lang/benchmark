Choose some of the following 7 items so that the total value is maximized while keeping the total weight at most 20 (the 0-1 knapsack problem). Each item is either chosen or not chosen, and the same item cannot be chosen two or more times. The name, weight and value of each item, in the given order, are as follows.
tent (weight 10, value 120)
stove (weight 3, value 65)
lantern (weight 2, value 45)
rope (weight 3, value 20)
camera (weight 5, value 90)
blanket (weight 5, value 85)
water (weight 6, value 100)
Find the maximum total value by building a table with dynamic programming, and reconstruct the chosen items by tracing back through that table. There is exactly one choice of items that maximizes the total value.

Output format:
Print the following 3 lines in this order.
Line 1: "max value: V" (V is the total value of the chosen items)
Line 2: "total weight: W" (W is the total weight of the chosen items)
Line 3: "items:" followed by the names of the chosen items, listed in the order of the items above
Put exactly one ASCII space between "max" and "value", between "total" and "weight", after each ":", and between item names. Write everything else in ASCII lowercase exactly as shown. Write every number as a decimal integer with no extra leading zeros. Print only these 3 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
max value: 275
total weight: 18
items: tent stove camera
