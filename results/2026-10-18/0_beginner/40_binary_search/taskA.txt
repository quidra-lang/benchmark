Write a program that, in an array of 16 elements sorted in ascending order with the values 3, 8, 11, 15, 19, 24, 27, 31, 36, 42, 47, 53, 58, 64, 70, 77, searches for the target values 42, 3, 77, 31, 50, 1 (6 values) in this order using binary search, and prints the history of the positions examined and the result.
Array indices start at 0 for the first element. For each target value, perform the binary search with the following steps.
(1) Start with lo = 0, hi = 15.
(2) While lo is less than or equal to hi, let mid be the quotient of (lo + hi) divided by 2 (fractional part truncated), and record this mid as an examined position.
(3) If the value at index mid equals the target value, the target is found and the search for that target ends. If it is smaller than the target value, set lo = mid + 1; if it is larger, set hi = mid - 1; then go back to (2).
(4) When lo becomes greater than hi, the target is not found and the search ends.
Since hi can become -1, compute lo, hi and mid as integers that can also hold negative values.

Output format:
Print one line per target value, in the order of the target values listed above.
If found, use the format "T: probes I1 I2 ... Im -> index K"; if not found, use the format "T: probes I1 I2 ... Im -> not found".
T is the target value, I1 I2 ... Im are all the recorded mid values in the order they were recorded, and K is the index of the position where it was found.
Put exactly one space after "T:", after "probes", between consecutive mid values, and before and after "->". Write every number as a decimal integer without a sign or extra leading zeros.
Print only these 6 lines, with no trailing whitespace on any line, and end every line with a newline.
The example output below is for searching a different array 2, 5, 7, 12, 18, 25, 29, 33, 40, 44, 51, 56, 62, 68, 73, 80 (16 elements) for the target values 25, 9 in this order.

Example output (the numbers are illustrative and differ from the actual answer):
25: probes 7 3 5 -> index 5
9: probes 7 3 1 2 -> not found
