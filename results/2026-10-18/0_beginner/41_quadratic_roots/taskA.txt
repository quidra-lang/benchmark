Write a program that, for the 6 sets of coefficients a, b, c given as (1, -3, -10), (-2, 5, 4), (3, 1, -2), (4, -12, 9), (1, 2, 5), (-2, 3, -4), solves the quadratic equation ax^2 + bx + c = 0 using the quadratic formula.
Let the discriminant be D = b^2 - 4ac (compute D as an integer), and distinguish the following cases. Compute the roots in double-precision floating point.
- When D > 0: compute the two real roots (-b + sqrt(D)) / (2a) and (-b - sqrt(D)) / (2a); call the larger one x1 and the smaller one x2.
- When D = 0: compute the double root X = -b / (2a).
- When D < 0: compute the two imaginary roots P + Qi and P - Qi, where P = -b / (2a) and Q = sqrt(-D) / (2|a|), so Q is positive.

Output format:
Print one line per set of coefficients, in the given order. Each line has one of the following formats.
When D > 0: "a b c: x1 = X1, x2 = X2"
When D = 0: "a b c: x = X"
When D < 0: "a b c: x = P + Qi, P - Qi"
a b c are the three coefficients in the given order, written as decimal integers separated by a single space (negative numbers are prefixed with "-"). For X1, X2, X, P and Q, write the computed value with exactly 4 digits after the decimal point (rounding half up at the fifth digit), and prefix negative numbers with "-". "i" is the ASCII letter i itself, representing the imaginary unit.
Put exactly one space after ":", before and after "=", after ",", and before and after the "+" or "-" between P and Qi of the imaginary roots (no space goes between a "-" denoting a negative number and its digits). In the given data, no printed value is 0 and no value is close to a rounding boundary.
Print only these 6 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
1 -5 6: x1 = 3.0000, x2 = 2.0000
1 -4 4: x = 2.0000
2 -2 5: x = 0.5000 + 1.5000i, 0.5000 - 1.5000i
