Define the Fibonacci sequence by F(1) = 1, F(2) = 1, and F(n) = F(n-1) + F(n-2) for n >= 3. With the number of terms set to 30, write a program that computes the 30 terms F(1) through F(30) in order, and also computes the sum of those 30 terms.

Output format:
Line 1 contains the 30 values F(1) through F(30), in this order, separated by single spaces.
Line 2 contains the text "sum:" followed by a single space and then the sum of the 30 terms.
Write every number as a decimal integer with no sign and no extra leading zeros. Output only these 2 lines, with no trailing whitespace on any line, and end every line with a newline. The example output below is for the case where the number of terms is 6.

Example output (the numbers are illustrative and differ from the actual answer):
1 1 2 3 5 8
sum: 20
