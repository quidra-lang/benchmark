Determine the outcome of each of 6 tic-tac-toe boards. Each board is given as 3 strings, from the top row down; the double quotes only mark the boundaries and are not part of the strings. The characters of each string represent the 3 cells of that row from left to right; "X" and "O" (both uppercase ASCII letters) are the marks of the respective players, and "." (an ASCII period) is an empty cell.
Board 1: "XXX", "OO.", "O.X"
Board 2: "X.O", ".X.", "O.."
Board 3: "XO.", ".OX", "XO."
Board 4: "XOX", "XOO", "OXX"
Board 5: "X.O", "XO.", "O.X"
Board 6: "XOX", "OXO", "OXX"
Among the 8 lines in total, the 3 rows, the 3 columns and the 2 diagonals, if the 3 cells on any line all have the same mark, the player with that mark wins. Every given board is a position that can occur in a real game in which the players place marks alternately with X moving first, and if there is a winner, there is only one.
If there is a winner, the result is that player's win; if there is no winner and no empty cell, the result is a draw; if there is no winner and empty cells remain, the result is in progress. Even when there is no empty cell, if there is a winner, the result is that player's win.

Output format:
Print 6 lines in total, one line per board, from board 1 onward. Each line consists of, in this order: "board", one space, the board number (a decimal integer from 1 to 6), ":", one space, and the result. The result is "X wins" if X wins, "O wins" if O wins, "draw" for a draw, and "in progress" if the game is in progress (the whitespace inside "X wins", "O wins" and "in progress" is one space). Do not put trailing whitespace at the end of any line, and end every line, including the last one, with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
board 1: draw
board 2: X wins
board 3: in progress
board 4: O wins
