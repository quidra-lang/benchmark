Write a program that encodes the following 5 strings consisting only of uppercase English letters (each line is one string), in this order, using run-length encoding, and then decodes each encoded string.
AAABBBCCCD
WWWWWWWWWWWWBWWWWWWWWWWWWBBB
ALGORITHM
MISSISSIPPI
XXXXXXXXXXYYYYYYYYYYYYYYYYYYYYYZ
The second string is 12 W's, 1 B, 12 W's and 3 B's in this order (28 characters), and the fifth string is 10 X's, 21 Y's and 1 Z in this order (32 characters).
To encode, split the string into runs of the same consecutive character (each run taken as long as possible), and replace each run, from the beginning, with "the decimal number giving the length of the run" followed by "that character". A run of length 1 is also written in full, without omitting the "1". For example, AAAB becomes 3A1B.
To decode, read the encoded string from the beginning, read each sequence of consecutive digits (it may have two or more digits) as a decimal count, and repeat the character immediately after it that many times. Decode from the encoded string, without using the original string.

Output format:
Print one line per string, in the given order, in the format "S -> E -> D".
S is the original string, E is the encoded string, and D is the decoded string. Put exactly one space before and after each "->".
Print only these 5 lines, with no trailing whitespace on any line, and end every line with a newline.

Example output (the numbers are illustrative and differ from the actual answer):
AABCCC -> 2A1B3C -> AABCCC
HELLO -> 1H1E2L1O -> HELLO
