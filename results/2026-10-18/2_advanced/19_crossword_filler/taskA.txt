[Overview]
Write a program that automatically fills crossword puzzle grids (a crossword construction tool). The program reads four files: the settings file input/params.txt, the scored word list input/words.txt, the dictionary of clues (the question text attached to each word) input/clues.txt, and the grid template file input/templates.txt. The word list and the clue dictionary are checked line by line, and from the word list the program builds indexes by word length and by each (length, position, letter) combination. The templates are checked one at a time for format, symmetry, connectivity of the white cells and so on. For each valid template, the program extracts the sequences of 3 or more consecutive white cells across or down (slots), numbers them in the standard way, and places the specified theme words. It then fills the grid with a backtracking search with forward checking that assigns words starting from the slot with the fewest candidate words. Candidates are tried in descending order of score, ties in alphabetical order, and the same word is never used twice in one grid. The number of words tried in the search (the node count) has an upper limit, and when the grid could not be filled, the search is redone with a lowered minimum score for the words used. As the result, the program writes the filled grid (the best partial solution when it could not be filled), the numbered list of clues, the search statistics, an evaluation of grid quality, and the results of checking the word list to four files in the output/ folder. All computation is done with integers; floating-point numbers are not used. Nothing is printed to standard output.

[Input files]
The input files are the four files input/params.txt, input/words.txt, input/clues.txt and input/templates.txt. Every file consists only of printable ASCII characters (including spaces) and newlines (LF), and every line (including the last line) ends with a newline. In every file, lines are numbered from the top, with the first line as line 1, counting blank lines and comment lines as well (line numbers). A blank line is a line that contains no characters at all.

* input/params.txt (settings file)
Blank lines and lines beginning with "#" (comment lines) are ignored. Every other line has the form "key value" (a key and a value separated by a single space), and each of the following 5 keys appears exactly once, in any order. The values are always correctly formatted and within the ranges stated below.
- node_budget: the default upper limit on the node count of the search. An integer from 1 to 100000 inclusive.
- min_score: the default minimum score of the words used. An integer from 1 to 100 inclusive.
- symmetry: the default symmetry required of templates. One of "rot180", "mirror" and "none".
- relax_step: the amount by which the minimum score is lowered. An integer from 0 to 100 inclusive.
- weak_score: the threshold below which a word's score makes it a weak word. An integer from 1 to 100 inclusive.
Integer values are written in decimal without extra leading zeros.

* input/words.txt (word list)
Each line is one entry. A valid entry has the form "word score", but invalid lines are also included (they are checked in step 3 of [Processing]). Each line is 1 to 40 characters long.

* input/clues.txt (clue dictionary)
Blank lines and lines beginning with "#" (comment lines) are ignored. Every other line is called a clue line. A valid clue line has the form "word|clue" (a word and a clue separated by a single "|"), and means that the clue (question text) is attached to the word. Multiple clues may be attached to one word. Invalid lines are also included (they are checked in step 4 of [Processing]). Each line is at most 100 characters long.

* input/templates.txt (template file)
A sequence of one or more template blocks. Outside the blocks there are only blank lines and lines beginning with "#" (comment lines), which are ignored. A block consists of a line "TEMPLATE s", the content lines of the block (0 or more lines), and a line "END", in this order. s is the name of the template, a string of 1 to 30 characters containing no spaces (whether it is valid as a name is checked in step 5 of [Processing]). The content lines of a block are 1 to 30 characters long and are not "END". A line inside a block is not a comment line even if it begins with "#".
Among the content lines of a block, a line that contains a space is called an option line, and a line that contains no space is called a grid line. Option lines and grid lines may appear intermixed.
- An option line is a setting that applies only to that template. Within the block, from top to bottom, the option lines alone are numbered 1, 2, 3, ... (option numbers).
- The grid lines, from top to bottom, represent line 1, line 2, ... of the grid. The j-th character of a grid line represents the j-th cell from the left in that row. "." represents a white cell with no letter, "#" a black cell, and an uppercase letter (A to Z) a white cell that contains that letter from the start.

[Processing]
* 1. Terms and common rules
- Cells: let h be the number of grid lines and w the number of characters in grid line 1 (in a valid template every grid line has w characters). Rows are counted from the top as row 1, row 2, ..., row h, and columns from the left as column 1, column 2, ..., column w; the cell in row r and column c is written cell (r,c). Whenever cells are examined or listed in order, unless stated otherwise, the order is ascending row number, and within the same row ascending column number (row-major order).
- White and black cells: a "#" cell is called a black cell, and any other cell a white cell. A white cell for which the grid line contains an uppercase letter is called a given-letter cell.
- Valid as a word: 3 to 15 characters long and consisting only of uppercase letters (A to Z).
- Valid as an integer (range a to b): consists only of one or more digits (0 to 9), its first character is not "0", and its value read as a decimal number is at least a and at most b. For example, "07", "+5" and "0" are not valid as integers in the range 1 to 100.
- Valid as a name: 1 to 20 characters long and consisting only of lowercase letters (a to z), digits (0 to 9) and "_".
- Strings are compared and sorted in lexicographic order of ASCII codes. Since words consist only of uppercase letters, this is the same as alphabetical order.
- Decimal notation: the "d-decimal notation" of a rational number x >= 0 is the decimal representation of x rounded half up to d decimal places, formed by concatenating, in this order, the integer part (in decimal without extra leading zeros; "0" if less than 1), ".", and a fractional part of exactly d digits. When x = p / q (p an integer >= 0, q an integer >= 1), let N = floor((2*p*10^d + q) / (2*q)); then the quotient of N divided by 10^d is the integer part, and the remainder is the fractional part (padded on the left with 0s to d digits) (example: the 2-decimal notation of 2/3 is "0.67", and the 1-decimal notation of 16 is "16.0"). In the inputs of this task, values exactly halfway (equally far from rounding down and rounding up) do not occur.
- The program first reads the settings, the word list and the clue dictionary in steps 2 to 4, then processes the templates one at a time in file order in steps 5 to 12, and finally computes the totals of step 13, and then writes the four output files.

* 2. Settings
Read the values of params.txt. For each template, the values of node_budget, min_score and symmetry (the template settings) are the value given by an option line of that template if there is one, and the value from params.txt otherwise. relax_step and weak_score are common to all templates and take the values from params.txt.

* 3. Reading the word list
Examine the lines of words.txt one by one starting from line 1, and mark a line as an invalid line, with the reason of the first of the following (a) to (c) that applies.
(a) The line does not contain exactly one space: "bad format"
(b) The part before the space (the word) is not valid as a word: "bad word"
(c) The part after the space is not valid as an integer (range 1 to 100): "bad score"
Among the lines that are not invalid, a line whose word is the same as a word added to the word list by an earlier line is a duplicate line and is not added to the word list (the score of that word is the one from the line that added it first). Every other line adds its word to the word list, with the value of the part after the space as its score.
Word rank: the order in which all words of the word list are arranged in descending order of score, ties in lexicographic order of the word, is called rank order. Whenever a collection of words is listed, unless stated otherwise, it is in rank order.
To find search candidates quickly, the word list should keep, as indexes, the collection of words for each word length and the collection of words for each (length, position, letter) combination (the words of that length that have that letter at that position) (the results must be the same as those obtained exactly by the definition in step 8).

* 4. Reading the clue dictionary
Examine the clue lines of clues.txt one by one starting from line 1, and mark a line as an invalid clue line, with the reason of the first of the following (a) to (c) that applies.
(a) The line does not contain exactly one "|": "bad format"
(b) The part before the "|" (the word) is not valid as a word: "bad word"
(c) The part after the "|" (the clue) is not 1 to 60 characters long, or its first or last character is a space: "bad clue"
Among the clue lines that are not invalid, a line whose word is not in the word list is an unknown clue line and is not used (the word's score does not matter). For every other clue line, its clue is appended to the end of that word's clue list (even if clues with the same string are duplicated, they are added separately). The clues in each word's clue list are numbered 1, 2, ... from the start of the list (clue numbers). Each clue also has a use count. The use count is 0 at first and is increased by the processing of step 12.

* 5. Checking templates
Process the blocks of templates.txt one at a time from the beginning. For each block, check the following (1) to (10) in order; if one applies, the template is an error (invalid template) with the reason of the first one that applies (the string in double quotes, with k, i, r, c and K replaced by their values), and no further checks are made. If none applies, it is a valid template.
(1) The name is not valid as a name: "bad name"
(2) The name is the same as the name of an earlier block in this file (including blocks that were errors): "duplicate name"
(3) There is an invalid option line: "bad option k" (k is the smallest option number among the invalid option lines)
  For an option line, the part before the first space is the key, and the part after the first space (including any second and later spaces) is the value. Examine the option lines in order of option number; a line is a valid option line if any of the following holds.
  - The key is "node_budget" and the value is valid as an integer (range 1 to 100000).
  - The key is "min_score" and the value is valid as an integer (range 1 to 100).
  - The key is "symmetry" and the value is one of "rot180", "mirror" and "none".
  - The key is "theme", the value is valid as a word, and it differs from every theme value of the earlier option lines of this block.
  However, when the key is one of node_budget, min_score and symmetry and an option line with the same key appears earlier in that block, the line is an invalid option line (the theme key may be used any number of times). The values of the theme option lines are called theme words and are numbered 1, 2, ... in order of option number (theme numbers).
(4) The number of grid lines is not between 3 and 15 inclusive: "bad height"
(5) Examining the grid lines from top to bottom, line i has a number of characters not between 3 and 15 inclusive, or different from the number of characters of line 1, or contains a character other than ".", "#" and uppercase letters: "bad row i" (determined by the first line that matches)
(6) The template's symmetry is rot180 and there is a cell (r,c) such that exactly one of cell (r,c) and cell (h+1-r,w+1-c) is a black cell, or the symmetry is mirror and there is a cell (r,c) such that exactly one of cell (r,c) and cell (r,w+1-c) is a black cell: "asymmetric at r,c" ((r,c) is the first such cell in row-major order). If the symmetry is none, this check is not made. Whether a cell contains a letter does not matter.
(7) The number K of connected components of white cells is not 1: "disconnected components=K". White cells adjacent vertically or horizontally are considered connected, and a set of white cells that can all reach one another by following connections is called a connected component. If there are no white cells, K is 0.
(8) There is a run (defined in step 6) of length exactly 2: "short slot at r,c across" or "short slot at r,c down". Examine the cells in row-major order, and for each cell check, in the order the across run then the down run that start at that cell, whether its length is 2. Let (r,c) be the first cell of the first run of length 2 found, and write "across" if it is an across run and "down" if it is a down run.
(9) There is a white cell not contained in any slot (defined in step 6): "orphan cell r,c" ((r,c) is the first such white cell in row-major order)
(10) Placing the theme words (defined in step 7) fails: "unknown theme k" or "theme k does not fit"

* 6. Runs, slots and numbers
- Runs: among the white cells lying consecutively left to right in the same row, a sequence that cannot be extended further left or right is called an across run; among the white cells lying consecutively top to bottom in the same column, a sequence that cannot be extended further up or down is called a down run. A single isolated white cell is also a run of length 1. The first cell of a run is the leftmost cell for an across run and the topmost cell for a down run. The length of a run is the number of cells it contains.
- Slots: a run of length 3 or more is called a slot. A slot that is an across run is called an across slot, and a slot that is a down run is called a down slot. The cells of a slot are ordered from left to right for an across slot and from top to bottom for a down slot, and are called the positions of the 1st letter, 2nd letter, ... from the start. The length of a slot is the length of the run.
- Numbers: examine the cells in row-major order, and number the cells that are the first cell of an across slot or the first cell of a down slot 1, 2, 3, ... in order (even if one cell is the first cell of both, it gets one number). The number of a slot is the number of its first cell.
- Labels: the label of a slot is its number in decimal followed by "A" for an across slot or "D" for a down slot (examples: 1A, 12D).
- Slot order: ascending number, and for the same number the across slot first. Whenever slots are examined or listed, unless stated otherwise, it is in this order.
- Crossing: when an across slot and a down slot contain the same cell, the two slots are said to cross. The crossing slots of a slot s are the slots that cross s.
- Checking: a white cell contained in two slots is called a checked cell, and a white cell contained in only one slot is called an unchecked cell.

* 7. Placing theme words and the initial state
A grid state is the combination of the letter in each white cell (a cell may have no letter) and the word assigned to each slot (a slot may have no assignment). In a state, a word assigned to some slot is called a used word.
For a template to which none of checks (1) to (9) applied, first create the state in which only the given-letter cells contain their letters and no slot has an assignment. Next, place the theme words one at a time in order of theme number. Letting T be the theme word with theme number k, do the following.
(a) T is not in the word list: the template is an error "unknown theme k".
(b) Examine the slots in slot order and find the first slot that satisfies all of the following conditions.
  - It has no assignment.
  - Its length equals the number of letters of T.
  - For every position i, if the cell at the i-th letter of the slot contains a letter, that letter equals the i-th letter of T.
  If none is found, the template is an error "theme k does not fit".
(c) Assign T to the slot found, and put the i-th letter of T into the cell at each position i of that slot.
A slot to which T is assigned is called a theme slot. The state after all theme words have been placed is called the initial state of the template. The minimum score does not apply to theme words.

* 8. Candidates
Given a state and a minimum score m, the candidates of a slot s are the words W of the word list that satisfy all of the following conditions.
- The number of letters of W equals the length of s.
- The score of W is at least m.
- W is not a used word.
- For every position i, if the cell at the i-th letter of s contains a letter, the i-th letter of W equals that letter.
Candidates are always listed in rank order. The pattern of a slot s is the string formed by concatenating, in position order, for each position's cell of s, its letter if it contains a letter and "." otherwise.

* 9. Search (one attempt)
Performing one search to fill the grid, using an initial state, a minimum score m and a node count limit B, is called one attempt. An attempt has the following values.
- Node count, number of backtracks, number of prunes, number of dead ends: all are 0 at first.
- Assignment sequence: the sequence of the slots to which the search assigned words, in the order assigned. It is empty at first. The length of the assignment sequence is called the depth (theme slots are not included).
- Maximum depth: 0 at first.
- Best partial solution: holds one state. It is the initial state at first.
- Failure count of each slot: 0 for every slot at first.
- Trace: a sequence of strings. It is empty at first.
In an attempt, with the initial state as the current state, the following procedure "search" is called once. In this section, candidates are with minimum score m. If its result is "complete", the attempt's result is "filled"; if "fail", "unfillable"; if "abort", "budget".
The procedure "search" performs the following steps.
(a) If there is no slot without an assignment, return "complete".
(b) For each slot without an assignment, find the number of its candidates in the current state, and choose the slot with the fewest. On a tie, choose the one that comes first in slot order. Let s be the chosen slot, and C the sequence of candidates of s at this point.
(c) If C is empty, add 1 to the number of dead ends and to the failure count of s, and return "fail".
(d) Try the words of C one at a time from the beginning. To try a word W, do the following 1 to 7.
  1. If the node count equals B, immediately return "abort" (the state is left as it is).
  2. Add 1 to the node count. Assign W to s, and put the i-th letter of W into the cell at each position i of s (a cell that already contained a letter does not change, since it is the same letter). Append s to the end of the assignment sequence.
  3. Forward check: examine the crossing slots of s that have no assignment, in slot order; if any of them has 0 candidates in the current state (the state after assigning W), the first such slot is the wiped-out slot.
  4. If the node count is at most 10, append to the end of the trace the string formed by concatenating the label of s, "=", and W in this order. However, if there is a wiped-out slot, append "!" to the end of that string (examples: "3D=ABILITY", "9A=GLIMPSE!").
  5. If there is a wiped-out slot t, add 1 to the number of prunes and to the failure count of t, and let the result of W be "fail". If there is no wiped-out slot, then only if the depth is greater than the maximum depth, update the maximum depth to the depth and replace the best partial solution with a copy of the current state. Then call the procedure "search" and let its result be the result of W.
  6. If the result of W is "complete" or "abort", immediately return that result (the state is left as it is).
  7. If the result of W is "fail", remove the assignment of s, clear again the cells that received a letter in 2 and had no letter just before 2, and remove s from the end of the assignment sequence (the state is now the same as just before 2). Add 1 to the number of backtracks and move on to the next word of C.
(e) When all words of C have been tried, return "fail".
When the result of the attempt is filled, the state at the end of the attempt is called the completed grid. In the completed grid, every slot has an assigned word and every white cell contains a letter.

* 10. Repeating attempts (relaxing the minimum score)
For each valid template, perform one or more attempts as follows. The attempts are numbered 1, 2, ... in the order performed (attempt numbers).
- The minimum score of the first attempt is the template's min_score.
- Every attempt starts from the template's initial state, and its node count limit is the template's node_budget. No values carry over between attempts (the node count and the others are counted from 0).
- If the result of an attempt is not filled, relax_step is at least 1, and the minimum score of that attempt is greater than 1, perform the next attempt with the larger of "the minimum score of that attempt - relax_step" and 1 as the new minimum score. Otherwise, stop repeating attempts.
The last attempt performed is called the final attempt. The result of the template is the result of the final attempt (one of filled, unfillable and budget). If the result of the template is filled, the completed grid of the final attempt, and otherwise the best partial solution of the final attempt, is called the final grid of the template.

* 11. Statistics per template
For each valid template, compute the following values (the output format is defined in [Output files]).
(1) Grid statistics: the number of black cells, the number of white cells, the black cell ratio (100 * number of black cells / (w*h)), the number of given-letter cells, and the symmetries that hold (whether the rot180 condition and the mirror condition each hold over the whole grid, with the same test as in (6) of step 5; both are checked regardless of the template's symmetry).
(2) Slot statistics: the number of across slots, the number of down slots, the total number of slots, the number of slots of each length, the average slot length (sum of lengths / total number of slots), the maximum slot length, and the number of unchecked cells.
(3) Word supply: for each value that occurs as a slot length of the template, the number of words of the word list that have that number of letters and a score of at least the template's min_score.
(4) Tightest slots: in the initial state, find the number of candidates of each slot other than theme slots (with the template's min_score as the minimum score), and take the first 3 slots (all of them if fewer than 3) in ascending order of the number, ties in slot order.
(5) Most-failed slots: the slots whose failure count in the final attempt is at least 1, in descending order of failure count, ties in slot order; take the first 3 (all of them if fewer than 3).
(6) Quality (computed only when the result of the template is filled): for the completed grid, compute the following values. The score of a slot is the score of the word assigned to that slot (theme slots included).
  - Total score: the sum of the scores of all slots. Average score: total score / total number of slots.
  - Weakest slot: the slot with the smallest score (on a tie, the one that comes first in slot order).
  - Weak slots: the slots whose score is less than weak_score (in slot order).
  - Letters used: the number of distinct letters among the letters of all white cells, and the uppercase letters not used (in alphabetical order). If all 26 letters are used, it is a pangram.
  - Average letter points: the sum of the letter points of all white cells / the number of white cells. The letter points are A=1, B=3, C=3, D=2, E=1, F=4, G=2, H=4, I=1, J=8, K=5, L=1, M=3, N=1, O=1, P=3, Q=10, R=1, S=1, T=1, U=1, V=4, W=4, X=8, Y=4, Z=10.
  - Worst crossing: for each checked cell, compute the sum of the score of the across slot and the score of the down slot that contain that cell, and take the cell with the smallest sum (on a tie, the first in row-major order). If there are no checked cells, there is none.
(7) Partial solution status (computed only when the result of the template is not filled): for the final grid (best partial solution), the number of slots that have an assigned word (theme slots included), the number of white cells that contain a letter (given-letter cells included), and the slots without an assignment that have 0 candidates in that state (with the minimum score of the final attempt) (blocked slots).

* 12. Choosing clues
The clues written in the list lines of output/clues.txt are chosen as follows. Process the valid templates in file order, and in each template process the across slots in slot order, followed by the down slots in slot order. If a word W is assigned to the slot in the final grid (including theme slots and slots assigned in a partial solution), choose from W's clue list the clue with the smallest use count (on a tie, the one with the smallest clue number), and add 1 to that clue's use count. If W has no clue at all, there is no clue. No clue is chosen for a slot without an assignment.

* 13. Overall totals
After all templates have been processed, compute the following values.
- Ranking: the templates whose result is filled, in descending order of average score, ties in lexicographic order of name. Average scores are compared as fractions (one with total score a and b slots and one with total score c and d slots are compared by a*d versus c*b).
- Reused words: the words assigned to some slot of the completed grid (theme slots included) in two or more templates whose result is filled. For each word, find the number of templates in which it appears and the names of those templates (in file order).
- Clue usage: over all clues (the clues in the clue lists of all words), the number of clues with a use count of 1 or more, the number with 0, and the clues with 2 or more.

[Output files]
The program writes the following four files into the output/ folder. Every file consists only of ASCII characters, every line ends with a newline (LF), and no line has trailing spaces. No blank lines are output other than those specified as paragraph separators. Integers are written in decimal without extra leading zeros (negative numbers do not occur). In the formats, only the symbols explained are replaced by values; all other characters are output as they are. The template name s is output exactly as the string written in the "TEMPLATE s" line (the same for error templates). When a slot is written as "label:word:score", the slot's label, the assigned word and that word's score are joined with ":" (example: 12A:ODE:21).

* output/grid.txt
Output one paragraph for each block of templates.txt, in file order. Put exactly one blank line between consecutive paragraphs, and no blank line at the beginning or end of the file.
The paragraph of an error template is the 2 lines "TEMPLATE s" and "error reason".
The paragraph of a valid template consists of the following lines in this order.
1. "TEMPLATE s"
2. "outcome=O attempts=A min_score=M": O is the result of the template, A is the number of attempts performed, and M is the minimum score of the final attempt.
3. The grid lines (h lines): line r (r = 1, ..., h) is the concatenation of the cells from column 1 to column w, each written as "#" for a black cell, its letter for a white cell that contains a letter in the final grid, and "." for a white cell that contains no letter.
4. "numbers"
5. The number diagram (h lines): line r is the cells from column 1 to column w, each represented by 2 characters, joined with single spaces. A black cell is "##", a numbered cell is its number right-aligned in width 2 (padded on the left with one space if it has 1 digit), and an unnumbered white cell is " ." (a space and ".").

* output/clues.txt
Output one paragraph for each valid template, in file order. Put exactly one blank line between consecutive paragraphs, and no blank line at the beginning or end of the file (if there are no valid templates, the file is empty).
A paragraph consists of the following lines in this order.
1. "TEMPLATE s"
2. If there is at least one across slot, the line "ACROSS" followed by one list line for each across slot, in slot order.
3. If there is at least one down slot, the line "DOWN" followed by one list line for each down slot, in slot order.
4. "clued=X missing=Y unfilled=Z": among the list lines of this paragraph, X is the number of lines for which a clue was chosen, Y the number of "(no clue)" lines, and Z the number of "(unfilled)" lines.
A list line has the form "n. C (L) E S". n is the slot's number and L is the slot's length.
- When a word W is assigned to the slot in the final grid: C is the clue chosen in step 12 ("(no clue)" if there is no clue), E is W, and S is W's score. If it is a theme slot, " theme" (a space and theme) is appended to the end of the line.
- When there is no assignment: C is "(unfilled)", E is the slot's pattern in the final grid, and S is "-".

* output/search_stats.txt
Output one paragraph for each valid template, in file order, followed by the ranking paragraph, the reuse paragraph and the summary paragraph, in this order. Put exactly one blank line between consecutive paragraphs, and no blank line at the beginning or end of the file.
The paragraph of a valid template consists of the following lines in this order. A line with a condition is output only when the condition holds.
1. "TEMPLATE s"
2. "grid size=WxH blocks=B white=N density=D givens=G required=R symmetry=Y": W is w, H is h, B is the number of black cells, N is the number of white cells, D is the 1-decimal notation of the black cell ratio, G is the number of given-letter cells, R is the template's symmetry, and Y is those of rot180 and mirror that hold, in this order, joined with "," ("none" if neither holds).
3. "slots across=A down=D total=T lengths=X avg_length=V longest=M unchecked=U": A is the number of across slots, D the number of down slots, T the total number of slots, X is, for each value that occurs as a slot length, in ascending order, "length:count" joined with ",", V is the 2-decimal notation of the average slot length, M is the maximum slot length, and U is the number of unchecked cells.
4. (when there is a theme slot) "themes X": X is the theme slots in slot order, each written as "label:word:score", joined with single spaces.
5. "coverage X": X is the word supply of (3) of step 11, in ascending order of length, each written as "length:count", joined with single spaces.
6. "tightest X": X is the tightest slots of (4) of step 11, in that order, each written as "label:number of candidates", joined with single spaces ("-" if there is no slot other than theme slots).
7. One line per attempt, in order of attempt number, "attempt k min_score=M budget=B outcome=O nodes=N backtracks=K prunes=P dead_ends=E max_depth=X": k is the attempt number, M is the minimum score of that attempt, B is the node count limit, O is the result of the attempt, and N, K, P, E and X are that attempt's node count, number of backtracks, number of prunes, number of dead ends and maximum depth.
8. "trace X": X is the strings of the final attempt's trace, in order, joined with single spaces ("-" if the trace is empty).
9. "hotspots X": X is the most-failed slots of (5) of step 11, in that order, each written as "label:failure count", joined with single spaces ("-" if there are none).
10. (when the result of the template is filled) "order X": X is the labels of the slots of the final attempt's assignment sequence, in order, joined with single spaces ("-" if the assignment sequence is empty).
11. (when the result of the template is filled) "quality total=T average=V weakest=X weak=Y": T is the total score, V is the 2-decimal notation of the average score, X is the weakest slot written as "label:word:score", and Y is the weak slots in slot order, each written as "label:word:score", joined with "," ("-" if there are none).
12. (when the result of the template is filled) "letters distinct=N pangram=P missing=X scrabble=V worst_crossing=Z": N is the number of distinct letters used, P is "yes" if it is a pangram and "no" otherwise, X is the unused uppercase letters concatenated in alphabetical order ("-" if there are none), and V is the 2-decimal notation of the average letter points. Z is the worst crossing; letting (r,c) be its cell, La and Wa the label and word of the across slot, Ld and Wd the label and word of the down slot, and S the sum of the scores, it is written "r,c La:Wa+Ld:Wd=S" ("-" if there is no worst crossing).
13. (when the result of the template is not filled) "partial assigned=K/T letters=L/N blocked=X": K is the number of slots with an assigned word from (7) of step 11, T is the total number of slots, L is the number of white cells that contain a letter, N is the number of white cells, and X is the labels of the blocked slots in slot order joined with "," ("-" if there are none).

The ranking paragraph is the line "RANKING" followed by the rank lines. For the k-th template (k = 1, 2, ...) of the ranking, output the line "rank k s average=V total=T entries=E". V is the 2-decimal notation of the average score, T is the total score, and E is the total number of slots. If no template's result is filled, it is the single line "RANKING".

The reuse paragraph is the line "REUSE" followed by lines. List the reused words in descending order of the number of templates in which they appear, ties in lexicographic order of the word, and for each output the line "reused W n X". W is the word, n is the number of templates, and X is the names of those templates in file order joined with ",". If there are no reused words, it is the single line "REUSE".

The summary paragraph is the single line "SUMMARY templates=N invalid=I filled=F unfillable=U budget=B attempts=A nodes=X". N is the number of blocks in templates.txt, I is the number of error templates, F, U and B are the numbers of templates whose result is filled, unfillable and budget respectively, A is the total number of attempts performed over all valid templates, and X is the total node count over all attempts.

* output/wordlist.txt
Output the following lines in this order (with no blank lines).
1. "WORDLIST lines=L valid=V invalid=I duplicates=D": L is the number of lines of words.txt, V is the number of words in the word list, I is the number of invalid lines, and D is the number of duplicate lines.
2. For each invalid line, in order of line number, "invalid k R": k is the line number and R is the reason.
3. For each duplicate line, in order of line number, "duplicate k W first=j": k is the line number, W is the word, and j is the line number of the line that added that word to the word list.
4. For each number of letters of the words that occur in the word list, in ascending order, "length n words=C average=V best=W:S": n is the number of letters, C is the number of words with that number of letters, V is the 2-decimal notation of the average score of those words (sum of scores / C), and W and S are the first word in rank order among the words with that number of letters and its score.
5. "bands 1-20=A 21-40=B 41-60=C 61-80=D 81-100=E": A to E are the numbers of words whose score is from 1 to 20, from 21 to 40, from 41 to 60, from 61 to 80, and from 81 to 100 inclusive, respectively.
6. "top X": X is the first 5 words in rank order (all of them if fewer than 5), each written as "word:score", joined with single spaces.
7. "rare_letters X": for each uppercase letter, find the number of words that contain that letter at least once; take the first 5 letters in ascending order of that number, ties in alphabetical order, each written as "letter:count", joined with single spaces; this is X.
8. "CLUES entries=E valid=V invalid=I unknown=U words=W": E is the number of clue lines of clues.txt, V is the number of clues added to clue lists, I is the number of invalid clue lines, U is the number of unknown clue lines, and W is the number of words that have at least one clue.
9. For each invalid clue line, in order of line number, "clue_invalid k R": k is the line number and R is the reason.
10. For each unknown clue line, in order of line number, "clue_unknown k W": k is the line number and W is the word.
11. "CLUE_USE used=U unused=N repeated=R": from the clue usage of step 13, U is the number of clues with a use count of 1 or more, N is the number of clues with a use count of 0, and R is the number of clues with a use count of 2 or more.
12. For each clue with a use count of 2 or more, in lexicographic order of the word, and for the same word in order of clue number, "repeated W clue=k uses=n": W is the word, k is the clue number, and n is the use count.

[Source files]
Split the source into files with the following 6 roles (file names and extensions follow each language's conventions).
- main: the overall flow and the largest share of the processing. Reading the four input files, determining the settings, classifying the lines of the word list and the word list statistics (statistics per number of letters, counts per score band, top words, rare letters), reading and classifying the clue dictionary, splitting the template file into blocks, checking templates (determining the order and reasons of (1) to (10), including interpreting option lines), placing theme words, repeating attempts and relaxing the minimum score, statistics per template (grid and slot statistics, word supply, tightest slots, most-failed slots, quality, partial solution status), choosing clues and clue usage, the ranking, reused words, the summary, assembling all output lines and writing the four output files.
- grid: handling the cells (deciding white and black cells), the symmetry test, and counting the connected components of white cells.
- slots: computing run lengths, detecting runs of length 2, extracting and numbering slots, labels, the mapping from each cell to the slots that contain it, and the lists of crossing slots.
- word_index: checking the format of word list lines and clue lines, deciding validity as a word, sorting into rank order, the indexes by length and by (length, position, letter), and computing candidates from a pattern, a minimum score and the used words.
- filler: the search of one attempt (choosing the slot with the fewest candidates, trying candidates in order, forward checking, aborting at the node count limit, backtracking, the various counts, the trace, the best partial solution, and failure counts).
- render: assembling the grid lines and the number diagram lines, assembling the list lines, and d-decimal notation.

[Constraints]
- params.txt has at most 20 lines. words.txt has at most 2000 lines, clues.txt at most 200 lines, and templates.txt at most 400 lines with at most 30 blocks.
- The word list has at least 5 words.
- In a valid template, numbers are at most 99.
- In the inputs of this task, the total node count over all attempts is at most 20000.
- All intermediate values fit in the range of a signed 32-bit integer.
- Every selection and sort has a tie-breaking rule, so the result is uniquely determined. All score and point computations are done with integers, and every decimal is obtained from a fraction by d-decimal notation, so the result does not depend on the order of computation.

Line 21, "ICE AGE 10", is invalid because it contains 2 spaces. ERA on line 28 duplicates line 2 and is not used, so the score of ERA is 60. In tiny, the first attempt, with minimum score 70, has only 7 usable 3-letter words. Every word put into 1A other than POT is immediately pruned by the forward check, and after POT, putting PET into 1D leaves 4A with no candidates, so the result is unfillable. So a second attempt is made with the minimum score lowered to 70 - 20 = 50, and the grid is completed. "1A=ODE!" in the trace of the second attempt means that putting ODE into 1A leaves the crossing slot 2D with no candidates (unused 3-letter words beginning with D with a score of 50 or more) (1D has the candidates ORE and OAK). In corner, the theme word OVAL is placed in 1D, the first slot of length 4 in slot order. Therefore the pattern of 5A is ".A..", its only candidate with a score of 30 or more is RACK, and it appears first in tightest. stub is an error because row 2 has an across run of length 2, and skew is an error because the symmetry value "diagonal" is not valid. rush has a node count limit of 8, so after assigning ERA to 1A at the 8th node, it aborts when it tries the next word. The best partial solution is the last state that passed the forward check (depth 4). In choosing clues, the 2 clues of ORE are used once each, in tiny and corner. ERA has only one clue, so it is used 3 times, in tiny, corner and rush (clues are also chosen for the slots assigned in rush's partial solution). Line 10 of clues.txt is invalid because it contains 2 "|" characters, and ZOO on line 11 is an unknown clue line because it is not in the word list.
