[Overview]
Write a program that performs statistical process control (SPC) on measurement data from a manufacturing process. The values of one dimension of a part (the characteristic), measured as integers in micrometres, are given divided into groups (subgroups) of a fixed number of values each.
From the first m subgroups (Phase 1), the program estimates the control limits of the X-bar-R chart, the X-bar-s chart, and the chart of individual values and moving ranges (I-MR chart). Re-estimating after removing the points that fall outside the control limits is repeated up to a given number of times. The remaining subgroups (Phase 2) are monitored with those control limits and eight run rules (based on the Western Electric rules and the Nelson rules), and also with a CUSUM chart, an EWMA chart and a moving average chart, and the signals that indicate anomalies are listed. The signals are grouped into events, and the type of each event is determined.
In addition, the program builds p, np, c and u charts from the number of defectives and the number of defects of each inspection lot, and computes process capability indices (Cp, Cpk, Pp, Ppk, etc.). The results are written to 7 files: control limits, signals, events, a per-subgroup list, attribute charts, process capability, and charts drawn with characters.
The program reads the files in the input/ folder and writes files to the output/ folder. It prints nothing to standard output.

[Input files]
Every input file consists of ASCII characters only, and every line ends with a newline (LF). There are no empty lines and no spaces at the start or end of a line. Integers are written in decimal.

(1) input/measurements.csv: measurements
The first line is the header sample,subgroup,value. Each following line consists of 3 integers separated by ",": the sample number t, the subgroup number i and the measurement x_t (there are no spaces). t is 1, 2, ..., N in order, starting from the second line. Let n be the subgroup size (subgroup_size in spec.txt); N is a multiple of n, and the subgroup number of sample t is i = floor((t - 1) / n) + 1. That is, subgroup i consists of the n samples (i - 1) * n + 1 to i * n. Let K = N / n be the number of subgroups.

(2) input/attributes.csv: attribute data
The first line is the header lot,inspected,defectives,defects. Each following line consists of 4 integers separated by ",": the lot number l, the number inspected n_l, the number of defectives d_l and the number of defects c_l. Lot numbers are 1, 2, ..., L in order, starting from the second line.

(3) input/spec.txt: settings
Each line is a name followed by one or more values, separated by single spaces. The lines appear in the following order. The symbol after the name is the symbol that denotes that value in the description below.
- characteristic NAME: the name of the characteristic (1 to 32 characters consisting of lowercase English letters and "_").
- lsl LSL: the lower specification limit (integer).
- usl USL: the upper specification limit (integer).
- target tau: the target value (integer).
- subgroup_size n: the subgroup size (integer).
- phase1_subgroups m: the number of Phase 1 subgroups (integer).
- max_passes P: the maximum number of Phase 1 estimation passes (integer).
- rules <chart name> r_1 r_2 ...: the numbers of the run rules used for each chart (one or more integers from 1 to 8 in increasing order). Seven lines with the chart names XBAR_R, R, XBAR_S, S, I, MR, STD appear in this order.
- cusum_k k: the coefficient of the CUSUM reference value (real).
- cusum_h h: the coefficient of the CUSUM decision interval (real).
- ewma_lambda lambda: the EWMA weight (real).
- ewma_l E: the coefficient of the EWMA control limit width (real).
- ma_span w: the moving average span (integer).
- event_gap G: the number of subgroups without signals allowed when grouping signals into events (integer).
- ci_z zc: the confidence interval coefficient (real).
- histogram_bin B: the class width of the frequency distribution (integer).
- rolling_window V: the number of subgroups in a rolling capability window (integer).
- rolling_step J: the number of subgroups by which the rolling capability window is shifted (integer).
Real values are written as decimal numbers such as 0.5, 4, 2.7. For example, line 1 is a line like "characteristic wall_thickness" and line 8 is a line like "rules XBAR_R 1 2 3 4 5 6 7 8".

[Processing]
Process as described in Steps 1 to 15 below.

# Notation and arithmetic conventions
- All real numbers are computed in double-precision floating point (IEEE 754 64-bit format). The real values in spec.txt and the values in the table of Step 1 are treated as the double-precision values nearest to the written decimal numbers.
- Integer computations are exact (by [Constraints], the absolute values, including intermediate values, are less than 2^53). An expression written "a / b" where a and b are integers denotes the value obtained by converting the integers a and b each to a real and then dividing once.
- Expressions are evaluated parentheses first, multiplication and division before addition and subtraction, and operations of equal precedence from left to right (for example, A + B * C computes B * C and then adds A, and A * B * C computes A * B and then multiplies by C). sqrt(...) is the square root.
- A real-valued sum written with Sum is computed by starting from 0 and adding the terms one at a time, from the term with the smallest index upward.
- floor(x) is the largest integer <= x (negative numbers are rounded toward minus infinity; for example, floor(-2.5) = -3). min and max are the minimum and the maximum respectively.
- Subgroup numbers, sample numbers and lot numbers all count from 1.
- Number list: the numbers in increasing order, separated by single spaces. If there are no numbers, write none.

# Step 1. Control chart constants
The table of constants by subgroup size.
- n = 2: A2 = 1.880, A3 = 2.659, B3 = 0, B4 = 3.267, D3 = 0, D4 = 3.267, d2 = 1.128, c4 = 0.7979
- n = 3: A2 = 1.023, A3 = 1.954, B3 = 0, B4 = 2.568, D3 = 0, D4 = 2.574, d2 = 1.693, c4 = 0.8862
- n = 4: A2 = 0.729, A3 = 1.628, B3 = 0, B4 = 2.266, D3 = 0, D4 = 2.282, d2 = 2.059, c4 = 0.9213
- n = 5: A2 = 0.577, A3 = 1.427, B3 = 0, B4 = 2.089, D3 = 0, D4 = 2.114, d2 = 2.326, c4 = 0.9400
- n = 6: A2 = 0.483, A3 = 1.287, B3 = 0.030, B4 = 1.970, D3 = 0, D4 = 2.004, d2 = 2.534, c4 = 0.9515
- n = 7: A2 = 0.419, A3 = 1.182, B3 = 0.118, B4 = 1.882, D3 = 0.076, D4 = 1.924, d2 = 2.704, c4 = 0.9594
- n = 8: A2 = 0.373, A3 = 1.099, B3 = 0.185, B4 = 1.815, D3 = 0.136, D4 = 1.864, d2 = 2.847, c4 = 0.9650
- n = 9: A2 = 0.337, A3 = 1.032, B3 = 0.239, B4 = 1.761, D3 = 0.184, D4 = 1.816, d2 = 2.970, c4 = 0.9693
- n = 10: A2 = 0.308, A3 = 0.975, B3 = 0.284, B4 = 1.716, D3 = 0.223, D4 = 1.777, d2 = 3.078, c4 = 0.9727
Below, A2, A3, B3, B4, D3, D4, d2, c4 denote the values in the row for the subgroup size n. Also, d2, D3 and D4 of the row n = 2 are written d2(2), D3(2) and D4(2) respectively (they are used for moving ranges).

# Step 2. Subgroup statistics
For each subgroup i (i = 1, ..., K), compute the following values from its n measurements.
- Total T_i: the sum of the measurements (integer). Sum of squares Q_i: the sum of the squares of the measurements (integer).
- Mean xbar_i = T_i / n.
- Range R_i: the maximum measurement minus the minimum measurement (integer).
- Standard deviation s_i = sqrt((n * Q_i - T_i * T_i) / (n * (n - 1))). Here n * Q_i - T_i * T_i and n * (n - 1) are computed exactly as integers.
Also, the moving range of each sample t (t >= 2) is MR_t = |x_t - x_(t-1)| (integer).
The ordering and equality of the xbar_i values coincide with the ordering and equality of the T_i values.

# Step 3. Phase 1: estimating the control limits
Control limits are estimated independently for each of the following three families. Each family consists of two charts, and the control limits of a chart are three values: the lower control limit LCL, the center line CL and the upper control limit UCL. A value v is outside the control limits when v > UCL or v < LCL.
(1) Family XBAR_R: the points are subgroups. From a set U of points (a set of subgroups), compute the grand mean Xbar = (the sum of T_i over the subgroups in U) / (the number of subgroups in U * n) and the average range Rbar = (the sum of R_i over the subgroups in U) / (the number of subgroups in U), and from them define the control limits of the following two charts. The value representing subgroup i is xbar_i in the XBAR chart and R_i in the R chart.
  XBAR chart: LCL = Xbar - A2 * Rbar, CL = Xbar, UCL = Xbar + A2 * Rbar
  R chart: LCL = D3 * Rbar, CL = Rbar, UCL = D4 * Rbar
(2) Family XBAR_S: the points are subgroups. The grand mean Xbar is computed with the same formula as in (1), and the average standard deviation is sbar = (Sum s_i) / (the number of subgroups in U) (the Sum is taken over the subgroups of U in increasing subgroup number). The value representing subgroup i is xbar_i in the XBAR chart and s_i in the S chart.
  XBAR chart: LCL = Xbar - A3 * sbar, CL = Xbar, UCL = Xbar + A3 * sbar
  S chart: LCL = B3 * sbar, CL = sbar, UCL = B4 * sbar
(3) Family I_MR: the points are samples. Let y_1, y_2, ..., y_r be the measurements of the samples in U in increasing sample number, and let the moving ranges within U be M_j = |y_j - y_(j-1)| (j = 2, ..., r). With the mean Ybar = (y_1 + ... + y_r) / r and the average moving range MRbar = (M_2 + ... + M_r) / (r - 1), define the control limits of the following two charts. The value representing y_j is y_j in the I chart and M_j in the MR chart (y_1 has no MR chart value). When points are removed from U, M_j is recomputed between the remaining points.
  I chart: LCL = Ybar - 3 * MRbar / d2(2), CL = Ybar, UCL = Ybar + 3 * MRbar / d2(2)
  MR chart: LCL = D3(2) * MRbar, CL = MRbar, UCL = D4(2) * MRbar
The estimation proceeds as follows. The initial U is subgroups 1 to m for XBAR_R and XBAR_S, and samples 1 to m * n for I_MR. For p = 1, 2, ... in order, do the following as pass p of the estimation.
  (a) Compute the control limits of the two charts from U.
  (b) Collect the points of U for which at least one of the values representing the point is outside the control limits of its chart; this is the outlier set O.
  (c) If O is empty, the estimation has converged and ends. If O is not empty and p = P, the estimation is stopped and ends (the points of O stay in U). Otherwise, remove the points of O from U and go on to the next pass.
The control limits computed in (a) of the last pass are the final control limits of the family. The points in U when the estimation ends are called the retained points, and the Phase 1 points that are not in U are called the removed points.

# Step 4. Zones and run rules
For a chart with control limits (LCL, CL, UCL), let a = (UCL - CL) / 3 and b = (CL - LCL) / 3, and define the zone boundaries U1 = CL + a, U2 = CL + 2 * a, L1 = CL - b, L2 = CL - 2 * b.
Given a sequence v_1, v_2, ... of values of numbered points and a set of run rule numbers, perform the following checks for k = 1, 2, ... in order (up to the end of the sequence), and for each k, rule by rule from the smallest rule number upward. Let omega be the window length of rule r; only when k >= omega, examine the window v_(k-omega+1), ..., v_k. If the condition holds, it is a signal of rule r, whose start is the number of point k - omega + 1, whose end is the number of point k, and whose value is v_k. A signal has one of the directions UP, DOWN, NONE.
- Rule 1 (omega = 1): v_k > UCL or v_k < LCL. The direction is UP if v_k > CL, otherwise DOWN.
- Rule 2 (omega = 3): UP if v_k > U2 and 2 or more of the 3 values in the window are greater than U2. Otherwise, DOWN if v_k < L2 and 2 or more of the 3 values in the window are less than L2.
- Rule 3 (omega = 5): UP if v_k > U1 and 4 or more of the 5 values in the window are greater than U1. Otherwise, DOWN if v_k < L1 and 4 or more of the 5 values in the window are less than L1.
- Rule 4 (omega = 8): UP if all 8 values in the window are greater than CL, DOWN if all of them are less than CL.
- Rule 5 (omega = 6): UP if for every pair of adjacent values in the window (5 pairs) the later value is greater than the earlier value, DOWN if for every pair the later value is less than the earlier value.
- Rule 6 (omega = 14): NONE if none of the differences v_j - v_(j-1) between adjacent values in the window (13 of them) is 0 and the signs of adjacent differences alternate (positive and negative alternate).
- Rule 7 (omega = 15): NONE if all 15 values in the window satisfy L1 < v < U1.
- Rule 8 (omega = 8): NONE if all 8 values in the window satisfy v > U1 or v < L1, and there are at least one value greater than U1 and at least one value less than L1.
A point whose value equals CL is neither greater than nor less than CL.

# Step 5. Phase 1 pattern check
For each family, arrange the retained points in increasing number and, using the final control limits, apply the checks of Step 4 to the following six sequences. The run rules are those of the rules line in spec.txt with the same chart name. This check does not remove any points.
- XBAR_R: xbar_i of the retained subgroups of family XBAR_R (the subgroup number is the point number). R: R_i of the same subgroups.
- XBAR_S: xbar_i of the retained subgroups of family XBAR_S. S: s_i of the same subgroups.
- I: the values y_1, ..., y_r of the retained samples of family I_MR (the sample number is the point number). MR: M_2, ..., M_r (M_j is the moving range of adjacent y_(j-1) and y_j among the retained samples, and its point number is the sample number of y_j).

# Step 6. Phase 2: monitoring with Shewhart charts
Subgroups m + 1 to K are called the Phase 2 subgroups, and samples m * n + 1 to N are called the Phase 2 samples. For each of the following six charts, apply the checks of Step 4 to the sequence of values of the Phase 2 points in increasing number, with the final control limits and the run rules in spec.txt of the same chart name (windows consist of Phase 2 points only).
- XBAR_R: xbar_i of Phase 2 subgroup i, with the control limits of the XBAR chart of family XBAR_R. The point number is the subgroup number.
- R: R_i, with the control limits of the R chart of family XBAR_R.
- XBAR_S: xbar_i, with the control limits of the XBAR chart of family XBAR_S.
- S: s_i, with the control limits of the S chart of family XBAR_S.
- I: x_t of Phase 2 sample t, with the control limits of the I chart of family I_MR. The point number is the sample number.
- MR: MR_t of Phase 2 sample t (for the first t, it is the moving range with the immediately preceding Phase 1 sample), with the control limits of the MR chart of family I_MR.

# Step 7. CUSUM chart
Let mu0 be the CL of the XBAR chart and Rbar the CL of the R chart in the final control limits of family XBAR_R, and let sigma = Rbar / d2 / sqrt(n), Kc = k * sigma and Hc = h * sigma. Starting from C_plus = 0, C_minus = 0, eta_plus = 0, eta_minus = 0, do the following for the Phase 2 subgroups i = m + 1, ..., K in order.
  (a) Update C_plus to max(0, C_plus + (xbar_i - mu0 - Kc)) and C_minus to max(0, C_minus + (mu0 - xbar_i - Kc)).
  (b) If C_plus > 0, add 1 to eta_plus; otherwise set eta_plus to 0. Do the same for eta_minus with C_minus (eta_plus and eta_minus are the numbers of consecutive subgroups in which C_plus and C_minus are positive).
  (c) The C_plus and C_minus at this point are C_plus_i and C_minus_i of subgroup i.
  (d) If C_plus > Hc, it is an UPPER signal with start i - eta_plus + 1, end i, value C_plus and direction UP. If C_minus > Hc, it is a LOWER signal with start i - eta_minus + 1, end i, value C_minus and direction DOWN.
  (e) If (d) produced an UPPER signal, reset C_plus and eta_plus to 0; if it produced a LOWER signal, reset C_minus and eta_minus to 0.

# Step 8. EWMA chart
Let q = (1 - lambda) * (1 - lambda), rho = lambda / (2 - lambda) and W_E = E * sigma * sqrt(rho) (sigma and mu0 are those of Step 7). With z_0 = mu0 and f_0 = 1, for the j-th Phase 2 subgroup i = m + j (j = 1, 2, ...), compute
  z_j = lambda * xbar_i + (1 - lambda) * z_(j-1), f_j = f_(j-1) * q, w_j = E * sigma * sqrt(rho * (1 - f_j)),
  LCL_j = mu0 - w_j, UCL_j = mu0 + w_j
If z_j > UCL_j, it is an UPPER signal (direction UP); if z_j < LCL_j, it is a LOWER signal (direction DOWN). Both the start and the end are i, and the value is z_j.

# Step 9. Moving average chart
For Phase 2 subgroup i, let the start of the window be beta = max(m + 1, i - w + 1) and the number of subgroups in the window be kappa = i - beta + 1, and compute the mean of subgroups beta to i, A_i = (T_beta + ... + T_i) / (n * kappa), and w_i = 3 * sigma / sqrt(kappa), LCL_i = mu0 - w_i, UCL_i = mu0 + w_i. If A_i > UCL_i, it is an UPPER signal (direction UP); if A_i < LCL_i, it is a LOWER signal (direction DOWN). The start is beta, the end is i, and the value is A_i. Also, let W_M = 3 * sigma / sqrt(w).

# Step 10. Signal list
Sort the signals obtained in Steps 6 to 9 in chart order (XBAR_R, R, XBAR_S, S, I, MR, CUSUM, EWMA, MA; the signals of Steps 7 to 9 are CUSUM, EWMA and MA respectively), then, for the same chart, in increasing end, and if that is also the same, in rule order (1, 2, ..., 8, UPPER, LOWER).
The subgroup number g of each signal is floor((end - 1) / n) + 1 for I and MR signals, and the end for all other signals.

# Step 11. Events
Arrange the values of the subgroup numbers g of the signals in increasing order, without duplicates. For two adjacent values g < g', put them in the same event if g' - g - 1 <= G, and in different events otherwise. Number the resulting events 1, 2, ... in order. The start of an event is the minimum of g in the event, the end is the maximum, the length len is end - start + 1, and the signals whose subgroup number g is >= the start and <= the end are the signals of the event. For each event, compute the following values.
- The location charts are XBAR_R, XBAR_S, I, CUSUM, EWMA, MA, and the spread charts are R, S, MR. location_up is the number of signals of location charts with direction UP, location_down is the number of signals of location charts with direction DOWN, spread_up and spread_down are the numbers of signals of spread charts with direction UP and DOWN, and pattern is the number of signals with direction NONE.
- Type: according to which of location_up, location_down, spread_up, spread_down, pattern is the largest (if several have the same value, the one that comes first in this order), SHIFT_UP, SHIFT_DOWN, SPREAD_UP, SPREAD_DOWN, PATTERN respectively.
- Onset estimate: the minimum start of the CUSUM signals of the event. If there are no CUSUM signals, the start of the event.
- Shift: (X_e - mu0) / sigma, where X_e = (T_start + ... + T_end) / (n * len).
- Spread ratio: S_e / sbar_f, where S_e = (Sum s_i) / len (the Sum is taken over the subgroups from the start to the end in subgroup number order), and sbar_f is the CL of the S chart in the final control limits of family XBAR_S.
- Out-of-spec count: the number of samples of the subgroups from the start to the end with x_t < LSL or x_t > USL.
- Detection: for each chart (in the chart order of Step 10), the minimum subgroup number g of the signals of the event on that chart. If that chart has no such signals, "-".

# Step 12. Control limits for the next period
For each family, let U be the set of the retained points plus the points of the Phase 2 subgroups that are not contained in any event (whose subgroup number is not >= the start and <= the end of any event) (for I_MR, the n samples of each such subgroup are added), and compute the control limits once with the formulas of Step 3 (1) to (3). For I_MR, M_j is computed among the samples of U arranged in increasing sample number.

# Step 13. Attribute charts
For each of the four charts p, np, c, u, perform the following independently. From a set A of lots, compute D_A = the sum of d_l over A, C_A = the sum of c_l over A, S_A = the sum of n_l over A and N_A = the number of lots in A (all integers), and define the center line CL, the value v_l of lot l and the standard deviation sigma_l as follows.
- p: CL = D_A / S_A, v_l = d_l / n_l, sigma_l = sqrt(CL * (1 - CL) / n_l).
- np: CL = D_A / N_A, v_l = d_l, sigma_l = sqrt(CL * (1 - D_A / S_A)).
- c: CL = C_A / N_A, v_l = c_l, sigma_l = sqrt(CL).
- u: CL = C_A / S_A, v_l = c_l / n_l, sigma_l = sqrt(CL / n_l).
For lot l, let UCL_l = CL + 3 * sigma_l, LCL_l = CL - 3 * sigma_l (0 if it is less than 0) and the standardized value Z_l = (v_l - CL) / sigma_l; the status is high if v_l > UCL_l, low if v_l < LCL_l, and ok otherwise.
With all lots as the initial A, repeat the estimation with the same procedure as (a) to (c) of Step 3 (the maximum number of passes is also the same P). However, in (a) CL is computed from A (the sigma_l, control limits and status of each lot are determined by this CL), and in (b) the lots of A whose status is not ok form the outlier set O. The CL of the last pass is the final center line, and with the final center line, compute the value, control limits, standardized value and status of every lot (including the removed lots).
Furthermore, apply the checks of Step 4 to the sequence Z_1, ..., Z_L in lot number order, with LCL = -3, CL = 0, UCL = 3 and the run rules of STD in spec.txt (the point number is the lot number).

# Step 14. Process capability
For a set Gamma of subgroups, the target is the sequence of the measurements of the samples of those subgroups in sample number order, and N_Gamma is their count. Compute the following values.
- Mean mu = (the sum of the target measurements) / N_Gamma.
- Within-subgroup standard deviation sigma_w = Rbar_Gamma / d2, where Rbar_Gamma = (the sum of R_i over the subgroups in Gamma) / (the number of subgroups in Gamma).
- Standard deviation based on sbar, sigma_s = sbar_Gamma / c4, where sbar_Gamma = (Sum s_i) / (the number of subgroups in Gamma) (the Sum is taken over the subgroups of Gamma in subgroup number order).
- Overall standard deviation sigma_o = sqrt((Sum (x - mu) * (x - mu)) / (N_Gamma - 1)). The Sum is taken over the target measurements x in order, and each term is (x - mu) * (x - mu).
- Cp = (USL - LSL) / (6 * sigma_w), Cpu = (USL - mu) / (3 * sigma_w), Cpl = (mu - LSL) / (3 * sigma_w), Cpk = min(Cpu, Cpl).
- Pp, Ppu, Ppl, Ppk: the formulas of Cp, Cpu, Cpl, Cpk with sigma_w replaced by sigma_o.
- Cpm = (USL - LSL) / (6 * sqrt(sigma_o * sigma_o + (mu - tau) * (mu - tau))).
- Confidence intervals: taking each of Cpk and Ppk as X, compute delta = zc * sqrt(1 / (9 * N_Gamma) + X * X / (2 * (N_Gamma - 1))); the lower bound is X - delta and the upper bound is X + delta.
- Out of specification: below is the number of measurements with x < LSL, above is the number of measurements with x > USL, and ppm = (1000000 * (below + above)) / N_Gamma.
- Verdict: capable if Cpk >= 1.33, otherwise marginal if Cpk >= 1.00, and incapable if neither.
- Frequency distribution: with lo = B * floor(min(the minimum of the target, LSL) / B) and hi = B * floor(max(the maximum of the target, USL) / B) + B, for each class lower end a = lo, lo + B, ..., hi - B, count the measurements that fall into the class a to a + B - 1 (the frequency). Let top be the maximum frequency; the bar length of each class is ceil(50 * frequency / top) (the integer obtained by dividing 50 * frequency by top and rounding up the fractional part).
Gamma is two sets: phase1 (the retained subgroups of family XBAR_R) and phase2 (the Phase 2 subgroups). In addition, as rolling capability, for each a among a = m + 1, m + 1 + J, m + 1 + 2 * J, ... that satisfies a + V - 1 <= K, compute the same values with Gamma = subgroups a to a + V - 1.

# Step 15. Character charts
The picture in each row of a chart is a band of 61 characters with positions 0 to 60. Set every position to "." and then place characters in the order described below (when characters are placed at the same position, the later character overwrites the earlier one). If a value obtained in a position calculation is less than 0, use 0; if it is greater than 60, use 60.
(1) XBAR, R and S pictures: for control limits (LCL, CL, UCL) and a value v, let phi = (v - LCL) / (UCL - LCL); the position of v is floor(60 * phi + 0.5) (the position of CL is also computed with the same formula with v = CL). Place ":" at positions 0 and 60, "|" at the position of CL, and the point symbol at the position of v. The point symbol is "*" if the subgroup is a Phase 2 subgroup and the corresponding chart (XBAR_R for XBAR, R for R, S for S) has a signal whose end is that subgroup, and "o" otherwise.
(2) CUSUM picture: place ":" at positions 0 and 60 and "|" at position 30. If C_minus_i > 0, at position 30 - min(30, floor(30 * (C_minus_i / Hc) + 0.5)) place "*" if there is a LOWER signal whose end is subgroup i, otherwise "-". After that, if C_plus_i > 0, at position 30 + min(30, floor(30 * (C_plus_i / Hc) + 0.5)) place "*" if there is an UPPER signal whose end is subgroup i, otherwise "+".
(3) EWMA and MA pictures: for the width W (W_E for EWMA, W_M for MA), the row's w (w_j for EWMA, w_i for MA) and the value v (z_j or A_i), let e = min(30, floor(30 * (w / W) + 0.5)). Place "|" at position 30 and ":" at positions 30 - e and 30 + e, and, with d = (v - mu0) / W, at position 30 + floor(30 * d + 0.5) place "*" if that chart has a signal whose end is that subgroup, otherwise "o".
(4) Standardized value pictures: place ":" at positions 0 and 60 and "|" at position 30, and at position 30 + floor(10 * Z_l + 0.5) place "o" if the status is ok, otherwise "*".

[Output files]
Write the following 7 files to the output/ folder. Every file consists of ASCII characters only, and every line ends with a newline (LF). Do not output empty lines. In the formats below, the parts enclosed in < > are replaced by values, and everything else is output as is. Unless stated otherwise, the words in a line are separated by single spaces, with no spaces at the start or end of a line.
Integers (counts, numbers, n, K, N, m, w, x_t, R_i, frequencies, class ends and other values defined as integers) are written in decimal without extra zeros (there are no negative numbers). All other values (control limits, means, standard deviations, indices, ratios, etc.) are reals and are written rounded to 4 decimal places (e.g. 2501.8783, 0.0000, -1.6741). However, if the resulting string is -0.0000, write 0.0000. Also, the <value> of a signal (phase1_signal in limits.txt, signals.csv, signal in attribute_charts.txt) is written as a real even when it is an integer value (e.g. 26.0000). By [Constraints], the exact value of an output real is never exactly halfway between two rounding candidates.

Chart names 1 and 2 are XBAR and R for XBAR_R, XBAR and S for XBAR_S, and I and MR for I_MR. Point numbers are subgroup numbers for XBAR_R and XBAR_S and sample numbers for I_MR. <status> is converged if the estimation converged and stopped if it was stopped.
Then, for the six sequences of Step 5, in the order XBAR_R, R, XBAR_S, S, I, MR, output one phase1_signal line for each signal of that sequence in the order the signals were found, followed by one phase1_check line.

(4) output/subgroups.csv: per-subgroup list
The first line is the header subgroup,phase,mean,zone,range,sd,cusum_upper,cusum_lower,ewma,ma,signals,event. From the second line on, output one line for each subgroup i = 1, ..., K, consisting of the following 12 values separated by "," (with no spaces).
  subgroup number, phase, xbar_i, zone, R_i (integer), s_i, C_plus_i, C_minus_i, z_j, A_i, signal count, event number

- Zone: using the final control limits of the XBAR chart of family XBAR_R and their zone boundaries (Step 4), classify v = xbar_i as follows. OUT+ if v > UCL, OUT- if v < LCL; otherwise A+ if v > U2, B+ if v > U1, C+ if v > CL, A- if v < L2, B- if v < L1, C- if v < CL, and C0 if none of these (if v = CL).

- Event number: the number of the event that contains subgroup i (start <= i <= end). If there is no such event, write "-".

[Source files]
There are the following 7 source files. The names are language-neutral role names; extensions and the use of upper and lower case follow the conventions of each language.
- main: handles the overall flow and contains most of the processing: calling each module, the repeated Phase 1 estimation (the procedure of Step 3) and the pattern check (Step 5), building the Phase 2 sequences (Step 6), the CUSUM, EWMA and moving average charts (Steps 7 to 9), sorting the signals (Step 10), grouping and characterizing the events (Step 11), the control limits for the next period (Step 12), the repeated estimation of the attribute charts and the standardized value check (Step 13), building the process capability targets and the rolling capability (Step 14), and writing the 7 files.
- dataset: reading the 3 input files, and the table of control chart constants (Step 1).
- variable_charts: the subgroup statistics (Step 2) and the control limit formulas of the families XBAR_R, XBAR_S, I_MR (Step 3 (1) to (3)).
- attribute_charts: computing the center line, control limits, standardized values and status of the p, np, c, u charts (the formulas of Step 13).
- run_rules: the zone boundaries and run rules 1 to 8 (Step 4).
- capability: the process capability values and verdict, and building the frequency distribution rows (the formulas of Step 14).
- plot: building the bands of the character charts (Step 15).

[Constraints]
- 2 <= n <= 10 and 2 <= m < K <= 100 (N = K * n <= 1000).
- 1 <= x_t <= 99999, 1 <= LSL < USL <= 99999 and LSL <= tau <= USL.
- 1 <= L <= 100, 1 <= n_l <= 10000, 0 <= d_l <= n_l and 0 <= c_l <= 100000.
- 1 <= P <= 10, 1 <= w <= 20, 0 <= G <= 10, 1 <= B <= 1000, 2 <= V <= K - m and 1 <= J <= 100.
- k, h, E and zc are positive reals, and 0 < lambda < 1.
- In every U of Phase 1 and of Step 12, there are 2 or more subgroups for XBAR_R and XBAR_S and 3 or more samples for I_MR, and Rbar, sbar and MRbar are positive.
- In every pass of the attribute charts, 0 < D_A < S_A and C_A > 0 (therefore every sigma_l is positive).
- In every Gamma of the process capability, sigma_w, sigma_s and sigma_o are positive.
- Intermediate values of integer computations such as n * Q_i may be 2^31 or more, but their absolute values are less than 2^53.
- In the given data, every comparison used for a decision (comparisons with control limits and zone boundaries, comparisons of C_plus and C_minus with Hc and with 0, magnitude comparisons in the run rules, max and min, verdicts such as capable, floor(...) in position calculations, etc.) is far enough from its boundary that its result does not change under the small errors of double-precision computation (up to about 10^-9 relative). However, when integers are compared with each other, or values obtained with exact rounding in the form "a / b" (a and b integers) are compared with each other, they may be equal (in that case they are judged as equal).
- The exact value of every output real is at least 10^-9 away from the exact halfway point of rounding.
