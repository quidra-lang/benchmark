[Overview]
Write a program that performs link analysis of a Web graph from data on pages and links collected by crawling the Web. The input is the four files in the input/ folder (the page list, the link list, the queries and the settings), and the results are written to six files in the output/ folder. Nothing is printed to standard output.
First, the program checks the links and builds a directed graph, and examines the degree distributions, the reciprocal links, the clustering coefficients and k-cores of the graph viewed as an undirected graph, the strongly connected components and the bow-tie structure, and the distances between pages. Next, it computes PageRank by the power method and its variants (CheiRank with the links reversed, TrustRank starting from trusted pages, personalized PageRank for each query, PageRank with other damping factors, and weighted PageRank at the host level), and ranks and compares them together with HITS on the whole graph and harmonic centrality. Further, it detects top pages with low trust as suspected spam and computes PageRank with their influence removed, and for each query it builds a root set and a base set and finds hubs and authorities with HITS and SALSA.
No random numbers are used. All iteration counts are determined by the settings, and the result is uniquely determined. The only real-number operations used in the computation are the four arithmetic operations (+ - * /) and the square root.

[Input files]
The input files are the four files input/pages.csv, input/links.csv, input/queries.txt and input/params.txt. Every file consists of ASCII characters only, and every line (including the last one) ends with a newline (LF). There are no spaces at the beginning or end of a line, and there are no empty lines.
Integers are decimal numbers without extra leading zeros. Decimals are decimal numbers consisting of a sequence of one or more digits (the integer part), ".", and a sequence of one or more digits (the fractional part), in this order (examples: 0.85, 0.0001).

== input/pages.csv (the page list) ==
The first line is a header line, the string id,host,title. Each line from the second line on represents one page: the page's id, host name and title, in this order, separated by commas (,).
- The id is an integer from 1 to 9999 inclusive, and is different for each page.
- The host name is a string of 1 to 30 characters consisting of lowercase letters, digits, "." and "-".
- The title is 1 to 8 words, each consisting of 1 to 12 lowercase letters, separated by single spaces. The words contained in a title are called its "title words".
The lines are in arbitrary order (not necessarily in id order).

== input/links.csv (the link list) ==
The first line is a header line, the string src,dst. Each line from the second line on is the record of one link: the id of the source page and the id of the destination page of the link, in this order, separated by a comma. Both are integers from 1 to 9999 inclusive, but the file may contain ids that are not in pages.csv, duplicates of the same record, and records whose source and destination are the same (how they are handled is defined in section 2 of [Processing]).
The lines of the file are numbered in order, with the header line as line 1 (the first record is line 2).

== input/queries.txt (the queries) ==
Each line is one query; starting from line 1, they are called query 1, query 2, .... Each line consists of the sequence of query words, a single space, "|", a single space, and the sequence of seed page ids, in this order (example: coffee -cheap | 4005).
- The sequence of query words is 1 to 4 distinct query words separated by single spaces. A query word is either a word of 1 to 12 lowercase letters (an "include word") or "-" followed by a word of 1 to 12 lowercase letters (an "exclude word"). Every line contains at least one include word.
- The sequence of seed page ids is 1 to 5 distinct ids that are in pages.csv, separated by single spaces.

== input/params.txt (the settings) ==
It consists of the following 11 lines, in this order. Each line is a keyword followed by one or more values, separated by single spaces.
- DAMPING d: the damping factor (a decimal greater than 0 and less than 1).
- PAGERANK_ITERATIONS T: the number of PageRank iterations (an integer from 10 to 100 inclusive).
- TOLERANCE eps: the threshold of the L1 change below which an iteration is regarded as converged (a positive decimal).
- DAMPING_SWEEP d_1 d_2 ...: the sequence of damping factors used for comparison (1 to 5 decimals, each greater than 0 and less than 1).
- TRUSTED t_1 t_2 ...: the sequence of ids of the trusted pages (1 to 10 distinct ids that are in pages.csv).
- SPAM_TOP R: the number of top pages examined for suspected spam (an integer from 1 to n inclusive, where n is the number of pages).
- SPAM_THRESHOLD tau: the threshold for the trust ratio (a positive decimal).
- HITS_ITERATIONS K: the number of HITS iterations (an integer from 1 to 100 inclusive).
- TOP_K k: the number of pages listed in a top list (an integer from 1 to 20 inclusive).
- ROOT_LIMIT r: the maximum number of pages in a root set (an integer from 1 to 100 inclusive).
- NEIGHBOR_LIMIT L: the maximum number of neighboring pages added to a base set (an integer from 1 to 100 inclusive).

[Processing]
== 1. Notation and computation rules ==
- Let n be the number of pages. "Page order" is increasing order of id. Whenever pages are listed or summed, this is done in page order unless stated otherwise.
- "Host order" is the ASCII order of host names (compare the character codes one character at a time from the beginning; at the first differing character, the string with the smaller character comes first; when one string is a prefix of the other, the shorter one comes first).
- A link whose source is u and whose destination is v is written u -> v.
- A sum of real numbers starts from 0 and adds one term at a time in the stated order (page order if no order is stated). |x| is the absolute value of x, and sqrt is the square root.
- The "6-decimal value" of a real number x is x rounded to 6 decimal places (the same as the value written to the output files). Likewise, the "4-decimal value" is x rounded to 4 decimal places. Many of the comparisons for ranking and selection are made on 6-decimal values; whenever that is the case, it is always stated explicitly.
- The "reduced fraction" of a ratio of integers a / b (b > 0) is a and b each divided by the greatest common divisor of |a| and b (when a = 0 it is 0/1).
- When page v can be reached from page u by following zero or more links in their direction, we say that "u can reach v" (or that "v is reachable from u"); every page can reach itself. For a set of pages X, "reachable from X" means reachable from some page of X.

== 2. Reading the links ==
Examine the records of links.csv in line-number order, and classify each record as an "ignored record" or an "accepted link" by the following rules.
1. If the source id or the destination id is not in pages.csv: the record is ignored with reason unknown.
2. If 1 does not apply and the source and the destination are the same: the record is ignored with reason self.
3. If neither 1 nor 2 applies and a record with the same source and destination has already been accepted earlier: the record is ignored with reason duplicate.
4. Otherwise, the record is accepted.
Let E be the set of accepted links and m their number. Every "link" below is a link of E.
- The out-neighbors of page u are the pages v with u -> v, and the in-neighbors of u are the pages v with v -> u; listed in page order, they are called the "out-neighbor list" and the "in-neighbor list". Their numbers are the out-degree out(u) and the in-degree in(u).
- A page with out-degree 0 is called a "dangling page".
- A link u -> v is an "intra-host link" when u and v have the same host name, and an "inter-host link" when their host names differ.

== 3. Graph statistics ==
(1) Basic values
- Reciprocal links: let r be the number of links u -> v for which the reverse link v -> u is also in E (u -> v and v -> u are each counted as one link). The reciprocity is the reduced fraction of r / m.
- The mean degree is m / n.
- List the pages with no in-neighbors (the pages with in-degree 0) and the dangling pages, each in page order.
- Find the maximum in-degree and all pages that have it, and the maximum out-degree and all pages that have it.
- In-degree distribution: for each value x, the number of pages with in-degree x. The out-degree distribution is defined likewise.
(2) Undirected graph
Pages u and v (u != v) are "adjacent" when at least one of u -> v and v -> u is in E. Consider the undirected graph whose edges are given by this relation, and call the number of pages adjacent to page v the "undirected degree" g(v) of v.
- Number of undirected edges: the number of (unordered) pairs of adjacent pages.
- For page v, let c(v) be the number of (unordered) pairs of pages adjacent to v whose two pages are also adjacent to each other.
- The transitivity is the reduced fraction of (sum of c(v)) / (sum of g(v) * (g(v) - 1) / 2). Both sums are taken only over the pages v with g(v) >= 2.
- The average clustering coefficient is obtained by computing, for each page v with g(v) >= 2, the local clustering coefficient c(v) / (g(v) * (g(v) - 1) / 2), and dividing their sum (in page order) by the number of pages with g(v) >= 2.
- k-core: the k-core number of each page is determined by the following procedure. Initially all pages remain, and the remaining degree of each page is its undirected degree. Starting from j = 0, repeat the following until no page remains. If a remaining page with remaining degree j or less exists, remove one of them, set its k-core number to j, and decrease by 1 the remaining degree of each remaining page adjacent to it. If no remaining page has remaining degree j or less, increase j by 1. (Whatever removal order is chosen, the k-core number of each page is the same.) The maximum k-core number is called the "degeneracy".
(3) Strongly connected components
A maximal set of pages that can all reach one another is called a strongly connected component. Number the strongly connected components 1, 2, 3, ... in increasing order of the smallest id of the pages they contain.
- Largest strongly connected component: the strongly connected component with the most pages (on a tie, the one with the smaller number). It is called the "core component".
- A strongly connected component with exactly one page is called a "singleton component".
- For a strongly connected component X, its "incoming links" are the links from outside X into X, and its "outgoing links" are the links from inside X to outside X. A strongly connected component with 0 outgoing links and 2 or more pages is called a "sink component".
- Condensation graph: the graph whose nodes are the strongly connected components, with an edge from A to B whenever there is at least one link from a page of component A to a page of component B (A != B). Find its number of edges (the number of ordered pairs (A, B)). The depth of the condensation graph is the maximum number of edges contained in a path of the condensation graph (0 if there are no edges).
- Weakly connected components: the maximal sets of pages that are connected when the direction of the links is ignored. Find their number and the number of pages of the largest one.
(4) Bow-tie structure
Relative to the core component, assign each page to one of the following regions. Check them from the top; the first one that applies is the page's region.
1. CORE: pages of the core component.
2. IN: pages that can reach a page of the core component.
3. OUT: pages reachable from the core component.
4. TUBE: pages that are reachable from a page of the IN region and can reach a page of the OUT region.
5. IN_TENDRIL: pages reachable from a page of the IN region.
6. OUT_TENDRIL: pages that can reach a page of the OUT region.
7. OTHER: all other pages.
"Region order" is the order CORE, IN, OUT, TUBE, IN_TENDRIL, OUT_TENDRIL, OTHER. For each pair of regions (A, B), count the number of links from a page of region A to a page of region B.
(5) Distances and harmonic centrality
The distance dist(u, v) from page u to page v is the minimum number of links followed to get from u to v (it is undefined when u cannot reach v).
- Reachable pairs: the ordered pairs (u, v) with u != v such that u can reach v. Let P be their number and Q the sum of their distances. The average distance is the reduced fraction of Q / P.
- The diameter is the maximum distance D over the reachable pairs. Among the pairs attaining the diameter, the one whose u is earliest in page order, and on a tie the one whose v is earliest in page order, is called the "diameter pair".
- Distance distribution: for each x = 1, 2, ..., D, the number of reachable pairs at distance x.
- Effective diameter: the smallest x such that 10 times the number of reachable pairs at distance x or less is at least 9 * P (compared as integers).
- The harmonic centrality H(v) of page v is the sum of 1 / dist(u, v) over all pages u other than v that can reach v (added in page order of u).

== 4. The PageRank procedure ==
This section defines a computation procedure common to several PageRank variants. The procedure receives the following.
- A sequence of nodes (its order is called the "node order") and weighted edges from a node u to a node v (the weight w(u, v) is a positive integer). Let W(u) be the sum of the weights of the edges leaving node u; a node with W(u) = 0 is called a "dangling node".
- A teleport set S (let s be its number of nodes), a damping factor d, and an iteration count T.
The computation is as follows. Every sum is added in node order.
1. Initial values: x_v = 1 / s for each node v of S, and x_v = 0 for every other node.
2. For t = 1, 2, ..., T in this order, do the following.
  (a) Dangling mass Dg = (sum of x_u over the dangling nodes u)
  (b) Teleport value b = ((1 - d) + d * Dg) / s
  (c) For each node v, inflow c_v = (sum of (x_u * w(u, v)) / W(u) over each node u with w(u, v) > 0; u in node order)
  (d) For each node v, new value y_v = d * c_v + b (when v is a node of S), y_v = d * c_v (otherwise)
  (e) L1 change delta_t = (sum of |y_v - x_v| over each node v)
  (f) Replace x_v with y_v at every node.
3. The x_v after the T iterations is the value of node v.
4. The convergence point converged_at is the smallest t (1 <= t <= T) with delta_t < eps. If there is no such t, it is "none".
When the procedure is used on the page graph, the nodes are the pages (node order is page order), the edges are the links u -> v, and all weights are 1 (then W(u) is the out-degree, (x_u * 1) / W(u) has the same value as x_u / out(u), and the dangling nodes are the dangling pages). The same eps is used for the convergence test of every PageRank.

== 5. Page scores ==
Compute the following scores.
- PageRank: the values of the procedure of section 4 on the page graph with S = all pages, damping factor d and iteration count T.
- CheiRank: the values of the procedure of section 4 on the graph with every link reversed (link u -> v becomes edge v -> u, with weight 1), with S = all pages, damping factor d and iteration count T. The dangling nodes are then the pages with in-degree 0.
- TrustRank: the values of the procedure of section 4 on the page graph with S = the TRUSTED pages, damping factor d and iteration count T.
- Trust ratio: TrustRank / PageRank (PageRank is always positive).
- Trust distance: the minimum distance from a TRUSTED page (0 for the TRUSTED pages). A page that is not reachable from any TRUSTED page has trust distance -1.
- Authority score and hub score: the values obtained by iterating the HITS of section 6 (1) K times, with all pages as the set of nodes and all inter-host links as the set of edges.
- Harmonic centrality: H(v) of section 3 (5).
The "rank" by a score is a page's position (starting from 1) when the pages are sorted by the 6-decimal value of the score in decreasing order (on a tie, by id in increasing order). The "top list" by a score is obtained by taking, from the front of this order, at most k of the pages whose 6-decimal value is greater than 0. The rank by PageRank is called the "PageRank rank".
- Dangling mass: the sum of the PageRank of the dangling pages.
- Contribution: the contribution of link u -> v is (d * (PageRank of u)) / out(u). The "main contributors" of page v are the first at most 3 in-neighbors of v when they are sorted by the 6-decimal value of the contribution in decreasing order (on a tie, by id in increasing order).

== 6. HITS and SALSA ==
(1) HITS
It receives a set of nodes B (a set of pages) and a set F of links whose both ends are in B, and gives each page v in B an authority score a_v and a hub score h_v.
1. Initial values: a_v = 1 and h_v = 1 for every v in B.
2. Perform the following iteration the specified number of times.
  (a) For each v in B, A_v = (sum of h_u over each u with a link u -> v in F; u in page order)
  (b) For each u in B, H_u = (sum of A_v over each v with a link u -> v in F; v in page order; use the A_v computed in (a))
  (c) Let Na = sqrt((sum of A_v * A_v over v in B)) and Nh = sqrt((sum of H_u * H_u over u in B)), and set a_v = A_v / Na and h_u = H_u / Nh.
If F is not empty, Na and Nh are positive. The values of pages not in B are regarded as 0.
(2) SALSA
For B and F (F is not empty), the values are computed as follows.
- The pages that are the destination of some link of F are the "authority-side pages"; let A_s be their set, and let in_F(v) be the in-degree of page v in F (the number of links u -> v in F).
- Two authority-side pages are directly connected when some page links to both of them by links of F; a maximal set of pages that can be reached from one another by following direct connections is an "authority-side component".
- For a component C, let |C| be its number of pages and E_C the sum of in_F over the pages of C; the SALSA authority score of a page v of C is (|C| * in_F(v)) / (|A_s| * E_C). Compute the numerator and the denominator as integers and divide only once at the end.
- The hub side is analogous. Let H_s be the set of pages that are the source of some link of F, and out_F(u) the out-degree of page u in F; two hub-side pages are directly connected when some page is linked from both of them by links of F. For a hub-side component C, the SALSA hub score is (|C| * out_F(u)) / (|H_s| * E_C) (E_C is the sum of out_F over the pages of C).
- The values of pages not on the authority side (hub side) are regarded as 0.

== 7. Rank comparison ==
(1) Rank correlation
Kendall's rank correlation coefficient of two integer sequences x and y (each with one value per page) is defined as follows. For every pair of pages (i, j) with i < j in page order, the pair is "concordant" if x_i - x_j and y_i - y_j are both positive or both negative, "discordant" if one is positive and the other is negative, and neither otherwise (when either is 0); the coefficient is the reduced fraction of (number of concordant pairs - number of discordant pairs) / (n * (n - 1) / 2).
The quantities compared are the following 7 (this order is called the "quantity order"): in_degree (in-degree), pagerank, cheirank, authority, hub, trustrank, harmonic (PageRank, CheiRank, authority score, hub score, TrustRank and harmonic centrality, respectively). The in-degree is used as it is; for the other quantities, the integer obtained by multiplying the 6-decimal value by 10^6 is used. Compute the rank correlation for every pair (A, B) in which A comes before B in quantity order.
(2) Damping factor comparison
For each damping factor d' of DAMPING_SWEEP (in sequence order), perform the procedure of section 4 on the page graph with S = all pages, damping factor d' and iteration count T; its values are called the "comparison PageRank". The rank by the comparison PageRank is called the "comparison rank".
- Overlap: the number of pages contained both in the pages with PageRank rank k or less and in the pages with comparison rank k or less.
- Footrule distance: the sum of |comparison rank - PageRank rank| over all pages.
- Rank correlation: the rank correlation of (1) between the 6-decimal values of PageRank and the 6-decimal values of the comparison PageRank (both as integers multiplied by 10^6).
- Largest shift: the page with the largest |comparison rank - PageRank rank| (on a tie, the one with the smaller id).
- Comparison top: the pages with comparison rank 1 to k.

== 8. Spam detection and demotion ==
(1) Suspected spam
Among the pages with PageRank rank R or less, those whose trust ratio has a 4-decimal value less than tau are the "suspect pages"; they are listed in PageRank rank order.
(2) Totals by trust distance
For each value that occurs as the trust distance of some page (the values 0 or greater in increasing order, then -1), find the number of pages with that trust distance, the sum of their TrustRank and the sum of their PageRank.
(3) Demotion
When there is at least one suspect page, the set of host names of those pages (without duplicates, sorted in host order) is called the "suspect hosts", and every link whose two end pages both have the same suspect host as their host name (the intra-host links of the suspect hosts) is removed. On the page graph with only the remaining links (the dangling nodes are the pages whose out-degree among the remaining links is 0), the values of the procedure of section 4 with S = all pages, damping factor d and iteration count T are called the "demoted PageRank", and the rank by it is called the "demoted rank".

== 9. Query processing ==
For each query, do the following in order.
(1) Matching pages: the pages whose title words contain all of the include words and none of the exclude words. Their number is the "match count". The matching pages listed in PageRank rank order are the "search results".
(2) Root set: the set of the first at most r pages of the search results.
(3) Base set: the set of pages consisting of the pages of the root set plus, for each page p of the root set, the first at most L pages of the out-neighbor list of p and the first at most L pages of the in-neighbor list of p.
(4) Subgraph: let F be the set of inter-host links among the links whose both ends are in the base set. The number of intra-host links whose both ends are in the base set is the number of "dropped intra-host links".
(5) Personalized PageRank: the values of the procedure of section 4 on the page graph with S = the seed pages, damping factor d and iteration count T. The number of pages reachable from the seed pages is the "reach count", and the sum of the personalized PageRank of the seed pages is the "seed mass". Find the top list of the personalized PageRank (by the same rules as in section 5); the number of pages in it with PageRank rank k or less is the "overlap with global".
(6) HITS and SALSA: when F is not empty, iterate the HITS of section 6 (1) K times with the base set as B, and compute the SALSA of section 6 (2). Find the top list (by the same rules as in section 5) for each of the HITS authority score, the HITS hub score, the SALSA authority score and the SALSA hub score.
- Authority overlap: the number of pages contained both in the top list of the HITS authority score and in the top list of the SALSA authority score. The hub overlap is defined likewise.
- Authority host count: the number of distinct host names of the pages in the top list of the HITS authority score.
- Co-citation: let p be the first page of the top list of the HITS authority score. Let Ci be the set of in-neighbors of p; for each page q other than p, the co-citation count of q is the number of pages of Ci that have a link to q. The first at most k pages with a positive co-citation count, sorted by co-citation count in decreasing order (on a tie, by id in increasing order), are the "related pages".
- Bibliographic coupling: let p' be the first page of the top list of the HITS hub score. Let Ct be the set of out-neighbors of p'; for each page q other than p', the coupling count of q is the number of pages of Ct that are linked from q. The first at most k pages with a positive coupling count, sorted by coupling count in decreasing order (on a tie, by id in increasing order), are the "similar pages".
The in-neighbors, out-neighbors and links here are those of the whole of E, not of the subgraph.

== 10. Host graph ==
Group the pages by host name and build a graph whose nodes are the hosts, arranged in host order. For each inter-host link u -> v, increase by 1 the weight from the host of u to the host of v (intra-host links do not become edges).
- Host PageRank: the values of the procedure of section 4 on this graph (node order is host order) with S = all hosts, damping factor d and iteration count T. The host rank is a host's position when the hosts are sorted by the 6-decimal value of the host PageRank in decreasing order (on a tie, in host order).
- For each host, find the number of pages, the number of pages in the CORE region, the number of intra-host links, the intra-host link density (with p the number of pages: number of intra-host links / (p * (p - 1)) if p >= 2, and 0 if p = 1), the number of outgoing inter-host links, the number of incoming inter-host links, the number of dangling pages, the sum of the PageRank of its pages (in page order), and the representative page (the page with the smallest PageRank rank).
- Find the number of edges of the host graph (the number of ordered pairs (G, H) with positive weight), the number of reciprocal edges (the number of pairs (G, H) with positive weight for which (H, G) also has positive weight), the number of strongly connected components of the host graph, and the number of hosts of the largest one.
- Heavy edges: the first at most k edges of the host graph when sorted by weight in decreasing order, on a tie in host order of the source host, and on a further tie in host order of the destination host.

[Output files]
Write the six files output/graph_stats.txt, output/pagerank.csv, output/rankings.txt, output/convergence.txt, output/queries.txt and output/hosts.csv.

== Common rules ==
- Output consists of ASCII characters only, and every line (including the last one) ends with a newline (LF). Put no extra spaces at the beginning or end of a line, and insert no empty lines other than those specified.
- In the formats below, each part enclosed in < > is replaced by a value, and all other characters are written as they are. Values are separated by a single space (by a comma in .csv files). A part followed by "...", such as "<id>...", means that the values are listed separated by single spaces. When there are no values to list, the single space immediately before them is not written either.
- Integers are written as decimal numbers without extra leading zeros (negative numbers are prefixed with -).
- Real numbers are rounded to the specified number of decimal places (6, 4 or 10) and written in fixed-point notation with exactly that many digits after the decimal point (example: 0.0012345 written with 6 decimals is 0.001235). Exponential notation is not used, and when the integer part is 0, 0 is written. Negative numbers are prefixed with -, but a value that becomes 0 after rounding is written without -. Real numbers below whose number of decimals is not stated are written with 6 decimals.
- A value described as a "fraction" is the reduced fraction written in the form <numerator>/<denominator> <value>. <value> is numerator / denominator as a real number written with 4 decimals (example: 3/8 0.3750).
- A "rank line" is a line of the following form. <rank> is the position in that list (the first is 1), and <value> is the score used by that list (6 decimals).
<rank> <id> <value> <host name> <title>
The title is written as in the input (with a single space between words).

[Source files]
Split the program into the following six source files (the file names follow the conventions of each language).
- main: handles the overall flow and most of the processing: checking the links and building the neighbor lists, the graph statistics (degrees and their distributions, reciprocal links, the transitivity, clustering coefficients and k-cores of the undirected graph, the table of strongly connected components and the condensation graph, the bow-tie structure and the links between regions, the distance distribution and harmonic centrality), calling the various PageRank computations and HITS, ranking and top lists, contributions, rank correlations, the damping factor comparison, spam detection and demotion, query processing (the match test, root set, base set, subgraph, SALSA, co-citation and bibliographic coupling), the host graph, and assembling the contents of the six output files.
- graph_io: reads the four input files and returns the page list, the sequence of link records, the sequence of queries and the setting values.
- components: strongly connected component decomposition (Tarjan's algorithm, implemented without recursion, with an explicit stack), reachability search from multiple start pages, distances by breadth-first search, and weakly connected components.
- pagerank: the computation procedure of section 4 (weighted edges, the teleport set, the dangling mass, and recording the L1 change of each iteration).
- hits: the HITS iteration of section 6 (1) (updating the values and L2 normalization).
- report: formatting of real numbers (the number of decimals, rounding, handling of -0), formatting of fractions (including the computation of the reduced fraction), and writing a sequence of lines to a file.

[Constraints]
- 2 <= n <= 500, links.csv has from 1 to 6000 records, and 1 <= m. There are from 1 to 20 queries.
- The given data have n = 386 (26 hosts), 3114 records (m = 3085) and 11 queries, with d = 0.85, T = 40, K = 30 and k = 10. The distance computation follows about 1.05 million links in total, the rank correlations examine the pairs of pages (about 74,000 pairs) 24 times, and the procedure of section 4 is performed 19 times (760 iterations in total).
- The input files follow the formats above exactly. There is no need to check for input errors.
- There is at least one page with g(v) >= 2, and there is at least one inter-host link.
- Every integer appearing in the computation is less than 2^31.
- In the given data, every real number output is sufficiently far from a rounding boundary. Also, the comparisons by 6-decimal and 4-decimal values, the comparisons with thresholds and the determination of the convergence points have enough margin that they are not changed by differences in the order of additions, by fused multiply-add (computing a * b + c with a single rounding), or by differences in the last digit of square root results. Every L1 change is greater than 10^-6, and its difference from eps is greater than 0.5% of eps. Nevertheless, compute with the formulas and in the order defined in this statement.
