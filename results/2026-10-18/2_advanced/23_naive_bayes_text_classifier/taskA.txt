[Overview]
Write a program that classifies short English news articles into their field (class). The classifiers are three naive Bayes models (the multinomial model multinomial, the Bernoulli model bernoulli and the complement model complement) and, for comparison, a Rocchio classifier (cosine similarity between TF-IDF vectors and class centroids).
From the text of a document, the program extracts runs of letters and digits as words, removes stopwords and one-character words, and adds pairs of adjacent words (bigrams) to obtain a sequence of "terms". It selects a vocabulary by document frequency and the chi-square statistic, and selects the naive Bayes smoothing parameter alpha by 5-fold cross-validation. It classifies the test documents with the selected models and evaluates them, together with a majority vote of the four classifiers. In addition, it computes a learning curve, a comparison by vocabulary size and with or without bigrams, an evaluation of the posterior probabilities, the accuracy per document length, a comparison of the models by the McNemar statistic and the bootstrap, an analysis of misclassifications, a list of characteristic terms per class, and semi-supervised learning by EM using unlabelled documents.
The input is five files in the input/ folder (training documents, test documents, unlabelled documents, stopwords, settings), and the results are written to seven files in the output/ folder. Nothing is written to standard output. Random numbers are used only in the bootstrap, with a specified generator. Since every rule is fully specified, the result is uniquely determined.

[Input files]
There are five input files: input/train.txt, input/test.txt, input/unlabelled.txt, input/stopwords.txt and input/params.txt. Every file consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). There are no empty lines.
A "text" is a string of one or more characters consisting only of characters with character codes 32 to 126 (including the space). The tab character (character code 9) never appears in a text; it is used only as the value separator in train.txt and test.txt.

* input/train.txt (training documents)
Each line is one "training document", consisting of a class, one tab character and a text, in this order. A class is a string of 1 to 16 lowercase English letters.
The training documents are numbered 1, 2, 3, ... in order from the first line of the file; this number is called the "document number". Let N be the number of training documents. The order of document numbers is called the "training order".

* input/test.txt (test documents)
Each line is one "test document", consisting of an ID, one tab character, a class or "?", one tab character and a text, in this order. An ID is a string of 1 to 8 characters consisting of uppercase English letters and digits; the IDs are distinct from each other.
A test document whose class is "?" is a document whose correct class is unknown. Every other test document is called a "labelled test document", and its class is called its "true class". A true class is always a class that appears in the training documents.
The order of the lines in the file is called the "test order". Let N_test be the number of test documents and L the number of labelled test documents.

* input/unlabelled.txt (unlabelled documents)
Each line is the text of one "unlabelled document". The order of the lines in the file is called the "unlabelled order", and the number of unlabelled documents is U.

* input/stopwords.txt (stopwords)
Each line is one stopword, a string of 1 to 16 lowercase English letters. The stopwords are distinct from each other, and their order has no meaning.

* input/params.txt (settings)
It consists of the following 12 lines, in this order. Each line is a keyword followed by one or more values, separated by single spaces. An integer is a base-10 number without extra leading zeros. A "two-decimal number" is a base-10 number consisting of, in this order, a sequence of one or more digits (the integer part, without extra leading zeros), ".", and a sequence of exactly two digits (examples: 0.05, 1.00, 12.50).
- ALPHAS alpha_1 alpha_2 ...: the candidates for the smoothing parameter alpha (distinct positive two-decimal numbers, in increasing order).
- MIN_DF k: the lower limit of the document frequency of a term put into the vocabulary (a positive integer).
- FEATURES m: the number of terms selected by chi-square (an integer >= 0; 0 means no selection).
- BIGRAMS yes or BIGRAMS no: whether bigrams are used.
- TOP T: the number of entries in the lists (a positive integer).
- CURVE s_1 s_2 ...: the numbers of training documents used for the learning curve (distinct positive integers, in increasing order; each is <= N).
- SIZES m_1 m_2 ...: the numbers of terms selected by chi-square, used for the feature comparison (distinct integers >= 0; they are used in the order written; 0 means no selection).
- THRESHOLDS t_1 t_2 ...: the thresholds of the posterior probability (distinct two-decimal numbers greater than 0 and less than 1, in increasing order).
- LENGTHS e_1 e_2 ...: the boundaries of the document length buckets (distinct positive integers, in increasing order).
- EM_ITERATIONS R: the number of EM iterations (a positive integer).
- EM_WEIGHT lambda: the weight applied to the unlabelled documents in EM (a two-decimal number greater than 0 and <= 1).
- BOOTSTRAP B S: the number B of bootstrap repetitions (a positive integer) and the random seed S (an integer from 1 to 2147483646).

[Processing]
* 1. Notation and computation rules
- The order of strings (class order, term order) is the lexicographic order by ASCII character code (compare one character at a time from the start; the string whose first differing character has the smaller code comes first; if one string is a prefix of the other, the shorter one comes first).
- The set of all classes that appear in the training documents is called the "class set", and the class set sorted in string order is called the "class order". Let K be the number of classes.
- log is the natural logarithm, exp is the exponential function, sqrt is the square root, |x| is the absolute value of x, and max and min are the maximum and the minimum. floor(x) is the largest integer <= x, and x mod y is the remainder of dividing an integer x >= 0 by a positive integer y. x^2 means x * x.
- Real numbers are computed in double-precision floating point. When a fraction p / q of integers p and q is converted to a real number, the integers p and q are computed first and then exactly one division is performed (this is written "computed with one division").
- SUM (written in place of the summation sign) denotes the sum obtained by adding the terms one at a time from the start, in the indicated order. Its initial value is 0.
- The "hundredfold value" of a two-decimal number is the integer equal to 100 times that value (examples: the hundredfold value of 0.05 is 5, the hundredfold value of 1.00 is 100). In formulas, alpha, the thresholds and lambda are expressed through their hundredfold values.
- The "4-decimal value" of a real number v is v rounded to 4 decimal places (the same value as written to the output files).
- There are five "models": multinomial, bernoulli, complement, rocchio and vote; this order is called the "model order". The first three are called the "NB models", and the first four the "base models".
- Every rule that selects a maximum or minimum and every sorting rule always comes with the treatment of equal values.

* 2. Tokenization
The text of a document is converted into a "term sequence" as follows.
(1) Words: take the parts of the text that are runs of consecutive letters (A-Z, a-z) and digits (0-9) that cannot be extended further either backward or forward (every character other than a letter or digit is a separator), in their order in the text, and convert uppercase letters to lowercase; each result is called a "word" (example: the words of "O'Brien's 2.5-inch TV" are the 7 words o, brien, s, 2, 5, inch, tv).
(2) Word classification: a word that equals one of the stopwords is a "stopword"; otherwise, a word of one character is a "short word"; a word that is neither is a "kept word".
(3) Word sequence: the kept words in their order in the text form the "word sequence" w_1, w_2, ..., w_k.
(4) Bigrams: for i = 1, ..., k - 1, the string obtained by concatenating w_i, "_" (underscore, character code 95) and w_(i+1) in this order is the i-th "bigram" (example: if the word sequence is summer, song, festival, the bigrams are summer_song and song_festival). If k <= 1, there are no bigrams.
(5) Term sequence: words and bigrams together are called "terms". There are the following two kinds of term sequences.
- The unigram term sequence: w_1, ..., w_k
- The bigram term sequence: w_1, ..., w_k followed by the 1st through the (k - 1)-th bigrams in this order
Since a word never contains "_", a word and a bigram are never the same string. If BIGRAMS is yes, the bigram term sequence is the "term sequence" of the document; if it is no, the unigram term sequence is. Every process except the feature comparison of section 11 uses this term sequence.
(6) For a document x and a term t, the number of times t appears in the term sequence of x is written tf(t, x).

* 3. Building a vocabulary
From a sequence D of training documents (M documents) and an integer m >= 0, a "vocabulary" is built as follows. Unless stated otherwise, the term sequences are those of section 2 (5) and m is the value of FEATURES.
(1) Document frequency: for a term t, df(t) is the number of documents of D whose term sequence contains t at least once. A term that appears in the term sequence of some document of D is called a "term of D".
(2) Candidates: the terms of D with df(t) >= MIN_DF are the "candidates".
(3) Chi-square: for each candidate t and each class c, let M_c be the number of documents of D whose class is c, and compute the following four counts.
- A: the number of documents whose class is c and in which t appears
- B = df(t) - A: the number of documents whose class is not c and in which t appears
- C = M_c - A: the number of documents whose class is c and in which t does not appear
- E = M - M_c - B: the number of documents whose class is not c and in which t does not appear
Compute the integers X = M * (A * E - B * C)^2 and Y = df(t) * (M - df(t)) * M_c * (M - M_c). If Y = 0, chi2(t, c) = 0; otherwise chi2(t, c) = X / Y (computed with one division).
The "chi-square value" chi2(t) of t is the maximum of chi2(t, c) over all classes. The class with the largest chi2(t, c) (ties: the one earlier in class order) is the "best class" of t.
(4) Ranking: the candidates sorted in decreasing order of chi-square value (ties: in term order) form the "chi-square ranking".
(5) Vocabulary: if m > 0 and there are more than m candidates, the first m terms of the chi-square ranking form the "vocabulary"; otherwise all candidates form the vocabulary. The vocabulary terms sorted in term order are called the "vocabulary order", and V is the number of vocabulary terms.
(6) The "vocabulary term sequence" of a document x is the sequence obtained by removing from the term sequence of x every term not in the vocabulary (the remaining terms keep their order). Its length (the total number of occurrences of vocabulary terms) is called the "length" of x. The "first-occurrence sequence" is the sequence obtained by removing from the vocabulary term sequence every term that has already appeared earlier in it.

* 4. Naive Bayes models
Training an NB model with alpha (hundredfold value a) on a sequence D of training documents and the vocabulary built from D by section 3 means computing the following values. c is a class and t is a vocabulary term.
- M_c: the number of documents of D whose class is c. M is the number of documents of D.
- n(t, c): the sum of tf(t, x) over the documents x of D of class c. T_c is the sum of n(t, c) over all vocabulary terms.
- n(t) = SUM n(t, c) (sum over all classes), T = SUM T_c, nbar(t, c) = n(t) - n(t, c), Tbar_c = T - T_c (the number of occurrences in documents of classes other than c, and its total).
- d(t, c): the number of documents of D of class c whose term sequence contains t.
- The log prior P_c = log(M_c / M).
These values are integers (except P_c), so they do not depend on the summation order. The "class score" s_c of a document x for a class c is computed per model as follows. Every fraction is computed with one division before the log is taken.
(1) multinomial: for each vocabulary term t, let w(t, c) = log((100 * n(t, c) + a) / (100 * T_c + a * V)). s_c is obtained by starting from 0, adding w(t, c) for each term t of the vocabulary term sequence of x in order, and finally adding P_c.
(2) bernoulli: for each vocabulary term t, let p(t, c) = (100 * d(t, c) + a) / (100 * M_c + 2 * a) and q(t, c) = (100 * (M_c - d(t, c)) + a) / (100 * M_c + 2 * a), and let G_c = SUM log q(t, c) (sum in vocabulary order). s_c is obtained by starting from G_c, adding (log p(t, c) - log q(t, c)) (the subtraction is performed first) for each term t of the first-occurrence sequence of x in order, and finally adding P_c. This is the same (except for rounding errors) as adding log p(t, c) for the vocabulary terms that appear in x and log q(t, c) for the vocabulary terms that do not.
(3) complement: for each vocabulary term t, let theta(t, c) = (100 * nbar(t, c) + a) / (100 * Tbar_c + a * V). s_c is obtained by starting from 0, subtracting log theta(t, c) for each term t of the vocabulary term sequence of x in order, and finally adding P_c (the more often a term appears in documents of classes other than c, the lower it makes the class score of class c).

* 5. Posterior probabilities and prediction (NB models)
From the class scores s_c of an NB model, the following are computed.
- The predicted class c_hat: the class with the largest s_c (ties: the one earlier in class order).
- Let Z = SUM exp(s_c - s_(c_hat)) (sum in class order); the posterior probability of class c is P(c | x) = exp(s_c - s_(c_hat)) / Z. P(c_hat | x) is called the "predicted posterior".
- The classes sorted in decreasing order of s_c (ties: in class order) form the "class ranking". Its second class is called the "runner-up class", and s_(c_hat) minus the class score of the runner-up class is called the "margin".

* 6. Rocchio classifier
Training rocchio on a sequence D of training documents and the vocabulary built from D by section 3 means computing the following values. t is a vocabulary term.
- idf(t) = log(M / df(t)) (df(t) is the document frequency in D of section 3 (1); for vocabulary terms, df(t) >= MIN_DF >= 1).
- The vector v(x) of a document x: its component for each vocabulary term t is v_t(x) = tf(t, x) * idf(t). Its length is |v(x)| = sqrt(SUM v_t(x)^2) (sum in vocabulary order).
- Centroid: the centroid g_c of class c is the vector whose component for each vocabulary term t is g_c(t) = (SUM u_t(x)) / M_c. The sum goes over the documents x of D of class c in the order of D, and u_t(x) is v_t(x) / |v(x)| if |v(x)| > 0 and 0 if |v(x)| = 0. The length of the centroid is |g_c| = sqrt(SUM g_c(t)^2) (sum in vocabulary order).
The "similarity" of a document x to a class c is (SUM v_t(x) * g_c(t)) / (|v(x)| * |g_c|) if |v(x)| > 0 and |g_c| > 0 (the sum in the numerator is in vocabulary order, and in the denominator the multiplication is performed first); otherwise it is 0. In every sum, components with v_t(x) = 0 do not change the sum and may be skipped.
The class with the largest similarity (ties: the one earlier in class order) is the predicted class, and its similarity is called the "predicted similarity". The classes sorted in decreasing order of similarity (ties: in class order) form the "class ranking". When |v(x)| = 0 (including when the vocabulary term sequence is empty), all similarities are 0, so the predicted class is the first class in class order.

* 7. Classification evaluation
For a sequence of (true class, predicted class) pairs, the following are computed.
- Confusion matrix: for each class a (row) and each class b (column) in class order, C[a][b] is the number of pairs whose true class is a and whose predicted class is b.
- For a class c, let TP = C[c][c], P = the sum of column c (the number of pairs whose predicted class is c), and A = the sum of row c (the number of pairs whose true class is c); precision = TP / P, recall = TP / A, F1 = (2 * TP) / (P + A). A is called the "support". A metric whose denominator is 0 has no value.
- Correct count: the number of pairs whose predicted class equals the true class. Micro F1 = correct count / (number of pairs) (the same as the accuracy).
- Macro F1: the F1 values (real numbers computed with one division) of the classes with P + A > 0, added in class order and divided by the number of such classes.

* 8. Cross-validation and selection of alpha
(1) Folds: the training document with document number i is put into fold ((i - 1) mod 5) + 1. For a fold f (f = 1, ..., 5), D_f is the sequence of the training documents not in fold f, in training order, and the training documents of fold f are called the "validation documents of fold f".
(2) For each fold f, build a vocabulary from D_f (section 3), train each NB model with each alpha of ALPHAS using D_f and that vocabulary (section 4), train rocchio using D_f and that vocabulary (section 6), and compute the predicted class of each validation document of fold f. This is called the "cross-validation prediction" of that training document. Each training document is predicted once for each combination of NB model and alpha, and once by rocchio.
(3) Cross-validation results: for each combination of NB model and alpha, and for rocchio, compute the evaluation (section 7) of the sequence of (class, cross-validation prediction) pairs of all training documents (in training order). Its correct count and macro F1 are called the "cross-validation correct count" and the "cross-validation macro F1". Also, for each fold f, the number of validation documents of fold f whose cross-validation prediction is correct is called the "correct count of fold f".
(4) Selection of alpha: for each NB model, the alpha with the largest 4-decimal value of the cross-validation macro F1 (ties: the smaller alpha) is the "selected alpha" of that model. From here on, in every process after cross-validation, the NB models are trained with their selected alpha. rocchio has no alpha.

* 9. Final models and prediction of the test documents
Build a vocabulary from all training documents (in training order); this is the "final vocabulary". The NB models trained with their selected alpha on all training documents and the final vocabulary, together with rocchio trained on them, are the "final models".
With the final models, compute the predicted class of every test document. The "score" of a test document is the predicted posterior for the NB models and the predicted similarity for rocchio.
vote: for each test document, count the predicted classes of the four base models as one vote each; the class with the most votes is the predicted class of vote. If two or more classes have the most votes, it is the class, among those classes, predicted by the base model that comes first in model order. The score of vote is (number of votes of the predicted class) / 4.

* 10. Learning curve
For each value s of CURVE, let D be the training documents with document numbers 1 to s (in training order); build a vocabulary from D, train each NB model with its selected alpha on D and that vocabulary, train rocchio, and compute the predicted class of each labelled test document. For each base model, compute the evaluation (section 7) of the sequence of (true class, predicted class) pairs (in test order).

* 11. Feature comparison
For each kind of term sequence, unigrams (the unigram term sequence) and bigrams (the bigram term sequence) (in this order, independent of the value of BIGRAMS), and for each value m of SIZES (in SIZES order), do the following. Build a vocabulary with m from the term sequences of that kind of all training documents. Train each NB model with its selected alpha on all training documents and that vocabulary, train rocchio, compute the predicted class of each labelled test document (using the term sequence of that kind), and compute the evaluation (section 7) for each base model.

* 12. Evaluation of posterior probabilities
For each NB model, compute the following for the predictions of the final model on the labelled test documents (in test order). y is the true class and p is the predicted posterior.
- Log loss: the loss log(Z) - (s_y - s_(c_hat)) of each document, added in test order and divided by L (the loss equals -log P(y | x)).
- Brier score: for each document, compute the sum, in class order, of (P(c | x) - delta_c)^2 (delta_c is 1 if c = y and 0 otherwise); add these in test order and divide by L.
- Bins: with the values of THRESHOLDS t_1, ..., t_k, make k + 1 bins with lower bounds 0, t_1, ..., t_k. The bin with lower bound 0 consists of the documents with p < t_1, and the bin with lower bound t_j consists of the documents with t_j <= p < t_(j+1) (the last bin consists of the documents with t_k <= p). For each bin, compute the number of documents, the number of correctly predicted documents, and the mean of p (the p of the documents in the bin added in test order and divided by the number of documents).
- Thresholds: for each value t_j of THRESHOLDS, the documents with p >= t_j are the "accepted documents"; compute the number of accepted documents and how many of them are correctly predicted.
When p is compared with a threshold, the threshold is the real number (hundredfold value) / 100.

* 13. Accuracy per length
Use the lengths (section 3 (6)) of the labelled test documents in the final vocabulary. With the values of LENGTHS e_1, ..., e_k, make k + 1 buckets with lower bounds 0, e_1, ..., e_k. The bucket with lower bound 0 consists of the documents with length less than e_1, and the bucket with lower bound e_j consists of the documents with length at least e_j and less than e_(j+1) (the last bucket consists of the documents with length at least e_k). For each bucket, compute the number of labelled test documents and, for each model in model order (including vote), the number of correctly predicted documents.

* 14. Comparison of models
Sort the pairs (X, Y) of base models (X comes before Y in model order; 6 pairs in total) by the model order of X, then by the model order of Y, and for each pair compute the following from the predictions of the final models.
- Agreement count: the number of test documents (among all test documents) for which X and Y predict the same class.
- b: the number of labelled test documents for which the prediction of X is correct and the prediction of Y is not correct. c: the number of labelled test documents for which the prediction of Y is correct and the prediction of X is not correct.
- McNemar statistic: let u = (max(0, |b - c| - 1))^2; it is u / (b + c) if b + c > 0, and 0 if b + c = 0.
Also, for k = 0, 1, 2, 3, 4, compute the number of labelled test documents for which exactly k of the four base models predict incorrectly.

* 15. Bootstrap
Initialize the integer state x with the seed S, and repeat the following procedure B times (r = 1, ..., B). x keeps being updated across the B repetitions (it is not reset to the seed at each repetition).
- L times, update x to (48271 * x) mod 2147483647, and each time select one document: number the labelled test documents 0, 1, ..., L - 1 in test order and select the document with number (x mod L) (the same document may be selected any number of times).
- For each model in model order, compute the number K_r of the L selected documents (counting duplicates) for which the prediction of the final model (including vote) is correct.
For each model, compute mean = (SUM K_r) / (B * L) (computed with one division), low = the (floor(B / 40) + 1)-th value when the K_r are sorted in increasing order, and high = the (floor(B / 40) + 1)-th value when the K_r are sorted in decreasing order.
Also, for the same 6 pairs (X, Y) of base models as in section 14, compute the number of r for which K_r of X is greater than K_r of Y (wins), the number of r for which they are equal (ties), and the number of r for which it is smaller (losses).

* 16. Hard documents
A training document for which the cross-validation predictions of all four base models (for the NB models, those with the selected alpha) are incorrect is a "hard document". Compute the number of hard documents and the number per class.

* 17. Uncertain test documents
For every test document, compute the margin (section 5) of the multinomial final model. The test documents sorted in increasing order of the 4-decimal value of the margin (ties: in test order) form the "uncertainty order".

* 18. Evidence for misclassifications
A labelled test document for which the prediction of the multinomial final model is incorrect is a "misclassified document". Let a be the hundredfold value of the selected alpha of multinomial, and let n(t, c) and w(t, c) be the values (section 4) of the multinomial final model.
For a misclassified document x, let c_hat be its predicted class and y its true class, and define the "ratio" of each term t of the first-occurrence sequence of x as r(t) = (100 * n(t, c_hat) + a) / (100 * n(t, y) + a). Sort these terms in decreasing order of r(t) (ties: in term order); the first 3 (all of them if there are fewer than 3) are the "evidence terms". Ratios are compared exactly by integer comparison: r(t_1) > r(t_2) is decided as (100 * n(t_1, c_hat) + a) * (100 * n(t_2, y) + a) > (100 * n(t_2, c_hat) + a) * (100 * n(t_1, y) + a).
The "evidence value" of an evidence term t is w(t, c_hat) - w(t, y). Since r(t) and the evidence value have the same ordering up to a constant that does not depend on the term, the evidence terms are (mathematically) in decreasing order of evidence value.

* 19. Characteristic terms
For the multinomial and bernoulli final models, compute the "characteristic terms" of each class. a is the hundredfold value of the selected alpha of that model, and n(t, c), nbar(t, c), T_c, Tbar_c, d(t, c), M_c and M are the values (section 4) of the final model.
- multinomial: the "total" of class c is T_c and its "other" is Tbar_c; the "count" of a vocabulary term t is n(t, c) and its "other count" is nbar(t, c).
- bernoulli: the "total" of class c is M_c and its "other" is M - M_c; the "count" of a vocabulary term t is d(t, c) and its "other count" is dbar(t, c) (the number of documents of classes other than c in which t appears; the sum of d(t, c) over all classes minus d(t, c)).
Write h for the count, hbar for the other count, H for the total and Hbar for the other. Sort the vocabulary terms in decreasing order of the ratio (100 * h + a) / (100 * hbar + a) (ties: in term order; the comparison is decided exactly by integer multiplication, as in section 18); the first T (all of them if there are fewer than T vocabulary terms) are the characteristic terms. The "log-odds" of a term t is log((100 * h + a) / (100 * H + a * V)) - log((100 * hbar + a) / (100 * Hbar + a * V)) for multinomial, and log((100 * h + a) / (100 * H + 2 * a)) - log((100 * hbar + a) / (100 * Hbar + 2 * a)) for bernoulli (each fraction is computed with one division).

* 20. Semi-supervised learning (EM)
Starting from the multinomial final model, perform EM with the unlabelled documents R times. a is the hundredfold value of the selected alpha of multinomial, l is the hundredfold value of lambda, and lambda = l / 100 (computed with one division). The vocabulary is the final vocabulary; for the unlabelled documents too, the vocabulary term sequence and the first-occurrence sequence are built from the term sequence (section 2 (5)).
(1) The model theta^(0) is the multinomial final model.
(2) For r = 0, 1, ..., R in order, do the following with the model theta^(r).
- E step: for each unlabelled document, compute the class scores s_c of theta^(r) (section 4 (1)) and the posterior probabilities P(c | u) (section 5). u is the unlabelled document. The predicted class under theta^(r) is the "assignment" of u.
- Evaluation: with theta^(r), compute the predicted class of each labelled test document, and compute the correct count and macro F1 of the evaluation (section 7).
- Changed count: for r >= 1, the number of unlabelled documents whose assignment differs from their assignment under theta^(r-1).
- If r < R, build theta^(r+1) from the posterior probabilities of this E step by the following M step.
(3) M step: compute the following real numbers.
- n'(t, c): starting from the integer n(t, c) of the final model, go through the unlabelled documents u in unlabelled order, let w = lambda * P(c | u), and add w * tf(t, u) for each term t of the first-occurrence sequence of u.
- M'_c: starting from the integer M_c of the final model, add w = lambda * P(c | u) of each document in unlabelled order.
- T'_c = SUM n'(t, c) (sum in vocabulary order).
- D' = N + (l * U) / 100 (divide the integer l * U by 100 once, then add N).
theta^(r+1) is the multinomial model in which w(t, c) of section 4 (1) is replaced by log((100 * n'(t, c) + a) / (100 * T'_c + a * V)) and P_c by log(M'_c / D') (100 * n'(t, c) and the like are computed by real multiplication and addition).

[Output files]
Write the seven files output/vocabulary.txt, output/cv_results.csv, output/predictions.csv, output/learning_curve.csv, output/feature_study.csv, output/metrics.txt and output/top_features.txt.

* Common rules
- The output consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). Put no extra spaces at the start or end of a line, and no empty lines unless specified.
- In the formats below, parts enclosed in < > are replaced by values, and every other character is written as is. Values are separated by a single space (a single comma in .csv files). A part written like "<...> ..." means values of the same kind listed with one separator between them.
- Integers are written in base 10 without extra leading zeros.
- Real numbers are rounded to 4 decimal places and written in fixed-point notation with exactly 4 digits after the decimal point (examples: 0.5 is 0.5000, 2.71828 is 2.7183). Exponent notation is not used, and 0 is written when the integer part is 0. Negative numbers get a leading -, but a value that becomes 0 after rounding is written without - (example: -0.00004 is 0.0000). The data contain no values close to a rounding boundary.
- A value shown in a format as a division, like <correct count / L>, is the real number obtained by computing that fraction with one division, written by the real-number rule above (not in the "proportion" form below).
- alpha, thresholds and lambda are written as two-decimal numbers. If the hundredfold value is h, concatenate, in this order, the quotient of h divided by 100, ".", and the remainder of h divided by 100 written with 2 digits (with a leading 0 if it has 1 digit) (examples: hundredfold value 5 is 0.05, hundredfold value 100 is 1.00).
- A "proportion" is written in the form <a>/<b> <v>. a and b are integers and are not reduced. v is the real number a / b (example: 120/135 0.8889).
- A "reduced-fraction metric" is written in the form <p>/<q> <v>. p / q is the reduced fraction obtained by dividing the numerator and denominator of the metric by their greatest common divisor (0/1 if the numerator is 0), and v is its value as a real number (example: numerator 50 and denominator 55 give 10/11 0.9091). When there is no value, - - is written.
- <class counts> lists, for each class c in class order, c and its count in this order (<c> <count> ...).
- The "evaluation format" writes an evaluation of section 7 as the following lines.
Line 1: true\predicted followed by each class in class order (example: true\predicted food music tech). "\" is a single backslash character (character code 92).
Then, for each class a in class order, <a> followed by C[a][b] (b in class order).
Then, for each class c in class order, class <c> precision <reduced-fraction metric> recall <reduced-fraction metric> f1 <reduced-fraction metric> support <A>. The numerator and denominator of the metric are TP and P for precision, TP and A for recall, and 2 * TP and P + A for f1.
Finally, micro_f1 <micro F1> macro_f1 <macro F1>.

* output/vocabulary.txt
On line 1 write
documents <N> terms <number of "terms of D" when D is all training documents> candidates <number of candidates> vocabulary <V>
and then, for each term of the final vocabulary, in the order of the chi-square ranking, one line
<rank> <term> <df> <chi-square value> <best class>
Every value is the one from building the final vocabulary (section 9). Ranks are 1, 2, ....

* output/cv_results.csv
Line 1 is model,alpha,correct,accuracy,macro_f1,selected. Then, for each combination of NB model (in model order) and alpha of ALPHAS (in ALPHAS order; alpha is the inner loop), one line
<model>,<alpha>,<cross-validation correct count>,<cross-validation correct count / N>,<cross-validation macro F1>,<yes if this is the selected alpha, otherwise no>
Finally, for rocchio, write
rocchio,-,<cross-validation correct count>,<cross-validation correct count / N>,<cross-validation macro F1>,yes

* output/predictions.csv
Line 1 is id,model,label,score. Then, for each test document (in test order), for each of the five models in model order, one line
<ID>,<model>,<predicted class>,<score>
(the predictions of section 9; test documents whose class is "?" are also written).

* output/learning_curve.csv
Line 1 is size,vocabulary,model,correct,accuracy,macro_f1. Then, for each value s of CURVE (in CURVE order), for each base model in model order, one line

* output/feature_study.csv

<kind of term sequence (unigrams or bigrams)>,<m>,<V of that vocabulary>,<model>,<correct count>,<correct count / L>,<macro F1>

* output/metrics.txt
Write the following parts in this order. Put one empty line between consecutive parts (none before the first part or after the last part).
(1) Data
documents train <N> test <N_test> labelled <L> unlabelled <U> classes <K>
followed, for each class c in class order, by
class <c> train <number of training documents of class c> test <number of labelled test documents whose true class is c>
and then the following 4 lines.
train_tokens raw <number of words> stopwords <number of stopwords> short <number of short words> unigrams <number of kept words> bigrams <number of bigrams>
train_terms unigrams <number of distinct words> bigrams <number of distinct bigrams> candidates <number of candidates> vocabulary <V>
test_terms total <total length of the term sequences> in_vocabulary <total length in the final vocabulary>

The values of train_tokens are totals over all training documents (stopwords, short words and kept words are the counts of the words classified by section 2 (2)). The number of bigrams is the total number of bigrams contained in the term sequences (section 2 (5)) of the training documents; it is 0 if BIGRAMS is no. The words and bigrams of train_terms are the numbers of distinct words and distinct bigrams that appear in the term sequences of all training documents, and the number of candidates and V are those from building the final vocabulary. The values of test_terms are totals over all test documents. In test_oov, take the words that appear in the word sequences (section 2 (3)) of all test documents and are not in the final vocabulary, sort them in decreasing order of their number of occurrences in the word sequences of the test documents (ties: in term order), and write the word and its number of occurrences for the first T of them (all of them if there are fewer). If there is no such word, write only test_oov.
(2) Folds
folds 5
followed, for each fold f (f = 1, ..., 5), by

selection
followed, for each base model in model order, by

The lower bounds of the bins are written as two-decimal numbers (0 is 0.00). [Source files]
Split the program into the following six source files (file names follow the conventions of each language).
- main: the overall flow and most of the processing. Reading the input files and interpreting the settings, cross-validation (making the folds, building the vocabulary and training the models per fold, collecting the predictions) and selection of alpha, training of the final models and prediction of the test documents, the majority vote (vote), the learning curve, the feature comparison, the evaluation of posterior probabilities (log loss, Brier score, bins, thresholds), the accuracy per length, the comparison of models (McNemar statistic, overlap of errors), the bootstrap, hard documents, uncertain test documents, evidence for misclassifications, characteristic terms, semi-supervised learning by EM, and assembling and writing the contents of the seven output files.
- tokenizer: extracting words from text (runs of letters and digits, conversion to lowercase), removing stopwords and short words, making bigrams, building the two kinds of term sequences, and counting the words per word classification.
- vocabulary: computing document frequencies, computing chi-square from the 2x2 document counts and the best class, selecting the candidates, the chi-square ranking and the selection of the top m terms, and the vocabulary order.
- naive_bayes: training the NB models (counting documents per class, term occurrences and documents containing each term), computing the weights and class scores of the three NB models, the posterior probabilities (normalization by the sum of exponentials after subtracting the largest class score), and the predicted class and class ranking.
- rocchio: idf, TF-IDF vectors and their lengths, class centroids, and prediction and class ranking by cosine similarity.
- evaluation: the confusion matrix, the reduced fractions of precision, recall and F1, micro F1 and macro F1, assembling the evaluation format, the real-number format (rounding, treatment of -0), and the formats of proportions and reduced-fraction metrics.

[Constraints]
- 2 <= K <= 8, 10 <= N <= 1500, 1 <= N_test <= 500, 1 <= L, 1 <= U <= 1000. There are at least 1 and at most 300 stopwords, and every text has at most 600 characters.
- ALPHAS has 1 to 10 values, each at least 0.01 and at most 10.00; 1 <= MIN_DF <= 10, 0 <= FEATURES <= 5000, 1 <= T <= 50; CURVE has 1 to 10 values; SIZES has 1 to 10 values, each at most 5000; THRESHOLDS has 1 to 9 values; LENGTHS has 1 to 9 values, each at most 1000; 1 <= R <= 20, 1 <= B <= 10000.
- Each D_f of section 8, and the training documents with document numbers 1 to s for each value s of CURVE, always contain documents of every class (therefore M_c is always at least 1, and the log priors and centroids are well defined).
- The input files follow the formats above correctly. There is no need to check the input for errors.
- The given data are short news articles in five fields (business, health, science, sports, travel), with N = 637, 150 test documents (135 of them labelled) and 400 unlabelled documents. The final vocabulary is 600 terms selected from about 1500 candidates, and cross-validation performs 19 trainings (3 NB models * 6 alphas, plus rocchio) in each of the 5 folds.
- In the given data, every real number that is output is more than 1e-9 away from a rounding boundary. In determining the predicted class of an NB model (including all of cross-validation, the test documents, the learning curve, the feature comparison and EM), the difference between the largest and second largest class scores is always greater than 1e-6, and in determining the predicted class of rocchio, the difference between the largest and second largest similarities is always greater than 1e-9 (except when |v(x)| = 0 and all similarities are 0; in that case, by the rule, it is the first class in class order). In the top2 decision and in determining the runner-up class of multinomial too, whenever it affects the result, the difference between the class scores (similarities for rocchio) of the second and third classes in the class ranking is always greater than 1e-6 (1e-9 for rocchio). The comparison of posterior probabilities with thresholds, the selection of alpha by the 4-decimal value of macro F1, and the sorting by the 4-decimal value of the margin also have enough margin not to change under differences in summation order, fused multiply-add, or differences in the last digit (about 1 ulp) of the results of log and exp. Distinct values of chi2(t, c) differ from each other by a relative amount of at least 1e-9, so comparing the real numbers computed with one division gives the same result as the exact comparison of the fractions. Nevertheless, compute with the formulas and the order defined in this statement.
- Every integer value (including X and Y of chi-square, the products in the ratio comparisons of sections 18 and 19, and 48271 * x of the bootstrap), including intermediate values, is less than 2^53.

Some points about this example:
- The words of the text of training document 8 are the 12 words grilled, fish, with, lemon, and, garlic, is, a, summer, dinner, for, 2; with, and, is, a, for are stopwords and 2 is a short word. The word sequence is grilled, fish, lemon, garlic, summer, dinner, and the bigrams are the 5 bigrams grilled_fish, fish_lemon, lemon_garlic, garlic_summer, summer_dinner.
- The term phone has df(t) = 3, and all three occurrences are in documents of class tech (M_c = 4), so for tech A = 3, B = 0, C = 1, E = 11, X = 15 * (3 * 11 - 0 * 1)^2 = 16335 and Y = 3 * 12 * 4 * 11 = 1584, and the chi-square value is 16335 / 1584 = 10.3125. software has the same value, so they are ordered phone, software in term order. The 5 terms at ranks 7 to 11 also have equal chi-square values, so they are in term order (software_update comes before update).
- D_f of fold 5 has exactly 16 candidates, so all candidates form the vocabulary.
- For every NB model, the 4-decimal values of the cross-validation macro F1 for alpha = 0.50 and alpha = 1.00 are equal, so the smaller one, 0.50, is selected.
- For test document T4, multinomial and rocchio predict music and bernoulli and complement predict food; the votes are tied at 2 each, so music, predicted by multinomial (the first in model order), is the predicted class of vote. The score of vote is 2 / 4 = 0.5000. The true class of T4 is food, so T4 is a misclassified document of multinomial.
- The first-occurrence sequence of T4 is festival, band, fresh, bread, and their ratios are (100 * 2 + 50) / (100 * 0 + 50) = 5, (100 * 3 + 50) / (100 * 0 + 50) = 7, (100 * 0 + 50) / (100 * 5 + 50) = 1/11 and (100 * 0 + 50) / (100 * 3 + 50) = 1/7. In decreasing order of ratio, band, festival, bread are the evidence terms. The length of T4 is 4, so its length bucket is the one with lower bound 4.
- The class of test document T5 is "?", so its predictions are written to predictions.csv and to the uncertain test documents, but it is not used in the evaluations.
- In the bootstrap, B = 50, so low and high are the floor(50 / 40) + 1 = 2nd values when the K_r are sorted.
- In class tech of top_features.txt, phone and software both have count 3 and other count 0, so their ratios are equal and they are in term order.
