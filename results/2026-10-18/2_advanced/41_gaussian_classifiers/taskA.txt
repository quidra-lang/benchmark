[Overview]
Write a program that identifies the variety (class) of grains from tabular data of measured grain shapes. From the training data it estimates three kinds of classifiers that assume the feature values of each class follow a multivariate normal distribution, Gaussian naive Bayes (NB), linear discriminant analysis (LDA) and quadratic discriminant analysis (QDA), and it predicts the class of each row of the test data together with its posterior probabilities. In addition, it performs evaluation by confusion matrices and other measures, decisions that take the cost of errors into account, an ensemble that averages the posterior probabilities of the three models, comparisons between models by McNemar tests and the bootstrap, comparisons of feature subsets and models by cross-validation, feature selection by forward selection, and tuning of the strengths of smoothing and shrinkage. It also makes, for each specified pair of two features, maps that draw the decision regions in characters, and draws a scatter plot of the training data projected onto the two directions found by Fisher's discriminant analysis.
The input is four files in the input/ folder (training data, test data, cost table, settings), and the results are written to five files in the output/ folder. Nothing is written to standard output. Random numbers are generated only by the generator defined in this statement, and since every rule is fully specified, the result is uniquely determined.

[Input files]
There are four input files: input/train.csv, input/test.csv, input/costs.csv and input/params.txt. Every file consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). There is no whitespace at the start or end of a line. Values are separated by a single comma in the CSV files and by a single space in params.txt.
A decimal number is a base-10 number consisting of, in this order, "-" (only for negative numbers), a sequence of one or more digits (the integer part), ".", and a sequence of one or more digits (the fractional part) (examples: 5.62, 0.001, 13.5). An integer is a base-10 number without extra leading zeros.

* input/train.csv (training data)
The first line is a header line listing id, d feature names and label in this order, separated by commas (example: id,length,width,label). A feature name is a string of 1 to 16 characters consisting of lowercase English letters and "_"; the feature names are distinct from each other and differ from both id and label. The features are called feature 1, feature 2, ..., feature d in the order they appear in the header line, and this order is called the "feature order".
Each line from the second line on is one "training row", listing the ID, the d feature values and the label in this order, separated by commas.
- An ID is a positive integer. The IDs of all rows of train.csv and test.csv are distinct from each other.
- The feature values are decimal numbers.
- A label is the name of a grain variety, a string of 1 to 16 lowercase English letters.
Let n be the number of training rows. The order of the rows in the file is called the "row order". The rows are not necessarily sorted by ID.

* input/test.csv (test data)
The first line is a header line, exactly the same string as the header line of train.csv. Each line from the second line on is one "test row", in the same format as the rows of train.csv. The label of a test row is always the same as the label of some training row.
Let m be the number of test rows; the order of the rows in the file is called the "test row order".

* input/costs.csv (cost table)
The first line is a header line: the string actual followed by the names of all classes, each exactly once, in some order. Each line from the second line on is a class name (the actual class) followed by the costs for each class listed in the header line (the decided class), in the same order as the header line. For every class there is exactly one line whose actual class is that class, and the lines are in arbitrary order. A cost is a decimal number >= 0 with one digit in the fractional part.
The cost of deciding class b for a row whose actual class is a is written cost(a, b).

* input/params.txt (settings)
It consists of the following lines, in this order. Each line is a keyword followed by one or more values.
- PRIOR p: the prior mode (how the prior probabilities are determined); empirical or uniform.
- VAR_SMOOTHING eps: the coefficient of the variance smoothing of NB (a decimal number >= 0).
- SMOOTHING_GRID eps_1 eps_2 ...: the list of values tried when tuning eps (distinct decimal numbers >= 0, at least one).
- QDA_GAMMA gamma: the strength of the shrinkage of the QDA covariance matrices (a decimal number between 0 and 1 inclusive).
- GAMMA_GRID gamma_1 gamma_2 ...: the list of values tried when tuning gamma (distinct decimal numbers between 0 and 1 inclusive, at least one).
- CV_FOLDS F: the number of folds of cross-validation (an integer >= 2).
- CALIBRATION_EDGES e_1 e_2 ...: the boundaries of the confidence bins (distinct decimal numbers greater than 0 and less than 1, at least one, in increasing order).
- REJECT_THRESHOLDS t_1 t_2 ...: the list of confidence thresholds for accepting a judgment (decimal numbers greater than 0 and at most 1, at least one, in increasing order).
- CURVE s_1 s_2 ...: the list of numbers of training rows per class used for the learning curve (positive integers, at least one, in increasing order).
- OUTLIER_THRESHOLD theta: the threshold on the squared Mahalanobis distance used to select outliers (a positive decimal number).
- BOOTSTRAP B seed: the number B of bootstrap resamples (a positive integer) and the random seed seed (an integer between 1 and 2147483646 inclusive).
- MAP_SIZE W H: the number of columns W and the number of rows H of the decision region maps (integers >= 2).
- PLOT_SIZE PW PH: the number of columns PW and the number of rows PH of the scatter plot (integers >= 2).
- SUBSET name f_1 f_2 ...: a feature subset compared by cross-validation. name is a name of 1 to 12 characters consisting of lowercase English letters and digits, and it is followed by one or more distinct feature names. There are one or more such lines, and the names are distinct from each other. The order of the SUBSET lines is called the "subset order".
- PAIR fx fy: the two features (distinct feature names) for which decision region maps are made. There are one or more such lines, and the order of the PAIR lines is called the "pair order".

[Processing]
* 1. Notation and computation rules
- The order of strings is the lexicographic order by ASCII character code (compare one character at a time from the start; the string whose first differing character has the smaller code comes first; if one string is a prefix of the other, the shorter one comes first).
- ln is the natural logarithm, exp is the exponential function, sqrt is the square root, |t| is the absolute value of t, floor(t) is the largest integer not greater than t, and pi is the ratio of a circle's circumference to its diameter. a mod b (integers a >= 0, b > 0) is the remainder of a divided by b.
- SUM (written in place of the summation sign) denotes the sum obtained by adding the elements one at a time from the start, in the order of the indicated sequence; the initial value of a sum is 0. A sum for which no sequence is indicated is added in the order of the elements of the expression written here (row order or test row order for rows, class order for classes, the order of the feature sequence in use for features).
- Expressions are evaluated with the parts inside parentheses first, and operations of the same precedence from left to right (example: a - b / 2 - c / 2 is (a - (b / 2)) - (c / 2)).
- Every rule that selects a maximum or minimum and every sorting rule always comes with the treatment of equal values.
- Unless stated otherwise, a "sequence" of rows keeps the row order (the test row order for test rows). A sequence obtained by removing some rows from a sequence also keeps the remaining rows in their original order.

* 2. Classes, feature sequences, models
- The labels that appear in the training rows, sorted in string order, are called the "class order", and they are class 1, class 2, ..., class C. The first characters of the class names are distinct from each other. The "uppercase letter" of class k is the first character of the class name converted to an uppercase English letter, and its "lowercase letter" is the first character of the class name itself.
- The class of a row's label is called the "class" of that row. The number of the class of row i is written y_i.
- A "feature sequence" is a sequence of the features in use (f_1, ..., f_p) (p is the number of features in use). The "vector" of a row for a feature sequence is (x_1, ..., x_p), the values of each f_j in order. Unless stated otherwise, the feature sequence is "all features" (all features in feature order; p = d).
- There are three kinds of models, NB, LDA and QDA, and this order is called the "model order".

* 3. Matrix computations
Indices of matrices and vectors start at 1, and the entry in row i, column j of a matrix A is written A[i][j]. The following procedures are used for square matrices of size D.
(1) Cholesky decomposition: compute a lower triangular matrix L from a symmetric positive definite matrix A. For i = 1, ..., D in this order, and for each i for j = 1, ..., i in this order, compute
  s = A[i][j] - SUM_{k=1}^{j-1} L[i][k] * L[j][k]
(compute the sum first, then subtract it from A[i][j]; when j = 1 the sum is 0), and set L[i][i] = sqrt(s) if i = j, and L[i][j] = s / L[j][j] if i > j. All other entries of L are 0. For the matrices decomposed by Cholesky in this problem, s is always positive.
(2) Forward substitution: from L and a vector r, compute z_i = (r_i - SUM_{k=1}^{i-1} L[i][k] * z_k) / L[i][i] for i = 1, ..., D in this order. This vector z is written fw(L, r).
(3) Backward substitution: from L and a vector u, compute v_i = (u_i - SUM_{k=i+1}^{D} L[k][i] * v_k) / L[i][i] for i = D, D - 1, ..., 1 in this order (the sum is added in increasing order of k). This vector v is written bw(L, u).
(4) Log-determinant: ld(L) = 2 * SUM_{i=1}^{D} ln(L[i][i])
(5) Quadratic form: for a vector r, with z = fw(L, r), Q(L, r) = SUM_{i=1}^{D} z_i * z_i. When L is the Cholesky decomposition of A, this is the squared Mahalanobis distance of r with respect to A.
(6) Jacobi method: computes the eigenvalues and eigenvectors of a symmetric matrix A. Let the matrix M be a copy of A, V the identity matrix, and the sweep count 0, then repeat the following.
 1. Compute off = sqrt(SUM M[a][b] * M[a][b]). The sum is added for a = 1, ..., D - 1 in this order, and for each a for b = a + 1, ..., D in this order. If off < 0.000000000001 or the sweep count is 50, end the repetition.
 2. For a = 1, ..., D - 1 in this order, and for each a for b = a + 1, ..., D in this order, perform the following rotation if M[a][b] != 0 (do nothing if M[a][b] = 0).
  Let theta = (M[b][b] - M[a][a]) / (2 * M[a][b]), t = sg / (|theta| + sqrt(theta * theta + 1)) (sg is 1 if theta >= 0 and -1 if theta < 0), co = 1 / sqrt(t * t + 1), si = t * co.
  For each k other than a and b (in increasing order of k), from the current values x = M[k][a] and y = M[k][b], set both M[k][a] and M[a][k] to co * x - si * y, and both M[k][b] and M[b][k] to si * x + co * y.
  Next, using the current value w = M[a][b], set M[a][a] to M[a][a] - t * w and M[b][b] to M[b][b] + t * w, and set M[a][b] and M[b][a] to 0.
  Finally, for each k = 1, ..., D, from the current values x = V[k][a] and y = V[k][b], set V[k][a] to co * x - si * y and V[k][b] to si * x + co * y.
 3. Increase the sweep count by 1 and return to 1.
When the repetition ends, M[i][i] is the i-th eigenvalue, and column i of V, (V[1][i], ..., V[D][i]), is its eigenvector. The sweep count at that time is also used.

* 4. Per-class statistics
For a sequence R of rows used for training (N rows) and a feature sequence (p features), compute the following values using the vector x of each row. R contains at least two rows of every class.
- N_k: the number of rows of R whose class is k
- the mean mu_k of class k: mu_k[j] = (SUM x_j) / N_k (sum over the rows of R whose class is k)
- the scatter matrix S_k of class k: S_k[a][b] = SUM (x_a - mu_k[a]) * (x_b - mu_k[b]) (sum over the rows of R whose class is k; a, b = 1, ..., p)
- the center c: c[j] = (SUM x_j) / N (sum over all rows of R)
- the feature variance var_j = (SUM (x_j - c[j]) * (x_j - c[j])) / N (sum over all rows of R)
- the prior probability pi_k: N_k / N if the prior mode is empirical, and 1 / C if it is uniform.

* 5. Training the three models
"Training a model" means computing the statistics of section 4 from a sequence R of rows and a feature sequence, and determining for each class k the mean mu_k, the covariance matrix K_k (p rows, p columns) and the prior probability pi_k as follows. Unless stated otherwise, eps, gamma and the prior mode are the values of VAR_SMOOTHING, QDA_GAMMA and PRIOR.
- NB: compute V = (the maximum of var_1, ..., var_p) and the added amount A = eps * V, and let K_k be the matrix whose diagonal entries are K_k[j][j] = S_k[j][j] / N_k + A and whose other entries are 0.
- LDA: let the pooled covariance matrix P be P[a][b] = (SUM_{k=1}^{C} S_k[a][b]) / (N - C), and let K_k = P for every class.
- QDA: K_k[a][a] = S_k[a][a] / (N_k - 1), and for a != b, K_k[a][b] = S_k[a][b] / (N_k - 1) * (1 - gamma).
For each class, compute the Cholesky decomposition L_k of K_k and the log-determinant ld_k = ld(L_k) (for LDA these are the same for every class).
The three models trained on the sequence of all training rows with all features are called the "main models".

* 6. Discriminant scores, prediction, posterior probabilities, decision
For a model and the vector x of a row for the same feature sequence, define the following.
(1) Discriminant score: for each class k, g_k = ln(pi_k) - h - ld_k / 2 - Q(L_k, x - mu_k) / 2. Here h = p * ln(2 * pi) / 2, and x - mu_k is the componentwise difference (x_1 - mu_k[1], ..., x_p - mu_k[p]).
(2) Prediction: the class with the largest g_k (ties: the smaller number) is called the "predicted class". When the predicted class is the same as the class of the row, the prediction is "correct".
(3) Posterior probabilities: let G = (the maximum of g_1, ..., g_C), e_k = exp(g_k - G) and s = SUM_{k=1}^{C} e_k; the posterior probability of class k is P_k = e_k / s. The maximum of the posterior probabilities is called the "confidence".
(4) Log posterior probability: the log of the posterior probability of class k is computed as (g_k - G) - ln(s).
(5) Decision: for each class b compute the expected cost R_b = SUM_{k=1}^{C} P_k * cost(class k, class b); the class with the smallest R_b (ties: the smaller number) is called the "decided class".
(6) Squared Mahalanobis distance: for class k, q_k = Q(L_k, x - mu_k).

* 7. Fractions and evaluation measures
- The "reduced fraction" of the ratio a / b of integers a and b (b > 0) is a and b each divided by the greatest common divisor of |a| and b (if a = 0, it is 0/1).
- From the class and the predicted class of each row of a sequence of rows (N rows), build the C x C confusion matrix T. T[a][b] is the number of rows whose class is a and whose predicted class is b. Let r_a = SUM_{b=1}^{C} T[a][b] (the number of rows of class a) and c_b = SUM_{a=1}^{C} T[a][b] (the number of rows predicted as class b), and define the following values. A sequence of rows from which a confusion matrix is built contains rows of every class.
- correct count = SUM_{k=1}^{C} T[k][k], accuracy = correct count / N
- the recall of class k = T[k][k] / r_k, its precision = T[k][k] / c_k (no value if c_k = 0), its F1 = (2 * T[k][k]) / (r_k + c_k)
- balanced accuracy = (the sum of the recalls of the classes) / C. The sum of the recalls is computed exactly as a fraction.
- kappa (the kappa coefficient) = (N * correct count - E) / (N * N - E), where E = SUM_{k=1}^{C} r_k * c_k.
- macro F1 = (SUM_{k=1}^{C} F1_k) / C. Here F1_k is the F1 of class k computed as a real number, (2 * T[k][k]) / (r_k + c_k).
All values other than macro F1 are expressed as reduced fractions.
- In a McNemar test comparing two predictions A and B on the same sequence of rows, let b01 = (the number of rows where A is correct and B is not correct) and b10 = (the number of rows where A is not correct and B is correct); if b01 != b10, chi2 = (|b01 - b10| - 1) * (|b01 - b10| - 1) / (b01 + b10), and if b01 = b10, chi2 = 0 (compute the numerator as an integer, then divide). The test is significant if chi2 > 3.841.

* 8. Cross-validation
Given a feature sequence and a model type (and, if needed, the value of eps or gamma), cross-validation is performed as follows. Fold f (f = 0, 1, ..., F - 1) is the set of training rows with ID mod F = f. For f = 0, 1, ..., F - 1 in this order, train the model on the sequence of training rows not contained in fold f, and with that model predict the class of each training row of fold f. The resulting predictions for all training rows are called the "cross-validation predictions", the number of training rows of fold f whose prediction is correct is called the "fold f correct count", and the number of all training rows whose prediction is correct is called the "cross-validation correct count".

* 9. Random numbers
Random numbers are generated by the following generator. The initial value of the state x is seed; each time a random number is drawn, x is updated to (48271 * x) mod 2147483647, and the updated x is the drawn value. Since 48271 * x is less than 2^53, it can be computed exactly with 64-bit integers.

* 10. Details of the main models (models.txt)
(1) LDA linear discriminant functions: with L the Cholesky decomposition of the main LDA model, compute for each class k the coefficient vector coef_k = bw(L, fw(L, mu_k)) and the intercept b_k = ln(pi_k) - (SUM_{j=1}^{d} mu_k[j] * coef_k[j]) / 2.
(2) QDA eigenvalues: apply the Jacobi method to K_k of each class of the main QDA model, and arrange the d eigenvalues in decreasing order. The condition number is (the largest eigenvalue) / (the smallest eigenvalue).
(3) Class separation: take the pairs of classes (a, b) with a < b in increasing order of a, and for equal a in increasing order of b. For each pair, with the difference delta = (mu_a[1] - mu_b[1], ..., mu_a[d] - mu_b[d]) (means of the main models), compute the following.
- the Mahalanobis distance: sqrt(Q(L, delta)) (L is the Cholesky decomposition of the main LDA model)
- the Bhattacharyya distance: from the covariance matrices of the main QDA model build Sm[i][j] = (K_a[i][j] + K_b[i][j]) / 2, let Lm be its Cholesky decomposition, and compute Q(Lm, delta) / 8 + (ld(Lm) - (ld_a + ld_b) / 2) / 2 (ld_a and ld_b are the values of the main QDA model)
(4) Outliers: with the main QDA model, compute for each training row i the squared Mahalanobis distance q_(y_i) for its class y_i; the training rows where it is greater than theta are outliers. They are sorted by q in decreasing order (ties by row order).

* 11. Evaluation on the test data (predictions.csv, evaluation.txt)
(1) Prediction by the main models: with each main model, compute for each test row the predicted class, the posterior probabilities, the confidence and the decided class.
(2) Per-model evaluation: for each main model, compute the confusion matrix of the sequence of test rows and the measures of section 7, and the log loss = -(SUM (the log of the posterior probability of the row's class, for each test row)) / m. A test row whose prediction is not correct is called an "error".
(3) Confidence bins: with K the number of boundaries, form the sequence 0, e_1, ..., e_K, 1 by adding 0 before and 1 after the boundaries, and from each two adjacent values form the K + 1 bins [0, e_1), [e_1, e_2), ..., [e_K, 1] (every bin includes its lower edge; only the last bin includes its upper edge). For each bin, compute the number of test rows whose confidence falls in the bin, the mean confidence (the sum of their confidences (in test row order) divided by the count), and the accuracy of those rows. ECE = (SUM |correct count of the bin - sum of confidences of the bin|) / m (the sum is added in bin order).
(4) Accepting judgments: for each threshold t, the test rows whose confidence is >= t are accepted. Compute the number of accepted rows, the coverage = (the number of accepted rows) / m, and the accuracy of the accepted rows.
(5) Ensemble: for each test row, the mean posterior probability of class k is (P_k(NB) + P_k(LDA) + P_k(QDA)) / 3 (P_k(X) is the posterior probability of main model X; the sum is in model order), and the class with the largest mean posterior probability (ties: the smaller number) is the ensemble's predicted class.
(6) McNemar tests: arrange the four predictions NB, LDA, QDA and the ensemble (named ENSEMBLE) in this order, take all pairs (A, B) in which A comes before B, ordered by A, and for equal A by B, and perform the McNemar test of section 7 on the sequence of test rows.
(7) Costs: for each main model, compute the total cost when deciding by the predicted class, SUM cost(class of the row, predicted class), and the total cost when deciding by the decided class, SUM cost(class of the row, decided class) (both added in test row order), the number of test rows whose decided class differs from the predicted class, and the accuracy based on the number of test rows whose decided class is the same as the class of the row.
(8) Novel rows: with the main QDA model, compute for each test row the squared Mahalanobis distances q_1, ..., q_C of all classes. The test rows whose minimum is greater than theta are novel rows, and the class giving the minimum (ties: the smaller number) is the nearest class. They are sorted by the minimum in decreasing order (ties by test row order).
(9) Bootstrap: using the generator of section 9, make B resamples one after another. For one resample, draw m random numbers in succession, and for each drawn value x select the ((x mod m) + 1)-th test row in test row order (the same row may be selected any number of times). For each main model, the number of the selected m rows whose prediction is correct (duplicates are counted) is the correct count of that resample. The generator is not reinitialized for each resample but is used continuously. For each main model, sort the B correct counts in increasing order; the lower bound is the (floor(B / 40) + 1)-th correct count from the smallest, and the upper bound is the (floor(B / 40) + 1)-th correct count from the largest. The mean accuracy is (the sum of the B correct counts) / B / m. Also, for each pair (A, B) of NB, LDA and QDA in which A comes before B, count the resamples in which the correct count of A is greater than that of B (wins), equal to it (ties), and smaller than it (losses).
(10) Effect of the prior: with the prior mode that differs from PRIOR (uniform if PRIOR is empirical, empirical if it is uniform), retrain each model from all training rows with all features and predict the test rows; compute the accuracy, the balanced accuracy, and the number of test rows whose predicted class differs from that of the main model.
(11) Learning curve: for each s of CURVE, let R_s be the sequence of the training rows that are among the first s rows, in row order, of the rows of the same class. Train each model with R_s and all features, and compute the accuracy on the test rows.

* 12. Comparison by cross-validation (evaluation.txt)
(1) Feature subsets: in subset order, for each SUBSET, perform the cross-validation of each model in model order, with the feature sequence in the order written on that line. Select the (subset, model) with the largest cross-validation correct count. Ties go to the one with fewer features; if still tied, to the one earlier in subset order; if still tied, to the one earlier in model order. Retrain from all training rows with the feature sequence of the selected subset and the selected model, and compute the correct count and the accuracy on the test rows.
(2) McNemar tests on cross-validation: for the cross-validation predictions of NB, LDA and QDA with all features, take all pairs (A, B) in which A comes before B, in the same order as section 11 (6), and perform the McNemar test on the sequence of training rows.
(3) Cross-validation confusion matrices: for the cross-validation predictions of each model with all features, compute the confusion matrix of the sequence of training rows, the balanced accuracy and kappa.
(4) Leave-one-out: for each model, for each training row i (in row order), train the model on the sequence of training rows other than i with all features, predict the class of i, and count the correct predictions.
(5) Forward selection: for each model, start the selected feature sequence S as the empty sequence, and repeat the following until S has d features. For each feature f not contained in S, compute the cross-validation correct count with the sequence obtained by appending f to the end of S, and append the f with the largest count (ties: the earlier one in feature order) to the end of S. The number of additions made so far is the step number (1 to d). The step with the largest cross-validation correct count (ties: the smaller number) is the best step.
(6) Tuning the smoothing: for each value eps_i of SMOOTHING_GRID, perform the cross-validation of NB with all features and eps = eps_i. Select the value with the largest cross-validation correct count (ties: the later one in the list), retrain NB from all training rows with that eps, and compute the correct count and the accuracy on the test rows.
(7) Tuning the shrinkage: for each value of GAMMA_GRID, do the same as (6) for gamma of QDA.

* 13. Decision region maps (boundaries.txt)
In pair order, for each PAIR fx fy, do the following. The feature sequence is (fx, fy).
(1) Range and grid: let xmin and xmax be the minimum and maximum of the fx values of the training rows, ymin and ymax the minimum and maximum of the fy values, dx = (xmax - xmin) / (W - 1) and dy = (ymax - ymin) / (H - 1). The grid point at row r (0 to H - 1, from the top) and column c (0 to W - 1, from the left) is the point with the vector (xmin + c * dx, ymax - r * dy).
(2) Decision regions: in model order, train each model with all training rows and the feature sequence (fx, fy). The decision region map represents each grid point by the uppercase letter of the class predicted by that model. Also compute the accuracy on the sequence of training rows (the rows used for training are predicted as they are) and the accuracy based on the cross-validation correct count with the feature sequence (fx, fy).
(3) Agreement map: at each grid point, count how many distinct classes the three models predict, and represent the point by . if there is 1, by 2 if there are 2, and by 3 if there are 3.
(4) Uncertainty map: with the QDA trained in (2), compute the confidence at each grid point, let u = (1 - confidence) / (1 - 1 / C) and level = floor(10 * u) (9 if it exceeds 9), and represent each grid point by its "level character". The level characters are the 10 characters " .:-=+*#%@", which represent levels 0 to 9 in this order (the first character is a space).
(5) Point map: for a value v, a range lo, hi and a size size, let cell(v, lo, hi, size) = floor((v - lo) / (hi - lo) * (size - 1) + 0.5). Start with every cell of W columns and H rows set to a space, and place each training row, in row order, in the cell at column cell(fx value, xmin, xmax, W) and row H - 1 - cell(fy value, ymin, ymax, H). When placing, if the cell is a space or already holds the lowercase letter of the class of that row, set it to the lowercase letter of that class; otherwise (a different lowercase letter or *) set it to *.

* 14. Fisher's discriminant analysis (projection.txt)
Use the statistics computed for the main models (all training rows and all features).
(1) Scatter matrices: compute the within-class scatter matrix SW[a][b] = SUM_{k=1}^{C} S_k[a][b] and the between-class scatter matrix SB[a][b] = SUM_{k=1}^{C} N_k * (mu_k[a] - c[a]) * (mu_k[b] - c[b]) (c is the center).
(2) Per-feature F values: let F_j = (SB[j][j] / (C - 1)) / (SW[j][j] / (n - C)), and sort the features by F value in decreasing order (ties by feature order).
(3) Symmetrization: let L be the Cholesky decomposition of SW. Column j of the matrix Y is fw(L, column j of SB), and column i of the matrix Z is fw(L, row i of Y) (row i of Y is (Y[i][1], ..., Y[i][d])). Then, for all a and b, let Ms[a][b] = (Z[a][b] + Z[b][a]) / 2.
(4) Eigenvalues: apply the Jacobi method to Ms. The eigenvalues sorted in decreasing order (ties: the smaller number first) form the "eigenvalue order", and each eigenvalue divided by the sum of the eigenvalues SUM_{i=1}^{d} (the i-th eigenvalue) (added in index order) is its contribution ratio.
(5) Discriminant directions: for the eigenvectors y of the first and second eigenvalues in eigenvalue order, let v' = bw(L, y), the norm nv = sqrt(SUM_{j=1}^{d} v'_j * v'_j), and v_j = v'_j / nv. If v_j < 0 for the j with the largest |v_j| (ties: the smaller j), flip the sign of every component. The two vectors obtained this way are discriminant direction 1 and discriminant direction 2. The standardized coefficients of discriminant direction t are v_j * sqrt(P[j][j]) (P is the pooled covariance matrix of the main LDA model).
(6) Projection: the projection of a vector x of all features is z_t(x) = SUM_{j=1}^{d} v_j * (x_j - c[j]) (v is discriminant direction t; t = 1, 2). The centroid of class k is z_t(mu_k). The spread of class k is sqrt((SUM (z_t(x) - z_t(mu_k)) * (z_t(x) - z_t(mu_k))) / N_k) (sum over the training rows whose class is k).
(7) Nearest-centroid classification: with 1 dimension the distance is (z_1(x) - z_1(mu_k)) * (z_1(x) - z_1(mu_k)), and with 2 dimensions it is (z_1(x) - z_1(mu_k)) * (z_1(x) - z_1(mu_k)) + (z_2(x) - z_2(mu_k)) * (z_2(x) - z_2(mu_k)); the class with the smallest distance (ties: the smaller number) is the predicted class. Compute the accuracy on the sequence of training rows and on the sequence of test rows.
(8) Scatter plot: let lo1 and hi1 be the minimum and maximum of z_1 over the training rows, and lo2 and hi2 the minimum and maximum of z_2. Start with every cell of PW columns and PH rows set to a space, and place each training row, in row order, in the cell at column cell(z_1, lo1, hi1, PW) and row PH - 1 - cell(z_2, lo2, hi2, PH), by the same rule as section 13 (5). After that, in class order, replace the cell of the centroid of each class k (computed with the same formulas) with the uppercase letter of class k.

[Source files]
Split the program into the following six source files (file names follow each language's conventions).
- main: handles the overall flow and most of the processing: calling the input reading, training the main models and the contents of models.txt (linear discriminant functions, eigenvalues and condition numbers, class separation, outliers), predicting the test rows and the contents of predictions.csv, the evaluation on the test data (measures, errors, confidence bins, accepting judgments, ensemble, McNemar tests, costs, novel rows, bootstrap, effect of the prior, learning curve), the comparison by cross-validation (feature subsets, McNemar tests, confusion matrices, leave-one-out, forward selection, tuning of smoothing and shrinkage), the decision region maps, Fisher's discriminant analysis and the scatter plot, and assembling the contents of the five output files.
- dataset: reads the four input files and returns the feature names, the training rows and test rows (ID, feature values, label), the cost table rearranged in class order, and the setting values.
- linalg: handles the Cholesky decomposition, forward substitution, backward substitution, log-determinant, quadratic form and the Jacobi method.
- gaussian_models: handles the per-class statistics, training of NB, LDA and QDA, discriminant scores, prediction, posterior probabilities, log posterior probabilities and cost-based decisions.
- evaluation: handles reduced fractions, sums of fractions, confusion matrices, b01, b10 and chi2 of the McNemar test, and the random number generator.
- plot: handles the formatting of real numbers and fractions (rounding, handling of -0), framing of maps, computing the cell position cell, and writing sequences of lines to files.

[Constraints]
- 2 <= d <= 6, 3 <= C <= 5, n <= 400, m <= 200, 2 <= F <= 10, B <= 2000, W <= 60, H <= 30, PW <= 80, PH <= 30. The given data has d = 5, C = 4, n = 321, m = 161, F = 10, B = 1000. Models are trained about 1800 times in total, including cross-validation, leave-one-out, forward selection and so on.
- The input files correctly follow the formats above. There is no need to check for input errors.
- The test rows contain rows of every class. Each value of CURVE is at most the number of training rows of every class.
- In every model trained in this problem (including cross-validation, leave-one-out, the learning curve, forward selection, tuning, the decision region maps and the effect of the prior), the sequence of rows used for training contains at least two rows of every class, and every matrix decomposed by Cholesky is positive definite (s is always positive during the decomposition).
- In Fisher's discriminant analysis, the first and second eigenvalues in eigenvalue order, and the second and third eigenvalues (when d >= 3), are sufficiently far apart, and in each discriminant direction the component with the largest |v_j| is sufficiently larger than the absolute values of the other components.
- For the given data, every real number written to the output is sufficiently far from a rounding boundary. Size comparisons, selections of maxima and minima (in every prediction, the difference between the largest and the second largest discriminant score is greater than 0.000001), comparisons with thresholds, the termination test of the Jacobi method, and the results of floor(...) have enough margin that they do not change with differences in the order of additions, fused multiply-add, or differences in the last digit (about 1 ulp) of the results of exp, ln and sqrt. Nevertheless, compute with the formulas and orders defined in this statement.
- For the given data, the absolute values of the integers that appear in fraction computations such as the balanced accuracy are less than 2^31 (they can be computed with values at most the product of the per-class row counts multiplied by C). Only 48271 * x of the random number generator can be 2^31 or more.
