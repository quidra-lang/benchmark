[Overview]
Write a program that trains a soft-margin support vector machine (SVM), which separates two-dimensional points into two classes, with Platt's SMO method (sequential minimal optimization), and evaluates and analyzes it. The kernels (linear, polynomial, RBF) and the candidate values of the regularization coefficient C are given in a file. k-fold cross-validation selects the best C of each kernel and the best combination overall; for the final model of each kernel the program computes the support vectors, the threshold, the dual objective and more, and predicts the decision values of the test data. In addition, it outputs, for the selected model, the training progress, the change with C, a learning curve, calibration to probabilities by Platt's method, a comparison with the Pegasos method (which solves the linear SVM by stochastic subgradient descent), McNemar tests between models, multi-class classification of three-class data by one-vs-rest and one-vs-one, and plots of the decision regions drawn with ASCII characters.
The input is four files in the input/ folder (training data, test data, multi-class data, settings), and the results are written to five files in the output/ folder. Nothing is written to standard output. All selection rules of the SMO method and the random numbers (the MINSTD generator) are specified in [Processing], so the result is uniquely determined.

[Input files]
There are four input files: input/train.csv, input/test.csv, input/multiclass.csv and input/params.txt. Every file consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). There is no whitespace at the start or end of a line. Values are separated by a comma in the CSV files, and by a single space in params.txt.
An integer is a base-10 number without extra leading zeros; a negative number has a leading -. A decimal number is a base-10 number consisting of, in this order, "-" (only for negative numbers), a sequence of one or more digits (the integer part), ".", and a sequence of one or more digits (the fractional part) (examples: 0.25, -2.121, 3.0). Exponent notation is not used.

* input/train.csv (training data)
Line 1 is the header line, the string id,x1,x2,label. Each line from line 2 on represents one training example, listing the ID, the coordinate x1, the coordinate x2 and the label in this order, separated by commas.
- An ID is a string of 1 to 8 characters consisting of uppercase English letters and digits; the IDs are distinct within the file.
- x1 and x2 are decimal numbers.
- The label is 1 or -1.
Let n be the number of training examples; in the order of the lines in the file they are called training example 1, ..., training example n. This order is called the "training data order". The point of training example i is x_i = (x_i1, x_i2), and its label is y_i.

* input/test.csv (test data)
Same format as train.csv. Let m be the number of test examples; in the order of the lines in the file they are called test example 1, ..., test example m. This order is called the "test data order". The point of test example j is t_j, and its label is u_j. The labels of the test examples are used only for evaluation.

* input/multiclass.csv (multi-class data)
Line 1 is the header line, the string id,x1,x2,class,role. Each line from line 2 on represents one example, listing the ID, the coordinate x1, the coordinate x2, the class and the role in this order, separated by commas. The ID and the coordinates have the same format as in train.csv, and the IDs are distinct within this file. The class is one of 1, 2, 3, and the role is train or test.
The lines whose role is train, in file order, are called the "multi-class training data", and the lines whose role is test, in file order, are called the "multi-class test data"; their numbers of examples are N_m and M_m, respectively.

* input/params.txt (settings)
The following lines appear in this order. Each line is an uppercase keyword followed by values, separated by single spaces. Only KERNEL lines appear 1 to 4 times; every other keyword appears on exactly one line.
- C_GRID c_1 c_2 ...: the candidate values of the regularization coefficient C (positive decimal numbers, 1 to 6 of them, in increasing order and distinct). This order is called the "C candidate order".
- KERNEL name kind arguments...: a kernel definition. name is the name of the kernel (1 to 8 characters consisting of lowercase English letters and digits, different on each line, and not pegasos), and kind is the kind of kernel, one of linear, poly, rbf. The arguments are: none for linear; three for poly, the degree d (an integer from 1 to 5), the coefficient g (a positive decimal number) and the constant r0 (a decimal number >= 0); one for rbf, gamma (a positive decimal number). The order of the KERNEL lines is called the "kernel order". There is at least one kernel of kind linear.
- TOLERANCE tau: the tolerance of the KKT conditions (a positive decimal number).
- EPS eps: the value that determines the lower limit of the change of alpha (a positive decimal number).
- MAX_PASSES P_max: the upper limit on the number of passes of the SMO method (a positive integer).
- FOLDS k: the number of folds of cross-validation (an integer from 2 to n).
- LEARNING_CURVE q_1 q_2 ...: the fractions of the training data used for the learning curve (percentages; 1 to 10 distinct integers from 1 to 100, in increasing order).
- NEWTON_ITERATIONS N_it: the number of iterations of Newton's method in the calibration (a positive integer).
- MULTICLASS name C_m: the name of the kernel used for multi-class classification (one that appears on a KERNEL line) and the value of C (a positive decimal number).
- PEGASOS lambda T seed: the regularization coefficient lambda of the Pegasos method (a positive decimal number), the number of iterations T (a positive integer that is a multiple of 10), and the seed of the MINSTD generator, seed (an integer from 1 to 2147483646).
- PLOT_X x_min x_max: the range of the horizontal axis of the plots (decimal numbers, x_min < x_max).
- PLOT_Y y_min y_max: the range of the vertical axis of the plots (decimal numbers, y_min < y_max).
- PLOT_SIZE W H: the number of characters W across and the number of characters H down of the plots (positive integers).

[Processing]
* 1. Notation and computation rules
- All real-number computation is done in double precision (IEEE 754 64-bit floating point). Input decimal numbers are converted to double precision before use.
- exp is the exponential function, ln is the natural logarithm, sqrt is the square root, |t| is the absolute value of t, floor(t) is the largest integer <= t, and max and min are the maximum and the minimum. a mod b is the remainder of dividing an integer a >= 0 by a positive integer b.
- A sum written with SUM starts from 0 and adds one term at a time in increasing order of the index (for examples, in the order of that sequence). Other sums are computed the same way unless stated otherwise. Multiplications and divisions in an expression are computed from left to right in the order written, and so are additions and subtractions.
- The sign sgn(v) of a real number v is 1 if v > 0, and -1 otherwise.
- Since a label is 1 or -1, multiplying by a label only changes the sign and introduces no error.
- Integer counting (numbers of correct predictions and so on) is done with integers. The "ratio a/b" is the value of the real division a / b (how it is written in the output is specified in [Output files]).

* 2. Kernels
The kernel value K(a, b) of two points a = (a1, a2) and b = (b1, b2) is computed for each kind of kernel as follows.
- linear: K(a, b) = a1 * b1 + a2 * b2
- poly: let s = g * (a1 * b1 + a2 * b2) + r0; the value is obtained by starting from 1.0 and multiplying by s d times, one multiplication at a time (for d = 3 it is ((1.0 * s) * s) * s).
- rbf: with e1 = a1 - b1 and e2 = a2 - b2, K(a, b) = exp(-gamma * (e1 * e1 + e2 * e2))
The "kernel matrix" of a sequence of points z_1, ..., z_N is the N-row, N-column table whose (i, j) entry is K(z_i, z_j). Since K(a, b) = K(b, a), the kernel matrix is symmetric. For training, the whole kernel matrix is computed in advance and its entries are used.

* 3. Training by the SMO method
From a sequence of points z_1, ..., z_N (N >= 2), their labels y_1, ..., y_N (1 or -1), a kernel matrix Q (Q_ij = K(z_i, z_j)) and a coefficient C, a model is trained as follows. tau, eps and P_max are the values in params.txt. Below, example numbers i and j are between 1 and N inclusive, and the order of the examples is the order of their numbers.

(1) State
The model holds alpha_i for each example and a threshold b. During training, it also keeps an error E_i for each example. Initially, alpha_i = 0 and E_i = -y_i for all i, and b = 0.
An example with 0 < alpha_i < C is called a "non-bound" example.
In addition, the following counts are kept (all start from 0): the number of full passes P_f, the number of non-bound passes P_n, the number of examine calls, the number of successful steps, the number of successes for each way of choosing the partner (three counts: heuristic, nonbound_loop, full_loop), and the number of successes for each clipping case (three counts: none, lower, upper).
The "snap" of a real number a is 0 if a < 0.00000001, C if a > C - 0.00000001, and a itself otherwise.

(2) Step take(i1, i2)
Tries to update the alphas of example i1 and example i2 simultaneously, and returns success or failure. On failure, the state is not changed at all.
Step 1. If i1 = i2, it fails.
Step 2. Let alpha1 = alpha_i1, alpha2 = alpha_i2, y1 = y_i1, y2 = y_i2, E1 = E_i1, E2 = E_i2 (all are values before the update).
Step 3. If y1 != y2, let lo = max(0, alpha2 - alpha1) and hi = min(C, C + alpha2 - alpha1); if y1 = y2, let lo = max(0, alpha2 + alpha1 - C) and hi = min(C, alpha2 + alpha1). If lo = hi, it fails.
Step 4. Let k11 = Q_i1i1, k12 = Q_i1i2, k22 = Q_i2i2, eta = k11 + k22 - 2 * k12. If eta <= 0, it fails.
Step 5. Compute a2 = alpha2 + y2 * (E1 - E2) / eta. If a2 < lo, replace a2 by lo (clipping case lower); otherwise, if a2 > hi, replace a2 by hi (upper); if neither, leave it as it is (none). Then replace a2 by its snap.
Step 6. If |a2 - alpha2| < eps * (a2 + alpha2 + eps), it fails.
Step 7. Compute a1 = alpha1 + y1 * y2 * (alpha2 - a2), and replace it by its snap.
Step 8. Let t1 = y1 * (a1 - alpha1), t2 = y2 * (a2 - alpha2), b1 = E1 + t1 * k11 + t2 * k12 + b, b2 = E2 + t1 * k12 + t2 * k22 + b. The new threshold b' is b1 if 0 < a1 < C; otherwise b2 if 0 < a2 < C; and (b1 + b2) / 2 if neither.
Step 9. Let delta = b' - b, and for every example i (in increasing order of number) replace E_i by E_i + (t1 * Q_i1,i + t2 * Q_i2,i - delta). Then, if 0 < a1 < C, set E_i1 = 0, and if 0 < a2 < C, set E_i2 = 0.
Step 10. Set alpha_i1 = a1, alpha_i2 = a2, b = b'. Add 1 to the number of successful steps and to the count of the clipping case determined in step 5, and return success.

(3) Examining an example, examine(i2)
Add 1 to the number of examine calls. Let r2 = E_i2 * y_i2. If neither "r2 < -tau and alpha_i2 < C" nor "r2 > tau and alpha_i2 > 0" holds, return 0. Otherwise, search for a partner example i1 in the following order.
Step 1. If there are one or more non-bound examples other than i2, take as i1 the example i among them with the largest |E_i - E_i2| (ties: the smaller number), and perform take(i1, i2). If it succeeds, add 1 to heuristic and return 1.
Step 2. For i1 = 1, ..., N in this order, perform take(i1, i2) for each non-bound example i1 (including the example tried in step 1 and i2 itself). If one succeeds, add 1 to nonbound_loop and return 1.
Step 3. For i1 = 1, ..., N in this order, perform take(i1, i2) for every example i1. If one succeeds, add 1 to full_loop and return 1.
Step 4. If none succeeds, return 0.

(4) Passes
A "full pass" performs examine(i) for every example i, for i = 1, ..., N in this order. A "non-bound pass" performs examine(i), for i = 1, ..., N in this order, for each example i that is non-bound at that moment (after the updates made by the preceding examine calls). In both cases, the sum of the values returned by examine is the "change count" of that pass.
Set the flag all to true, and repeat the following steps 1 to 4.
Step 1. If all is true, perform a full pass and add 1 to P_f; if it is false, perform a non-bound pass and add 1 to P_n. For this pass, record its kind (full or non-bound), the number of examine calls within this pass, and the change count. For a full pass, also record all alpha_i at the moment it ends.
Step 2. If it was a full pass and the change count is 0, training "converges" and ends.
Step 3. Otherwise, if P_f + P_n = P_max, training ends without converging.
Step 4. If all is true, set all to false. Otherwise (all is false), if the change count is 0, set all to true. Return to step 1.
P_f + P_n is called the "number of passes". The result of training is the alpha_i, b, the counts, whether it converged, and the record of each pass. The passes are numbered from 1 in the order they were recorded. The errors E_i are not used outside training.

* 4. Decision values and objectives of a model
For a model trained by 3, an example with alpha_i > 0 is called a "support vector"; among them, those with alpha_i = C are called "bound support vectors", and those with 0 < alpha_i < C are called "non-bound support vectors".
- Decision value at a point z: f(z) = S - b, where S = SUM alpha_j * y_j * K(z_j, z), adding only over the j with alpha_j > 0, in increasing order of number.
- Decision value of example i: f_i = s_i - b, where s_i = SUM alpha_j * y_j * Q_ij, adding only over the j with alpha_j > 0, in increasing order of number.
- q = SUM alpha_i * y_i * s_i (i = 1, ..., N), and the dual objective J = SUM alpha_i - q / 2 (both sums are over all i).
The decision value at the point t_j of a test example is f(t_j) (the formula above for the decision value at a point z, with z = t_j).

* 5. Cross-validation and model selection
For each kernel in kernel order, compute the kernel matrix G of the training points x_1, ..., x_n, and for each C in C candidate order perform the following k-fold cross-validation.
- For each fold phi = 1, ..., k, the training examples i with (i - 1) mod k = phi - 1 are the "test examples of fold phi", and the other training examples are the "training examples of fold phi" (both in training data order).
- Train a model by the method of 3 with the points and labels of the training examples of fold phi, the kernel matrix obtained by extracting the rows and columns of those training examples from G, and C.
- For each test example i of fold phi, compute the decision value of this model at the point x_i, and call it the "cross-validation decision value" of training example i. The number of test examples of fold phi with sgn(cross-validation decision value) = y_i is the correct count of fold phi.
- The sum of the correct counts of all folds is the "correct count" of this (kernel, C) combination. Also compute, over the models of all folds, the sum of the numbers of support vectors, the sum of the numbers of passes, and the sum of the numbers of successful steps.
For each kernel, the C with the largest correct count (ties: the smaller C) is the "best C" of that kernel. Compare the correct counts of the kernels at their best C; the kernel with the largest (ties: the one whose best C is smaller; if that is also equal, the one earlier in kernel order) is the "selected kernel", and its best C is the "selected C".
Sort all (kernel, C) combinations by correct count in decreasing order, ties by C in increasing order, and if that is also equal by kernel order, and assign ranks from 1 in this order.

* 6. Evaluation of the final models
For each kernel in kernel order, train a model by the method of 3 with all training examples (points x_1, ..., x_n, labels y_1, ..., y_n, kernel matrix G) and the best C of that kernel; this is the "final model" of that kernel. The final model of the selected kernel is called the "selected model". For each final model, compute the decision values f_i of the training examples and the decision values f(t_j) of the test examples, and compute the following values.
(1) Alignment: with S_y = SUM SUM y_i * y_j * G_ij and S_g = SUM SUM G_ij * G_ij (both summed for i = 1, ..., n in this order, and for each i, for j = 1, ..., n in this order), it is S_y / (n * sqrt(S_g)).
(2) The number of support vectors, and the numbers of bound and non-bound ones among them. Further, count the bound and non-bound support vectors separately for the examples with label 1 and the examples with label -1.
(3) The equality constraint value: SUM alpha_i * y_i.
(4) Only for kernels of kind linear, compute the weight vector (w1, w2): w1 = SUM alpha_i * y_i * x_i1, w2 = SUM alpha_i * y_i * x_i2 (summed over all i).
(5) The norm sqrt(q), the margin width 2 / sqrt(q), and the dual objective J (q and J are computed by the formulas of 4).
(6) The primal objective Pr = q / 2 + C * Xi (Xi = SUM max(0, 1 - y_i * f_i)), and the duality gap Pr - J.
(7) KKT violations: for each training example let r_i = y_i * f_i - 1, and the violation v_i is max(0, -r_i) if alpha_i = 0, max(0, r_i) if alpha_i = C, and |r_i| otherwise. Compute the number of training examples with v_i > tau, and the maximum of v_i.
(8) xi-alpha estimate: let R = (the maximum of G_ii (i = 1, ..., n)) - (the minimum of all entries of G); the number of training examples with 2 * alpha_i * R + max(0, 1 - y_i * f_i) >= 1 is the "estimated error count".
(9) Training correct count: the number of training examples with sgn(f_i) = y_i.
(10) Test evaluation: the prediction for each test example is sgn(f(t_j)); count tp (label 1, prediction 1), fp (label -1, prediction 1), tn (label -1, prediction -1) and fn (label 1, prediction -1). The test correct count is tp + tn.
(11) AUC: for every pair of a test example j1 with label 1 and a test example j2 with label -1 (j1 in test data order, and for each j1, j2 in test data order), add 1 if f(t_j1) > f(t_j2), 0.5 if f(t_j1) = f(t_j2), and 0 otherwise; the AUC is this sum divided by (the number of test examples with label 1) * (the number of test examples with label -1).
(12) The number of test examples with |f(t_j)| < 1 (the number inside the margin), the mean of the decision values of the test examples with label 1, and the mean of the decision values of the test examples with label -1 (added in test data order and divided by the count).

* 7. Analysis of the selected model
(1) Training progress: uses the record of each pass of the training of the selected model. For a full pass, also compute the dual objective J by the formulas of 4, taking the recorded alpha_i as the alpha_i of the model (the kernel matrix is G).
(2) Change with C: for each C in C candidate order, train a model with the selected kernel from all training examples and that C (when C is the selected C, the result is the same as the selected model), and compute the numbers of support vectors (total, bound, non-bound), the dual objective J, the training correct count, the test correct count (the number of test examples with sgn(f(t_j)) = u_j), the number of passes, the number of successful steps, and whether it converged.
(3) Learning curve: for each q in LEARNING_CURVE order, let s = floor(n * q / 100) (integer arithmetic), and train a model of the selected kernel with training examples 1, ..., s (and the kernel matrix of their points) and the selected C. Compute the number of support vectors, the training correct count on training examples 1, ..., s, the test correct count on all test examples, the number of passes, the number of successful steps, and whether it converged.

* 8. Calibration to probabilities (Platt's method)
Using the cross-validation decision values v_1, ..., v_n of the combination of the selected kernel and the selected C (computed in 5), compute the coefficients A and B of the function p(v) = 1 / (1 + exp(A * v + B)), which converts a decision value v into a probability.
Let N+ be the number of training examples with label 1, and N- the number of training examples with label -1. The target value theta_i of training example i is (N+ + 1) / (N+ + 2) if y_i = 1, and 1 / (N- + 2) otherwise. With p_i = p(v_i), the negative log-likelihood is NLL = -(SUM (theta_i * ln(p_i) + (1 - theta_i) * ln(1 - p_i))) (compute the sum, then change its sign).
Initially A = 0 and B = ln((N- + 1) / (N+ + 1)). Then perform the following Newton iteration N_it times. Compute p_i with the current A and B, let
  g1 = SUM v_i * (theta_i - p_i), g2 = SUM (theta_i - p_i),
  h11 = SUM v_i * v_i * p_i * (1 - p_i), h21 = SUM v_i * p_i * (1 - p_i), h22 = SUM p_i * (1 - p_i),
  det = h11 * h22 - h21 * h21
and replace A by A - (h22 * g1 - h21 * g2) / det and B by B - (h11 * g2 - h21 * g1) / det (both use the values computed with A and B before the update).
With the final A and B, compute the probability p'_j = p(f(t_j)) of each test example under the selected model, and compute the following values.
- log_loss = -(SUM l_j) / m, where l_j is ln(p'_j) if u_j = 1, and ln(1 - p'_j) otherwise.
- brier = (SUM (p'_j - e_j) * (p'_j - e_j)) / m, where e_j is 1 if u_j = 1, and 0 otherwise.
- Bins: put each test example into bin beta, where beta = min(4, floor(p'_j * 5)). For each bin beta = 0, ..., 4, compute the number of test examples, the mean of p'_j (added in test data order and divided by the count), and the ratio of the number of examples with label 1 to the number of examples in the bin.
- Closest examples: the first 5 test examples when sorted by |f(t_j)| in increasing order (ties: test data order).

* 9. Pegasos method
The first kernel of kind linear in kernel order is called the "comparison linear kernel". A linear decision function psi(z) = w1 * z1 + w2 * z2 + w0 (z = (z1, z2), w0 is the bias) is computed by the Pegasos method (stochastic subgradient descent on the hinge loss; the bias is also regularized) as follows.
Random numbers are produced by the MINSTD generator. The generator holds an integer state rho, initially rho = seed. "Drawing a random number" means replacing rho by (48271 * rho) mod 2147483647 and returning the new rho (the product is less than 2^53, so it can be computed exactly with 64-bit integers or with double precision).
Set w1 = w2 = w0 = 0, the sums for averaging S1 = S2 = S0 = 0, and the number of updates to 0. For t = 1, ..., T in this order, do the following.
Step 1. Draw a random number; i is the remainder of that value divided by n, plus 1.
Step 2. Let eta_t = 1 / (lambda * t) and sigma = 1 - eta_t * lambda.
Step 3. If y_i * psi(x_i) < 1 (psi is computed with w1, w2, w0 before the update), replace w1 by sigma * w1 + eta_t * y_i * x_i1, w2 by sigma * w2 + eta_t * y_i * x_i2, and w0 by sigma * w0 + eta_t * y_i, and add 1 to the number of updates. Otherwise, replace w1, w2, w0 by sigma * w1, sigma * w2, sigma * w0, respectively.
Step 4. Add w1, w2, w0 to S1, S2, S0, respectively.
Step 5. If t mod (T / 10) = 0, as a "checkpoint", compute psi(x_i) for all training examples, and compute the objective lambda / 2 * (w1 * w1 + w2 * w2 + w0 * w0) + Xi / n (Xi = SUM max(0, 1 - y_i * psi(x_i))) and the number of training examples with sgn(psi(x_i)) = y_i.
The w1, w2, w0 at the end of the T iterations are the "Pegasos weights", and (S1 / T, S2 / T, S0 / T) are the "average weights". Compute the training correct count and the test correct count with the Pegasos weights, and the test correct count with the average weights (the prediction is sgn(psi(z))).
Compute the cosine with the weight vector (v1, v2) of the final model of the comparison linear kernel (6 (4)), (w1 * v1 + w2 * v2) / (sqrt(w1 * w1 + w2 * w2) * sqrt(v1 * v1 + v2 * v2)), and the number of test examples for which the prediction with the Pegasos weights, sgn(psi(t_j)), agrees with the prediction of the final model of the comparison linear kernel, sgn(f(t_j)).

* 10. McNemar test
The final models of the kernels (in kernel order) followed by the decision function of the Pegasos weights, in this order, form the "comparison order". For each test example, a model is correct on that example if its prediction (the sign of its decision value) agrees with the label. For every pair (a, b) where a comes before b in comparison order (a in comparison order, and for each a, b in comparison order), count the number n1 of test examples on which a is correct and b is not, and the number n2 of test examples on which b is correct and a is not, and if n1 + n2 > 0, compute chi2 = (|n1 - n2| - 1) * (|n1 - n2| - 1) / (n1 + n2) (compute the numerator and the denominator as integers, and do the real division last).

* 11. Multi-class classification
The kernel of MULTICLASS is the multi-class kernel, and C_m is the multi-class C. Let the points of the multi-class training data be z_1, ..., z_Nm and their classes c_1, ..., c_Nm, and let G_m be the kernel matrix of those points.
- one-vs-rest: for k = 1, 2, 3 in this order, with the label 1 if c_i = k and -1 otherwise, train a model with all multi-class training examples, G_m and C_m; this is "model k-rest". Its decision value at a point z is g_k(z).
- one-vs-one: for (a, b) = (1, 2), (1, 3), (2, 3) in this order, using only the multi-class training examples whose class is a or b (in file order), with the label 1 if the class is a and -1 if it is b, train a model with the kernel matrix obtained by extracting the rows and columns of those examples from G_m, and C_m; this is "model a-b". Its decision value at a point z is h_ab(z).
A point z is classified as follows.
- one-vs-rest prediction: the class whose g_1(z), g_2(z), g_3(z) is the largest (ties: the smaller class number).
- one-vs-one prediction: set the votes and the score of each class to 0, and for (a, b) = (1, 2), (1, 3), (2, 3) in this order, compute h = h_ab(z), give one vote to class a if h > 0 and to class b otherwise, add h to the score of a, and subtract h from the score of b. The class with the most votes is the prediction. When two or more classes have the most votes (this is called a "vote tie"), the prediction is the one among them with the largest score (ties: the smaller class number).
The test correct count of each model is counted as follows. For model k-rest, it is the number of examples, among all multi-class test examples, for which sgn(g_k(z)) agrees with "1 if the class is k, and -1 otherwise". For model a-b, it is the number of examples, among the multi-class test examples whose class is a or b, for which sgn(h_ab(z)) agrees with "1 if the class is a, and -1 if it is b".
For each of the multi-class training data and test data, count the number of examples whose one-vs-rest prediction agrees with the class, the number of examples whose one-vs-one prediction agrees with the class, the number of examples on which the two predictions agree, and the number of examples that had a vote tie.
For the multi-class test data, build a confusion matrix for each of one-vs-rest and one-vs-one. A confusion matrix is a 3-row, 3-column table U, where U[c][p] is the number of examples whose class is c and whose prediction is p. The precision of class k is the ratio of U[k][k] to the sum of column k of U, and the recall is the ratio of U[k][k] to the sum of row k of U.

* 12. Decision region plots
A plot is a grid of W characters across and H lines down. Let dx = (x_max - x_min) / W and dy = (y_max - y_min) / H. The center of the "cell" in row r from the top and column c from the left (r = 0, ..., H - 1, c = 0, ..., W - 1) is (x_min + (c + 0.5) * dx, y_max - (r + 0.5) * dy). The cell of a point (p1, p2) is the cell with c = floor((p1 - x_min) / dx) and r = floor((y_max - p2) / dy); unless 0 <= c < W and 0 <= r < H, the point is "outside the plot".
(1) Two-class plot: from the decision value v of the selected model at the center of each cell, place the character + if v >= 1, . if 0 < v < 1, - if -1 < v <= 0, and a space if v <= -1. Then, for each training example in training data order: if it is outside the plot, add 1 to the outside count. Otherwise, if no training example has been assigned to its cell yet, or if this training example is a support vector of the selected model and the training example already assigned is not a support vector, assign the cell to this training example (in any other case the assignment is not changed). Finally, replace the character of each cell that has an assigned training example by X if that training example is a support vector with label 1, x if it is a non-support-vector example with label 1, O if it is a support vector with label -1, and o if it is a non-support-vector example with label -1.
(2) Probability plot: for the decision value v of the selected model at the center of each cell, compute p(v) with the A and B found in 8, and place the single digit min(9, floor(p(v) * 10)). No training examples are placed.
(3) Sign agreement: for the final model of each kernel, compute the sign sgn(v) of the decision value at the center of every cell. For every pair (a, b) where a comes before b in kernel order (a in kernel order, and for each a, b in kernel order), count the number of cells where the signs agree and, for each of a and b, the number of cells where its sign is 1.
(4) Multi-class plot: classify the center of each cell by the method of 11, and place the character ? if the one-vs-rest prediction and the one-vs-one prediction differ, and otherwise a space if the predicted class is 1, . if it is 2, and : if it is 3. Then, for each example in multi-class training data order: if it is outside the plot, add 1 to the outside count; otherwise, if no example has been assigned to its cell yet, assign the cell to this example. Finally, replace the character of each cell that has an assigned example by the digit of that example's class (1, 2, 3).
The "number of points" of (1) and (4) is the number of cells that have an assigned example. The number of cells of each character is counted after the replacement by the point characters.
