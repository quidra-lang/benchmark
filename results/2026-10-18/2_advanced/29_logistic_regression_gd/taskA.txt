[Overview]
Write a program that trains and evaluates logistic regression on data consisting of numeric features and class labels. The features are expanded into monomials up to degree P and then standardized. For binary classification (deciding whether a row belongs to a given class), the L2 regularization coefficient lambda is chosen by 5-fold cross-validation, and models are trained and compared with three methods: gradient descent, mini-batch stochastic gradient descent, and Newton's method (using the Cholesky decomposition). In addition, the program outputs the changes with lambda, the degree and the amount of training data; evaluation on the test data such as the confusion matrix, ROC curve, AUC and calibration; the coefficient table and diagnostics of the Newton's method model (Hosmer-Lemeshow test, leverage and Cook's distance, marginal effects, bootstrap, permutation importance, and so on); a comparison of multiclass softmax regression with one-vs-rest; and maps of the predictions.
The input is three files in the input/ folder (training data, test data, settings), and the results are written to five files in the output/ folder. Nothing is written to standard output. All rules, including how random numbers (the MINSTD generator) are used, are defined in [Processing], so the result is uniquely determined.

[Input files]
There are three input files: input/train.csv, input/test.csv and input/params.txt. Every file consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). There is no whitespace at the start or end of a line. Values are separated by a comma in the CSV files and by a single space in params.txt.
An integer is a base-10 number without extra leading zeros; negative integers do not appear. A decimal number is a base-10 number consisting of, in this order, "-" (only for negative numbers), a sequence of one or more digits (the integer part), ".", and a sequence of one or more digits (the fractional part) (examples: 0.5, -1.62, 0.003). Exponent notation is not used.

* input/train.csv (training data)
The first line is a header line listing the string id, the d names of the base features, and the string label in this order, separated by commas (example: id,x1,x2,label). A base feature name is a string of 1 to 8 characters that starts with a lowercase English letter and consists of lowercase English letters and digits only; the names are distinct from each other and are not intercept.
Each line from the second line on represents one example, listing the ID, the d base feature values (decimal numbers) and the label in this order, separated by commas.
- An ID is a string of 1 to 8 characters consisting of uppercase English letters and digits; the IDs are distinct within the file.
- A label is a class number, an integer >= 0.
Let n be the number of examples; in the order of the lines in the file they are called training row 1, ..., training row n. This order is called the "training data order". K = (the maximum label in the training data) + 1 is called the "number of classes".

* input/test.csv (test data)
It has the same format as train.csv, and its header line is also the same as that of train.csv. Let m be the number of examples; in the order of the lines in the file they are called test row 1, ..., test row m, and this order is called the "test data order". The labels are between 0 and K - 1 inclusive. The labels of the test data are used only for evaluation. The test data may contain rows whose base feature values are all the same as those of another row (rows that differ only in the ID, or only in the ID and the label).

* input/params.txt (settings)
The following 11 lines appear in this order. Each line consists of an uppercase keyword and values, separated by single spaces.
- POSITIVE c+: the number of the class whose rows are the "positive examples" in binary classification (an integer from 0 to K - 1).
- DEGREE P: the degree of the expansion (an integer from 1 to 3).
- THRESHOLD tau: the prediction threshold (a decimal number greater than 0 and less than 1).
- LAMBDAS lambda_1 lambda_2 ...: the candidates for the regularization coefficient lambda (positive decimal numbers, 1 to 8 of them, distinct and in increasing order, with at most 4 digits in the fractional part). This order is called the "lambda candidate order".
- GD alpha_g T_g: the learning rate (a positive decimal number) and the number of iterations (a multiple of 100 from 100 to 1000) of gradient descent.
- SGD alpha_s B E seed_s: the learning rate (a positive decimal number), the mini-batch size B (an integer from 1 to n), the number of epochs E (an integer from 1 to 100) and the random seed seed_s (an integer from 1 to 2147483646) of stochastic gradient descent.
- SOFTMAX alpha_m T_m lambda_m: the learning rate (a positive decimal number), the number of iterations (a multiple of 100 from 100 to 1000) and the regularization coefficient (a positive decimal number with at most 4 digits in the fractional part) of softmax regression.
- BOOTSTRAP N_b seed_b: the number of bootstrap resamples (a multiple of 40 from 40 to 1000) and the random seed (an integer from 1 to 2147483646).
- PERMUTATION N_p seed_p: the number of repetitions of permutation importance (an integer from 1 to 20) and the random seed (an integer from 1 to 2147483646).
- MAP W H: the width of the map in characters and its height in characters (integers from 1 to 80).
- COST c_fp c_fn: the cost of one false positive and the cost of one false negative (integers from 1 to 100).

[Processing]
* 1. Notation and computation rules
- All real-number computations are done in double precision (IEEE 754 64-bit floating point). Input decimal numbers are converted to double precision before use.
- exp is the exponential function, ln is the natural logarithm, sqrt is the square root, |t| is the absolute value of t, floor(t) is the largest integer less than or equal to t, and max and min are the maximum and the minimum. a mod b is the remainder of dividing an integer a >= 0 by a positive integer b.
- A sum written with SUM (in place of the summation sign) starts from 0 and adds one term at a time in increasing order of the index (or, when an order of the sequence is defined, in that order). Other sums follow the same rule unless stated otherwise. Multiplications and divisions in an expression are computed from left to right in the written order, and additions and subtractions are also computed from left to right in the written order.
- Counting is done with integers. A division that obtains a real number from integers (except for ratios) converts both operands to double precision before dividing. How to write a "ratio" and a "fraction" is defined in [Output files].
- The "length" of a vector with components v_1, ..., v_k is sqrt(SUM v_i * v_i).
- Random numbers are produced by the MINSTD generator. A generator has an integer state rho, which is initially the given seed. "Draw one random number" means replacing rho with (48271 * rho) mod 2147483647 and returning the new rho (the product is less than 2^47, so it can be computed exactly with either 64-bit integers or doubles). Generators with different seeds are independent of each other.
- To "shuffle" a sequence a_1, ..., a_L of length L with a generator means: for i = L, L - 1, ..., 2 in order, draw one random number, call its value r, let k = (r mod i) + 1, and swap a_i and a_k.

* 2. Feature expansion
The feature columns of train.csv are called the "base features" and are numbered 1, ..., d in column order.
For k = 1, ..., P in order, for each k, list all index tuples (i_1, ..., i_k) satisfying 1 <= i_1 <= i_2 <= ... <= i_k <= d in increasing lexicographic order; all the tuples arranged in this order are the "expanded features" (example: for d = 2, P = 3 there are 9 of them: (1), (2), (1, 1), (1, 2), (2, 2), (1, 1, 1), (1, 1, 2), (1, 2, 2), (2, 2, 2)). Let p be the number of expanded features, and number them 1, ..., p in this order. The length k of the tuple is called the "degree" of the feature, and p_D is the number of features of degree D or less (the features of degree D or less are the first p_D features, and p_P = p).
- Name: the names of the base features of the indices of the tuple, joined with * in the order of the tuple (examples: x1, x1*x2, x1*x1*x2).
- Value: with v_1, ..., v_d the base feature values of a row, the value of the tuple (i_1, ..., i_k) is v_i1 * v_i2 * ... * v_ik (the product multiplied from the left; for k = 1 it is v_i1 itself). These p values are called the "expanded values" of the row.

* 3. Standardization
From the expanded values of a sequence of rows R (r rows), compute for each expanded feature j (j = 1, ..., p) the mean mu_j = (SUM phi_ij) / r and the standard deviation s_j = sqrt((SUM (phi_ij - mu_j) * (phi_ij - mu_j)) / (r - 1)). phi_ij is the value of feature j of the i-th row of R, and the sums are added in the order of R. These are called the "statistics of R".
The "standardized vector" of a row by the statistics mu, s is the (p + 1)-dimensional vector with components 0, 1, ..., p, xt = (1, (phi_1 - mu_1) / s_1, ..., (phi_p - mu_p) / s_p) (component 0 is always 1.0, and phi_j are the expanded values of that row).
The statistics of all training rows (in training data order) are called the "overall statistics", and the standardized vectors by them the "overall standardized vectors". Unless stated otherwise, both training rows and test rows use the overall standardized vectors. When "only the first q features are used", the statistics are computed from expanded features 1, ..., q only (or only entries 1, ..., q of already computed statistics are used), and (q + 1)-dimensional standardized vectors with components 0, ..., q are used.

* 4. Binary logistic regression
The target y of each row is 1 if its label is c+ and 0 otherwise. Rows with y = 1 are called positive examples, and rows with y = 0 negative examples. Below, the dimension of the standardized vectors and of the weights is q + 1 (components 0, ..., q) (q = p unless stated otherwise). In the weights w = (w_0, ..., w_q), w_0 is called the intercept.
- Score: u(w, xt) = SUM w_j * xt_j (j = 0, ..., q)
- Probability: sigma(u) is 1 / (1 + exp(-u)) if u >= 0, and e / (1 + e) (e = exp(u)) if u < 0. sigma(u(w, xt)) is called the "probability" of the row.
- Loss: ell(u, y) = max(u, 0) - y * u + ln(1 + exp(-|u|))
- For a sequence of rows (standardized vectors xt_1, ..., xt_r, targets y_1, ..., y_r) and lambda, the objective function is J(w) = (SUM ell(u_i, y_i)) / r + lambda * S / 2, where u_i = u(w, xt_i) and S = SUM w_j * w_j (j = 1, ..., q; the intercept is not included). (SUM ell(u_i, y_i)) / r is called the "average loss" (it does not include the regularization term).
- Gradient g(w): with e_i = sigma(u_i) - y_i and G_j = SUM e_i * xt_ij (i = 1, ..., r), g_0 = G_0 / r and g_j = G_j / r + lambda * w_j (j = 1, ..., q).
- Hessian H(w): with v_i = sigma(u_i) * (1 - sigma(u_i)), the components with j >= k are H_jk = (SUM v_i * xt_ij * xt_ik) / r, and when j = k >= 1, lambda is further added. H_kj = H_jk.
- Prediction: for a probability pi, it is 1 if pi >= tau and 0 otherwise. A prediction is "correct" when it equals y. The "number correct" of a sequence of rows is the number of rows whose prediction is correct.

* 5. The three optimization methods
In every method, the initial weights have all components 0. "Move the weights by alpha in the direction of g" means replacing w_j with w_j - alpha * g_j for every j (g is the one computed with w before the replacement).
(1) Gradient descent (GD): for t = 1, ..., T_g in order, compute the gradient g(w) on all training rows and move the weights by alpha_g in the direction of g. The weights at t = 0 (before training) and whenever t becomes a multiple of 100 are recorded as the "weights at checkpoint t".
(2) Stochastic gradient descent (SGD): prepare a generator with seed seed_s, and prepare the sequence o = (1, 2, ..., n). For epochs e = 1, ..., E in order, do the following. First, shuffle o with the generator (the sequence shuffled in the previous epoch is shuffled further). Next, split o from the start into chunks of B elements (the last chunk may have fewer than B elements), and in chunk order, for each "mini-batch", compute the gradient g(w) on the sequence of the training rows of the mini-batch arranged in the order of o (r is the number of rows in the mini-batch), and move the weights by alpha_s in the direction of g. The weights at e = 0 (before training) and at the end of each epoch are the "weights at checkpoint e".
(3) Newton's method: for t = 1, ..., 10 in order, compute g = g(w) and H = H(w) on the sequence of rows used, solve H Delta = g by the Cholesky decomposition below, and replace w_j with w_j - Delta_j for every j. The weights at t = 0 and after each iteration are the "weights at checkpoint t".
- Cholesky decomposition: for a symmetric matrix A (components 0, ..., s - 1), for j = 0, ..., s - 1 in order, and for each j for i = j, ..., s - 1 in order, let sigma_ij = A_ij - (SUM L_ik * L_jk (k = 0, ..., j - 1)) (the sum is computed first and then subtracted); if i = j, L_jj = sqrt(sigma_jj), otherwise L_ij = sigma_ij / L_jj.
- Solution of the linear system A x = b: by forward substitution, for i = 0, ..., s - 1 in order, compute z_i = (b_i - SUM L_ik * z_k (k = 0, ..., i - 1)) / L_ii; then by back substitution, for i = s - 1, ..., 0 in order, compute x_i = (z_i - SUM L_ki * x_k (k = i + 1, ..., s - 1)) / L_ii.
When training with these methods, the sequence of rows used, the targets and lambda are stated explicitly. Below, when the text simply says "train with Newton's method", all training rows (with the overall standardized vectors) are used.

* 6. Inverse matrix and leverage
- Inverse matrix: Cholesky-decompose the symmetric matrix A (components 0, ..., s - 1), and for each k = 0, ..., s - 1, solve A x = b with b the vector whose component k is 1.0 and whose other components are 0.0; component j of the solution is the (j, k) entry M_jk of the inverse matrix M.
- Influence computation: for weights w, a sequence of rows (xt_i, y_i, i = 1, ..., r) and lambda, let M be the inverse matrix of H(w), and compute the following values for each row i.
  pi_i = sigma(u_i), v_i = pi_i * (1 - pi_i), Q_i = SUM SUM xt_ij * M_jk * xt_ik (for j = 0, ..., q in order, and for each j for k = 0, ..., q in order, added as a single sum),
  leverage h_i = v_i * Q_i / r, Pearson residual e_i = (y_i - pi_i) / sqrt(v_i), standardized residual t_i = e_i / sqrt(1 - h_i),
  Cook's distance D_i = e_i * e_i * h_i / ((q + 1) * ((1 - h_i) * (1 - h_i)))
- Fit measures: the effective number of parameters edf = SUM h_i, the deviance dev = 2 * r * L (L is the average loss of w), AIC = dev + 2 * edf, and BIC = dev + ln(r) * edf.

* 7. Cross-validation and the choice of lambda
Training row i is a "validation row of fold f" if (i - 1) mod 5 = f - 1, and a "training row of fold f" otherwise (f = 1, ..., 5; both are arranged in training data order).
"Cross-validate lambda with the first q features" means doing the following for f = 1, ..., 5 in order. Compute the statistics (of the first q features) of the training rows of fold f, and train with Newton's method on the standardized vectors of the training rows of fold f by those statistics, their targets, and lambda. For each validation row i of fold f, compute the score u_i with its standardized vector by the same statistics, record the "validation loss" ell_i = ell(u_i, y_i) and the "validation probability" sigma(u_i), and count an error if the prediction from the validation probability differs from y_i. The loss of fold f is (the sum of ell_i over the validation rows of fold f) / (the number of validation rows of fold f). When all 5 folds are done, compute the cross-validation loss CV = (SUM ell_i (i = 1, ..., n)) / n.
For each lambda in lambda candidate order, cross-validate with the first p (that is, all) features. The lambda with the smallest CV (if tied, the larger one) is the "selected lambda", written lambda*.
- One-standard-error rule: for the 5 fold losses f_1, ..., f_5 of lambda*, let f_bar = (SUM f_k) / 5 and se = sqrt((SUM (f_k - f_bar) * (f_k - f_bar)) / 4) / sqrt(5); the largest lambda candidate with CV <= (CV of lambda*) + se is lambda_1se.
- Validation evaluation: with the validation probabilities of the cross-validation of lambda*, compare the predictions with y and count tp (y = 1, prediction 1), fp (y = 0, prediction 1), tn (y = 0, prediction 0) and fn (y = 1, prediction 0); also compute the AUC (11 (3)) with the validation probabilities as the scores.

* 8. lambda path, degree comparison, learning curve
(1) lambda path: for each lambda in lambda candidate order, train with Newton's method with lambda, and compute J(w), the average loss of the training rows, the average loss of the test rows, the number correct of the training rows, the number correct of the test rows, and the length of (w_1, ..., w_p).
(2) Degree comparison: for D = 1, ..., P in order, let q = p_D, use only the first q features (the statistics remain the overall statistics), and train with Newton's method with lambda*. Compute the CV obtained when cross-validating lambda* with the first q features, the average losses of the training rows and of the test rows, the number correct of the test rows, the AUC with the probabilities of the test rows as the scores, and edf, AIC and BIC from the influence computation with its weights, all training rows (standardized vectors of the first q features) and lambda*.
(3) Learning curve: for k = 1, ..., 4 in order, let s = floor(k * n / 4), compute the statistics of training rows 1, ..., s, and train with Newton's method on the standardized vectors of training rows 1, ..., s by those statistics, their targets, and lambda*. Standardize the test rows with the same statistics as well, and compute the average loss of training rows 1, ..., s, the average loss of the test rows, the number correct of the test rows, and the AUC with the probabilities of the test rows as the scores.

* 9. Final models
The models trained with lambda* by gradient descent, stochastic gradient descent and Newton's method are called gd, sgd and newton respectively, and this order is called the "model order". The weights of each model are the weights at its last checkpoint. The weights of newton are written w^N. In addition, the model trained by the softmax regression of 10 is called softmax.
- Weights in original units: for weights w, let w'_j = w_j / s_j (j = 1, ..., p) and w'_0 = w_0 - SUM w'_j * mu_j (j = 1, ..., p) (mu and s are the overall statistics). These are the weights that multiply the expanded values directly.
- Correlation matrix and VIF: R_jk = (SUM xt_ij * xt_ik) / (n - 1) (j, k = 1, ..., p; i runs over all training rows, added in training data order) forms the p x p correlation matrix, and the (j, j) entry of its inverse matrix (6) is the VIF of feature j.
- Coefficient table: using the M of the influence computation with w^N, all training rows and lambda*, compute for j = 0, ..., p the standard error se_j = sqrt(M_jj / n), z_j = w^N_j / se_j, the lower bound w^N_j - 1.96 * se_j, the upper bound w^N_j + 1.96 * se_j, and the odds ratio exp(w^N_j).

* 10. Softmax regression
Each of the K classes has weights W_k = (W_k0, ..., W_kp) (k = 0, ..., K - 1). For a standardized vector xt, let a_k = u(W_k, xt), a_max = (the maximum of a_0, ..., a_{K-1}), b_k = a_k - a_max and S = SUM exp(b_k) (k = 0, ..., K - 1); the probability of class k is P_k = exp(b_k) / S. The predicted class is the k with the largest P_k (if tied, the smaller k). The loss of a row with label c is ln(S) - b_c.
- Objective function: J_m = (the sum of the losses) / r + lambda_m * S_W / 2. S_W is W_kj * W_kj added as a single sum, for k = 0, ..., K - 1 in order, and for each k for j = 1, ..., p in order.
- Gradient: for each class k, with e_ik = P_ik - delta_ik (delta_ik is 1 if the label of training row i is k and 0 otherwise) and G_kj = SUM e_ik * xt_ij (i = 1, ..., r), g_k0 = G_k0 / r and g_kj = G_kj / r + lambda_m * W_kj (j = 1, ..., p).
- Training: all training rows (overall standardized vectors, r = n) are used. Set all W_kj to 0; for t = 1, ..., T_m in order, compute the gradients of all k (with the weights before the replacement), and replace W_kj with W_kj - alpha_m * g_kj for all k and j. The weights at t = 0 and whenever t becomes a multiple of 100 are the "weights at checkpoint t".

* 11. Evaluation of the binary models
(1) Confusion matrix: for each model in model order, compute the probability pi_j of test row j, compare the prediction with y_j, and count tp, fp, tn and fn (with the same meaning as in 7). Let Pos be the number of positive examples and Neg the number of negative examples among the test rows.
(2) log_loss is the average loss of the test rows, and brier is (SUM (pi_j - y_j) * (pi_j - y_j)) / m.
(3) AUC: for a sequence of scores s_1, ..., s_N and a sequence of targets a_1, ..., a_N (N_+ is the number with a = 1 and N_- the number with a = 0), arrange all rows in increasing order of score; when a group of rows with equal scores (equal as double values) occupies positions b through e (counted from 1), the "doubled rank" of each row of the group is b + e. With A = (the sum of the doubled ranks of the rows with a = 1) - N_+ * (N_+ + 1) and B = 2 * N_+ * N_-, the AUC is expressed as the fraction A / B. This equals the sum, over all pairs of a row with a = 1 and a row with a = 0, of 1 if the score of the row with a = 1 is larger and 1/2 if they are equal, divided by N_+ * N_-.
(4) ROC points: let v_1, v_2, ... be the distinct values of the probabilities of the test rows (compared as double values) in decreasing order, and for each v_k compute the number of positive examples TP_k and the number of negative examples FP_k among the test rows with pi_j >= v_k. (v_k, TP_k, FP_k) is called an ROC point, and the ROC points are arranged in order of k.
(5) Average precision: AP = (SUM (TP_k - TP_{k-1}) * TP_k / (TP_k + FP_k)) / Pos (TP_0 = 0; each term is the real number obtained by dividing the integer (TP_k - TP_{k-1}) * TP_k by the integer TP_k + FP_k, and the terms are added in order of k).
(6) Youden point: the ROC point with the largest TP_k * Neg - FP_k * Pos (an integer) (if tied, the one with the larger v_k).
(7) Best F1 point: the ROC point with the largest 2 * TP_k / (Pos + TP_k + FP_k) (compared exactly as fractions; if tied, the one with the larger v_k).
(8) Minimum cost point: the ROC point with the smallest cost c_fp * FP_k + c_fn * (Pos - TP_k) (an integer) (if tied, the one with the larger v_k).
(9) Calibration table: put each test row into the bin beta = min(9, floor(pi_j * 10)). For each bin beta = 0, ..., 9, compute the number of rows c_beta, the sum of the probabilities S_beta (added in test data order), and the number of positive examples O_beta. Over the bins that contain rows (in order of beta), compute ECE = (SUM |S_beta - O_beta|) / m, MCE = the maximum of |S_beta / c_beta - O_beta / c_beta| (starting from 0 and keeping the larger value), and HL = SUM (O_beta - S_beta) * (O_beta - S_beta) / (S_beta * (1 - S_beta / c_beta)), and count the number of bins that contain rows.
(10) Gains table: arrange the test rows in decreasing order of probability (if tied, in test data order). For each g = 1, ..., 10, let size = floor(g * m / 10), and compute the number of positive examples hits among the first size rows.
(11) Also compute the number correct of the training rows.
(12) Model comparison: for each pair (a, b) in the order (gd, sgd), (gd, newton), (sgd, newton), count, among the test rows, the number of rows on which the predictions of the two models are equal, the number n_a of rows on which only a is correct, and the number n_b of rows on which only b is correct. The McNemar value is the ratio of (|n_a - n_b| - 1) * (|n_a - n_b| - 1) and n_a + n_b.

* 12. Diagnostics of newton
(1) Fit: let pi_bar = (the number of positive examples among the training rows) / n, and compute null_loss = -(pi_bar * ln(pi_bar) + (1 - pi_bar) * ln(1 - pi_bar)). With L the average loss of newton on the training rows, compute McFadden's R-squared 1 - L / null_loss, and compute dev, edf, AIC and BIC by the influence computation with w^N, all training rows and lambda*.
(2) Hosmer-Lemeshow test on the training rows: with the pi_i (the probabilities of the training rows) of the influence computation of (1), arrange the training rows in increasing order of probability (if tied, in training data order). For each g = 1, ..., 10, the rows at sorted positions floor((g - 1) * n / 10) + 1 through floor(g * n / 10) form group g; compute the number of rows of the group, the number of positive examples O_g and the sum of the probabilities E_g (added in sorted order), and compute HL = SUM (O_g - E_g) * (O_g - E_g) / (E_g * (1 - E_g / (the number of rows of group g))) (added in order of g).
(3) Iteration log: for each iteration t = 1, ..., 10 of the Newton's method of newton, compute, at the weights w before the replacement in that iteration (the weights at checkpoint t - 1), J(w), the length of g = g(w), the length of the solution Delta of H(w) Delta = g, and (SUM g_j * Delta_j) / 2.
(4) Marginal effects: for a vector of base feature values v = (v_1, ..., v_d) and a base feature k, the slope slope_k(v) is the sum, in expanded feature order, of w'_j * (c * Pi) over each feature j whose tuple contains k (w' is the weights of w^N in original units). c is the number of occurrences of k in the tuple, and Pi is the product of the values of the indices that remain after removing one k from the tuple, multiplied starting from 1.0 in the order of the remaining indices (1.0 if none remain).
  The average marginal effect is (SUM pi_i * (1 - pi_i) * slope_k(the base feature values of training row i)) / n (pi_i is the same as in (2)). The marginal effect at the mean is pi_bar_c * (1 - pi_bar_c) * slope_k(v_bar), where v_bar is the overall mean of the base features (mu_1, ..., mu_d of the overall statistics) and pi_bar_c is the probability of newton on the overall standardized vector of the expanded values of v_bar.
(5) Threshold table: for each k = 1, ..., 9, count tp, fp, tn and fn of newton on the test rows when predicting with the threshold k / 10 (1 if pi_j >= k / 10).
(6) Error examples: among the test rows of newton whose prediction differs from y, the first 5 rows (all of them if there are fewer than 5) when arranged in decreasing order of |pi_j - tau| (if tied, in test data order).
(7) Bootstrap: prepare a generator with seed seed_b. For b = 1, ..., N_b in order, draw m random numbers; for each drawn value r, select test row number (r mod m) + 1; then compute AUC = A_b / B_b with the newton probabilities and the targets of the m selected rows arranged in selection order (the same row may be included several times). With a_b = A_b / B_b (a real number), compute mean = (SUM a_b) / N_b and sd = sqrt((SUM (a_b - mean) * (a_b - mean)) / (N_b - 1)) (both added in order of b). Arrange the AUCs in increasing order of value; the (floor(N_b / 40) + 1)-th one is the lower bound and the (N_b - floor(N_b / 40))-th one is the upper bound.
(8) Influence: from the influence computation of (1), compute the number of training rows with |t_i| > 2, and the first 5 rows (all of them if there are fewer than 5) of the training rows arranged in decreasing order of Cook's distance (if tied, in training data order).

* 13. Permutation importance and profiles
(1) Permutation importance: as the baseline, compute the average loss L_0 of newton on the test rows, its AUC A_0 / B_0, and the number correct C_0 of softmax on the test rows (the number of rows whose predicted class equals the label). Prepare a generator with seed seed_p, and keep using the same generator for all repetitions of all base features (it is not reset when moving to the next base feature). For base features k = 1, ..., d in order, and for repetitions t = 1, ..., N_p in order, do the following. Shuffle the sequence o = (1, 2, ..., m) (each repetition starts from this sequence) with the generator, and build data in which the value of base feature k of each test row j is replaced with the value of base feature k of test row o_j (the other base features and the label are unchanged). With the overall standardized vectors of its expanded values, compute the average loss L_t of newton, the A_t of its AUC (B_t equals B_0), and the number correct C_t of softmax. Compute log_loss_increase = (SUM L_t) / N_p - L_0; the AUC is expressed as the fraction (SUM A_t) / (N_p * B_0), and the softmax accuracy as the ratio of (SUM C_t) and N_p * m.
(2) Profiles: for base features k = 1, ..., d in order, compute the minimum lo and the maximum hi of base feature k over the training rows, and for g = 0, ..., 4 in order, for the point obtained by replacing the k-th value of v_bar (12 (4)) with lo + (hi - lo) * g / 4, compute the probability of newton and the K probabilities of softmax with the overall standardized vector of its expanded values.

* 14. Evaluation of softmax and one-vs-rest
(1) Confusion matrix: for each test row, compute the probabilities P_jk of softmax and the predicted class; in the K x K table U, U[c][k] is the number of test rows whose label is c and whose prediction is k. row_k is the sum of U[k][0], ..., U[k][K - 1], and col_k is the sum of U[0][k], ..., U[K - 1][k].
(2) For each class k, precision is the ratio of U[k][k] and col_k, recall is the ratio of U[k][k] and row_k, f1 is the ratio of 2 * U[k][k] and col_k + row_k, and the AUC is computed with the scores P_jk and the targets (1 if the label is k, 0 otherwise).
(3) The accuracy is the ratio of SUM U[k][k] and m, and the kappa coefficient is the ratio of m * SUM U[k][k] - SUM row_k * col_k and m * m - SUM row_k * col_k (every sum is in order of k).
(4) log_loss is the sum of the losses of the test rows divided by m; brier is obtained by computing, for each test row, the sum of (P_jk - delta_jk) * (P_jk - delta_jk) added in order of k, adding these sums in test data order, and dividing by m.
(5) Binary view: with P_j,c+ (the probability of the positive class) as the score, compute the AUC with the targets y_j, log_loss = (SUM -ln(q_j)) / m (q_j is P_j,c+ if y_j = 1, and 1 - P_j,c+ otherwise), the number correct of the predictions obtained by the rule of 4 with P_j,c+ as the probability, and the number of test rows on which that prediction equals the prediction of newton.
(6) Confidence table: the confidence of each test row is the probability of the predicted class, and the row is a hit if the predicted class equals the label. Put the row into the bin beta = min(9, floor(confidence * 10)), and for each bin beta = 0, ..., 9 compute the number of rows, the sum of the confidences (in test data order) and the number of hits. ECE is |sum of the confidences - number of hits| over the bins that contain rows, added in order of beta and divided by m.
(7) one-vs-rest: for k = 0, ..., K - 1 in order, with the target 1 if the label is k and 0 otherwise, train with Newton's method with lambda_m, and compute J(w) at its weights (all training rows, lambda_m) and the AUC with the probabilities of the test rows as the scores (the target being whether the label is k). For each test row, the class whose model gives the largest probability among the K models (if tied, the smaller class) is the one-vs-rest prediction; count the number of rows whose prediction equals the label and the number of rows whose prediction equals the prediction of softmax.

* 15. Maps
Base feature 1 is the horizontal axis and base feature 2 the vertical axis; let lo_1 and hi_1 be the minimum and maximum of base feature 1 over the training rows, and lo_2 and hi_2 the minimum and maximum of base feature 2. A map is a grid W characters wide and H rows high; the center of the cell in row r from the top and column c from the left (r = 0, ..., H - 1, c = 0, ..., W - 1) is the point whose base feature 1 value is lo_1 + (c + 0.5) * (hi_1 - lo_1) / W, whose base feature 2 value is hi_2 - (r + 0.5) * (hi_2 - lo_2) / H, and whose other base feature values (when d >= 3) are those of v_bar.
With the overall standardized vector of the expanded values of each cell center, compute the predicted class of softmax and place its single digit on the "class map", and place the single digit min(9, floor(pi * 10)) computed from the probability pi of newton on the "probability map". Count, on the class map, the number of cells in which the digit of each class is placed.
