[Overview]
Write a program that performs survival analysis on the follow-up data of a clinical trial (subjects divided into several treatment groups and observed until an event (death) occurs or follow-up is censored).
For each group and for all subjects, compute the Kaplan-Meier survival estimates (with the Greenwood variance and 95% confidence intervals by the log-log transform), the Nelson-Aalen cumulative hazard, percentiles of the survival time (the median and others) with their confidence intervals, the restricted mean survival time (RMST), the median follow-up by the reverse Kaplan-Meier method, the event rate, and an actuarial life table.
As group comparisons, compute a comparison of baseline characteristics (Kruskal-Wallis test and chi-square tests of contingency tables), the k-group log-rank test, the Gehan-Breslow generalized Wilcoxon test, the Tarone-Ware test (each statistic is obtained with a (k - 1) x (k - 1) covariance matrix and Gaussian elimination), a trend test, stratified tests by stage or sex, a landmark analysis, pairwise comparisons (with Holm adjustment and hazard ratios), a subgroup analysis with heterogeneity tests, RMST differences, rate ratios, and survival differences at the report times. P-values are obtained from the chi-square distribution. The methods for computing the log-gamma function (Lanczos approximation) and the incomplete gamma function (series and continued fraction) needed for this are given in this statement, so no built-in gamma function or similar function of any language is used.
Further, fit the Cox proportional hazards model based on the Breslow partial likelihood by the Newton-Raphson method with exactly 25 iterations, and compute the coefficients, hazard ratios, standard errors, Wald tests, contrasts between groups, overall likelihood-ratio, Wald and score tests, likelihood-ratio tests against the models without each covariate, the C statistic, a check of proportional hazards using Schoenfeld residuals, martingale and deviance residuals, and adjusted survival. Finally, draw a character plot of the Kaplan-Meier curve of each group.
The only functions used in the computations are the four arithmetic operations, square root, the exponential function and the natural logarithm. All rules are defined in [Processing], so the results are uniquely determined.
The input is two files in the input/ folder (subject data and parameters), and the results are written to five files in the output/ folder. Nothing is printed to standard output.

[Input files]
The input files are input/subjects.csv and input/params.txt. Both files consist of ASCII characters only, and every line (including the last one) ends with a newline (LF). There are no blank lines, and no line has leading or trailing spaces. Integers are unsigned decimal numbers without extra leading zeros.

## input/subjects.csv (subject data)
The first line is the header line, the string id,group,time_days,event,age,sex,stage. Each line from the second line on represents one subject and consists of the following seven values in this order, separated by commas (there are no spaces).
- id: the subject number (an integer from 1 to 9999). It is different for every subject.
- group: the name of the subject's group. It is one of the names given in GROUPS of params.txt.
- time_days: the number of days from the start of follow-up to the day on which the event occurred or the subject was censored (an integer from 1 to 9999). Below, this is called the subject's "time".
- event: 1 means that the event occurred on that day; 0 means that the subject was censored on that day (the status after that day is unknown).
- age: the age (an integer from 18 to 99).
- sex: the sex, the single character F or M.
- stage: the disease stage (an integer from 1 to 4).
The lines are not necessarily in order of subject number.

## input/params.txt (parameters)
The following 10 lines appear in this order. Each line consists of an uppercase keyword and one or more values, separated by single spaces.
- GROUPS g_1 g_2 ... g_k: the group names (from 2 to 6 names, all distinct). A group name is a string of 1 to 16 characters that starts with a lowercase letter and consists of lowercase letters, digits and "_"; it differs from each of all, age, male and stage. This order is called the "group order", and g_1 is called the "control group". Below, group g_i is also written simply as group i.
- REPORT_TIMES t_1 t_2 ...: the time points (days) at which survival and other values are reported (from 1 to 10 distinct integers from 1 to 9999, in increasing order). This order is called the "report-time order".
- TAU tau: the upper limit, in days, of the period for the RMST (an integer from 1 to 9999).
- LIFE_TABLE w K: the width w of a life-table interval and the number K of intervals (w and K are positive integers, K <= 20, and w * K <= 9999).
- STRATA v: the name of the variable used for the stratified tests, sex or stage.
- SUBGROUPS v_1 ...: the names of the variables used for the subgroup analysis (one or two distinct names out of sex and stage, in any order).
- LANDMARK L: the landmark time in days (an integer from 1 to 9999).
- COX c_1 c_2 ... c_p: the names of the covariates of the Cox model (from 1 to 4 names, all distinct). Each name is age, male, stage, or a group name other than g_1. This order is called the "covariate order".
- RESIDUALS R: the number of residuals to write (an integer from 1 to 20, at most the number of subjects).
- PLOT W H T M: the number of columns W of the plot (an integer from 10 to 100), the number of rows H (an integer from 4 to 40), the range T of the horizontal axis in days (a positive integer <= 9999), and the number M of divisions of the at-risk table (an integer from 1 to 12). T is divisible by both W and M.

[Processing]
## 1. Notation and computation rules
- All real-number computations are done in double precision (IEEE 754 64-bit floating point). When an integer is used in a real-number computation, its value converted to double precision is used.
- sqrt is the square root, ln is the natural logarithm, exp is the exponential function, |x| is the absolute value of x, and floor(x) is the largest integer <= x.
- [A / B] is the real number obtained by dividing the integer A by the integer B. A and B are converted to double precision (when they are written as expressions, after first computing them exactly as integers) and divided once. For example, in [d * (n - d) / ((n - 1) * n * n)], the numerator and the denominator are each computed as integers and then divided.
- A sum written with the symbol sum starts from 0 and adds one term at a time in the specified order. A sum whose order is not stated is taken in increasing order of the index (or, for a sequence whose order is defined, in that order). Multiplications and divisions in an expression are computed from left to right in the written order, and additions and subtractions are also computed from left to right in the written order (parentheses are computed first). -x is the value of x with its sign inverted.
- z = 1.959963984540054 (the upper 2.5% point of the standard normal distribution).
- Unless stated otherwise, subjects are processed in increasing order of subject number. This is called the "subject order".
- Counting, such as "the number of subjects with time >= u", and comparisons of magnitude are done exactly with integers.
- For each rule that selects the "smallest" or "first" item, the handling when no item qualifies (NA and so on) is specified case by case.

## 2. Collections and risk sets
For a collection P of subjects, define the following. As P we use all subjects of each group (the "collection of group g"), all subjects (the "all collection"), and others.
- Let u_1 < u_2 < ... be the values of time that appear in P, in increasing order.
- The "risk-set size" n(u) at time u is the number of subjects in P with time >= u. When an event and a censoring happen on the same day, the event is considered to happen first. Therefore subjects censored on that day are also included in that day's risk set.
- The "number of events" d(u) at time u is the number of subjects in P with time = u and event = 1, and the "number censored" c(u) is the number with time = u and event = 0.
- A time u with d(u) >= 1 is called an "event time".

## 3. Kaplan-Meier estimator and Nelson-Aalen estimator
Let v_1 < v_2 < ... < v_m be the event times of P in increasing order, and let n_j = n(v_j) and d_j = d(v_j). Compute the following values for j = 1, ..., m in this order (with S_0 = 1, G_0 = 0, H_0 = 0, A_0 = 0).
- Survival: S_j = S_(j-1) * [(n_j - d_j) / n_j]
- Greenwood sum: G_j = G_(j-1) + [d_j / (n_j * (n_j - d_j))]. However, once n_j = d_j occurs, G_j is undefined for that j and all later j.
- Standard error: e_j = S_j * sqrt(G_j)
- Confidence interval: with l_j = ln(S_j) and omega = z * sqrt(G_j) / (-l_j), the lower limit is lo_j = exp(l_j * exp(omega)) and the upper limit is hi_j = exp(l_j * exp(-omega))
- When S_j = 0 (when n_j = d_j), e_j, lo_j and hi_j are undefined.
- Cumulative hazard: H_j = H_(j-1) + [d_j / n_j]
- Standard error of the cumulative hazard: sqrt(A_j), where A_j = A_(j-1) + [d_j / (n_j * n_j)]
- Censored column: the number of subjects with time >= v_j and < v_(j+1) (for j = m, time >= v_m) and event = 0. Subjects censored before v_1 are not counted in any row.
These values for one j together are called the "row" of event time v_j.
The values at time point t (days) are the values of the row with the largest j that satisfies v_j <= t. If there is no such j (t < v_1), the survival is 1, the standard error 0, the cumulative hazard 0 and the standard error of the cumulative hazard 0, and the lower and upper limits are undefined. This is called the "row at time t".

## 4. Summary of each collection
For each of the collections group 1, ..., group k and all, compute the following values. E is the total number of events in P (the number of subjects with event = 1).
(1) The number of subjects, the number of events E, the number censored (the number of subjects with event = 0), and the maximum time.
(2) Event rate: let PD be the sum of the times of all subjects in P (an integer), and rate = [1000 * E / PD] (events per 1000 person-days). With eta = z / sqrt(E), the lower limit is exp(ln(rate) - eta) and the upper limit is exp(ln(rate) + eta).
(3) Median follow-up (reverse Kaplan-Meier method): apply the estimator of section 3 to the data in which event 0 and 1 are swapped for every subject in P, and take the smallest v_j that satisfies S_j <= 0.5. If there is none, it is NA.
(4) Life-table median: in the life table of section 5, looking at the intervals in interval order, let [a, b) be the first interval whose survival is <= 0.5, let S' be the survival of the interval just before it (1 if it is the first interval) and S the survival of that interval; the median is a + w * (S' - 0.5) / (S' - S). If there is no such interval, it is NA.
(5) Percentiles: for each of the three cases (percentile 25, q = 0.75), (50, 0.5) and (75, 0.25), the time is the smallest v_j that satisfies S_j <= q, the lower limit is the smallest v_j that satisfies lo_j <= q, and the upper limit is the smallest v_j that satisfies hi_j <= q. In a row with S_j = 0, lo_j = hi_j = 0 is assumed. A value for which there is no such v_j is NA. For example, the time of percentile 50 is the median survival time.
(6) RMST: let v_1, ..., v_r be the event times that satisfy v_j <= tau, in increasing order, and let x_0 = 0, x_i = v_i (i = 1, ..., r) and x_(r+1) = tau. For i = 0, ..., r, compute the rectangle rect_i = s_i * (x_(i+1) - x_i) (s_0 = 1, s_i = S_i, and x_(i+1) - x_i is computed as an integer). Then let B_r = rect_r, and for i = r - 1, ..., 0 in this order let B_i = rect_i + B_(i+1). The RMST is mu = B_0, its variance is V = sum_(i=1...r) B_i * B_i * [d_i / (n_i * (n_i - d_i))] (the sum in increasing order of i), the standard error is se = sqrt(V), the lower limit is mu - z * se and the upper limit is mu + z * se.
(7) Report times: for each report time t, the risk-set size n(t) (the number of subjects with time >= t), the number of events up to t (the number of subjects with time <= t and event = 1), and the survival, standard error, lower limit, upper limit, cumulative hazard and standard error of the cumulative hazard of the row at time t.

## 5. Life table
For each of the collections group 1, ..., group k and all, for i = 0, ..., K - 1 in this order, compute the following values for each interval [a, b) (a = i * w, b = (i + 1) * w).
- Number entering the interval n: the number of subjects with time >= a
- Number of events d: the number of subjects with a <= time < b and event = 1
- Number withdrawn c: the number of subjects with a <= time < b and event = 0
- Let F = 2 * n - c (an integer); the number exposed is n - c / 2 = F / 2.
- q = [2 * d / F]
- Survival: the probability of surviving to the end of the interval, obtained as a product in interval order. The value before the first interval is 1, and for each interval the previous value is multiplied by [(F - 2 * d) / F].
- Standard error: survival * sqrt(sum [4 * d / (F * (F - 2 * d))]). The sum is over all intervals up to and including that interval (in interval order).
- Hazard (per 1000 person-days): [2000 * d / (w * (F - d))]
Subjects with time >= K * w are counted neither as events nor as withdrawals in any interval.

## 6. Comparison of baseline characteristics
(1) For each of the collections group 1, ..., group k and all, compute the number of subjects n, the mean age a_bar = [sum of the ages / n], the standard deviation of age sqrt((sum (age - a_bar) * (age - a_bar)) / (n - 1)) (the sum in subject order), the median age (the sum of the (floor((n - 1) / 2) + 1)-th and the (floor(n / 2) + 1)-th values of the ages sorted in increasing order, divided by 2), the number of males (M), and the number of subjects in each of the stages 1, 2, 3 and 4.
(2) Kruskal-Wallis test (age): sort all N subjects in increasing order of age, and give subjects with the same age the average of the ranks (counted from 1) that they occupy as their rank (if the subjects with the same age occupy positions p + 1 through q, their rank is the real number (p + 1 + q) / 2). Let R_g (a real number) be the sum of the ranks of the subjects in group g and N_g the number of subjects in group g, and let T (an integer) be the sum, over the ages, of t * t * t - t, where t is the number of subjects with that age.
  W_0 = 12 * (sum_g R_g * R_g / N_g) / (N * (N + 1)) - 3 * (N + 1) (the sum in group order; N * (N + 1) and 3 * (N + 1) are computed as integers)
  W = W_0 / (1 - [T / (N * N * N - N)])
  The degrees of freedom are k - 1.
(3) Chi-square test of a contingency table: for each of the variables sex and stage, the values that appear among all subjects, in increasing order (for sex, the order F, M), are the values 1, ..., J. Let O_gj be the number of subjects in group g with value j, r_g the number of subjects in group g, c_j the number of subjects with value j, and E_gj = [r_g * c_j / N], and let
  chi2 = sum_g sum_j (O_gj - E_gj) * (O_gj - E_gj) / E_gj (added in increasing order of g, and for each g in increasing order of j)
  The degrees of freedom are (k - 1) * (J - 1).

## 7. Weighted k-group test
For a collection P of subjects, the groups contained in P (k' groups, numbered 1, ..., k' in group order) and a kind of weight, the procedure that computes the following values is called a "weighted test". N is the total number of subjects (the number of lines of subjects.csv excluding the header line), not the number of subjects in P.
Go through the event times of P (regardless of which group the event belongs to) in increasing order, and at each time u obtain, for each group h, the risk-set size n_h (the number of subjects in P in group h with time >= u) and the number of events d_h, and n = sum_h n_h and d = sum_h d_h. The weight nu is 1 for logrank, [n / N] for gehan_wilcoxon, and sqrt([n / N]) for tarone_ware. Take the following sums in increasing order of event time.
- Number of events: sum d_h (for each group h, an integer)
- Observed: O_h = sum nu * d_h
- Expected: X_h = sum nu * [d * n_h / n]
- Covariance: Y_hl = sum nu * nu * [d * (n - d) / ((n - 1) * n * n)] * m_hl. This sum is taken only over the times with n >= 2. Here m_hl is the integer n_h * (n - n_h) if h = l, and -(n_h * n_l) if h != l.
From these, compute the statistic chi2 as follows. For the groups 1, ..., k' - 1 let U_h = O_h - X_h, solve the linear system Y x = U, whose coefficient matrix is Y restricted to the rows and columns 1, ..., k' - 1, by the method of 11 (1), and let chi2 = sum_h U_h * x_h (the sum over h = 1, ..., k' - 1). The degrees of freedom are k' - 1, and the p-value is computed by 11 (4). The values of group k' are not used for the statistic, but they are used in the output.
In a stratified test, compute the above sums (number of events, O, X, Y) for each stratum, add them component by component in stratum order (sum in stratum order), and compute chi2 from the totals in the same way.

## 8. Group comparisons
(1) Overall tests: with all subjects as P and k' = k, perform the weighted tests in the order logrank, gehan_wilcoxon, tarone_ware.
(2) Trend test: from the logrank values of (1), let U_T = sum_g g * (O_g - X_g) and V_T = sum_g (sum_h (g * h) * Y_gh) (g and h are 1, ..., k; compute the inner sum in increasing order of h, and add those in increasing order of g; g * h is an integer), and let chi2 = U_T * U_T / V_T with 1 degree of freedom.
(3) Stratified tests: the strata are the values of the STRATA variable that appear among all subjects, in increasing order (for sex, the order F, M); for each stratum, perform a weighted test with all subjects having that value as P (k' = k). For each of the three weights, perform the test of each stratum and the stratified test that adds them up.
(4) Landmark analysis: the logrank weighted test with all subjects with time > L as P (k' = k).
(5) Two-group comparison: for a collection P that consists only of two groups a and b (a is group 1 and b is group 2), perform the logrank weighted test, and from its O and X compute the hazard ratio HR = (O_2 / X_2) / (O_1 / X_1) and, with phi = 1 / X_1 + 1 / X_2 and lambda = ln(HR), the lower limit exp(lambda - z * sqrt(phi)) and the upper limit exp(lambda + z * sqrt(phi)).
(6) Pairwise comparisons: arrange all pairs of groups (a, b) with a < b in increasing order of a, and for equal a in increasing order of b (m pairs), and perform (5) on all subjects of group a and group b. The p-values adjusted by the Holm method are as follows. For the r-th pair (r = 1, ..., m) after sorting by increasing p-value (equal p-values in pair order), let c_r = (m - r + 1) * p, and the adjusted p-value is max(adjusted p-value of the preceding pair, min(1, c_r)) (the value preceding r = 1 is 0).
(7) Subgroup analysis: for each variable of SUBGROUPS (in SUBGROUPS order), the values that appear among all subjects, in increasing order (for sex, the order F, M), are the levels 1, ..., J. For the groups b = 2, ..., k in this order, and for each level, perform (5) with P consisting only of the subjects of group 1 and group b among the subjects having the value of that level (a = group 1). Then, from the weight psi_i = 1 / phi_i and y_i = ln(HR_i) of each level, compute y_bar = (sum psi_i * y_i) / (sum psi_i) and the heterogeneity statistic Q_het = sum psi_i * (y_i - y_bar) * (y_i - y_bar) (the sums in level order). The degrees of freedom are J - 1.
(8) RMST difference: for the groups g = 2, ..., k, compute the difference delta = mu_g - mu_1, the standard error s = sqrt(se_g * se_g + se_1 * se_1), the lower limit delta - z * s, the upper limit delta + z * s, and the statistic delta / s (mu and se are the values of 4 (6)).
(9) Rate ratio: for the groups g = 2, ..., k, with the ratio rho = rate_g / rate_1, s = sqrt([1 / E_g] + [1 / E_1]) and lambda = ln(rho), compute the lower limit exp(lambda - z * s), the upper limit exp(lambda + z * s), and the statistic lambda / s (rate and E are the values of 4 (2) and (1)).
(10) Survival difference: for each report time t (in report-time order), for the groups g = 2, ..., k in this order, let S' and e' be the survival and standard error of the row at time t of group g, and S and e those of the control group; compute the difference delta = S' - S, the standard error s = sqrt(e' * e' + e * e), the lower limit delta - z * s, the upper limit delta + z * s, and the statistic delta / s.
The p-value of the statistic zeta of (8) to (10) is computed by 11 (4), taking zeta * zeta as a chi-square statistic with 1 degree of freedom.

## 9. Cox proportional hazards model
(1) Covariates: the component x_jc of the covariate vector x_j = (x_j1, ..., x_jp) of subject j is the age if the covariate name c is age; 1 for M and 0 for F if it is male; the stage if it is stage; and, if it is a group name, 1 if the subject belongs to that group and 0 otherwise (all are integers).
(2) Evaluation: for a coefficient vector beta, compute the log partial likelihood ll(beta), the score U(beta) (p components) and the information matrix I(beta) (p x p) as follows.
  For each subject j, compute the linear predictor theta_j = sum_c beta_c * x_jc (c in covariate order) and r_j = exp(theta_j).
  Arrange the subjects in decreasing order of time (equal times in increasing order of subject number), and start the risk-set sums S0 (a real number), S1_c and S2_cd (c, d = 1, ..., p) all at 0. Go through the times that appear among all subjects in decreasing order; at each time u, first add all subjects with time = u one at a time in the arranged order. Adding subject j means adding r_j to S0, r_j * x_jc to S1_c, and r_j * x_jc * x_jd to S2_cd. When the additions are finished, if there are subjects with time = u and event = 1, let D be that set (with e subjects), and add the following values to ll, U_c and I_cd (all start at 0). Sums within D are in subject order.
  to ll: (sum_(i in D) theta_i) - e * ln(S0)
  to U_c: (sum_(i in D) x_ic) - e * S1_c / S0
  to I_cd: e * (S2_cd / S0 - (S1_c / S0) * (S1_d / S0))
  Also record S0 and S1_c at this moment as S0(u) and S1_c(u) of the event time u. The sums into ll, U and I are thus added in decreasing order of time.
(3) Newton-Raphson method: let beta^(0) be the zero vector; for iterations s = 1, ..., 25 in this order, solve the linear system I Delta = U by the method of 11 (1) using ll, U and I of the evaluation at beta^(s-1), and let beta^(s) = beta^(s-1) + Delta (component-wise). The estimate is beta_hat = beta^(25). The evaluation at beta_hat is called the "final evaluation", and the evaluation at the zero vector the "null evaluation".
(4) Covariance matrix: let I_hat be I of the final evaluation; for c = 1, ..., p, solve I_hat y = e_c (e_c is the vector whose c-th component is 1 and all others are 0) by the method of 11 (1), and let the solution y be the c-th column of C. The (a, b) entry C_ab of C is the a-th component of the solution of I_hat y = e_b.
(5) For each covariate c: se = sqrt(C_cc), the statistic zeta = beta_hat_c / se, the hazard ratio exp(beta_hat_c), the lower limit exp(beta_hat_c - z * se), and the upper limit exp(beta_hat_c + z * se).
  Contrasts: for every pair of two covariates a and b that are group names (a comes first in covariate order), in order of a and, for equal a, in order of b: the coefficient kappa = beta_hat_b - beta_hat_a, se = sqrt(C_bb + C_aa - 2 * C_ab), the statistic zeta = kappa / se, the hazard ratio exp(kappa), the lower limit exp(kappa - z * se), and the upper limit exp(kappa + z * se).
  The p-value of zeta is computed taking zeta * zeta as a chi-square statistic with 1 degree of freedom.
(6) Overall tests (all with p degrees of freedom): likelihood ratio 2 * (ll_hat - ll_0) (ll_hat is ll of the final evaluation and ll_0 is ll of the null evaluation), Wald sum_c beta_hat_c * (sum_d I_hat_cd * beta_hat_d) (compute the inner sum in increasing order of d, and add those in increasing order of c), and score sum_c U_c * y_c (U and I are the values of the null evaluation, and y is the solution of I y = U).
(7) Models without a covariate: for each covariate c (in covariate order), if p = 1, let ll_c = ll_0. If p >= 2, perform (2) and (3) with the covariates other than c (keeping the covariate order), and let ll_c be ll of the evaluation at its beta^(25). Test the likelihood ratio 2 * (ll_hat - ll_c) with 1 degree of freedom.
(8) C statistic: let theta_hat_j be the linear predictor of the final evaluation. An ordered pair (i, j) of two different subjects such that i has event = 1 and either time_i < time_j, or time_i = time_j and j has event = 0, is called a "comparable pair". Among the comparable pairs, count those in which x_i and x_j are equal (all components are equal) as "tied", and those in which they are not equal and theta_hat_i > theta_hat_j as "concordant". C = [(2 * number concordant + number tied) / (2 * number of comparable pairs)].
(9) Check of proportional hazards: arrange the subjects with event = 1 in increasing order of time (equal times in increasing order of subject number) (D' subjects), and let the Schoenfeld residual of each subject i be res_ic = x_ic - S1_c(u) / S0(u) (u is the time of i; use the values recorded in the final evaluation). Let t_bar = [sum of the times of those subjects / D'], and for each covariate c, from res_bar = (sum_i res_ic) / D' and
  Sxy = sum_i (res_ic - res_bar) * (time_i - t_bar), Sxx = sum_i (res_ic - res_bar) * (res_ic - res_bar), Syy = sum_i (time_i - t_bar) * (time_i - t_bar)
  (the sums in the order of the arrangement above), compute the correlation coefficient rho = Sxy / sqrt(Sxx * Syy) and the statistic zeta = 0.5 * ln((1 + rho) / (1 - rho)) * sqrt(D' - 3), and test zeta * zeta with 1 degree of freedom.
(10) Residuals: with the event times u of the final evaluation, define the Breslow baseline cumulative hazard Lambda(t) = sum e_u / S0(u) (the sum over the event times u <= t, in increasing order; e_u is the number of events at time u) (it is 0 if there is no event time <= t). For each subject j, with delta_j its event, compute
  the martingale residual M_j = delta_j - Lambda(time_j) * exp(theta_hat_j)
  the deviance residual Dv_j: sqrt(-2 * (M_j + ln(1 - M_j))) if delta_j = 1, and sqrt(-2 * M_j) if delta_j = 0, with the sign inverted unless M_j > 0,
  and select R subjects in decreasing order of |Dv_j| (equal values in increasing order of subject number).
(11) Adjusted survival: for the covariates that are age, male or stage, compute the mean over all subjects [sum of x_jc / N]. The "representative value" of group g is, for a covariate that is a group name, 1 if it is the name of group g and 0 otherwise, and for any other covariate the mean above. With x_bar_g the vector of representative values, let the risk be h_g = exp(sum_c beta_hat_c * x_bar_gc) (c in covariate order), and let the adjusted survival at time t be exp(-Lambda(t) * h_g). The median of the adjusted survival is, looking at the event times u of the final evaluation in increasing order, the first u for which exp(-Lambda(u) * h_g) <= 0.5; if there is none, it is NA.

## 10. Plot
The Kaplan-Meier estimator of the collection of group g is drawn with the g-th uppercase letter in group order (group 1 is A, group 2 is B, ...). The plot consists of cells in H rows and W columns, and column i (i = 0, ..., W - 1) represents the time t_i = i * (T / W) (T / W is an integer). The rows are the "bands" q = H - 1, ..., 0, arranged from top to bottom.
For each group, for the columns 0, 1, ... in order, and only while t_i is <= the maximum time of that group (once it exceeds it, the drawing of that group ends), compute the band q_i = min(H - 1, floor(S * H)) from the survival S of the row at time t_i. In column i the group occupies the cell (band q_i, column i). In addition, when the group is also drawn in the preceding column i - 1 and q_(i-1) - 1 > q_i, it also occupies the cells of bands q_i + 1, ..., q_(i-1) - 1 (the vertical line of the curve).
The character of each cell is a space if no group occupies it, the letter of the group if exactly one group occupies it, and * if two or more groups occupy it.

## 11. Numerical procedures
(1) Gaussian elimination: for an m x m matrix A and a vector b, solve the linear system A x = b as follows (working copies of A and b are modified).
  Forward elimination: for k = 1, ..., m in order, for i = k + 1, ..., m in order, let f = A_ik / A_kk, replace A_ij with A_ij - f * A_kj for j = k, ..., m in order, and then (once for each i, after the j loop) replace b_i with b_i - f * b_k.
  Back substitution: for i = m, ..., 1 in order, x_i is the value obtained by subtracting A_i(i+1) * x_(i+1), ..., A_im * x_m one at a time in this order from b_i and dividing the result by A_ii.
(2) Log-gamma function lnGamma(a) (a > 0): let the coefficients be gamma_1 = 76.18009172947146, gamma_2 = -86.50532032941677, gamma_3 = 24.01409824083091, gamma_4 = -1.231739572450155, gamma_5 = 0.001208650973866179 and gamma_6 = -0.000005395239384953. Let xi_0 = a + 5.5, xi_1 = xi_0 - (a + 0.5) * ln(xi_0), sigma = 1.000000000190015 and y = a, and for i = 1, ..., 6 in order, replace y with y + 1 and then replace sigma with sigma + gamma_i / y. lnGamma(a) = -xi_1 + ln(2.5066282746310005 * sigma / a).
(3) Regularized upper incomplete gamma function Q(a, x) (a > 0, x >= 0): if x = 0, Q = 1. If x > 0, let pref = exp(-x + a * ln(x) - lnGamma(a)), and
  - when x < a + 1 (series): let alpha = a, xi = 1 / a and sigma = xi, and repeat the following steps at most 1000 times. Replace alpha with alpha + 1, then xi with xi * (x / alpha) (using the new alpha), and then sigma with sigma + xi (using the new xi); if |xi| < |sigma| * 10^(-15), stop repeating. Q = 1 - sigma * pref.
  - when x >= a + 1 (continued fraction): let eps = 10^(-300), b = x + 1 - a, c = 1 / eps, d = 1 / b and h = d. Repeat the following steps for i = 1, ..., 1000 in order. Let an = -i * (i - a), replace b with b + 2, then replace d with an * d + b (using the new b), and if |d| < eps, set d = eps. Replace c with b + an / c, and if |c| < eps, set c = eps. Replace d with 1 / d, let Delta = d * c, replace h with h * Delta, and if |Delta - 1| < 10^(-15), stop repeating. Q = pref * h.
  10^(-15) and 10^(-300) are the values 1e-15 and 1e-300 converted to double precision, respectively.
(4) p-value: the p-value of a chi-square statistic chi2 with f degrees of freedom is Q(f / 2, chi2 / 2) (f / 2 and chi2 / 2 are real-number divisions).
