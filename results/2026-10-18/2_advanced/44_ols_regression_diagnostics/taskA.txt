[Overview]
Write a program that reads tabular data containing numeric columns and categorical columns (for example, records of house sales), fits the multiple regression models (linear regression models) specified by model formulas, and outputs coefficient tables and model statistics similar to the summary of the statistical software R, regression diagnostics, variable selection, and predictions for new data. In a model formula, a categorical variable is expanded into dummy variables relative to a reference level, and an interaction is represented by a product of columns. Fitting is done by QR decomposition with Householder transformations; a column that is a linear combination of other columns (an alias) is detected and its coefficient is NA. A model with a weight column specified is fitted by weighted least squares.
The p-values of the coefficient t tests, F tests and chi-square tests are obtained from the log-gamma function (Lanczos approximation) and the regularized incomplete beta function and regularized incomplete gamma function computed by continued fractions etc., all defined in this task. The regression diagnostics compute the leverage, studentized residuals, Cook's distance, DFFITS, DFBETAS, VIF (by auxiliary regressions), the Durbin-Watson statistic, the Breusch-Pagan test, the Jarque-Bera test, the RESET test and the outlier test, and flag the observations that exceed the criteria. The variable selection performs backward elimination by p-value, forward selection by AIC and best subsets by BIC, and records every step.
The input is 4 files in the input/ folder (data, model formulas, prediction data, settings), and the results are written to 5 files in the output/ folder. Nothing is written to standard output. All rules are defined in [Processing] and [Output files], so the results are uniquely determined.

[Input files]
The input files are the 4 files input/data.csv, input/model.txt, input/predict.csv and input/params.txt. Every file consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). There are no spaces at the start or end of a line. The values in the CSV files are separated by a single comma; no quotation marks or spaces are used. The values in params.txt are separated by a single space.
A "number" is a decimal number consisting of, in this order, "-" (only for a negative number), a sequence of one or more digits, and "." followed by a sequence of one or more digits (this last part may be absent) (examples: 46.00, -1.5, 7, 0.0000001). Exponent notation is not used.

== input/data.csv (data) ==
The first line is the header line, which lists the column names separated by commas. A column name is a string of 1 to 16 characters that starts with a lowercase English letter and consists only of lowercase English letters, digits and "_"; the column names are distinct. The order in the header line is called the "column order".
Each line from the second line on is one record, which lists as many values as the header line, in column order. Each value is one of the following.
- A number
- A label: a string of 1 to 12 characters that starts with an uppercase English letter and consists only of English letters and digits. The string NA is not a label.
- NA: represents a missing value (no value).
A column in which at least one non-NA value is a label is a "categorical column"; any other column is a "numeric column". All non-NA values of a categorical column are labels, and all non-NA values of a numeric column are numbers.
Let N be the number of records; the records are given row numbers 1, 2, ..., N in the order of the lines of the file. This order is called the "data order".

== input/model.txt (model formulas) ==
A file of M lines, each describing one model. Each line has the form "<formula>" or "<formula> weights=<column name>". In the latter form, the column with that column name is called the "weight column" of the model. The models are numbered 1, 2, ..., M in line order.
<formula> is the concatenation, in this order, of the column name of the response variable, " ~ " (one space before and after ~), and one or more "term expressions" separated by " + " (one space before and after +) (example: price ~ area + rooms + C(district) + area:rooms).
A term expression is one "factor", or two or three factors joined by ":" only, or two or three factors joined by "*" only. A term expression contains no spaces, and ":" and "*" are never mixed. A factor is one of the following three kinds.
- The column name of a numeric column (example: area)
- C(<column name of a categorical column>) (example: C(district)). A categorical column appears as a factor only in this form.
- I(<column name of a numeric column>^<k>), where k is 2 or 3 (example: I(age^2)).
The string of a factor itself is called the "factor name", and the column whose column name appears in a factor is called the "factor column". The response column and the weight column are numeric columns and do not appear as factor columns. The non-NA values of the weight column are positive. The same factor does not appear twice within one term expression.

== input/predict.csv (prediction data) ==
A file in the same format as data.csv. The column names in its header line are some of the column names of data.csv (in any order) and include all factor columns of every model. It may also include the response column. The values of each column are read according to the kind (categorical column or numeric column) of the column of data.csv with the same name. A categorical column may contain labels that do not appear in data.csv. Let K be the number of records; they are called prediction rows 1, ..., K in line order.

== input/params.txt (settings) ==
The following 13 lines appear in this order. Each line consists of an uppercase keyword and its values, separated by single spaces.
- RANK_TOL tau: the tolerance for the rank decision (a positive number).
- ALPHA_REMOVE alpha: the criterion for removing a term in backward elimination (a number greater than 0 and less than 1).
- CONFIDENCE gamma: the confidence level of the confidence intervals and prediction intervals (a number at least 0.5 and less than 1).
- LEVERAGE c_h: the coefficient for the leverage flag (a positive number).
- STUDENTIZED c_t: the criterion for the studentized residual flag (a positive number).
- COOK c_c: the coefficient for the Cook's distance flag (a positive number).
- DFFITS c_f: the coefficient for the DFFITS flag (a positive number).
- VIF c_v: the criterion for the VIF (a positive number).
- DURBIN_WATSON d_L: the criterion for the Durbin-Watson statistic (a number greater than 0 and less than 2).
- BREUSCH_PAGAN alpha_h: the significance level of the Breusch-Pagan test (a number greater than 0 and less than 1).
- NORMALITY alpha_n: the significance level of the Jarque-Bera test (a number greater than 0 and less than 1).
- BEST_SUBSETS B: the number of best subsets to write (an integer, 1 or more).
- PLOT W H L: the width W of the residual plots in characters (an integer from 10 to 80), the height H in lines (an integer from 5 to 41), and the range L of the vertical axis (a positive number).

[Processing]
== 1. Rules of computation ==
- All real computations are done in double precision (IEEE 754 64-bit floating point). Input numbers are converted to the nearest double-precision value. In an operation between an integer and a real, the integer is converted to a real before the computation (for example, n / 6 is a real division).
- sqrt is the square root, ln the natural logarithm, exp the exponential function, |x| the absolute value of x, floor(x) the largest integer not exceeding x, and min the minimum. pi is the double-precision value 3.141592653589793.
- Expressions are evaluated in the order written. Parentheses are evaluated first, multiplications and divisions from left to right, and additions and subtractions also from left to right (examples: a * b / c is (a * b) / c, and a - b + c is (a - b) + c).
- A sum written with SUM starts from 0.0 and adds one term at a time in increasing order of the index (or in the specified order when an order is specified). Each term is computed before it is added. In an expression containing a sum, the sum is computed first and then the rest of the computation is done.
- Comparisons of magnitude and sorting use the double-precision values. The handling of equal values is specified in each case.

== 2. Term expansion ==
The term expressions of the model formula are processed from left to right to build the sequence of "terms" of the model. A term is a sequence of factors.
- A term expression that does not contain "*" produces one term: the sequence of factors obtained by splitting it at ":" (if there is one factor, the sequence of that one factor only).
- A term expression joining factors f_1, ..., f_m (m = 2 or 3) with "*" produces terms as follows. The non-empty subsets of the index set {1, ..., m} are ordered by increasing number of elements, and subsets with the same number of elements are ordered lexicographically by the sequences of their elements listed in increasing order; in this order, each subset produces the term consisting of the factors with the indices in the subset, in increasing order of index (examples: a*b produces the 3 terms a, b, a:b, and a*b*c produces the 7 terms a, b, c, a:b, a:c, b:c, a:b:c).
The produced terms are appended to the end of the sequence in the order produced. However, a term whose set of factor names equals the set of factor names of a term already in the sequence is not added (example: when a:b is present, b:a produced later is not added).
The order of the resulting sequence is called the "term order". The "name" of a term is its factor names joined by ":" in their order within the term (examples: area:rooms, C(district):C(type)).
When the set of factor names of term A is a proper subset of the set of factor names of term B, we say that "A is contained in B" (example: area is contained in area:rooms; because the factor names differ, age is not contained in I(age^2)).
The "variables" of a model are all factor columns, the response column, and the weight column (if any).

== 3. Used rows and levels ==
The records in which none of the values of the model variables is NA, arranged in data order, are the "used rows" of the model, and their number is n. Below, the i-th (i = 1, ..., n) record of the used rows is called "row i".
The "levels" of the column c of a factor C(c) are the distinct labels of c in the used rows, sorted in increasing order of character code (ASCII) (lexicographic order comparing one character at a time from the start; when one is a prefix of the other, the shorter one comes first). The first level is called the "reference level", and the number of levels is L_c.

== 4. Design matrix ==
From the terms and levels of the model, the sequence of "columns" of the design matrix is built as follows. Each column has a name and has a real value for each record.
(1) The first column is the "intercept" column, whose name is (Intercept) and whose value is always 1.0. The intercept column belongs to no term.
(2) Next, the columns belonging to each term are arranged in term order. First, the "components" of each factor are defined as follows (v is the value of x in the record).
  - Column name x of a numeric column: one component, whose name is x and whose value is v.
  - I(x^k): one component, whose name is I(x^k) and whose value is v * v if k = 2 and v * v * v if k = 3.
  - C(c): L_c - 1 components. In level order, for each level lev from the second level on, the component's name is C(c) immediately followed by lev (example: C(district)East), and its value is 1.0 if the label of c in the record is lev, and 0.0 otherwise.
  The columns belonging to a term with factors f_1, ..., f_m are all the tuples (s_1, ..., s_m) that choose one component of each factor. They are arranged in the order in which the choice of the component of f_1 changes fastest (each time the component of f_1 cycles once through the components in component order, the component of f_2 advances to the next one, and each time the component of f_2 cycles once, the component of f_3 advances to the next one). The name of the column is the names of s_1, ..., s_m joined by ":" in this order, and its value is s_1 * s_2 * ... * s_m (if m = 1, the value of s_1 itself).
  Example: if the levels for C(district):C(type) are Central, East, North, South, West and Apartment, House, Townhouse respectively, the columns are the 8 columns C(district)East:C(type)House, C(district)North:C(type)House, C(district)South:C(type)House, C(district)West:C(type)House, C(district)East:C(type)Townhouse, ..., C(district)West:C(type)Townhouse.
Let p be the number of columns, numbered 1, ..., p in column order. The value of column j in row i is X_ij, the value of the response variable is y_i, and the weight is w_i (1.0 for a model without a weight column).

== 5. Fitting ==
A "fit" with an n-by-p matrix X and vectors y and w of length n (w_i > 0) is defined as follows. All fits below (each model of the variable selection, the auxiliary regressions, etc.) are performed by this procedure, and the tolerance is always tau.
(1) Let a_i = sqrt(w_i), Z_ij = a_i * X_ij and z_i = a_i * y_i. Compute the length of each column j, nu_j = sqrt(SUM Z_ij * Z_ij (i = 1, ..., n)). Let the working matrix A be a copy of Z and the working vector b be a copy of z.
(2) Let the number of accepted columns be k = 0, and do the following for j = 1, ..., p in order.
  - Compute eta = sqrt(SUM A_ij * A_ij (i = k + 1, ..., n)). If eta <= tau * nu_j, column j is an "alias"; go on to the next j without changing A or b (a column with nu_j = 0 is always an alias).
  - Otherwise, increase k by 1, make column j the k-th "accepted column", and write c_k = j. If A_kj >= 0, let alpha = -eta, otherwise alpha = eta; let v_k = A_kj - alpha, v_i = A_ij (i = k + 1, ..., n), and V = SUM v_i * v_i (i = k, ..., n). Record R_lk = A_lj (l = 1, ..., k - 1) and R_kk = alpha.
  - For each column l = j + 1, ..., p, compute delta = 2 * (SUM v_i * A_il (i = k, ..., n)) / V, and replace A_il with A_il - delta * v_i for i = k, ..., n. Likewise for b, compute delta = 2 * (SUM v_i * b_i (i = k, ..., n)) / V, and replace b_i with b_i - delta * v_i for i = k, ..., n.
(3) The final k is the rank r. R is an r-by-r upper triangular matrix (R_lk with l > k is 0.0). phi_k = b_k (k = 1, ..., r) are called the "effects".
(4) Coefficients: for k = r, r - 1, ..., 1 in this order, beta_{c_k} = (phi_k - SUM R_kl * beta_{c_l} (l = k + 1, ..., r)) / R_kk. Alias columns have no coefficient (NA).
(5) The inverse T of R: for each m = 1, ..., r, for l = r, r - 1, ..., 1 in this order, T_lm = (d_lm - SUM R_lq * T_qm (q = l + 1, ..., r)) / R_ll, where d_lm is 1.0 if l = m and 0.0 otherwise. The "variance factor" is C_k = SUM T_km * T_km (m = 1, ..., r) (k = 1, ..., r).
(6) For each row i (i = 1, ..., n), compute the following values (every sum index runs over 1, ..., r).
  - u_ik = SUM Z_{i,c_m} * T_mk (sum over m; k = 1, ..., r), and the leverage h_i = SUM u_ik * u_ik (sum over k)
  - g_ik = SUM T_km * u_im (sum over m; k = 1, ..., r)
  - The fitted value f_i = SUM X_{i,c_k} * beta_{c_k} (sum over k), the residual e_i = y_i - f_i, and the weighted residual eps_i = a_i * e_i
  - The residual sum of squares RSS = SUM eps_i * eps_i (sum over i = 1, ..., n)
The fit of a model is the fit with the design matrix of section 4, the response variable and the weights.

== 6. Model statistics ==
For a fitted model, compute the following values.
- The degrees of freedom df = n - r, and the residual standard error s = sqrt(RSS / df)
- The sum of the weights S_w = SUM w_i, the mean ybar = (SUM w_i * y_i) / S_w, and the total sum of squares TSS = SUM w_i * (y_i - ybar) * (y_i - ybar)
- The coefficient of determination R2 = 1 - RSS / TSS, and the adjusted coefficient of determination R2_adj = 1 - (1 - R2) * (n - 1) / df
- The F value F = ((TSS - RSS) / (r - 1)) / (RSS / df) and its p-value p_F(F, r - 1, df) (section 7)
- The log-likelihood LL = 0.5 * (SUM ln(w_i) - n * (ln(2 * pi) + 1 - ln(n) + ln(RSS))), AIC = -2 * LL + 2 * (r + 1), and BIC = -2 * LL + ln(n) * (r + 1)
- PRESS = SUM (eps_i / (1 - h_i)) * (eps_i / (1 - h_i)), and the predicted coefficient of determination R2_pred = 1 - PRESS / TSS
- Residual quantiles: let q_0, q_1, ..., q_{n-1} be eps_1, ..., eps_n sorted in increasing order. The quantile for a proportion P is, with G = (n - 1) * P and k = floor(G), q_k + (G - k) * (q_{k+1} - q_k) if k + 1 <= n - 1, and q_k otherwise. The quantiles for P = 0, 0.25, 0.5, 0.75 and 1 are called Min, 1Q, Median, 3Q and Max respectively.
- The critical t value t* = Tq(gamma, df) (section 7 (5))

== 7. Special functions and p-values ==
(1) The log-gamma function lnGamma(x) (x > 0): with c_1 = 76.18009172947146, c_2 = -86.50532032941677, c_3 = 24.01409824083091, c_4 = -1.231739572450155, c_5 = 0.001208650973866179 and c_6 = -0.000005395239384953, let
  t_0 = x + 5.5, T_0 = t_0 - (x + 0.5) * ln(t_0), S = 1.000000000190015 + SUM c_j / (x + j) (j = 1, ..., 6; the terms are added to 1.000000000190015 in order), and lnGamma(x) = -T_0 + ln(2.5066282746310005 * S / x).
(2) The regularized incomplete beta function I(x; a, b) (a > 0, b > 0): it is 0.0 if x <= 0 and 1.0 if x >= 1. Otherwise, let
  F_0 = exp(lnGamma(a + b) - lnGamma(a) - lnGamma(b) + a * ln(x) + b * ln(1 - x))
  and I = F_0 * CF(a, b, x) / a if x < (a + 1) / (a + b + 2), and I = 1 - F_0 * CF(b, a, 1 - x) / b otherwise.
  CF(a, b, x) is the following continued fraction computation. Below, "the small-value replacement" means replacing a value t with |t| < 1e-300 by 1e-300.
  - Let c = 1.0 and d = 1 - (a + b) * x / (a + 1); apply the small-value replacement to d, then let d = 1 / d and h = d.
  - Do the following for m = 1, 2, ..., 1000 in order.
    Let q = m * (b - m) * x / ((a - 1 + 2 * m) * (a + 2 * m)), d = 1 + q * d (apply the small-value replacement, then let d = 1 / d), c = 1 + q / c (apply the small-value replacement), and h = h * (d * c).
    Next, let q = -(a + m) * (a + b + m) * x / ((a + 2 * m) * (a + 1 + 2 * m)), and likewise d = 1 + q * d (replace, then let d = 1 / d), c = 1 + q / c (replace), Delta = d * c, and h = h * Delta. If |Delta - 1| < 1e-15, end the iteration.
  - The value of h when the iteration ends is CF(a, b, x).
(3) The regularized upper incomplete gamma function Q(a, x) (a > 0, x > 0): let F_0 = exp(-x + a * ln(x) - lnGamma(a)).
  - If x < a + 1 (series): let t = 1 / a, S = t and e = a; repeat e = e + 1, t = t * (x / e), S = S + t at most 1000 times, and stop when |t| < |S| * 1e-15. Q = 1 - S * F_0.
  - Otherwise (continued fraction): let beta = x + 1 - a, c = 1 / 1e-300, d = 1 / beta and h = d; for i = 1, 2, ..., 1000 in order, let q = -i * (i - a), beta = beta + 2, d = q * d + beta (apply the small-value replacement, then let d = 1 / d), c = beta + q / c (replace), Delta = d * c and h = h * Delta, and stop if |Delta - 1| < 1e-15. Q = F_0 * h.
(4) p-values: the two-sided p-value of a t statistic t with nu degrees of freedom is p_t(t, nu) = I(nu / (nu + t * t); nu / 2, 0.5); the p-value of an F statistic F with (d_1, d_2) degrees of freedom is p_F(F, d_1, d_2) = I(d_2 / (d_2 + d_1 * F); d_2 / 2, d_1 / 2); and the p-value of a chi-square statistic x with k degrees of freedom is p_chi(x, k) = Q(k / 2, x / 2).
(5) The quantile of the t distribution Tq(gamma, nu): let lo = 0.0 and hi = 1000.0, and repeat the following 100 times: let mid = (lo + hi) / 2; if p_t(mid, nu) > 1 - gamma, let lo = mid, otherwise let hi = mid. Finally, let Tq = (lo + hi) / 2.
(6) Significance mark: for a p-value p, the mark is *** if p < 0.001, ** if p < 0.01, * if p < 0.05, . (a single period) if p < 0.1, and there is no mark otherwise.

== 8. Coefficient inference ==
For each column j, compute the following values. If column j is an alias, all of the values below are NA. Otherwise, with the k such that c_k = j:
- The estimate beta_j, the standard error se_j = s * sqrt(C_k), the t value t_j = beta_j / se_j, the p-value p_t(t_j, df) and its significance mark
- The confidence interval: lower limit beta_j - t* * se_j, upper limit beta_j + t* * se_j
- The robust standard error (HC3): with omega_i = eps_i * eps_i / ((1 - h_i) * (1 - h_i)), se'_j = sqrt(SUM omega_i * g_ik * g_ik (i = 1, ..., n)), the t value beta_j / se'_j, its p-value p_t(beta_j / se'_j, df) and its significance mark

== 9. Analysis of variance ==
(1) Sequential analysis of variance: for each term in term order, collect in increasing order the indices k of the accepted columns belonging to that term (the k for which c_k belongs to that term); their number is the degrees of freedom d. Terms with d = 0 are excluded. Compute the sum of squares SS = SUM phi_k * phi_k (in the order of the collected k), the mean square MS = SS / d, the F value MS / (RSS / df), the p-value p_F(MS / (RSS / df), d, df) and its significance mark.
(2) Marginal F tests (tests dropping one term at a time): in term order, for each term U that is not contained in any other term of the model, fit the model whose term sequence is the model's term sequence with U removed (the remaining terms keep their order), with the same used rows, the same levels and the same weights, and obtain its residual sum of squares RSS' and its rank r'. Let the degrees of freedom be d = r - r' and the sum of squares SS = RSS' - RSS; if d > 0, compute the F value (SS / d) / (RSS / df), the p-value p_F(F, d, df) and its significance mark. If d = 0, the F value and the p-value are NA.

== 10. VIF ==
For each accepted column c_k from the second accepted column on (k = 2, ..., r; the first accepted column is always the intercept column), fit with the matrix of the accepted columns other than c_k (including the intercept, in column order), with the values x_i = X_{i,c_k} of column c_k as the response variable, and with the same weights w as the model (auxiliary regression). Let its residual sum of squares be RSS_x, and with xbar = (SUM w_i * x_i) / S_w, TSS_x = SUM w_i * (x_i - xbar) * (x_i - xbar) and R2_x = 1 - RSS_x / TSS_x, let VIF = 1 / (1 - R2_x). When VIF > c_v, the column "has a high VIF".

== 11. Regression diagnostics ==
(1) Per-row values: for row i, compute the standardized residual z_i = eps_i / (s * sqrt(1 - h_i)), the studentized residual t_i = z_i * sqrt((df - 1) / (df - z_i * z_i)), Cook's distance D_i = z_i * z_i * h_i / (r * (1 - h_i)), and DFFITS_i = t_i * sqrt(h_i / (1 - h_i)).
(2) Flags: row i gets the flag H if h_i > c_h * r / n, the flag O if |t_i| > c_t, the flag C if D_i > c_c / n, and the flag F if |DFFITS_i| > c_f * sqrt(r / n). The "flag string" of a row is the flags it got, concatenated in the order H, O, C, F (- if it got none).
(3) DFBETAS: for row i and accepted column c_k, with s_(i) = s * sqrt((df - z_i * z_i) / (df - 1)), DFBETAS_ik = g_ik * eps_i / (1 - h_i) / (s_(i) * sqrt(C_k)). For each accepted column, find the row i with the largest |DFBETAS_ik| (on a tie, the smaller i).
(4) Durbin-Watson statistic: DW = SUM (eps_i - eps_{i-1}) * (eps_i - eps_{i-1}) (i = 2, ..., n) / RSS. If DW < d_L, the result is "positive autocorrelation"; if DW > 4 - d_L, it is "negative autocorrelation"; otherwise it is "no autocorrelation".
(5) Breusch-Pagan test: with g'_i = eps_i * eps_i as the response variable, fit with the matrix of the X values (not multiplied by the weights) of the accepted columns (in column order), with all weights 1.0. Let its rank be r_g and its residual sum of squares RSS_g, and with gbar = (SUM g'_i) / n and TSS_g = SUM (g'_i - gbar) * (g'_i - gbar), compute the statistic BP = n * (1 - RSS_g / TSS_g), the degrees of freedom r_g - 1, and the p-value p_chi(BP, r_g - 1). If the p-value < alpha_h, the result is "heteroscedastic"; otherwise it is "homoscedastic".
(6) Jarque-Bera test: with epsbar = (SUM eps_i) / n and delta_i = eps_i - epsbar, compute m_2 = (SUM delta_i * delta_i) / n, m_3 = (SUM delta_i * delta_i * delta_i) / n, m_4 = (SUM delta_i * delta_i * delta_i * delta_i) / n, the skewness sk = m_3 / (m_2 * sqrt(m_2)), the kurtosis ku = m_4 / (m_2 * m_2), the statistic JB = n / 6 * (sk * sk + (ku - 3) * (ku - 3) / 4), and the p-value p_chi(JB, 2). If the p-value < alpha_n, the result is "non-normal"; otherwise it is "normal".
(7) RESET test: fit with the matrix consisting of the X values of the accepted columns (in column order) followed by the two columns f_i * f_i and f_i * f_i * f_i in this order, with the same y and w as the model. Let its rank be r_a and its residual sum of squares RSS_a; with q = r_a - r and df_a = n - r_a, compute the F value ((RSS - RSS_a) / q) / (RSS_a / df_a) and the p-value p_F(F, q, df_a).
(8) Outlier test: for the row i with the largest |t_i| (on a tie, the smaller i), compute the unadjusted p-value p_u = p_t(t_i, df - 1) and the Bonferroni-adjusted p-value min(1.0, n * p_u).
(9) Rows with the largest Cook's distances: the first 3 rows (all rows if n < 3) when the rows are sorted in decreasing order of D_i (on a tie, in increasing order of i).

== 12. Prediction ==
For each model, do the following for prediction rows 1, ..., K in order. If any of the values of the model's factor columns in a prediction row is NA, or a label of a categorical column is not among the levels of that model, the prediction row is "not predictable".
For a predictable prediction row, build its column values x_j (j = 1, ..., p) by the same rules as section 4 (with the same levels), and compute the predicted value f = SUM x_{c_k} * beta_{c_k} (k = 1, ..., r; alias columns are not used), u_k = SUM x_{c_m} * T_mk (sum over m = 1, ..., r; k = 1, ..., r), the standard error se = s * sqrt(SUM u_k * u_k), the half-width of the confidence interval t* * se, and the half-width of the prediction interval t* * sqrt(s * s + se * se). For each of the confidence interval and the prediction interval, the lower limit is f minus the half-width and the upper limit is f plus the half-width.
If the prediction row has the response column and its value y' is not NA, compute the error y' - f and whether lower limit of the prediction interval <= y' <= upper limit of the prediction interval holds.
For each model, compute the number of prediction rows that could be predicted, the number k_e of those for which the error was computed, RMSE = sqrt((SUM error * error) / k_e) (added in prediction-row order; NA if k_e = 0), and the number of prediction rows inside the prediction interval.

== 13. Variable selection ==
Variable selection is performed for model 1. The terms of model 1 are called the "original terms", and their number is T. For a subset S of the original terms, "the model of S" is the model with the terms of S arranged in the order of the original terms, fitted with the used rows, the levels and the weights of model 1 (if S is empty, it is the model with only the intercept column).
(1) Backward elimination: starting with S as the set of all original terms, do the following for steps 1, 2, ... in order.
  - Record the RSS, df and AIC of the model of S. If S is empty, finish.
  - Perform the marginal F tests of section 9 (2) for the model of S (the targets are the terms of S that are not contained in any other term of S, in the term order of S), and record their F values, degrees of freedom and p-values.
  - If the p-value of the term with the largest p-value (on a tie, the earlier one in term order) is greater than alpha, remove that term from S and proceed to the next step. Otherwise, finish.
(2) Forward selection: starting with S as the empty set, do the following for steps 1, 2, ... in order.
  - Record the AIC of the model of S.
  - Among the original terms not in S, those for which every original term contained in the term is in S are the "candidates". If there are no candidates, finish.
  - For each candidate U in the order of the original terms, record the AIC of the model of the set S with U added. If the AIC of the candidate with the smallest AIC (on a tie, the earlier one in the order of the original terms) is smaller than the AIC of the model of S, add that candidate to S and proceed to the next step. Otherwise, finish.
(3) Best subsets: for the integers m = 0, 1, ..., 2^T - 1 in order, build the subset S that contains the t-th (t = 1, ..., T) original term exactly when the 2^(t-1) digit of the binary representation of m is 1. When, for every term of S, all original terms contained in that term are in S, S is a "hierarchical subset"; compute the BIC, AIC and rank of the model of S. Sort the hierarchical subsets in increasing order of BIC (on a tie, in increasing order of m), and select the first B of them (all of them if there are fewer than B).

== 14. Data summary ==
Compute the following values for the whole of data.csv (all records).
(1) For each numeric column (in column order), with its non-NA values v_1, ..., v_m (in data order): their number m, the number of NAs, the mean vbar = (SUM v_i) / m, the standard deviation sqrt((SUM (v_i - vbar) * (v_i - vbar)) / (m - 1)), the minimum and the maximum
(2) For each categorical column (in column order): the number of non-NA values, the number of NAs, and the distinct labels (in the same character-code order as in section 3) with the count of each
(3) For each pair (a, b) of numeric columns, from the value pairs (x_i, y_i) (i = 1, ..., m) of the records (in data order) in which neither a nor b is NA, compute xbar = (SUM x_i) / m, ybar = (SUM y_i) / m, S_xy = SUM (x_i - xbar) * (y_i - ybar), S_xx = SUM (x_i - xbar) * (x_i - xbar), S_yy = SUM (y_i - ybar) * (y_i - ybar), and the correlation coefficient S_xy / sqrt(S_xx * S_yy) (pairs with a = b are computed by the same formulas).

== 15. Residual plots ==
For each model, build plots that count the points with horizontal-axis values xi_i and vertical-axis values zeta_i (i = 1, ..., n) on a grid of W characters across and H lines down. The range of the horizontal axis is lo to hi (lo < hi). The range of the vertical axis is -L to L, with larger values in upper lines.
The cell of point i has the column index min(floor((xi_i - lo) / (hi - lo) * W), W - 1) and the row index floor((L - zeta_i) / (2 * L) * H) clamped to the range 0 to H - 1 (0 if it is less than 0, H - 1 if it is greater than H - 1) (column indices are counted from the left and row indices from the top, both starting at 0). The number of points in each cell is counted.
- "Residual plot": the horizontal axis is the fitted value f_i (lo is the minimum of f_i, hi is the maximum), and the vertical axis is the studentized residual t_i.
- "Leverage plot": the horizontal axis is the leverage h_i (lo = 0.0, hi is the maximum of h_i), and the vertical axis is the studentized residual t_i.
- "Residual histogram": for each row index rho = 0, ..., H - 1 of the residual plot, compute the sum N_rho of the point counts of the cells in that row (points outside the vertical range are also counted, in the top or bottom row), and the range the row represents (lower end L - 2 * L * (rho + 1) / H, upper end L - 2 * L * rho / H). With N_max the maximum of N_rho, the bar length is ceil(N_rho * 40 / N_max), that is, the quotient of the integer (N_rho * 40 + N_max - 1) divided by N_max (the remainder is discarded).
Also count the number of rows with t_i > 2, the number of rows with t_i < -2, and the number of rows with |t_i| > L.

== Common formatting ==

- Integers are written in decimal without extra leading zeros (a negative number is prefixed with -).
- A "4-digit" value is rounded to 4 decimal places and written in fixed-point notation with exactly 4 digits after the decimal point (examples: 2.5 is 2.5000, -0.12346 is -0.1235).
