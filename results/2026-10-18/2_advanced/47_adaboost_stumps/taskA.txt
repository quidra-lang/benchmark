[Overview]
Write a boosting program that combines decision stumps (weak classifiers that only compare the value of one feature with a threshold). From inspection data of a production line (numeric features, and a label that is 1 for a defective item and -1 for a good item), it trains four variants, discrete AdaBoost, Real AdaBoost, Gentle AdaBoost and LogitBoost, and evaluates them on test data. The number of rounds of discrete AdaBoost is chosen by cross-validation. In addition, it computes the per-round progression of error rate, loss and margin, the margin distribution, feature importance (the sum of stump magnitudes, and the drop in the number of correct predictions when values are permuted), the shape of the per-feature additive model, ROC, probability calibration, and comparisons between variants (including a score that combines the variants, and a bootstrap), and it runs experiments that vary the training data size, the shrinkage factor, the number of features used and the label noise. It also compares SAMME and one-vs-rest multi-class classification on multi-class data (the given data have 3 classes).
The input is the four files in the input/ folder (training data, test data, multi-class data, settings), and the results are written to nine files in the output/ folder. Nothing is printed to standard output. The choice of weak classifiers, the handling of ties and the random numbers (the MINSTD generator) are all specified in [Processing], so the results are uniquely determined.

[Input files]
There are four input files: input/train.csv, input/test.csv, input/multiclass.csv and input/params.txt. Every file consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). There are no blank lines, and no spaces at the beginning or end of a line. Values are separated by a single comma in the CSV files and by a single space in params.txt.
An integer is written in decimal without extra leading zeros, and a negative number has a leading -. A "numeric value" is a decimal number made of, in this order, "-" (only when negative), a sequence of one or more digits (the integer part), and, when there is a fractional part, "." followed by a sequence of 1 to 3 digits (examples: 1450, -2.5, 0.125, 3.0). The integer part is written as 0 when it is 0, and otherwise has no extra leading zeros. Exponent notation is not used.
A "name" is a string of 1 to 16 characters that starts with a lowercase letter and consists of lowercase letters, digits and "_".

## input/train.csv (training data)
Line 1 is the header line: id, the feature names (d of them) and label, in this order, separated by commas (1 <= d <= 10). The feature names are distinct names, and differ from both id and label. The features are called feature 1, ..., feature d in header order, and this order is called the "feature order".
Each line from line 2 on is one "training row": the ID, the values (numeric values) of feature 1, ..., feature d, and the label, in this order, separated by commas. The ID is a string of 1 to 8 characters consisting of uppercase letters and digits, and IDs are distinct across train.csv and test.csv. The label is 1 or -1.
Let n be the number of training rows, and call them training row 1, ..., training row n in file order. Let x_ij be the value of feature j of training row i, and y_i its label.

## input/test.csv (test data)
The same header line and format as train.csv. Each line is called a "test row"; let m be their number, and call them test row 1, ..., test row m in file order. The labels of the test rows are used only for evaluation.

## input/multiclass.csv (multi-class data)
Line 1 is the header line: id, the feature names (e of them), class and role, in this order, separated by commas (1 <= e <= 10). The feature names are distinct names, and differ from each of id, class and role (they are unrelated to the feature names of train.csv). The features are taken in header order, and this is the feature order of this data set.
Each line from line 2 on contains the ID (1 to 8 characters consisting of uppercase letters and digits, distinct within this file), the value of each feature (numeric values), the class and the role, in this order, separated by commas. The class is an integer from 1 to K (K is the value of CLASSES in params.txt), and the role is train or test.
The rows with role train, in file order, are the "multi-class training rows", and the rows with role test, in file order, are the "multi-class test rows"; let N and M be their respective numbers.

## input/params.txt (settings)
The following 15 lines appear in this order. Each line consists of an uppercase keyword and values, separated by single spaces.
- ROUNDS T: the maximum number of boosting rounds (an integer from 1 to 50).
- VARIANTS v_1 v_2 ...: the names of the variants to train (1 to 4 distinct names among discrete, real, gentle, logit; discrete is always included). The order of this list is called the "variant order".
- BINS B: the number of bins of Real AdaBoost (an integer from 2 to 10).
- SMOOTHING epsilon: the smoothing value of Real AdaBoost (a positive numeric value).
- CONVERGENCE delta: the value used for the convergence test of Real AdaBoost (a positive numeric value).
- CLIP c: the upper bound on the absolute value of the LogitBoost working responses (a positive numeric value).
- FOLDS k: the number of cross-validation folds (an integer from 2 to 10).
- MARGINS theta_1 theta_2 ...: the values at which the margin distribution is examined (1 to 10 distinct numeric values from -1 to 1, in increasing order).
- CLASSES K: the number of classes of the multi-class data (an integer from 3 to 6).
- SAMME_ROUNDS T_s: the maximum number of rounds of multi-class classification (an integer from 1 to 50).
- PERMUTATION H seed: the number of repetitions H of the permutation importance (an integer from 1 to 20) and the random seed seed (an integer from 1 to 2147483646).
- NOISE seed q_1 q_2 ...: the random seed seed of the label noise experiment (an integer from 1 to 2147483646) and the fractions q of labels to flip (percentages; 1 to 5 distinct integers from 1 to 50).
- SIZES q_1 q_2 ...: the fractions used in the training data size experiment (percentages; 1 to 5 distinct integers from 1 to 100).
- SHRINKAGE nu_1 nu_2 ...: the factors used in the shrinkage experiment (1 to 5 distinct numeric values greater than 0 and at most 1).
- BOOTSTRAP S_b seed: the number of bootstrap resamples S_b (an integer from 1 to 1000) and the random seed seed (an integer from 1 to 2147483646).

[Processing]
## 1. Notation and arithmetic rules
- All real-number computation is done in double precision (IEEE 754 64-bit floating point). Input numeric values are converted to double precision (numeric values with the same string become the same value).
- exp is the exponential function, ln the natural logarithm, sqrt the square root, |t| the absolute value of t, floor(t) the largest integer not exceeding t, and max and min the maximum and the minimum. a mod b is the remainder of dividing a nonnegative integer a by a positive integer b.
- A sum written as sum(...) starts from 0 and adds one term at a time in the order of the sequence (row order for rows, round order for rounds). Other sums follow the same rule unless stated otherwise. In expressions, parentheses are evaluated first, multiplications and divisions are evaluated from left to right in the written order, and additions and subtractions are likewise evaluated from left to right in the written order.
- Since a label y is 1 or -1, multiplying by y only changes the sign and introduces no rounding error.
- The "ratio a/b" is the value of the real division a / b (how it is written in the output is specified in [Output files]). Integer counting is done with integers.
- Random numbers are produced by the MINSTD generator. The generator has an integer state rho. "Drawing a random number" means replacing rho by (48271 * rho) mod 2147483647 and returning the new rho (the product is less than 2^53, so it can be computed exactly with either 64-bit integers or doubles).

## 2. Row sets, decision stumps, threshold candidates
Each of the training procedures below takes one "row set". A row set is a sequence of rows in some order (called the "row order"; the rows are row 1, ..., row N, where N is the number of rows of this row set), and each row has a sequence of feature values (whose feature order is also fixed) and a label (a class in multi-class classification). Normally it is all training rows (in file order), but the experiments of 14 and others use only some of the rows or some of the features.
A "decision stump" consists of one feature j, a sequence of thresholds (one or more) and a sequence of output values (one more than the thresholds). For a value sequence whose feature j value is x, the output of the stump is the iota-th value (counting from 0) of the output value sequence, where iota is the number of thresholds with x > (threshold). For a stump with a single threshold theta, the output when x <= theta (the 0th) is called the "left value", and the output when x > theta (the 1st) is called the "right value".
For a row set and a feature j, define the following.
- "Sorted order": the rows ordered by increasing value of feature j. Rows with equal values are ordered by row order.
- "Distinct values": the distinct values of feature j among the rows, in increasing order, v_1 < v_2 < ... < v_q.
- "Threshold candidates": theta_0 = v_1 - 1 and, for kappa = 1, ..., q - 1, theta_kappa = (v_kappa + v_(kappa+1)) / 2; q candidates in total. Increasing order of kappa is called the "threshold order". No row of the row set has a feature j value <= theta_0, and the rows with a value <= theta_kappa (kappa >= 1) are the rows whose value is <= v_kappa.
- "Left cumulative sum": when each row is given a real number u, the left cumulative sum P_kappa for the threshold candidate theta_kappa is defined as follows. P_0 = 0, and for kappa = 1, ..., q - 1, P_kappa is P_(kappa-1) plus the u of the rows whose feature j value is v_kappa, added one at a time in sorted order. In other words, it is the running sum, when u is added one at a time in sorted order, up to and including the rows whose value is <= v_kappa.

## 3. Choosing among candidates (tie handling)
The weak classifier of each round is chosen by giving each of several "candidates" a real value (an error rate or similar; smaller is better). The candidates have a fixed "candidate order". Let E* be the minimum of the values of all candidates; among the candidates whose value is <= E* + 0.000000001, choose the first one in candidate order (candidates whose difference from the minimum is at most 10^-9 are treated as equal to the minimum candidate, and among them the earlier candidate is preferred).

## 4. Discrete AdaBoost
From a row set (rows 1, ..., N, labels y_i), an initial weight w_i for each row, a maximum number of rounds T_max and a shrinkage factor nu, train as follows. Unless stated otherwise, w_i = 1 / N (all rows), T_max = T and nu = 1.
Let bound = 1, and for t = 1, 2, ..., T_max in this order, do steps 1 to 7 below.
Step 1. Compute W+ = sum(w_i of the rows with y_i = 1) and W- = sum(w_i of the rows with y_i = -1).
Step 2. The candidates are triples (feature j, threshold theta_kappa, polarity s). For each feature j in feature order, and for each threshold candidate theta_kappa in threshold order, compute the left cumulative sums L+ (with u = w_i if y_i = 1, and 0 otherwise) and L- (with u = w_i if y_i = -1, and 0 otherwise); the error rate of the candidate with polarity s = 1 is L+ + (W- - L-), and the error rate of the candidate with polarity s = -1 is L- + (W+ - L+). The candidate order is feature order, then threshold order within the same feature, then polarity 1, -1 within the same threshold.
Step 3. Using the error rate as the value, choose a candidate (j, theta, s) by the method of 3, and let e be its error rate.
Step 4. If e >= 0.5, end training without adding this round (the stop reason is weak).
Step 5. If e <= 0.0000000001, let alpha = 1; otherwise let alpha = nu * (0.5 * ln((1 - e) / e)). The stump of this round has feature j, threshold theta, left value -s * alpha and right value s * alpha. The "decision" h_i of row i is s if the feature j value of row i is greater than theta, and -s otherwise.
Step 6. For each row, replace w_i by w_i * exp(-alpha) if h_i = y_i, and by w_i * exp(alpha) otherwise. Then compute Z = sum(w_i), replace each w_i by w_i / Z, and replace bound by bound * Z.
Step 7. For this round, record the stump, the polarity s, the error rate e, alpha, Z, bound and the weights of this round (the weights used in step 1, that is, the w_i before the replacement in step 6). If e <= 0.0000000001, end training here (perfect).
After finishing T_max rounds, end training (completed). The result of training is the sequence of recorded rounds and the stop reason. A row with weight 0 keeps weight 0, and only 0 is added to sums for it.

## 5. Real AdaBoost
Train from a row set (rows 1, ..., N, labels y_i) as follows.
(1) Cuts and bins: for each feature j, let s_1 <= s_2 <= ... <= s_N be the feature j values of all rows in increasing order (equal values are repeated), and for b = 1, ..., B - 1, with r = floor(b * N / B) (integer arithmetic), compute the cut c_jb = (s_r + s_(r+1)) / 2. The "bin" of a value sequence whose feature j value is x is the number beta (from 0 to B - 1) of values b with c_jb < x. Cuts may have the same value; in that case no value falls into the bins between them.
(2) Let the initial weights be w_i = 1 / N and bound = 1, and for t = 1, ..., T in this order, do steps 1 to 6 below.
Step 1. For each feature j in feature order, and for each of beta = 0, ..., B - 1, compute W+_(j,beta) = sum(w_i of the rows whose feature j bin is beta and y_i = 1) and W-_(j,beta) = sum(w_i of the rows whose feature j bin is beta and y_i = -1), and compute Z_j = 2 * (sum of sqrt(W+_(j,beta) * W-_(j,beta))) (added in increasing order of beta).
Step 2. Take the features as the candidates (the candidate order is feature order), choose a feature j by the method of 3 using Z_j as the value, and let Z = Z_j.
Step 3. If Z >= 1 - delta, end training without adding this round (converged).
Step 4. For beta = 0, ..., B - 1, compute h_beta = 0.5 * ln((W+_(j,beta) + epsilon) / (W-_(j,beta) + epsilon)). The stump of this round has feature j, threshold sequence c_j1, ..., c_j(B-1) and output value sequence h_0, ..., h_(B-1) (the output is h_beta, where beta is the bin of the value).
Step 5. Replace bound by bound * Z, and record the stump, Z, bound and the weights of this round (the w_i before the replacement in step 6).
Step 6. For each row, let g_i be the output of this stump for row i, and replace w_i by w_i * exp(-y_i * g_i). Then replace each w_i by w_i / (sum(w_i)) (sum(w_i) is the sum of the weights after the multiplicative replacement has been finished for all rows, computed only once before the divisions start).
After finishing T rounds, end training (completed).

## 6. Gentle AdaBoost
"Regression stump search": from a row set (rows 1, ..., N) with a target value r_i and a weight w_i for each row, choose one stump as follows.
Compute W = sum(w_i), S = sum(w_i * r_i) and Q = sum(w_i * r_i * r_i). The candidates are pairs (feature j, threshold theta_kappa), and the candidate order is feature order, then threshold order within the same feature. For each candidate, compute the left cumulative sums W_L (u = w_i) and S_L (u = w_i * r_i), and let W_R = W - W_L and S_R = S - S_L. If kappa = 0, let a_L = 0 and G = S_R * S_R / W_R; if kappa >= 1, let a_L = S_L / W_L and G = S_L * S_L / W_L + S_R * S_R / W_R. Further, let a_R = S_R / W_R, and let the value of the candidate (the weighted squared error) be E = Q - G. Choose a candidate (j, theta) by the method of 3; the result of the search is the stump with feature j, threshold theta, left value a_L and right value a_R, together with its E.
Gentle AdaBoost trains from a row set (rows 1, ..., N, labels y_i) as follows. Let the initial weights be w_i = 1 / N, and for t = 1, ..., T in this order, perform the regression stump search with target values r_i = y_i and weights w_i, and record the obtained stump, E and the weights of this round (the w_i before the next replacement). Then, for each row, let g_i be the output of this stump for row i and replace w_i by w_i * exp(-y_i * g_i), and replace each w_i by w_i / (sum(w_i)) (sum(w_i) is the sum of the weights after the multiplicative replacement has been finished for all rows, computed only once before the divisions start). After finishing T rounds, end training (completed).

## 7. LogitBoost
Train from a row set (rows 1, ..., N, labels y_i) as follows. Let y*_i be 1 if y_i = 1, and 0 otherwise. Starting from the score F_i = 0 and the probability p_i = 0.5 for each row, for t = 1, ..., T in this order, do steps 1 to 4 below.
Step 1. For each row, compute q_i = p_i * (1 - p_i) and the working response z_i = (y*_i - p_i) / q_i, and replace z_i by c if z_i > c, and by -c if z_i < -c.
Step 2. Let the weights be w_i = q_i / (sum(q_i)) (sum(q_i) is computed only once), and perform the regression stump search (6) with target values z_i and weights w_i. From the left value a_L and the right value a_R of the obtained stump, make a stump with the same feature and threshold, left value a_L / 2 and right value a_R / 2; this is the stump of this round.
Step 3. For each row, let g_i be the output of this round's stump for row i, and replace F_i by F_i + g_i, and then replace p_i by 1 / (1 + exp(-2 * F_i)) using this new F_i.
Step 4. Compute the loss L = (sum(ln(1 + exp(-2 * y_i * F_i)))) / N, and record this round's stump, the E of the search, L and the weights w_i of this round (the w_i of step 2).
After finishing T rounds, end training (completed).

## 8. Score, prediction, loss, margin
Number the rounds of a training result in the order recorded as round 1, 2, ..., and let g_t(x) be the output of the stump of round t (x is a value sequence).
- Score: the score by the first t rounds is F_t(x) = sum(g_tau(x)) (added for tau = 1, ..., t in this order). The score by all rounds of a round sequence is written simply F(x). If there are no rounds, the score is 0.
- Prediction: 1 if the score is greater than 0, and -1 otherwise. A row whose prediction differs from its label is called an "error", and a row whose prediction matches its label is called "correct".
- Loss: the loss of a sequence of rows (labels y_i, scores f_i) is (sum(ln(1 + exp(-2 * y_i * f_i)))) / (number of rows) for LogitBoost scores, and (sum(exp(-y_i * f_i))) / (number of rows) for the scores of the other variants.
- Magnitude: the "magnitude" c_t of round t is the maximum of the absolute values of its stump's output value sequence (in discrete AdaBoost it is alpha). The sum of the magnitudes of the first t rounds, C_t = sum(c_tau) (tau = 1, ..., t), is the "total magnitude", and the total magnitude over all rounds of a round sequence is written simply C.
- Margin: the margin of a row with label y and value sequence x is y * F(x) / C (it lies between -1 and 1).
- Contribution: the contribution of feature j is the sum of g_t(x) over the rounds of the round sequence whose stump feature is j (added in round order; 0 if there is no such round).

## 9. Choosing the number of rounds by cross-validation
Put training row i (i = 1, ..., n) into fold ((i - 1) mod k) + 1. For each fold phi = 1, ..., k, do the following.
- Let n_phi be the number of training rows not in fold phi. With all training rows as the row set (the threshold candidates are also built from all training rows), with initial weight 1 / n_phi for the training rows not in fold phi and initial weight 0 for the training rows in fold phi, train discrete AdaBoost (T_max = T, nu = 1). Let R_phi be the number of recorded rounds.
- Call each training row of fold phi a "validation row", and for each t = 1, ..., T, count the validation rows that are errors under the score by the first min(t, R_phi) rounds.
For each t, compute cv_t, the sum of the error counts of all folds. The t with the smallest cv_t (the smaller t if tied) is the "selected number of rounds" T*.
For each training row, the score by the first min(T*, R_phi) rounds of the training of the fold in which that row is a validation row is the "cross-validation score" of that row.

## 10. Training and evaluating each variant
For each variant in variant order, with all training rows as the row set, train discrete with discrete AdaBoost (the default values of 4), real with Real AdaBoost, gentle with Gentle AdaBoost, and logit with LogitBoost. This is called the "full training" of each variant, and let R be its number of rounds. The "final model" of each variant is the round sequence consisting of the first min(T*, R) rounds of the full training for discrete, and of all rounds of the full training for the other variants. Below, unless stated otherwise, scores, predictions, margins and contributions are those of the final model.
(1) Curve: for each t = 1, ..., R of the full training, using the score F_t by the first t rounds, compute the number of training rows that are errors, the number of test rows that are errors, the loss of the training rows, the loss of the test rows, and the minimum margin (the minimum of y_i * F_t(x_i) over the training rows, divided by C_t).
(2) Metrics: for a sequence of rows and their scores, count tp (label 1 and prediction 1), fp (label -1 and prediction 1), tn (label -1 and prediction -1), fn (label 1 and prediction -1) and the number correct tp + tn, and compute the following values.
  - accuracy is the ratio (tp + tn)/(number of rows), precision is the ratio tp/(tp + fp), recall is the ratio tp/(tp + fn), and f1 is the ratio (2 * tp)/(2 * tp + fp + fn).
  - AUC: over all pairs of a row a with label 1 and a row b with label -1, count a "win" if the scores satisfy f_a > f_b and a "tie" if f_a = f_b; the AUC is the ratio (2 * number of wins + number of ties)/(2 * number of rows with label 1 * number of rows with label -1) (the numerator and the denominator are computed with integers).
  - Loss: the loss of 8.
  Compute these for the discrete cross-validation scores with the training row labels, for the training row scores of each variant, and for the test row scores of each variant.
(3) Curve minima: find the t with the smallest number of training rows that are errors in (1) (the smaller t if tied), and the t with the smallest number of test rows that are errors (the smaller t if tied).
(4) Errors of all variants: collect, in test row order, the test rows that are errors under the prediction of every variant.
(5) Variant comparison: for every pair (a, b) in which a comes before b in variant order (a in variant order, and for each a, b in variant order), count the number of test rows whose predictions agree, the number n1 of test rows where the prediction of a is correct and the prediction of b is an error, and the number n2 of test rows where the prediction of b is correct and the prediction of a is an error, and if n1 + n2 > 0, compute chi2 = the ratio ((|n1 - n2| - 1) * (|n1 - n2| - 1))/(n1 + n2) (the numerator and the denominator are computed with integers).
(6) Probability calibration: from the score f of each test row, compute the probability p = 1 / (1 + exp(-2 * f)). With y* = 1 if the label is 1 and 0 otherwise, compute the Brier score (sum((p - y*) * (p - y*))) / m. Also put each test row into bin min(4, floor(p * 5)), and for each of bins 0, ..., 4, compute the number of test rows, the mean of p (added in test row order and divided by the count), and the number of test rows with label 1.
(7) ROC: arrange the distinct values of the test row scores in decreasing order, and for each value v, compute the number of test rows with score >= v and label 1 and the number of test rows with score >= v and label -1.
(8) Data summary: for each feature in feature order, for the training rows and the test rows separately, compute the minimum, the maximum, the mean (added in row order and divided by the count) and the number of distinct values.
(9) Variant committee: for each row, the sum, over the variants in variant order, of the final-model score of each variant divided by its total magnitude C (score / C) is the "committee score" of that row. For the committee scores of the training rows and of the test rows, compute the metrics of (2) (the loss is computed with the formula for variants other than LogitBoost).
(10) Bootstrap: set the generator to rho = seed (the BOOTSTRAP seed), and for omega = 1, ..., S_b in this order, do the following. Draw m random numbers, and for each of them select the test row whose number is the remainder of that value divided by m, plus 1 (the same test row may be selected any number of times). For each variant in variant order, count c_omega, the number of the selected m test rows (a duplicate is counted as many times as it was selected) whose prediction is correct.
  For each variant, compute the mean, the ratio (sum(c_omega))/(S_b * m). Also sort c_1, ..., c_(S_b) in increasing order, and with g = floor(S_b / 40) (integer arithmetic), let the (g + 1)-th value be the "lower bound" and the (S_b - g)-th value be the "upper bound".
  Further, for the pairs of variants (a, b) in the same order as (5), count the number of omega for which c_omega of a is greater than c_omega of b, the number for which they are equal, and the number for which c_omega of a is smaller.

## 11. Margin distribution and feature importance
For the final model of each variant in variant order, compute the following.
(1) Compute the margin of each training row and each test row, and for the training rows and the test rows separately, compute the minimum and the mean of the margins (added in row order and divided by the count) and, for each theta of MARGINS, the number of rows whose margin is <= theta. Also, for the test rows, for each theta of MARGINS, compute the number of test rows whose margin has an absolute value greater than theta, and the number of those whose prediction is correct.
(2) Histogram: put each training row into bin min(19, floor((margin + 1) * 10)) ((margin + 1) * 10 is computed in this order), and compute the number of training rows in each of bins 0, ..., 19.
(3) Smallest-margin training rows: the first 5 rows when the training rows are ordered by increasing margin (row order if tied).
(4) Magnitude importance: for each feature j, the sum of the magnitudes c_t of the final model's rounds whose stump feature is j (added in round order; 0 if there are none) is the "importance" of feature j, and the number of those rounds is its "count". Let D be the sum of the importances of all features (added in feature order); the importance / D of each feature is its "share". Order the features by decreasing importance (feature order if tied), and assign ranks starting from 1 in this order.
(5) Permutation importance: let base be the number of correct test rows. For each feature j in feature order, for r = 1, ..., H in this order, do the following.
  - Make the sequence pi = (1, 2, ..., m), and for i = m, m - 1, ..., 2 in this order, draw one random number, let lambda be the remainder of that value divided by i, plus 1, and swap the i-th and lambda-th elements of pi (do nothing if i = lambda).
  - For each test row i, make the value sequence in which only the feature j value is replaced by the feature j value of test row pi(i) (the test row whose number is the i-th element of pi), and let c_r be the number of test rows i for which its prediction matches the label of test row i.
  Let sum(base - c_r) (added in order of r) be the "drop" of feature j, and also compute the minimum and the maximum of c_r. Order the features by decreasing drop (feature order if tied), and assign ranks starting from 1 in this order.
  Only one random number generator is used throughout all variants, and it is set to rho = seed (the PERMUTATION seed) before processing the first variant. Random numbers are drawn in variant order, feature order and order of r.

## 12. Shape as an additive model
For the final model of each variant in variant order, for each feature j in feature order, compute the following. Collect, in round order, the final model's rounds whose stump feature is j. Let e_1 < ... < e_r be the distinct values, in increasing order, of the thresholds (the cuts for Real AdaBoost) of the collected stumps. Interval 0 is "from -inf to e_1", interval iota (iota = 1, ..., r - 1) is "from e_iota to e_(iota+1)", and interval r is "from e_r to inf". The value of interval 0 is the sum of the 0th values of the output value sequences of the collected stumps, and the value of interval iota (iota >= 1) is the sum, over the collected stumps, of the (number of that stump's thresholds that are <= e_iota)-th value of its output value sequence (both are added in round order). This equals the contribution of feature j at a value x falling in that interval (e_iota < x <= e_(iota+1) for interval iota (1 <= iota <= r - 1), x <= e_1 for interval 0, and x > e_r for interval r). The maximum of the interval values minus the minimum is the "range". If no rounds are collected, r = 0, interval 0 is "from -inf to inf", and its value is 0.

## 13. Multi-class classification
Use the multi-class training rows (in file order) as the row set.
(1) Multi-class stump search: from the class c_i and the weight w_i of each row, choose one stump as follows. Compute W = sum(w_i) and, for each class kappa = 1, ..., K, W_kappa = sum(w_i of the rows whose class is kappa). The candidates are pairs (feature j, threshold theta), and the candidate order is feature order, then threshold order within the same feature. For each candidate, compute, for each class kappa, the left weight WL_kappa (the left cumulative sum with u = w_i if the class is kappa, and 0 otherwise) and the right weight WR_kappa = W_kappa - WL_kappa. Let a be the class with the largest WL_kappa (the smaller number if tied) and b the class with the largest WR_kappa (the smaller number if tied), and let the value of the candidate (the error rate) be e = W - (WL_a + WR_b). Choose a candidate (j, theta) by the method of 3; the result of the search is the stump with feature j, threshold theta, left value a and right value b (both are class numbers), together with its e.
(2) SAMME: let the initial weights be w_i = 1 / N, and for t = 1, ..., T_s in this order, do steps 1 to 4 below.
  Step 1. Find a stump and e by the search of (1). If e >= (K - 1) / K, end training without adding this round (weak).
  Step 2. If e <= 0.0000000001, let alpha = 1; otherwise let alpha = ln((1 - e) / e) + ln(K - 1).
  Step 3. Replace w_i by w_i * exp(alpha) for the rows whose class differs from the output of the stump (the other rows stay as they are), and replace each w_i by w_i / (sum(w_i)) (sum(w_i) is the sum of the weights after the multiplicative replacement has been finished for all rows, computed only once before the divisions start). Record the stump, e and alpha.
  Step 4. If e <= 0.0000000001, end training (perfect).
  After finishing T_s rounds, end training (completed). Let R_s be the number of recorded rounds.
  The "class scores" of a value sequence x by the first t rounds are, for each class kappa, the sum of alpha over those rounds whose stump output is kappa (added in round order; 0 if there are none). The prediction is the class with the largest score (the smaller number if tied). The prediction by all rounds is called the "SAMME prediction".
(3) One-vs-rest: for kappa = 1, ..., K in this order, train discrete AdaBoost (w_i = 1 / N, T_max = T_s, nu = 1) on the row set in which the label of each row is 1 if its class is kappa and -1 otherwise, and call it "model kappa". The "one-vs-rest prediction" is the class whose model has the largest score (8) by all of its rounds (the smaller number if tied).
(4) Evaluation: for the SAMME prediction and the one-vs-rest prediction separately, count the rows whose prediction differs from the class (errors) among the multi-class training rows and among the multi-class test rows, and build the confusion matrix of the multi-class test rows. The confusion matrix is a K-by-K table U, where U[kappa][lambda] is the number of test rows whose class is kappa and whose prediction is lambda. The precision of class kappa is the ratio of U[kappa][kappa] to the sum of column kappa of U, and the recall is the ratio of U[kappa][kappa] to the sum of row kappa of U.
  Also, for model kappa, count the rows for which the prediction (8) of the score by all rounds differs from "1 if the class is kappa, and -1 otherwise", among the multi-class training rows and among the test rows separately. Also count the multi-class test rows for which the SAMME prediction and the one-vs-rest prediction agree.
  The SAMME magnitude importance is 11 (4) with the magnitude c_t replaced by alpha (the features are those of multiclass.csv).
  As the SAMME curve, for each t = 1, ..., R_s, compute the number of multi-class training rows and the number of multi-class test rows that are errors under the prediction by the first t rounds.

## 14. Additional experiments
(1) Training data size: for each q in SIZES order, let s = floor(n * q / 100) (integer arithmetic), and with training rows 1, ..., s as the row set (the threshold candidates and the Real AdaBoost cuts are also built from these s rows), train each variant in variant order by the same procedure as 10 (no cross-validation is done even for discrete, and all rounds are used). Using the score by all rounds, compute the number of errors among training rows 1, ..., s and the number of test rows that are errors.
(2) Shrinkage: for each nu in SHRINKAGE order, train discrete AdaBoost on all training rows (w_i = 1 / n, T_max = T, that nu). Compute the number of training rows that are errors and the number of test rows that are errors under the score by all rounds, and, over each t = 1, ..., (number of rounds), the minimum of the number of test rows that are errors under the score by the first t rounds, together with the t at which it is smallest (the smaller t if tied).
(3) Number of features: use the top kappa features (kappa = 1, ..., d) by the discrete ranks of 11 (4), arranged in feature order. With the value sequences of all training rows restricted to these features (in this arranged feature order) as the row set, train discrete AdaBoost (w_i = 1 / n, T_max = T*, nu = 1), and using the score by all rounds, compute the number of training rows that are errors and the number of test rows that are errors (the test rows also use only the same features).
(4) Label noise: for each q in NOISE order, let f = floor(n * q / 100). For each q, reset the generator to rho = seed (the NOISE seed), and starting from the sequence pi = (1, 2, ..., n), for i = 1, ..., f in this order, draw one random number, let lambda be the remainder of that value divided by (n - i + 1), plus i, and swap the i-th and lambda-th elements of pi (do nothing if i = lambda). The training rows whose numbers are the first f elements of pi are the "flipped rows"; with the training rows in which the sign of the label of each flipped row is changed (the feature values stay as they are) as the row set, train each variant in variant order by the same procedure as 10 (no cross-validation is done even for discrete, and all rounds are used). Compute the number of training rows that are errors under the score by all rounds (counted with the labels after flipping), the number of test rows that are errors, over each t = 1, ..., (number of rounds) the minimum of the number of test rows that are errors under the score by the first t rounds together with the t at which it is smallest (the smaller t if tied), and the sum of the weights of the flipped rows among the weights recorded for the last round (added in row order).

## Common format
- The output consists of ASCII characters only, and every line (including the last line) ends with a newline (LF). Do not put extra spaces at the beginning or end of a line, and do not insert blank lines that are not specified.
- In the formats below, a part enclosed in < > is replaced by a value, and every other character is written as it is. Values are separated by a single space (a single comma in CSV files).
- Integers are written in decimal without extra leading zeros. Labels and predictions are written as 1 or -1, and classes as their numbers.
- Real numbers are rounded to 4 decimal places and written in fixed-point notation with exactly 4 digits after the decimal point (examples: 2.5 is 2.5000, 1450 is 1450.0000). However, a value annotated with a number of digits, such as "(6 decimals)", is written in the same way with that number of digits. Exponent notation is not used, and 0 is written when the integer part is 0. A negative number gets a leading -, but a value whose rounded result is 0 gets no - (example: -0.00003 is 0.0000). Values derived from input values, such as thresholds, epsilon, c, theta and nu, are also written this way.
- A value described as a "ratio" is the "ratio a/b" of 1, written as a real number (with 4 decimals) if b > 0, and written as - if b = 0.
- A value of the form <a>/<b> is written as two integers joined by / (example: 53/300).
- <variant> is the name of a variant (discrete, real, gentle, logit), <feature name> is the name of a feature, and <ID> is the ID of a row.
