[Overview]
Write a symbolic differentiation program that handles mathematical expressions built from rational constants, variables, the four arithmetic operations, powers and elementary functions. The program reads a sequence of commands from standard input, executes the commands in order, brings expressions into normal form by fixed rules, and performs definition of named expressions, simplification, expansion, differentiation (higher-order derivatives, gradients, entries of the Hessian matrix, implicit derivatives), substitution of expressions for variables, evaluation (an exact rational number or a decimal approximation), computation of the equations of tangent and normal lines, limits by L'Hopital's rule, and Taylor polynomials, writing the results to standard output.

[Input format]
The input consists of the following lines in this order.
- Line 1 is the number of commands N.
- Then N commands follow, one per line.
A command line consists either of the command name alone, or of the command name, one space and the argument part concatenated in this order. The command name runs from the beginning of the line up to just before the first space (the whole line if there is no space), and the argument part is everything after that space. There are the following 13 commands, with the following formats (EVAL has two formats; the part other than the command name shows how the argument part is written).
  LET name = e
  SIMPLIFY e
  EXPAND e
  DIFF e ; v
  DIFFN e ; v ; n
  GRAD e
  HESSIAN e
  IMPLICIT e ; v ; w
  SUBST e ; v ; e2
  EVAL e
  EVAL e ; a...
  TANGENT e ; v ; c
  LIMIT e ; v ; c
  TAYLOR e ; v ; c ; n
Here e and e2 are expression strings (defined in section 1), name is a name, v and w are variable names, n is an order, c is a point, and a is an assignment (defined in section 8). a... denotes zero or more assignments separated by spaces. The exact way the argument part is split is defined in [Processing].
Every input line satisfies [Constraints], but does not necessarily match a command format. How lines that do not match a format are handled is also defined in [Processing].

[Processing]
Process the commands one at a time in input order, writing the output of each command immediately. Below, a string enclosed in double quotes is a string that appears as is in the input or output. In the output descriptions, a part such as <P(f)> is replaced by its content.

1. Tokens and grammar of expressions
- A variable name is a string consisting of one lowercase letter (a to z) followed by zero or more lowercase letters or digits (0 to 9), excluding the six strings sin, cos, tan, exp, ln and sqrt (called function names) (for example, x, y2, ab, sinx and e are variable names). A name is a string consisting of one uppercase letter (A to Z) followed by zero or more uppercase letters or digits (for example, F, G2 and AB are names).
- An expression string is split into tokens from the beginning by the following rules. Spaces are skipped; they only separate tokens.
  (a) At a digit, the string formed by all consecutive digits from there is one token (a number token). The value of a number token is the integer obtained by reading it as a decimal number (leading zeros are allowed).
  (b) At a lowercase letter, the string formed by all consecutive lowercase letters and digits from there is one token. If it is a function name, it is a function token; otherwise it is a variable token.
  (c) At an uppercase letter, the string formed by all consecutive uppercase letters and digits from there is one token (a name token).
  (d) Each of "+" "-" "*" "/" "^" "(" ")" is a token of one character.
  (e) On encountering any other character, with that character as c, output error: invalid character '<c>' and finish processing that command.
  Tokenization is done first for the whole expression string, so if there is a character covered by (e), this error is reported before any grammar error. For example, "2x" is split into number token 2 and variable token x, "sinx" into variable token sinx, and "F1x" into name token F1 and variable token x.
- A valid expression is a token sequence defined as follows.
  Expression: one term, followed by zero or more pairs of "+" or "-" and a term.
  Term: one unary, followed by zero or more pairs of "*" or "/" and a unary.
  Unary: "-" followed by a unary, or a power expression.
  Power expression: one atom, followed by zero or one pair of "^" and a unary.
  Atom: a number token, a variable token, a name token, a function token followed by "(", an expression and ")" in this order, or "(", an expression and ")" in this order.
  By this grammar, "+" "-" "*" "/" associate to the left, "^" associates to the right, and "^" binds more tightly than a preceding "-". An exponent may begin with "-". For example, -x^2 means -(x^2), x^-2 means x^(-2), 2^3^2 means 2^(3^2), a-b-c means (a-b)-c, and a/b*c means (a/b)*c.
- Parsing: when the expression string yields the token sequence t1, t2, ..., tk without error (e), check the following two conditions in this order for i = 1, 2, ..., k in order, output the first one that applies, and finish processing that command.
  (f) There is no valid expression that begins with t1, ..., ti: error: unexpected '<ti>'
  (g) ti is a name token and that name is not defined (section 4): error: undefined name '<ti>'
  If none applies through the end and the whole t1, ..., tk is not a valid expression either (including the case k = 0), output error: unexpected end of expression and finish processing that command. For <ti>, write the token's string as is.
  (f) is the same as reporting the first token at which an ordinary parser that reads the tokens from the beginning according to precedence (such as recursive descent) can no longer proceed. For example, "x +" gives unexpected end of expression, and "2x" gives an unexpected error at "x", "x + * y" at "*", "sin x" at "x", "()" at ")", and "(x))" at the second ")".
- Value of an expression: if there is no error, the value (a normal form) of the expression string is computed for each part of the grammar as follows. The values of the parts are each computed from left to right; if an operation of section 3 produces an error along the way, output that error and finish processing the command.
  Number token: the number with its value. Variable token: the variable with that variable name. Name token: the normal form defined for that name.
  Atom of function token f: fn(f, a), where a is the value of the inner expression. Atom "(" expression ")": the value of the inner expression.
  Unary consisting of "-" followed by unary u: mul(number -1, value of u).
  Power expression consisting of atom b followed by "^" and unary u: pow(value of b, value of u).
  Term: let r be the value of the first unary; for each following pair in order, replace r by mul(r, value of u) if the pair is "*" and unary u, or by mul(r, pow(value of u, number -1)) if the pair is "/" and unary u. The final r is the value of the term.
  Expression: let r be the value of the first term; for each following pair in order, replace r by add(r, value of t) if the pair is "+" and term t, or by add(r, mul(number -1, value of t)) if the pair is "-" and term t. The final r is the value of the expression.

2. Normal forms
- A normal form is one of the following six kinds.
  Number: one rational number.
  Variable: one variable name.
  Sum: a sequence of two or more normal forms. The elements of the sequence are called terms.
  Product: a sequence of two or more normal forms. The elements of the sequence are called factors.
  Power: a pair of a base (a normal form) and an exponent (a normal form).
  Function: a pair of a function name (one of sin, cos, tan, exp, ln) and an argument (a normal form).
  In what follows, number q denotes the number whose value is q, and an integer denotes a number whose value is an integer. Two normal forms are equal when they are of the same kind and, respectively, for numbers the values, for variables the variable names, for sums and products the sequence lengths and the elements at each position, for powers the bases and the exponents, and for functions the function names and the arguments are equal. The set of variable names that appear in a normal form f is called the variables of f.
  Sums, products, powers and functions are always built with the operations add, mul, pow and fn of section 3 (fn converts sqrt into a power).
- Coefficient and monomial part: the coefficient (a rational number) and the monomial part (a sequence of normal forms) of a normal form t are defined as follows. If t is a number, the coefficient is the value of t and the monomial part is the empty sequence. If t is a product whose first factor is a number, the coefficient is the value of that number and the monomial part is the sequence of the remaining factors. If t is a product whose first factor is not a number, the coefficient is 1 and the monomial part is the sequence of all its factors. Otherwise, the coefficient is 1 and the monomial part is the sequence consisting of t alone.
- Base and exponent: if a normal form f is a power, the base and exponent of f are the base and exponent of that power. Otherwise, the base of f is f itself and the exponent is number 1.
- Order E: the order E on normal forms is defined as follows. If the kinds differ, the one whose kind comes earlier in the order variable, sum, product, power, function, number is smaller. If the kinds are the same, compare as follows.
  Variable: compare the variable names in ASCII lexicographic order (compare character by character from the beginning by ASCII code; when one is a prefix of the other, the shorter one is smaller).
  Sum and product: compare the sequences element by element from the beginning with E; the one with the smaller element at the first differing position is smaller. When one is a prefix of the other, the shorter one is smaller.
  Power: compare the bases with E; if they are equal, compare the exponents with E.
  Function: compare the function names in ASCII lexicographic order; if they are equal, compare the arguments with E.
  Number: the one with the smaller value is smaller.
- Exponent comparison: when two normal forms x and y are compared as exponents, if both are numbers, the one with the larger value is larger; if only one is a number, the one that is not a number is larger; if neither is a number, the one that is larger under E is larger.
- Term order: which of two normal forms s and t with different monomial parts is placed first is decided as follows. Collect the bases of all elements of the monomial part of s and of the monomial part of t, merge equal ones into one, and sort them in increasing order of E. For each base b in that order, compare, by exponent comparison, the exponent of the element of the monomial part of s whose base is b (number 0 if there is none) with the same for the monomial part of t (number 0 if there is none); at the first b for which they differ, the one with the larger exponent is placed first. For example, x^3, 2*x^2*y, x^2, x*y^2, y, 5, 1/x are in this order.

3. Operations that build normal forms
- add(a1, a2, ..., ak) (k >= 1, each ai is a normal form): computed by the following (1) to (4).
  (1) For i = 1, 2, ..., k in order, list the terms of ai in order if ai is a sum; if ai is a product of exactly two factors, a number and a sum (number c, then sum A, in that order), list mul(c, u) for each term u of A in order; otherwise list ai itself. This forms a sequence of terms.
  (2) Divide the sequence of terms into groups of terms whose monomial parts are equal, and compute the sum of the coefficients for each group.
  (3) For each group whose coefficient sum c is not 0, build the following term from c and the group's monomial part m. If m is empty, it is number c. If c = 1 and m has one element, it is that element. Otherwise, it is the product of number c and the elements of m in this order if c != 1, or the product of the elements of m if c = 1.
  (4) Sort the built terms by the term order. If there are no terms, the result is number 0; if there is one term, the result is that term; if there are two or more, the result is the sum of the terms in that order.
  For example, add(x, number 3, mul(number 2, x)) is 3*x + 3, and add(x, mul(number -1, x)) is number 0.
- mul(a1, a2, ..., ak) (k >= 0): computed by the following (1) to (5).
  (1) For i = 1, 2, ..., k in order, list the factors of ai in order if ai is a product, otherwise ai itself. This forms a sequence of factors.
  (2) Let c be the product of the values of all numbers in the sequence of factors (c = 1 if there are no numbers). If c = 0, the result is number 0.
  (3) Divide the factors that are not numbers into groups of factors whose bases are equal. The result of a group is its factor if the group has one factor; if it has two or more factors, the result is pow(base, x), where x is the normal form obtained by applying add to all exponents of the group's factors in sequence order.
  (4) If there is a number or a product among the group results, or there are two group results whose bases are equal, compute mul(number c, group result 1, group result 2, ...) (listing all group results) anew, and that is the result (for example, the group result x^2 of the group of (x^2)^(1/3) and (x^2)^(2/3), and the group result x of the group of x, both have base x).
  (5) Otherwise, let F be the sequence of the group results sorted in increasing order of E of their bases. If F is empty, the result is number c. If c = 1 and F has one element, the result is that element. Otherwise, the result is the product of number c and the elements of F in this order if c != 1, or the product of the elements of F if c = 1.
  For example, mul(x, number 2, x^3, y) is 2*x^4*y, and mul(number 2, add(x, number 1)) is the product of the two factors 2 and x + 1.
- pow(b, x): check the following from top to bottom; the first that applies gives the result.
  (1) If x is number 0, number 1 (0^0 is also 1).
  (2) If x is number 1, b.
  (3) When b is a number: if b = 1, number 1. If b = 0 and x is a number: number 0 if the value of x is positive, error: division by zero if it is negative. If x is an integer, the number whose value is b to the power x (if x is negative, a power of the reciprocal). If x is a number that is not an integer, with its value as the reduced fraction p/q (q >= 2): if the value of b is positive and, writing the value of b as the reduced fraction u/w, there are integers s >= 0 and t >= 0 with u = s^q and w = t^q, the number whose value is (s/t)^p. If none of the above applies, the power with base b and exponent x.
  (4) If b is a power and x is an integer, pow(base of b, mul(exponent of b, x)).
  (5) If b is a product and x is an integer, compute pow(fi, x) for each factor f1, ..., fm of b; the result is their mul.
  (6) If none of the above applies, the power with base b and exponent x.
  For example, pow(number 4, number 1/2) is number 2, pow(number 8, number -2/3) is number 1/4, pow(number 2, number 1/2) is the power sqrt(2), pow(x^3, number 2) is x^6, and pow(x^2, number 1/2) is the power (x^2)^(1/2) (its base is x^2).
- fn(f, a): check the following from top to bottom; the first that applies gives the result.
  (1) If f is sqrt, pow(a, number 1/2).
  (2) If f is sin or tan and a is number 0, number 0; if f is cos or exp and a is number 0, number 1; if f is ln and a is number 1, number 0.
  (3) If f is one of sin, cos, tan and the coefficient of a is negative, let a' = mul(number -1, a); the result is fn(cos, a') if f is cos, and mul(number -1, fn(f, a')) if f is sin or tan.
  (4) If f is exp and a is a function with function name ln, its argument; if f is ln and a is a function with function name exp, its argument.
  (5) If none of the above applies, the function with function name f and argument a.
- The normal forms built by these operations have the following properties (this is for explanation only; the rules are as given above). The terms of a sum are not sums, are not products of two factors, a number and a sum, have pairwise different monomial parts, and are arranged in term order. The factors of a product, except for at most one leading number (which is neither 0 nor 1), are neither numbers nor products, have pairwise different bases, and are arranged in increasing order of E of their bases. The exponent of a power is neither 0 nor 1. Note that the way to represent something as a normal form is not necessarily unique (for example, 2*(x + 1) and 2*x + 2 are different normal forms).

4. Name definitions
The program keeps as its state a set of pairs of a name and a normal form. Initially it is empty. A name that has a pair is said to be defined. Names are defined with the LET command. The value of a name token in an expression is the normal form defined at that time. A normal form, once defined, does not change even if another name is redefined later.

5. Notation
The notation P(f) of a normal form f is defined as follows.
- Number: if it is an integer, the decimal notation of its value (with a leading "-" if negative). Otherwise, with its value as the reduced fraction p/q (q >= 2), "<p>/<q>" (with "-" before p if negative). Examples: 3, -5, 1/2, -7/3.
- Variable: the variable name.
- Function: the function name, "(", P(argument) and ")" concatenated in this order.
- Sum: P(t1) of the first term t1, followed, for each of the second and later terms t in order, by " - " (a space on each side of "-") and the rest of P(t) after removing its leading "-" if P(t) begins with "-", and otherwise by " + " and P(t).
- Product: Q(c, sequence) below, for the coefficient c and the sequence of the monomial part.
- Power: if the exponent is a negative number, Q(1, the sequence consisting of that power alone). Otherwise, W(base, exponent).
The notations used here are defined as follows.
- Atomic: a number that is an integer >= 0, a variable, a function, and a power whose exponent is number 1/2 are called atomic. A(g) is P(g) if g is atomic, and otherwise "(", P(g) and ")" concatenated.
- W(b, x): if x is number 1/2, "sqrt(", P(b) and ")" concatenated. Otherwise, A(b), "^" and A(x) concatenated.
- Factor notation G(g): "(", P(g) and ")" concatenated if g is a sum; W(base of g, exponent of g) if g is a power; P(g) otherwise.
- Q(c, sequence): with the absolute value of c as the reduced fraction p/q (p >= 1, q >= 1), build a numerator list and a denominator list as follows. First, add the decimal notation of p to the numerator list if p != 1, and add the decimal notation of q to the denominator list if q != 1. Then, for each normal form g of the sequence in order: if g is a power whose exponent is a negative number -r (r > 0), add G(base of g) to the denominator list when r = 1, and W(base of g, number r) otherwise; else add G(g) to the numerator list. The numerator string is the elements of the numerator list joined with "*" ("1" if the numerator list is empty). The result is the numerator string if the denominator list is empty; the numerator string, "/" and that element concatenated if it has one element; and the numerator string, "/(", the elements of the denominator list joined with "*", and ")" concatenated if it has two or more elements. However, if c < 0, a "-" is prepended.
For example, the notation looks like this: 2*x^3 + sin(x), x^2*cos(x) + 2*x*sin(x), -x/(x + 1)^2 + 1/(x + 1), 1/(2*sqrt(x)), 3*x/2, -(x + 1), x^(3/2), 1/cos(x)^2, x^x*(ln(x) + 1), (-2)^x, (x^2)^(1/3), sqrt(2/3), 2^(1/x).

6. Differentiation
The derivative D(f, v) of a normal form f with respect to the variable name v is defined for each kind of f as follows (the operations on the right-hand side are computed in the order written).
- Number: number 0.
- Variable: number 1 if the variable name is v, otherwise number 0.
- Sum (terms t1, ..., tk): add(D(t1, v), ..., D(tk, v)).
- Product (factors f1, ..., fk): for i = 1, ..., k, let Pi be mul(f1, ..., f(i-1), D(fi, v), f(i+1), ..., fk) on the sequence with fi replaced by D(fi, v); the result is add(P1, ..., Pk).
- Power (base b, exponent x): the first of the following that applies.
  v is not among the variables of x: mul(x, pow(b, add(x, number -1)), D(b, v))
  v is not among the variables of b: mul(f, fn(ln, b), D(x, v))
  Otherwise: mul(f, add(mul(D(x, v), fn(ln, b)), mul(x, D(b, v), pow(b, number -1))))
- Function (function name g, argument a): mul(H, D(a, v)) for the following H. If g is sin, H = fn(cos, a); if cos, H = mul(number -1, fn(sin, a)); if tan, H = pow(fn(cos, a), number -2); if exp, H = f; if ln, H = pow(a, number -1).

7. Substitution, expansion and numerical evaluation
- Substitution R(f, sigma): sigma associates a normal form with each of some variable names. R(f, sigma) is defined as follows. A number stays as it is; a variable becomes the associated normal form if sigma has an association for it, and otherwise stays as it is. A sum becomes the add of R of each term, a product the mul of R of each factor, a power pow(R(base, sigma), R(exponent, sigma)), and a function fn(function name, R(argument, sigma)).
- Expansion X(f): numbers and variables stay as they are. A function becomes fn(function name, X(argument)). A sum becomes the add of X of each term. For a product (factors f1, ..., fk), let r = X(f1) and, for i = 2, ..., k in order, replace r by M(r, X(fi)); the result is the final r. For a power (base b, exponent x), let b' = X(b) and x' = X(x); if b' is a sum and x' is a positive integer n, let r = b' and repeat replacing r by M(r, b') n - 1 times; the result is r. Otherwise, the result is pow(b', x').
  Here M(g, h) is the add of all of the mul(a, b), listed for all pairs of an element a of the term list of g (the sequence of terms of g if g is a sum, otherwise the sequence consisting of g alone) and an element b of the term list of h, in the order of a, and for the same a in the order of b.
- Numerical value V(f): the value of a normal form f that contains no variables is computed as a double-precision floating-point number (IEEE 754 64-bit format) as follows.
  Number p/q: p divided by q.
  Sum: starting from 0, add the V of the terms in order from the first. Product: starting from 1, multiply by the V of the factors in order from the first.
  Power (base b, exponent x): compute u = V(b) and z = V(x) in this order. When the exponent is not an integer (if x is a number, its value is not an integer; if x is not a number, z is not an integer) and u < 0, error: domain error. Otherwise, the square root of u if x is number 1/2, and u to the power z otherwise.
  Function: with a as the V of the argument, sin, cos, tan and exp give the sine, cosine and tangent of a, and e^a. For ln, error: domain error if a <= 0, otherwise the natural logarithm of a.
  If any V produces an error, output that error at that point and finish processing the command.

8. Command checking and processing
For each command, check the following (1) to (4) in order, and output the first error that applies. A command that outputs an error changes nothing in the state (the name definitions) and outputs only the single error line.
(1) The command name is none of the 13 commands (uppercase and lowercase letters are distinguished): error: unknown command <command name>
(2) LET is as described below. For commands other than LET, split the argument part at ";", remove all leading and trailing spaces from each part, and call the results field 1, field 2, ... from the front (if there is no argument part, there are 0 fields; if the argument part contains m ";" characters, there are m + 1 fields). If the number of fields is not 1 for SIMPLIFY, EXPAND, GRAD and HESSIAN, 2 for DIFF, 3 for DIFFN, IMPLICIT, SUBST, TANGENT and LIMIT, 4 for TAYLOR, or 1 or 2 for EVAL: error: wrong number of arguments
(3) Check the fields of the format from the front, according to the kind of field, as follows.
  e, e2: parse as in section 1 and compute the value (a normal form). Below, the value of e is written f.
  v, w: if it is not a variable name, error: invalid variable '<field>'
  n: if it is none of "1" "2" "3" "4" "5" "6" "7" "8", error: invalid order '<field>'. Otherwise, its value is the order.
  c: if it is not a rational literal, error: invalid number '<field>'; if it is a rational literal whose denominator is 0, error: division by zero. Otherwise, its value is x0.
  A rational literal is a string consisting of zero or one "-" and one or more digits concatenated in this order, followed either by nothing or by "/" and one or more digits (examples: 3, -12, 1/2, -6/4, 0/5). Its value is p/q, where p is the decimal integer formed by the "-" and the first digit sequence, and q is the decimal integer formed by the digit sequence after the "/" (q = 1 if there is no "/").
  Field 2 of EVAL is checked as described for EVAL.
(4) Process as described for each command. If an operation in the description produces an error, output that error and finish processing.

- LET name = e: if the argument part (the empty string if there is no argument part) contains no "=", output error: wrong number of arguments. Otherwise, the parts before and after the first "=" in the argument part, each with all leading and trailing spaces removed, are the name and the e string. If name is not a name, output error: invalid name '<name>'. Next, parse e to obtain its value f, define name as f (if it is already defined, replace the definition), and output <name> = <P(f)>. Name tokens in e take the values of the definitions as they were before this command is processed.
- SIMPLIFY e: output simplified: <P(f)>.
- EXPAND e: output expanded: <P(X(f))>.
- DIFF e ; v: output d/d<v> = <P(D(f, v))>.
- DIFFN e ; v ; n: with the order as n, let f0 = f and fk = D(f(k-1), v) for k = 1, 2, ..., n, and output d^<k>/d<v>^<k> = <P(fk)> one per line for k = 1, 2, ..., n in order (n lines).
- GRAD e: let v1, ..., vm be the variables of f sorted in ASCII lexicographic order, and output d/d<vi> = <P(D(f, vi))> one per line for i = 1, ..., m in order. If m = 0, output no variables.
- HESSIAN e: for the same v1, ..., vm as in GRAD, arrange all pairs with 1 <= i <= j <= m in increasing order of i, and for equal i in increasing order of j, and for each output d2/d<vi>d<vj> = <P(D(D(f, vi), vj))> one per line. If m = 0, output no variables.
- IMPLICIT e ; v ; w: if v and w are equal, output error: same variable. Otherwise, as the derivative of w regarded as a function of v determined by the equation f = 0, output d<w>/d<v> = <P(mul(number -1, D(f, v), pow(D(f, w), number -1)))>.
- SUBST e ; v ; e2: let g be the value of e2 and let sigma associate g with v; output substituted: <P(R(f, sigma))>.
- EVAL e and EVAL e ; a...: if field 2 exists, examine the words (non-empty strings) obtained by splitting field 2 at spaces, from the front. For each word, output error: invalid assignment '<word>' if it does not have the form of a variable name, "=" and a rational literal concatenated in this order; error: division by zero if the denominator of the rational literal is 0; and error: duplicate variable <variable name> if that variable name also appears in an earlier word (for each word, check these three in this order). If there is no field 2, or field 2 contains no words, there are zero assignments.
  Next, examine the variables of f in ASCII lexicographic order; if there is a variable name that is not given a value by the assignments, output error: no value for <variable name> for the first such variable name (assignments to variable names that are not in f are ignored).
  If there is no error, let sigma associate each variable name of the assignments with the number of its value, and compute r = R(f, sigma). If r is a number, output exact: <P(r)>. Otherwise, let d be the decimal notation of V(r) rounded half up to 6 digits after the decimal point (at least one digit in the integer part, with a leading "-" if negative), and output approx: <d>.
- TANGENT e ; v ; c: let sigma associate number x0 with v, and compute m = R(D(f, v), sigma) and y0 = R(f, sigma) in this order. On the first line, output tangent: y = <P(add(mul(m, variable v), y0, mul(number -x0, m)))>. On the second line, if m is number 0, output normal: <v> = <P(number x0)>; otherwise, let k = pow(m, number -1) and output normal: y = <P(add(mul(number -1, k, variable v), y0, mul(number x0, k)))>.
- LIMIT e ; v ; c: consider the sequence of factors of f if f is a product, otherwise the sequence consisting of f alone. Among its elements, for those that are powers whose exponent is a negative number -r (r > 0), list pow(base, number r) in order; this is the denominator list.
