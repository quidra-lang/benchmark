[Overview]
Write a program that referees a game of Go and computes the score after the game ends. The program reads a sequence of commands from standard input, executes the commands in order, and writes the results to standard output. The commands cover setting up the board (board size, komi, handicap stones), checking moves and passes (capturing stones, suicide, ko, superko), undoing moves, displaying the board and territory, inspecting groups and liberties, judging atari, eyes, unconditional life and ladders, marking dead stones, scoring by the area method (counting stones and territory) and by the territory method (counting territory and prisoners), and printing and replaying game records.

[Input format]
The first line is the number of commands N. Each of the following N lines contains one command. The input consists of exactly these N + 1 lines.
Each line consists of one or more words separated by single spaces, with no whitespace at the start or end of the line. The first word is the command name and the remaining words are the arguments. There are the following 24 command formats (every part other than the command name is the name of an argument).
BOARD n komi
KOMI komi
SUPERKO mode
HANDICAP k
PLAY color point
PASS color
REPLAY sequence
UNDO
SHOW
MAP
STATUS
CAPTURES
HISTORY
MOVES
GROUP point
GROUPS
ATARI
LEGAL color
EYES color
SAFE color
LADDER point
DEAD point

SCORE method
An argument is of a correct form in the following cases.
- n: one of "9", "13", "19". Its value is the board size.
- komi: an optional "-", an integer part, and an optional fractional part, in this order. The integer part is a sequence of one or more digits (0-9); when it has two or more characters, it does not start with "0", and its value is at most 100. The fractional part is ".0" or ".5". The value is the value of the integer part, plus 0.5 if the fractional part is ".5", made negative if "-" is present. When "-" is present, the value must not be 0. For example, "6.5", "7", "0", "7.0", "-3.5", "0.5" and "100.5" are of a correct form, and "06.5", "6.25", "6.", ".5", "+5", "-0", "-0.0" and "101" are not.
- mode: "ON" or "OFF".
- k: a single character from "2" to "9".
- color: "B" (black) or "W" (white).
- method: "AREA" or "TERRITORY".
- point: a point name (its correct form is defined in section 1 of [Processing]).
- sequence: a move sequence (its correct form is defined in section 12 of [Processing]).

[Processing]
Process the commands one at a time in input order, writing the output of each immediately. Below, a string in double quotes is a string that appears verbatim in the input or output. In the output descriptions, a part such as <v> is replaced by its value. In the output, a color is written as "B" for black and "W" for white, and a point is written as its point name (section 1).

1. Board and points
- The board consists of the intersections of n vertical lines and n horizontal lines, where n is 9, 13 or 19. An intersection is called a point.
- The columns, from left to right, are assigned one character each, in order from the start of the string "ABCDEFGHJKLMNOPQRST" (the uppercase letters without "I"). When the board size is n, the first n characters are used. The c-th column from the left is called the column with column number c.
- The rows are given row numbers 1, 2, ..., n from bottom to top.
- The name of a point is its column character followed by its row number in decimal (e.g. "D4", "Q16"). A point name in the input is of a correct form when its first character is one of the n characters used for the current board size, and the rest is the decimal notation, without leading "0", of a number from 1 to n inclusive. For example, on a 9x9 board "J9" is of a correct form, and "I5", "K1", "d4", "D0", "D04", "D10" and "D" are not.
- The index of the point with column number c and row number r is n * (r - 1) + (c - 1). "Point order" means increasing order of this index, that is, rows from the bottom up and, within the same row, from left to right.
- The neighbors of a point p are those of the points above, below, left of and right of p that are on the board (2 for a corner point, 3 for an edge point that is not a corner, and 4 for any other point). The diagonal points of p are those of the points to the upper left, upper right, lower left and lower right of p that are on the board.
- Each point is either empty, has a black stone, or has a white stone. When one of black and white is called color c, the other is called the opponent color of c.
- For each board size, nine points P1 to P9 are defined as follows.
  9x9 board: P1 = C3, P2 = G7, P3 = C7, P4 = G3, P5 = C5, P6 = G5, P7 = E3, P8 = E7, P9 = E5
  13x13 board: P1 = D4, P2 = K10, P3 = D10, P4 = K4, P5 = D7, P6 = K7, P7 = G4, P8 = G10, P9 = G7
  19x19 board: P1 = D4, P2 = Q16, P3 = D16, P4 = Q4, P5 = D10, P6 = Q10, P7 = K4, P8 = K16, P9 = K10
  On a 19x19 board the nine points P1 to P9, and on 9x9 and 13x13 boards the five points P1 to P4 and P9, are called star points.

2. State
The program has the following state.
- The board size n and the komi
- The board (the state of each point)
- The player to move (black or white)
- Prisoners: the number of stones captured by black and the number of stones captured by white
- The number of consecutive passes
- Whether the game is over
- The list of handicap points (empty if there are no handicap stones)
- The history: the list of moves played (placements and passes) from oldest to newest. For UNDO, each move also records the board, the player to move, the prisoners, the number of consecutive passes, and whether the game was over, as they were immediately before that move was played.
- The position list: a list of board states, used for the ko and superko checks.
- The superko setting (on or off)
- The dead-stone marks: the set of points of stones that are marked
At program start, the superko setting is off and the rest of the state is the same as right after executing "BOARD 19 6.5".

3. Groups and liberties
- A group is a cluster of stones of the same color connected through neighboring points. The group containing a point p that has a stone is the set of all points (including p) that can be reached from p by repeatedly moving to a neighboring point that has a stone of the same color. The color of a group is the color of its stones.
- The size of a group is the number of its stones.
- A liberty of a group is an empty point that is a neighbor of some stone of the group. The number of liberties is the number of such empty points (each empty point is counted once).
- The representative point of a group is the first of the group's stone points in point order.
- When groups are listed (including when only some of the groups are listed), they are listed in point order of their representative points. When points are listed in the output, they are also listed in point order unless stated otherwise.

4. Placement rules
The operation of putting a stone of color c on an empty point p is called a placement, and consists of the following (1) to (3).
  (1) Put a stone of c on p on the board.
  (2) Remove from the board every group that contains a stone of the opponent color on a neighbor of p and has 0 liberties. The number of stones removed is the number of stones captured by this placement.
  (3) If the group containing p now has 0 liberties, this placement is a suicide.
When stones are captured in (2), the group of p gains a liberty, so a placement that captures stones is not a suicide.
In the game, c placing at p is forbidden for the first of the following reasons that applies, if any. A forbidden move cannot be played, and the state does not change.
  "occupied": p is not empty.
  "suicide": the placement is a suicide.
  "ko": the position list has two or more elements, and the board after the placement is the same as the second-to-last board of the position list. (This is a move that restores the board from before the opponent's immediately preceding move, i.e. immediately retaking a ko.)
  "superko": the superko setting is on, and the board after the placement is the same as some board of the position list.
Here, two boards are the same when every point has the same state. The player to move and the prisoners are not compared.

5. Playing a move
When color c plays a game move, do the following.
- If the move is c placing at point p, the board after performing (1) to (3) of section 4 becomes the new board, add the number of stones captured by this placement to the number of stones captured by c, and set the number of consecutive passes to 0.
- If the move is a pass by c, leave the board unchanged and add 1 to the number of consecutive passes. When it becomes 2, the game is over.
- In both cases, append the move (together with the state immediately before it was played) to the end of the history, make the opponent color of c the player to move, append the board at that time to the end of the position list, and clear all dead-stone marks.

6. Board frame
SHOW and MAP assign one character to each point and print the board in the following form of n + 2 lines.
- The first line and the last line: 3 spaces, followed by the column characters from left to right, separated by single spaces.
- Lines 2 to n + 1: one line per row, from the top row down (row numbers n, n - 1, ..., 1), consisting of the row number right-aligned in width 2 (preceded by one space when it has one digit), one space, the characters of the points of that row from the left column to the right, separated by single spaces, one space, and the row number (as is).

7. Regions
- The empty points of the board, divided into clusters connected through neighboring points, are called regions. The region containing an empty point p is the set of all empty points that can be reached from p by repeatedly moving to a neighboring empty point.
- If the stones that are neighbors of some point of a region are only black, the region is a black region; if only white, a white region; if both black and white, a neutral region. A region with no neighboring stones at all is also a neutral region.
- The representative point of a region is the first of the region's points in point order.
- The board without dead stones is the current board with every stone that has a dead-stone mark removed (made empty). MAP, REGIONS and SCORE compute regions on the board without dead stones.

8. Writing numbers
The komi, and the totals and the difference in SCORE, are integer multiples of 0.5. They are written as the integer part of the absolute value, ".", and the first decimal digit ("0" or "5"), in this order, preceded by "-" when negative (e.g. 6.5, 7.0, 0.0, -2.5). All other numbers are written as decimal integers without extra leading zeros.

9. Eyes
For a color c, an empty point p of the current board (dead-stone marks are not used) all of whose neighbors are stones of c is called an eye-shaped point of c. For an eye-shaped point p, let k be the number of diagonal points of p that have a stone of the opponent color of c. If p has 4 neighbors and k is at most 1, or p has 3 or fewer neighbors (edge and corner points) and k is 0, then p is a real eye; otherwise it is a false eye.

10. Unconditionally alive groups
For a color c, the unconditionally alive groups are found as follows (dead-stone marks are not used).
- A c-area is a cluster formed by connecting the points that have no stone of c (empty points and points with a stone of the opponent color) through neighboring points. The c-area containing a point q is the set of all points that can be reached from q by repeatedly moving to a neighboring point that has no stone of c.
- When every empty point of a c-area R is a liberty of a group X of c, R is called a vital area for X (an area with no empty point is a vital area for every group).
- When some point of a c-area R has a neighbor with a stone of a group X of c, R is said to touch X.
- First, let the set of groups S be all groups of c on the board, and let the set of areas T be all c-areas. Then repeat performing the following (1) and (2) in this order until nothing is removed in either (1) or (2).
  (1) Remove from S every group of S for which T does not contain two or more areas that are vital areas for that group.
  (2) Remove from T every area of T that touches a group of c not contained in S.
- The groups remaining in S at the end are the unconditionally alive groups.

11. Ladders
For a point p that has a stone, let G be the group containing p, d (the defender) the color of G, and a (the attacker) its opponent color. Ladder reading examines positions created on a copy of the current board. The state does not change.
- A move by color x at an empty point q during reading is a placement of section 4 (1) to (3), in which only suicide is forbidden (the player to move, ko and superko are not considered). This is called a reading placement. A move cannot be made on a point that is not empty.
- The stones of G are never captured during reading. Below, G always means the group containing p in the position concerned.
- The number of moves played during reading is called the depth. The current board has depth 0.
For a position Q with the defender to move in which G has 1 liberty, and its depth e, whether the defender can escape, and the escaping move, are determined as follows.
  (1) If e is 40 or more, the defender can escape.
  (2) The candidate points are the liberties of G and the liberties of the groups of a that have 1 liberty and have a stone on a neighbor of some stone of G (the same point is counted only once).
  (3) Examine the candidate points in point order. When d can make a reading placement at a candidate point q, let Q' be the position after the placement and m the number of liberties of G in Q'. If m is 3 or more, or if m is 2 and the attacker cannot capture when Q' is examined as a position with the attacker to move at depth e + 1, then the defender can escape, and q is the escaping move (the first such q found).
  (4) If the defender cannot escape with any candidate, the defender cannot escape.
For a position Q with the attacker to move in which G has 2 liberties, and its depth e, whether the attacker can capture, and the capturing move, are determined as follows.
  (1) If e is 40 or more, the attacker cannot capture.
  (2) Examine the liberties of G in point order. When a can make a reading placement at a liberty q, examine the position after the placement (in which G has 1 liberty) as a position with the defender to move at depth e + 1; if the defender cannot escape, the attacker can capture, and q is the capturing move (the first such q found).
  (3) If the attacker cannot capture with any liberty, the attacker cannot capture.

12. Record coordinates and move sequences
- The SGF coordinate of a point represents the point with two lowercase letters. The first letter represents the column: the column with column number c is represented by the c-th lowercase letter ("i" is also used). The second letter represents the row: the row with row number r is represented by the (n + 1 - r)-th lowercase letter (the top row is "a"). For example, on a 19x19 board D4 is "dp" and Q16 is "pd", and on a 9x9 board D4 is "df" and J9 is "ia".
- A move record is the string consisting of ";", a color ("B" or "W"), "[", the content, and "]", in this order. The content is either empty (representing a pass) or the SGF coordinate of a point of the current board (two characters, each one of the first n lowercase letters).
- A move sequence (sequence) is of a correct form when it is a string of one or more move records concatenated without separators. For example, on a 9x9 board ";B[ee];W[]" is of a correct form, and ";B[ee]" followed by extra characters, ";b[ee]", ";B[jj]", ";B[e]" and ";B(ee)" are not.

13. Commands
The behavior and output of each command are as follows. Checks such as argument validity are performed in the order of section 14.

BOARD n komi
Set the board size to n and the komi to the value of komi. Empty the board, set the player to move to black, the prisoners to 0 for both black and white, the number of consecutive passes to 0, and the game to not over, make the list of handicap points, the history and the dead-stone marks empty, and make the position list a list consisting of a single empty board. The superko setting is not changed. Output "board <n> komi <komi>".

KOMI komi
Set the komi to the value of komi and output "komi <komi>". The rest of the state is not changed.

SUPERKO mode
If mode is "ON", set the superko setting to on and output "superko on"; if "OFF", set it to off and output "superko off". The rest of the state is not changed.

HANDICAP k
If the history is not empty or there is at least one stone on the board, output "ERROR handicap not allowed". Otherwise, put black stones on the following points. For k = 2, P1, P2. For k = 3, P1 to P3. For k = 4, P1 to P4. For k = 5, P1 to P4, P9. For k = 6, P1 to P6. For k = 7, P1 to P6, P9. For k = 8, P1 to P8. For k = 9, P1 to P9. Set the list of handicap points to the list of these points in the order written here. Further, set the player to move to white, make the position list a list consisting of a single board, the board after placing the handicap stones, and clear the dead-stone marks. Output one line consisting of "handicap <k>" followed by the name of each point of the list of handicap points in the form " <point>".

PLAY color point
Let c be the color of color and p the point of point. If c is not the player to move, the reason is "turn"; otherwise, check the reasons of section 4. If there is a reason, output "ILLEGAL <c> <p> <reason>". If there is no reason, play the move of c placing at p as in section 5, and output "<c> <p>". However, if the number m of stones captured by this placement is 1 or more, append " captures <m>" to it.

PASS color
Let c be the color of color. If c is not the player to move, output "ILLEGAL <c> pass turn". Otherwise, play a pass by c as in section 5 and output "<c> pass"; if the game is now over, then also output "game over".

REPLAY sequence
Process the move records of sequence one at a time from the first, as game moves. Let c be the color of the move record; if the content is empty, the move is a pass by c, otherwise it is c placing at the point of that coordinate. For each move, if the game is over the reason is "game over"; otherwise, check the reason in the same way as PLAY or PASS ("turn" if c is not the player to move, and for a placement the reasons of section 4). If there is a reason, stop processing there (the moves played up to that point remain). If there is no reason, play the move as in section 5 (no output per move). Let k be the number of moves played; if all records were processed, output "replay <k> moves", and if processing stopped partway, output "replay <k> moves stopped <c> <point> <reason>". <point> is the point name of the move at which processing stopped ("pass" for a pass). Further, if the game is over at that time, then also output "game over".

UNDO
If the history is empty, output "ERROR nothing to undo". Otherwise, remove the last move from the history, restore the board, the player to move, the prisoners, the number of consecutive passes, and whether the game is over to their state immediately before that move was played, remove the last board from the position list, and clear the dead-stone marks. Let c be the color of the removed move; output "undo <c> <point>" for a placement, or "undo <c> pass" for a pass.

SHOW
Print the board in the frame of section 6. The character of each point is "X" for a black stone and "O" for a white stone, but "x" and "o" respectively for a stone with a dead-stone mark. An empty point is "+" if it is a star point, and "." otherwise.

MAP
Print the board without dead stones (section 7) in the frame of section 6. The character of each point is "X" for a black stone and "O" for a white stone. An empty point is "x" if the region containing it is a black region, "o" if it is a white region, and "." if it is a neutral region.

STATUS
Output the following 2 lines.
- "size <n> komi <komi> handicap <number of handicap stones> superko <setting>". The number of handicap stones is the length of the list of handicap points, and <setting> is "on" if on and "off" if off.
- If the game is over, "moves <number of moves in the history> game over"; if the game is not over, "moves <number of moves in the history> next <player to move> passes <number of consecutive passes>". <player to move> is "B" or "W".

CAPTURES
Output "captures B <number of stones captured by black> W <number of stones captured by white>".

HISTORY
Output "history <number of moves in the history>", then output each move of the history from oldest to newest, one line each, with i = 1, 2, ..., in the form "<i> <color> <point>" for a placement or "<i> <color> pass" for a pass. If the number m of stones captured by a placement is 1 or more, append " captures <m>" to the end of that line.

MOVES
Output the game record on one line. The line starts with "(;GM[1]FF[4]SZ[<n>]KM[<komi>]". If the list of handicap points is not empty, next write "HA[<number of handicap stones>]AB", and then, for each point of the list of handicap points in its order, write "[<SGF coordinate>]" without separators. Next, write each move of the history from oldest to newest, without separators, in the form ";<color>[<SGF coordinate>]" for a placement or ";<color>[]" for a pass, and finally write ")".

GROUP point
If the point of point is empty, output "ERROR no stone". Otherwise, for the group containing that point, output the following 3 lines.
- "group <color> <representative point> size <size> liberties <number of liberties>"
- "stones" followed by each stone point of the group in the form " <point>"
- "liberties" followed by each liberty of the group in the form " <point>"

GROUPS
Let k be the number of groups on the board; output "groups <k>", then for each group output one line "<color> <representative point> size <size> liberties <number of liberties>". For a group with dead-stone marks, append " dead" to the end of its line. (Either all stones of a group have dead-stone marks or none do.)

ATARI
For each group with exactly 1 liberty, output one line "atari <color> <representative point> size <size> at <liberty>". If there is no such group, output "atari none".

LEGAL color
Let c be the color of color. Without considering the player to move or whether the game is over, check for each empty point of the current board whether c placing there is forbidden for one of the reasons "suicide", "ko" or "superko" of section 4 (the first that applies). Let m be the number of empty points that are not forbidden; output "legal <c> <m>", then for each forbidden empty point output one line "<point> <reason>". The state does not change.

EYES color
Let c be the color of color. Let m be the number of eye-shaped points of c on the board; output "eyes <c> <m>", then for each eye-shaped point output one line, "<point> real" if it is a real eye by the judgment of section 9, or "<point> false" if it is a false eye.

SAFE color
Let c be the color of color. Let m be the number of unconditionally alive groups of c found in section 10; output "safe <c> <m>", then for each of those groups output one line "<representative point> size <size>".

LADDER point
If the point of point is empty, output "ERROR no stone". Otherwise, perform the reading of section 11 with p being the point of point, and output the following one line. <p> is the point name of point.
- If G has 3 or more liberties, "ladder <p> safe".
- If G has 1 liberty, examine the current board as a position with the defender to move at depth 0; if the defender can escape, "ladder <p> escapes <point of the escaping move>", and if not, "ladder <p> captured".
- If G has 2 liberties, examine the current board as a position with the attacker to move at depth 0; if the attacker can capture, "ladder <p> captured <point of the capturing move>", and if not, "ladder <p> escapes".

DEAD point
If the point of point is empty, output "ERROR no stone". Otherwise, let X be the group containing that point. If the stones of X have no dead-stone mark, mark all stones of X and output "dead <color> <representative point> size <size>". If they have marks, clear the marks of all stones of X and output "alive <color> <representative point> size <size>".

REGIONS
Let k be the number of regions of the board without dead stones; output "regions <k>", then output each region, in point order of the representative points, one line each in the form "<representative point> size <number of points> <owner>". <owner> is "B" for a black region, "W" for a white region, and "neutral" for a neutral region.

SCORE method
Count on the board without dead stones. The total number of points of the black regions is black's territory, and the total number of points of the white regions is white's territory.
- When method is "AREA": for each color, let s be the number of stones of that color on the board without dead stones and t the territory of that color; black's total is s + t, and white's total is s + t + komi. Output the 2 lines "B stones <s> territory <t> total <black's total>" and "W stones <s> territory <t> komi <komi> total <white's total>".
- When method is "TERRITORY": for each color, let t be the territory of that color and h the sum of the number of stones captured by that color and the number of stones of the opponent color that have a dead-stone mark; black's total is t + h, and white's total is t + h + komi. Output the 2 lines "B territory <t> prisoners <h> total <black's total>" and "W territory <t> prisoners <h> komi <komi> total <white's total>".
In both cases, then output the result line. With d = (black's total) - (white's total), it is "result B+<d>" if d > 0, "result W+<value of -d>" if d < 0, and "result Draw" if d = 0. The totals and the difference are written in the form of section 8. The computation is the same even if the game is not over. The state does not change.

14. Errors
Each command is checked in the following order; output one line for the first that applies, and proceed to the next command without changing the state.
  (1) If the command name is none of the 24 kinds in [Input format], "ERROR unknown command". Uppercase and lowercase are distinguished.
  (2) If the number of arguments differs from the format, or some argument other than point and sequence is not of a correct form, "ERROR bad arguments".
  (3) If point is not a point name of a correct form, "ERROR bad point". If sequence is not a move sequence of a correct form, "ERROR bad sequence".
  (4) For PLAY, PASS and REPLAY, if the game is over, "ERROR game over".
  (5) The "ERROR" or "ILLEGAL" lines given in the description of each command in section 13.
The validity of point is judged with the board size at the time the command is executed. A command whose description in section 13 does not say that it changes the state does not change the state.

[Output format]
For each command, output the lines defined in [Processing] in that order. The output consists of ASCII characters only; no line has trailing whitespace, and every line ends with a newline. No blank lines are output.

[Constraints]
- 1 <= N <= 500
- Each line has from 1 to 200 characters inclusive and consists only of printable ASCII characters and spaces.
- The number of reading placements made in one LADDER reading is at most 10000.
