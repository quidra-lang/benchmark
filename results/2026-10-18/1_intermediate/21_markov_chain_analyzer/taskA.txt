[Overview]
Write a program that analyzes finite-state discrete-time Markov chains with rational transition probabilities using exact fraction arithmetic. The program reads a sequence of commands from standard input and performs the following, writing the results to standard output: creating and editing multiple named chains, estimating a chain from a token sequence, decomposing a chain into communicating classes and determining recurrent/transient states and periods, testing whether a chain is absorbing, ergodic or regular, the distribution after k steps and powers of the transition matrix, stationary distributions, the fundamental matrix and absorption probabilities of absorbing chains, hitting probabilities and expected hitting times, mean first passage times, the distribution of first passage times, path probabilities and the most likely path, testing reversibility and time reversal, the mixing time by total variation distance, strong lumping, evaluating rewards, restricting a chain to a closed subset, simulation with pseudo-random numbers, and generating gambler's ruin chains.

[Input format]
The first line contains the number of commands N. Each of the following N lines contains one command. A command consists of the command name and zero or more arguments, separated by single spaces; there are no leading or trailing spaces on a line and there are no blank lines. There are 26 command formats:

  CHAIN c s1 s2 ... sn
  P c x y v
  ROW c x v1 v2 ... vn
  SHOW c
  CHECK c
  BUILD c k t1 t2 ... tm
  GAMBLER c g a v
  CLASSES c
  CLASSIFY c
  STEP c d k
  POWER c k
  STATIONARY c
  RECURRENCE c x
  ABSORB c
  HITTING c x1 x2 ... xm
  PASSAGE c
  FIRSTPASSAGE c x y k
  PATHPROB c x1 x2 ... xm
  MOSTLIKELY c x k
  REVERSIBLE c
  REVERSE c c2
  MIXING c k v
  LUMP c c2 B
  REWARD c v r1 r2 ... rn
  RESTRICT c c2 x1 x2 ... xm
  SIMULATE c x k seed

The arguments mean the following.
- c and c2 are chain names, and s1 to sn and t1 to tm are state names and tokens, respectively; all of them have the form of a "name". A name is a string consisting of one letter (A to Z or a to z) followed by zero or more letters or digits (0 to 9). Uppercase and lowercase letters are distinguished.
- x, y and x1 to xm are "state specifiers": either one name, or two names joined by "." (period) (example: the.cat). States whose names have the latter form appear only in chains built by BUILD with order 2 and in chains created from such chains by REVERSE, LUMP or RESTRICT.
- v and v1 to vn are "probability values": either a single integer p >= 0 alone, or two integers p >= 0 and q >= 0 joined by "/" in the form p/q (examples: 1, 0, 3/4, 2/8). The form with p alone means the same as p/1.
- d is one state specifier if it starts with a letter, or one or more probability values separated by "," (comma) if it starts with a digit (example: 1/2,1/4,1/4).
- B is one or more groups separated by "|", where each group (called a "block") is one or more state specifiers separated by "," (example: a,b|c|d,e).
- k, g, a, seed and r1 to rn are integers >= 0. All integers are written in decimal without extra leading zeros.
- The n and m in s1 ... sn, v1 ... vn, t1 ... tm, x1 ... xm and r1 ... rn are symbols for the number of values on that line; they are not written in the input. The number of values v1 ... vn of ROW, the number of values r1 ... rn of REWARD, and the number of values in d of STEP may differ from the number of states of the chain (how this is handled is defined in [Processing]).
It is guaranteed that every line follows this format and the ranges in [Constraints].

[Processing]
Process the commands in order starting from the first line, and output the result of each command according to [Output format]. Error checks are performed in the order written in "Common error checks" and in the description of each command; output only the line of the first error that applies, and do nothing else for that command (do not create or change any chain).

== Chains ==
- The program holds any number of named chains. Initially there are no chains. A command that creates a chain (CHAIN, BUILD, GAMBLER, REVERSE, LUMP, RESTRICT) replaces the existing chain with the same name as the chain it creates, if there is one, with the new chain.
- A chain consists of a sequence of states and transition probabilities. Each state has a name, and the names within one chain are all distinct. The states are numbered from 1 in the order of the sequence, and increasing order of these numbers is called "state order". Let n be the number of states, and write P(i,j) for the probability of moving from state i to state j in one step. For state i, the sequence P(i,1), P(i,2), ..., P(i,n) is called the "row" of i, and its sum is called the "row sum" of i.
- All computation is done exactly with fractions. A fraction is always kept as an irreducible fraction (with a positive denominator); floating-point numbers are not used.
- Unless stated otherwise, a sum is accumulated in increasing order of index (for a sum over states, in state order). sum_{j in S} f(j) denotes the sum of f(j) over the states j of the set S, added in state order. delta(i,j) is 1 if i=j and 0 otherwise.

== Number notation ==
- "Fraction notation" writes an irreducible fraction p/q as "<p>/<q>". Integer values are also written with denominator 1, and 0 is written as "0/1" (examples: 1/4, 3/1, 0/1).
- "Value notation" is fraction notation immediately followed by the decimal value truncated to 6 decimal places (the 7th decimal place and beyond are discarded), enclosed in "(" and ")". The decimal has the form "<integer part>.<6 fractional digits>" (examples: 2/3 is 2/3(0.666666), 5/2 is 5/2(2.500000), 1 is 1/1(1.000000), 0 is 0/1(0.000000), 50/13 is 50/13(3.846153)).
- Every fraction value that is output is 0 or greater.

== Common error checks ==
- Every command other than CHAIN, BUILD and GAMBLER first checks whether a chain named c exists, and if not, outputs "ERROR UNKNOWN CHAIN <c>".
- Every command other than CHAIN, P, ROW, SHOW, CHECK, BUILD and GAMBLER (these are called "analysis commands") next checks whether the chain c is "stochastic", that is, whether the row sum of every state equals 1. If not, it outputs "ERROR NOT STOCHASTIC <x>" for x, the first state in state order whose row sum is not 1.
- In the command descriptions, "check state specifier x" means: if x matches the name of no state of the chain, output "ERROR UNKNOWN STATE <x>" (<x> is the string exactly as specified).
- "Validate probability value p/q" means: output "ERROR BAD PROBABILITY" if q=0 or p>q (the value is greater than 1).
- "Check that there is one communicating class" means: output "ERROR NOT IRREDUCIBLE" if there are two or more communicating classes (defined below).

== Graph terminology ==
- If P(i,j)>0, there is an "edge" from i to j. If j can be reached from i by following zero or more edges, j is "reachable" from i (i is always reachable from i).
- If j is reachable from i and i is also reachable from j, then i and j belong to the same "communicating class". Every state belongs to exactly one communicating class. The states within a communicating class are listed in state order, and the communicating classes are ordered by the state order of their first states and numbered from 1 in that order.
- A communicating class C is "closed" if there is no edge from any state of C to a state outside C. The states of closed communicating classes are called "recurrent", and all other states are called "transient".
- The "period" d of a communicating class C is computed as follows. The "level" of the first state r of C is 0, and the level of any other state v of C is the minimum number of edges on a path from r to v that passes only through states of C (it can be found by breadth-first search from r). For every edge u->v with both u and v in C (including edges with u=v), compute "level of u + 1 - level of v", and let d be the greatest common divisor of these values. If there is no such edge, d=0.
- A state i with P(i,i)=1 is called "absorbing".

== Elimination procedure ==
Systems of linear equations are solved by the following "elimination procedure". For a matrix A with m rows and m+w columns (w>=1) (the left m columns are the coefficients and the right w columns are the right-hand sides), perform steps (1) to (3) below for column numbers j=1, 2, ..., m in this order.
(1) Let r be the first row, among row j and the rows after it (row j included), whose value in column j is not 0; if r!=j, swap row r and row j.
(2) Divide each element of row j by the value at row j, column j at that moment.
(3) For each row r other than row j, from top to bottom: if the value f at row r, column j is not 0, replace each element a of row r by "a - f * (the element of row j in the same column)".
When finished, the left m columns of A form the identity matrix, and the right w columns are the solution. The equations solved by this program always have exactly one solution, and step (1) never fails to find a row. Below, "solve the equations" means: order both the unknowns and the equations in state order, and use this procedure.

== Stationary distribution ==
Let c1, c2, ..., cm be the states of a closed communicating class C in state order. For the unknowns x1, ..., xm, solve the equations "sum_k (P(ck,cr) - delta(k,r)) * xk = 0" (k=1, ..., m) for r=1, ..., m-1, together with the m-th equation "x1 + x2 + ... + xm = 1". That is, row r, column k of A (r<=m-1) is P(ck,cr) - delta(k,r), and the right-hand side of row r is 0; row m has all coefficients equal to 1 and right-hand side 1. The distribution in which xk is the probability of state ck is called the "stationary distribution" of C. For a chain with only one communicating class, the stationary distribution of that class (which consists of all states) is called "the stationary distribution of the chain" and is written pi.

== Hitting probabilities and expected hitting times ==
When a set of states T is the target, compute for each state i the hitting probability h(i) (the probability, starting from i, of being in some state of T at some time, time 0 included) and the expected hitting time E(i) (the mean number of steps, starting from i, until first arriving at some state of T; 0 if i belongs to T) as follows.
- For i that belongs to T: h(i)=1 and E(i)=0.
- For i that does not belong to T and from which no state of T is reachable: h(i)=0.
- Let U be the set of the remaining states (states that do not belong to T and from which some state of T is reachable). For the states i of U, solve the equations "h(i) - sum_{j in U} P(i,j) * h(j) = sum_{j in T} P(i,j)" (row i, column j of A is delta(i,j) - P(i,j), and the right-hand side is sum_{j in T} P(i,j)).
- Let W be the set of states i of U with h(i)=1. For the states i of W, solve the equations "E(i) - sum_{j in W} P(i,j) * E(j) = 1" (row i, column j of A is delta(i,j) - P(i,j), and the right-hand side is 1).
- For a state i with h(i)<1, E(i) is infinite.
When U or W is empty, the corresponding equations are not solved.

== Matrix display ==
The "matrix display" of a sequence of state names q1, ..., qn and an n x n matrix M consists of one line "STATES <q1> <q2> ... <qn>" followed by n lines "ROW <qi> <M(i,1)> <M(i,2)> ... <M(i,n)>" (values in fraction notation) for i=1, ..., n in this order. The matrix display of a chain is the matrix display of the names of the chain's states (in state order) and P.

== Commands that create and edit chains ==

CHAIN c s1 s2 ... sn
Checks: if n>10, "ERROR TOO MANY STATES". Then examine the names starting from s1; if some si has the same name as an earlier s, output "ERROR DUPLICATE STATE <si>" for the first such si.
Processing: create chain c with the states s1, s2, ..., sn (in this order) and all P(i,j) equal to 0, and output "CHAIN <c> states=<n>".

P c x y v
Checks: check state specifiers x and y in this order, then validate probability value v.
Processing: set P(x,y) to v, and output "P <c> <x> <y> <P(x,y) in fraction notation> rowsum=<row sum of x in fraction notation>".

ROW c x v1 v2 ... vn
Checks: check state specifier x. If the number of values v differs from the number of states, "ERROR BAD LENGTH". Validate the probability values in order starting from v1.
Processing: for j=1, ..., n set P(x,j) to vj, and output "ROW <c> <x> rowsum=<row sum of x in fraction notation>".

SHOW c
Processing: output "MATRIX <c> states=<number of states>" and the matrix display of the chain.

CHECK c
Processing: if there is no state whose row sum is not 1, output "CHECK <c> ok". Otherwise, output "CHECK <c> bad=<number of such states>", followed by "BADROW <state> sum=<row sum in fraction notation>" for each such state in state order.

BUILD c k t1 t2 ... tm
Checks: if k is neither 1 nor 2, "ERROR BAD ORDER". If m<=k, "ERROR TOO FEW TOKENS". If there are 11 or more states as determined below, "ERROR TOO MANY STATES".
Processing: estimate a chain of order k from the token sequence t1, ..., tm. If k=1, each ti (i=1, ..., m) is an "observation"; if k=2, each "ti.t(i+1)" (i=1, ..., m-1; the string of the two tokens joined by ".") is an observation. Form the sequence o1, o2, ..., oL (L=m-k+1) of the observations in order. The states are the distinct strings that appear among the observations, in order of first appearance. For each of i=1, ..., L-1, count one transition from oi to o(i+1); let count(a,b) be the number of transitions from state a to state b, and total(a) the total number of transitions from a. If total(a)>0, P(a,b)=count(a,b)/total(a); if total(a)=0, P(a,a)=1; all other entries are 0. Create this chain as c, output "BUILD <c> order=<k> states=<number of states> transitions=<L-1>", and then, for each state a in state order, output "FROM <a> total=<total(a)> <b>:<count(a,b)> <b>:<count(a,b)> ..." if total(a)>0 (listing the states b with count(a,b)>0 in state order), or "FROM <a> total=0 absorbing" if total(a)=0.

GAMBLER c g a v
Checks: if g=0 or g>9, "ERROR BAD SIZE". If a>g, "ERROR BAD START". Validate probability value v; in addition, if v=0 or v=1, also output "ERROR BAD PROBABILITY".
Processing: name the state in which the gambler's capital is i "s<i>" (examples: s0, s3), and build the gambler's ruin chain with the states s0, s1, ..., sg (in this order). P(s0,s0)=P(sg,sg)=1, and for 0<i<g, P(si,s(i+1))=v and P(si,s(i-1))=1-v; all other entries are 0. Create this chain as c, perform the same computation as ABSORB, and obtain for each si the ruin probability ruin(i) (the probability of being absorbed in s0) and the mean duration dur(i) (the mean number of steps until absorption). For 0<i<g, ruin(i) is the value in the s0 column of B of ABSORB and dur(i) is the mean value of STEPS of ABSORB; ruin(0)=1, ruin(g)=0 and dur(0)=dur(g)=0. First output "GAMBLER <c> g=<g> p=<v in fraction notation> start=s<a> ruin=<ruin(a)> duration=<dur(a)>", then, for i=0, 1, ..., g in this order, output "CAPITAL s<i> ruin=<ruin(i)> win=<1-ruin(i)> duration=<dur(i)>". The values of ruin, win and duration are in value notation.

== Analysis commands (each performs the checks written for it after the "Common error checks") ==

CLASSES c
Processing: output "CLASSES <c> count=<number of communicating classes>", then, for each communicating class in number order, output "CLASS <number> <kind> period=<period> size=<number of states> <state> <state> ..." (states in state order). The kind is RECURRENT if the class is closed, and TRANSIENT otherwise. For a communicating class whose period d is 2 or more, output, immediately after its CLASS line, "CYCLIC <r> <state> <state> ..." for r=0, 1, ..., d-1 in this order. The states listed are the states of that class whose level leaves remainder r when divided by d (in state order); there is always at least one such state.

CLASSIFY c
Processing: examine the following three properties and output "CLASSIFY <c> absorbing_states=<number of absorbing states> absorbing=<A> ergodic=<E> regular=<R> exponent=<e>". A, E and R are each yes if the corresponding property holds, and no otherwise.
  Absorbing chain: there is at least one absorbing state, and from every state some absorbing state is reachable.
  Ergodic: there is only one communicating class.
  Regular: for some positive integer t, all elements of the t-th power of P are positive. This is decided not by the values but only by whether each element is 0. Let Z(i,j) be the truth value "P(i,j)>0", let Z1=Z, and let Z(t+1)(i,j) be "there is an l such that Zt(i,l) and Z(l,j) are both true". Examine t=1, 2, ..., (n-1)*(n-1)+1 in this order, and let e be the smallest t for which all elements of Zt are true. If such a t exists, the chain is regular; if not, the chain is not regular and e is "-" (hyphen).

STEP c d k
Checks: if d starts with a digit: if the number of values differs from the number of states, "ERROR BAD LENGTH"; then validate each value as a probability value from left to right; then, if the sum of the values is not 1, "ERROR BAD DISTRIBUTION". If d starts with a letter, check state specifier d.
Processing: the initial distribution mu_0 is mu_0(j) = (the j-th value) if d is a list of values, or, if d is a state specifier, mu_0(d)=1 and 0 for all other states. For t=1, ..., k let mu_t(j) = sum_i mu_(t-1)(i) * P(i,j) (i=1, ..., n). Output "STEP <c> k=<k>", then, for each state j in state order, output "PROB <state j> <mu_k(j) in value notation>" (if k=0, this is mu_0).

POWER c k
Processing: let M0 be the n x n identity matrix, and for t=1, ..., k let Mt(i,j) = sum_l M(t-1)(i,l) * P(l,j) (l=1, ..., n). Output "POWER <c> k=<k>", then the matrix display of the names of the chain's states (in state order) and Mk.

STATIONARY c
Processing: output "STATIONARY <c> count=<number of closed communicating classes>". Then number the closed communicating classes C from 1 in number order; with D being that number, output "DIST <D> class=<communicating class number of C> size=<number of states of C>", then, for each state of C in state order, output "PI <state> <probability of that state in the stationary distribution of C, in value notation>" (states outside C are not output).

RECURRENCE c x
Checks: check state specifier x. If x is transient, "ERROR TRANSIENT STATE <x>".
Processing: let C be the communicating class to which x belongs, and rho the probability of x in the stationary distribution of C. Output "RECURRENCE <c> <x> pi=<rho in value notation> mean=<1/rho in value notation> period=<period of C>". 1/rho is the mean number of steps, starting from x, until first returning to x.

ABSORB c
Checks: if there is no absorbing state, "ERROR NO ABSORBING STATE". If there is a non-absorbing state from which no absorbing state is reachable, output "ERROR NOT ABSORBING <x>" for x, the first such state in state order.
Processing: let T1, ..., Tt be the non-absorbing states in state order and A1, ..., Aa the absorbing states in state order, and output "ABSORB <c> transient=<t> absorbing=<a>". If t=0, this is all. If t>=1, let Q(i,j)=P(Ti,Tj) (i, j=1, ..., t), apply the elimination procedure to the matrix with t rows and 2t columns whose left t columns are I-Q (I is the identity matrix; row i, column j is delta(i,j) - Q(i,j)) and whose right t columns are I, and let the right t columns be the fundamental matrix N. Further compute
  tau_i = N(i,1) + N(i,2) + ... + N(i,t)   (the mean number of steps from Ti until absorption)
  sigma_i = (sum_j (2 * N(i,j) - delta(i,j)) * tau_j) - tau_i * tau_i   (j=1, ..., t; the variance of the number of steps from Ti until absorption)
  B(i,j) = sum_l N(i,l) * P(Tl,Aj)   (l=1, ..., t; the probability, starting from Ti, of being absorbed in Aj)
and output the following lines in order.
  "TRANSIENT <T1> <T2> ... <Tt>"
  "ABSORBING <A1> <A2> ... <Aa>"
  for i=1, ..., t in this order, "N <Ti> <N(i,1)> <N(i,2)> ... <N(i,t)>" (values in fraction notation)
  for i=1, ..., t in this order, "STEPS <Ti> mean=<tau_i in value notation> var=<sigma_i in value notation>"
  for i=1, ..., t in this order, "B <Ti> <B(i,1)> <B(i,2)> ... <B(i,a)>" (values in fraction notation)

HITTING c x1 x2 ... xm
Checks: for i=1, 2, ..., m in this order, check state specifier xi, and then, if xi is the same state as one specified before it, output "ERROR DUPLICATE STATE <xi>" (finish the checks for one xi before moving on to the next xi).
Processing: with T the set of the specified states, compute h and E as in "Hitting probabilities and expected hitting times". Output "HITTING <c> targets=<names of the states of T in state order, joined with ",">", then, for each state i in state order, output "HIT <i> prob=<h(i) in value notation> time=<E(i) in value notation>". If E(i) is infinite, write time=inf.

PASSAGE c
Checks: check that there is one communicating class.
Processing: compute the stationary distribution pi of the chain. The mean first passage time m(i,j) is E(i) for T={j} if i!=j, and 1/pi(j) if i=j. Taking i to be state 1 (the first state in state order), Kemeny's constant K is the sum of pi(j) * m(i,j) over the states j other than i, added in state order (this value is the same whichever state is taken as i). Output "PASSAGE <c> kemeny=<K in value notation>", then the matrix display of the state names and the matrix whose row i, column j is m(i,j). However, write "M" instead of "ROW" at the start of each row line of this matrix display.

FIRSTPASSAGE c x y k
Checks: check state specifiers x and y in this order. If k=0, "ERROR BAD STEPS".
Processing: for t=1, ..., k compute f(t), the probability that, starting from x, the first time at or after time 1 at which the chain is in y equals t. For every state l let g1(l)=P(l,y) and gt(l) = sum_{u!=y} P(l,u) * g(t-1)(u) (u ranges over all states other than y), and let f(t)=gt(x). If x=y, this is the distribution of the time of the first return. With F(t)=f(1)+f(2)+...+f(t), output "FIRSTPASSAGE <c> <x> <y> k=<k> total=<F(k) in value notation>", then, for t=1, ..., k in this order, output "FP <t> <f(t) in value notation> cum=<F(t) in value notation>".

PATHPROB c x1 x2 ... xm
Checks: check the state specifiers in order starting from x1.
Processing: compute the probability of starting from x1 and moving to x2, x3, ..., xm in order, by starting from 1 and multiplying by P(x1,x2), P(x2,x3), ..., P(x(m-1),xm) in order (it is 1 if m=1). Output "PATHPROB <c> steps=<m-1> prob=<probability in value notation>". However, if the product first became 0 at the t-th multiplication (when multiplying by P(xt,x(t+1))), append " zero_at=<t>" to the end of this line.

MOSTLIKELY c x k
Checks: check state specifier x. If k=0, "ERROR BAD STEPS".
Processing: among the k-step paths x0, x1, ..., xk starting from x0=x, find the one whose probability P(x0,x1) * P(x1,x2) * ... * P(x(k-1),xk) is the largest. If several paths have the largest probability, choose the lexicographically smallest one as a sequence of state numbers (the one whose x1 has the smallest number; if that is also equal, the one whose x2 has the smallest number; ...). Output "MOSTLIKELY <c> <x> k=<k> prob=<largest probability in value notation>" and "PATH <x0> <x1> ... <xk>".
(For reference: after computing fk(i)=1 and ft(i) = max_j P(i,j) * f(t+1)(j) for t=k-1, ..., 0 in this order, this path is obtained by taking, for t=0, 1, ..., k-1 in this order, the smallest-numbered j satisfying P(xt,j) * f(t+1)(j) = ft(xt) as x(t+1).)

REVERSIBLE c
Checks: check that there is one communicating class.
Processing: with the stationary distribution pi of the chain, examine the pairs of states (i,j) (i<j) in increasing order of i, and for equal i in increasing order of j, and count the pairs with pi(i) * P(i,j) != pi(j) * P(j,i) (pairs that violate detailed balance). If there is no such pair, output "REVERSIBLE <c> yes". Otherwise, output "REVERSIBLE <c> no violations=<number of pairs>", then, for each such pair in order, output "VIOLATION <i> <j> <pi(i)*P(i,j) in value notation> <pi(j)*P(j,i) in value notation>".

REVERSE c c2
Checks: check that there is one communicating class.
Processing: using the stationary distribution pi of the chain, create as c2 the chain (the time-reversed chain) that has states with the same names as c in the same order and transition probabilities P*(i,j) = pi(j) * P(j,i) / pi(i). Let R=yes if P*(i,j)=P(i,j) for all i, j, and R=no otherwise, and output "REVERSE <c> <c2> reversible=<R>" and the matrix display of c2.

MIXING c k v
Checks: if k=0, "ERROR BAD STEPS". Validate probability value v. Check that there is one communicating class.
Processing: let pi be the stationary distribution of the chain, and use the same Mt as POWER. For t=1, ..., k in this order, compute for each state i the total variation distance Dt(i) = (|Mt(i,1) - pi(1)| + |Mt(i,2) - pi(2)| + ... + |Mt(i,n) - pi(n)|) / 2; let Dt be the maximum of these values, and wt the first state in state order among the states attaining the maximum. The mixing time is the smallest t with Dt<=v (none if there is no such t). Output "MIXING <c> k=<k> eps=<v in fraction notation> time=<mixing time>", then, for t=1, ..., k in this order, output "TV <t> <Dt in value notation> from=<wt>".

LUMP c c2 B
Checks: go through the blocks of B from left to right, and within each block through the state specifiers from left to right, examining them one at a time as follows: check the state specifier, and then, if it is the same state as one that appeared before it, "ERROR BAD PARTITION". Finally, if some state does not appear in B, "ERROR BAD PARTITION".
Processing: arrange the states of each block in state order, arrange the blocks in the state order of their first states as K1, K2, ..., Ks, and call the first state of each block the "representative" of that block. For a state i and a block L, let S(i,L) = sum_{j in L} P(i,j). Examine the blocks K in order from K1, within that the blocks L in order from K1, and within that the states i of K in state order; if a combination is found in which S(i,L) differs from S(representative of K,L), output, for the first such combination, "LUMP <c> not lumpable block=<representative of K> target=<representative of L> <representative of K>=<S(representative of K,L) in value notation> <i>=<S(i,L) in value notation>" and finish (no chain is created). If there is no such combination, create as c2 the lumped chain whose state names are the names of the representatives of K1, ..., Ks in this order and whose transition probability from the a-th state to the b-th state is S(representative of Ka,Kb), and output "LUMP <c> <c2> blocks=<s>" and the matrix display of c2.

REWARD c v r1 r2 ... rn
Checks: if the number of values r differs from the number of states, "ERROR BAD LENGTH". Validate probability value v. If v=1, "ERROR BAD DISCOUNT".
Processing: at each of the times 0, 1, 2, ..., the reward ri of the state i occupied at that time is received. Compute the discounted value V(i) with discount factor gamma=v (the expected value, starting from i, of the sum of gamma^t * (reward at time t)) and the long-run average reward G(i) (the long-run average of the reward per time step, starting from i). V is obtained by solving the equations "V(i) - sum_j gamma * P(i,j) * V(j) = ri" (row i, column j of A is delta(i,j) - gamma * P(i,j), and the right-hand side is ri). G is computed as follows. For each closed communicating class C, let rhoC(i) be the probability of state i in the stationary distribution of C, let gC = sum_{i in C} rhoC(i) * ri, and let hC be the hitting probability for T=C; then G(i) = sum_C hC(i) * gC (C ranges over all closed communicating classes, added in communicating class number order). Output "REWARD <c> gamma=<v in fraction notation>", then, for each state i in state order, output "VALUE <i> discounted=<V(i) in value notation> gain=<G(i) in value notation>".

RESTRICT c c2 x1 x2 ... xm
Checks: as in HITTING, for i=1, 2, ..., m in this order, check state specifier xi, and then, if xi is the same state as one specified before it, output "ERROR DUPLICATE STATE <xi>". With S the set of the specified states, if there is an edge from a state of S to a state outside S, output "ERROR NOT CLOSED <x>" for x, the first such state of S in state order.
Processing: create as c2 the chain whose states are the states of S arranged in the original state order, with the transition probabilities between them kept as in the original chain. Output "RESTRICT <c> <c2> states=<number of states of S>" and the matrix display of c2.

SIMULATE c x k seed
Checks: check state specifier x. If k=0, "ERROR BAD STEPS". If seed=0 or seed>=2147483647, "ERROR BAD SEED".
Processing: let the random value X be seed and the current state be x, and repeat the following single step k times. Let L be the least common multiple of the denominators of the n values in the row of the current state i (the denominator of 0 is 1). Replace X by "the remainder of 48271 * X divided by 2147483647", and let u be the remainder of X divided by L. For j=1, 2, ... in order, compute the cumulative value Cj = (P(i,1) + P(i,2) + ... + P(i,j)) * L (it is an integer); the first j with Cj>u becomes the new current state. The path is the sequence of k+1 states including the starting state x. Output "SIMULATE <c> <x> steps=<k> seed=<seed> end=<last state of the path>" and "PATH <states of the path in order, separated by single spaces>", then, for each state in state order, output "VISIT <state> <number of times the state appears in the path>".
