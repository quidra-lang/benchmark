[Overview]
Write a program that simulates a casino blackjack table. It reads a sequence of commands from standard input, sets rules, seats and unseats players, sets bets, and plays rounds. The shoe (a pile made of several decks of playing cards put together) is shuffled with a specified random number generator; once dealing has reached the cut card position, the shoe is reshuffled before the next round. In each round the program deals cards, settles side bets, handles insurance and the dealer peek (checking for a dealer blackjack), and advances each player's hands one at a time through hit, stand, double down, split and surrender commands. An action that breaks the rules is rejected as an error, and processing moves on to the command on the next line. When all hands are finished, the dealer draws cards according to the rules, and the outcomes and payouts are computed. In addition, the program can show the recommended action according to basic strategy and play automatically by it, show the table state, show card counting values, and summarize statistics. Only the specified generator is used for randomness, so the results are completely determined.

[Input format]
The first line of standard input is the number of commands N. Each of the following N lines contains one command. Each line consists of a command name and zero or more arguments, separated by single ASCII spaces, with no whitespace at the start or end of the line. There are the following 20 command formats.

SHOE decks seed
RULE name value
RULES
PLAYER name bankroll
LEAVE name
REBUY name amount
BET name amount
SIDE name amount
DEAL
INSURANCE name amount
HIT name
STAND name
DOUBLE name
SPLIT name
SURRENDER name
HINT
AUTO name
STATUS
COUNT
STATS

The name and value of RULE are the name and value of a rule, explained in section 3. Every other name is a player name. decks, seed, bankroll and amount are integer words. The input may contain words that are invalid for these, in which case an error is reported (section 12).

An "integer word" is a word of 1 to 10 characters consisting only of digits (0-9) whose first character is not 0 if it has 2 or more characters (for example, 0, 25 and 2147483646 are integer words, while 007, -5, 2x and +3 are not). The range of allowed values for each argument is given in [Processing]. A word is invalid if it is not an integer word or its value is out of range.

[Processing]
Execute the commands in order from the first line, and print the result of each according to [Output format].

1. Cards
- A card is a combination of one of 4 suits (C, D, H, S) and one of 13 ranks (A, 2, 3, 4, 5, 6, 7, 8, 9, T, J, Q, K). A card is written as 2 characters: the rank character followed by the suit character (for example AS, TD, 7H). T stands for 10.
- The point value of a card is 1 for A, the number itself for 2-9, and 10 for T, J, Q, K. A card worth 10 points is called a "ten-card".
- C and S are black suits; D and H are red suits.

2. Shoe and random numbers
- The shoe is a pile consisting of decks decks of cards (one deck is 52 cards); let its number of cards be n = 52 * decks.
- The random number generator has a state x (an integer from 1 to 2147483646 inclusive). Each time a random number is taken, x is updated to (48271 * x) mod 2147483647, and the updated x is the random number.
- "Shuffling the shoe" means the following procedure.
(1) Arrange the n cards in the following order as an array d[0], d[1], ..., d[n-1]: deck 1, deck 2, ... in that order; within each deck, in suit order C, D, H, S; within each suit, in rank order A, 2, 3, 4, 5, 6, 7, 8, 9, T, J, Q, K (for example, d[0] is AC, d[12] is KC, d[13] is AD, d[51] is KS, and with 2 or more decks d[52] is the AC of deck 2).
(2) For i = n-1, n-2, ..., 1 in this order, take one random number r, let j = r mod (i+1), and swap d[i] and d[j].
(3) Set the "number of cards drawn" k to 0. From then on, to "draw" one card, take d[k] and increase k by 1.
- The SHOE command initializes the generator with x = seed and then shuffles the shoe.
- The "cut card position" c is n * PEN divided by 100, rounded down. PEN is the value of that rule at the time c is used (when printing the SHOE output and when making the check in 6.(1)) (section 3). When k >= c, the shoe "has reached the cut card". If the cut card has been reached, the shoe is reshuffled just before the next round is dealt (section 6). When reshuffling, the generator is not reinitialized; random numbers continue to be taken from its current state. Because the procedure restarts from step (1), all dealt cards also return to the shoe. The shoe is never reshuffled in the middle of a round.
- Count: the "Hi-Lo value" of a card is +1 for cards worth 2-6, 0 for cards worth 7-9, and -1 for ten-cards and A. The "running count" is the sum of the Hi-Lo values of the cards that have been turned face up among the cards drawn since the shoe was last shuffled. Shuffling the shoe resets the running count to 0. Only the dealer's second card (the hole card) is dealt face down; it is added to the running count at the moment it is turned face up (section 6). Every other card is face up at the moment it is drawn.

3. Rules
There are the following 12 rules, each initially at its default value. They can be changed with the RULE command, and a change stays in effect until the end of the input.
- DEALER: either S17 or H17; default S17. Determines whether the dealer draws on a soft 17 (section 6).
- PEN: an integer from 50 to 90 inclusive; default 75. Determines the cut card position (section 2).
- MIN: an integer from 1 to 10000 inclusive; default 10. The minimum bet.
- MAX: an integer from 1 to 10000 inclusive; default 500. The maximum bet.
- BJ: either 3:2 or 6:5; default 3:2. The blackjack payout (section 8).
- DAS: either ON or OFF; default ON. When ON, doubling down is allowed on split hands (section 7).
- DOUBLE: one of ANY, 9-11, 10-11; default ANY. Determines which hands may double down (section 7).
- HANDS: an integer from 1 to 4 inclusive; default 4. The maximum number of hands one player may hold in one round (section 7).
- RSA: either ON or OFF; default OFF. When ON, a split-ace hand may sometimes be split again (section 6).
- SURRENDER: either ON or OFF; default ON. When ON, surrender is allowed (section 7).
- CHARLIE: one of 0, 5, 6, 7; default 0. If not 0, a hand that reaches this number of cards without busting automatically wins (sections 6 and 8).
- SIDEMAX: an integer from 0 to 1000 inclusive; default 25. The maximum side bet amount.
The value of RULE is invalid unless it is one of the words shown above (for an integer rule, an integer word whose value is within the range).

4. Hands and totals
- Players and the dealer hold "hands", which are collections of cards. The cards of a hand are kept in the order in which they were added to the hand.
- Let s be the sum of the point values of the cards in a hand. If the hand contains at least one A and s + 10 <= 21, the hand's "total" is s + 10 and the hand is "soft". Otherwise the hand's total is s and the hand is "hard" (for example, AH 6C is a soft 17, AH 6C 9D is a hard 16, and AH AD is a soft 12).
- A hand whose total exceeds 21 is "bust".
- A player hand that is not a split hand (section 7) and has exactly 2 cards with a total of 21 is a "blackjack". The dealer's hand is a "blackjack" when the total of its first 2 cards is 21.
- The "hand display" is the cards of the hand in order, separated by single ASCII spaces, followed by one ASCII space, (, the status, and ). The status is blackjack if the hand is a blackjack, bust <total> if it is bust, otherwise soft <total> if it is soft, and <total> in all other cases (examples: "AS KD (blackjack)", "9H 7C 8D (bust 24)", "AH 6C (soft 17)", "TS 7D (17)", "8D (8)", "AS (soft 11)").

5. Players
- The table has 7 seats numbered 1-7, and at most 7 players can be seated at the same time. "Seat order" means increasing order of seat number.
- Each player has a name, a seat, a bankroll, a bet, a side bet amount, statistics (section 8), and a net. While the table is idle, the bet and the side bet amount are the amounts set for the next round, initially 0. During a round they keep the amounts they had when that round was dealt. The net is initially 0, and each settlement adds its profit to it.
- Each hand of a player has a number and a bet. Hand numbers are 1, 2, 3, ... in the order in which the player's hands are arranged. The "hand name" is the player name, [, the hand number, and ] concatenated (for example ALICE[1], BOB[3]). When a split creates a new hand, the numbers of the hands after it each increase by 1.
- Bankroll changes: when a round is dealt, each participant pays the bet and the side bet amount from the bankroll. Insurance, doubling down and splitting each also require paying the amount at that time. At settlement, the participant receives an amount according to the profit (section 8).

6. Round progression
The table state is one of "idle", "insurance" and "play", initially idle. The round number r is initially 0. If a DEAL command does not result in an error, a round starts as follows.
(1) If the cut card has been reached, reshuffle the shoe and print shuffle.
(2) Increase r by 1 and print round <r>.
(3) The players whose bet is not 0, in seat order, are the "participants" of this round. Each participant pays the bet and the side bet amount from the bankroll. Each participant's insurance amount is set to 0.
(4) Draw and deal cards in the following order: one card to each participant in seat order, one card to the dealer (the upcard), one more card to each participant in seat order, and one card to the dealer (the hole card). Each participant holds one hand consisting of the 2 dealt cards, and that hand's bet is the participant's bet. A blackjack hand becomes a "finished hand" at the moment it is dealt.
(5) For each participant in seat order, print the hand name and hand display, and then print the dealer's upcard.
(6) For each participant whose side bet amount is not 0, in seat order, settle the side bet. If the 2 dealt cards have the same rank and the same suit, the result is perfect (multiplier 25); if they have the same rank and different suits of the same color, colored (multiplier 12); if they have the same rank and different colors, mixed (multiplier 6). In these cases the profit is side bet amount * multiplier, and the participant receives the sum of the side bet amount and the profit. If the ranks differ, the result is lose and the profit is -(side bet amount).
(7) If the upcard is an A, set the state to insurance and print insurance offered. After this the participants, one at a time in seat order, decide an amount with the INSURANCE command (the participant who decides next is said to have the "insurance turn"); when everyone has decided, go to (8). If the upcard is a ten-card, go to (8) immediately. Otherwise, set the state to play and go to (9).
(8) Peek: if the dealer's hand is a blackjack, print dealer peeks: blackjack; otherwise print dealer peeks: no blackjack. Then, for each participant whose insurance amount is not 0, in seat order, settle the insurance. If the dealer's hand is a blackjack, the profit is insurance amount * 2 and the participant receives 3 times the insurance amount. Otherwise, the profit is -(insurance amount). If the dealer's hand is a blackjack, turn the hole card face up, print the dealer's hand, perform settlement (section 8), and end the round. Otherwise, set the state to play and go to (9).
(9) Turns: look at the participants in seat order and at each participant's hands in number order; the first hand found that is not finished is the "current hand". If the current hand has only 1 card (it is a hand newly created by a split), draw one card and add it to that hand, print the hand name and hand display, perform the check of (10), and if that hand is now finished, perform (9) again. If the current hand has 2 or more cards, wait for the action (section 7) of the hand's owner. If an action finishes the current hand, perform (9) again within the same command. When there are no unfinished hands left, go to (11).
(10) Automatic finish: when a card is added to a hand by HIT, DOUBLE, SPLIT or (9), check the following in this order.
 (a) If the hand is bust, the hand is finished (finish reason: bust).
 (b) If CHARLIE is not 0 and the number of cards in the hand equals CHARLIE, the hand is finished (finish reason: charlie).
 (c) If the hand's total is 21, the hand is finished.
 (d) If the hand is a split-ace hand (section 7) and has 2 cards, the hand is finished. However, if both cards are A, RSA is ON, and the owner's number of hands is less than HANDS, it is not finished.
(11) Dealer's turn: turn the hole card face up and print the dealer's hand. If at least one participant hand has a finish reason that is none of bust, surrender and charlie and is also not a blackjack, the dealer draws cards by the following rule: while the dealer's hand total is 16 or less, or the total is a soft 17 and DEALER is H17, draw one card, add it to the hand, and print the dealer's hand each time (the dealer hits line). Then perform settlement (section 8) and end the round.
When a round ends, set the bet and the side bet amount of every player to 0, and set the state to idle.

7. Player actions
HIT, STAND, DOUBLE, SPLIT and SURRENDER are actions that the owner of the current hand performs on the current hand. If the conditions for an action are not met, it is an error and nothing changes (the order of error checks is in section 12).
- A hand on which SPLIT was performed and the new hand created by it are called "split hands". If the 2 cards that were split are A, those hands are also "split-ace hands". The same applies to hands created by further splitting a split hand or a split-ace hand.
- HIT: if the hand is a split-ace hand, error split aces. Draw one card, add it to the hand, print <hand name> hits: <hand display>, and perform the check of 6.(10).
- STAND: finish the hand and print <hand name> stands: <hand display>.
- DOUBLE: check the following in this order. If the hand is a split-ace hand, error split aces; if the hand does not have exactly 2 cards, error two cards only. If DOUBLE is 9-11 and the hand is not "hard with a total from 9 to 11 inclusive", if DOUBLE is 10-11 and the hand is not "hard with a total from 10 to 11 inclusive", or if DAS is OFF and the hand is a split hand, error double not allowed. If the bankroll is less than the hand's bet, error insufficient funds. Otherwise, pay an amount equal to the hand's bet and double the hand's bet, draw one card and add it to the hand, print <hand name> doubles: <hand display>, perform the check of 6.(10), and finish the hand regardless of its result.
- SPLIT: check the following in this order. If the hand does not have exactly 2 cards, error two cards only; if the 2 cards have different point values, error not a pair (the comparison is by point value, so for example KD and QS are a pair); if the owner's number of hands is HANDS or more, error hand limit; if the bankroll is less than the hand's bet, error insufficient funds. Otherwise, pay an amount equal to the hand's bet and print <hand name> splits <first card> <second card>. The hand keeps only its first card, and a new hand consisting only of the second card, with the same bet, is added immediately after this hand. Next, draw one card and add it to this hand, print <hand name>: <hand display>, and perform the check of 6.(10). The second card of the new hand is dealt when that hand becomes the current hand (6.(9)).
- SURRENDER: if SURRENDER is OFF or the hand is a split hand, error surrender not allowed; if the hand does not have exactly 2 cards, error two cards only. Otherwise, finish the hand (finish reason: surrender) and print <hand name> surrenders: <hand display>.
- When deciding whether an action can be performed, "the action is possible" means that executing that action's command would not result in an error.

8. Settlement and statistics
- At settlement, look at the participants in seat order and at each participant's hands in number order, and determine the following result for each hand.
 If the dealer's hand was a blackjack at the peek: push if the player's hand is a blackjack, otherwise lose.
 Otherwise: blackjack if the player's hand is a blackjack; if the finish reason is one of bust, surrender, charlie, that reason (bust, surrender, charlie); otherwise win if the dealer's hand is bust or the player's hand total is larger, push if the totals are equal, and lose if it is smaller.
- With b the hand's bet, the profit is: for blackjack, b * 3 divided by 2 when BJ is 3:2, or b * 6 divided by 5 when BJ is 6:5, rounded down; b for win and charlie; 0 for push; -b for lose and bust; and (b divided by 2, rounded down) - b for surrender. The participant receives the sum of b and the profit.
- For each hand print <hand name> <result> <profit>, and after printing all hands of a participant, print <player> bankroll <bankroll>.
- A player has the following 10 statistics, all initially 0. rounds is the number of rounds participated in (counted when the round is dealt), hands is the number of hands settled, wins is the number of hands with result blackjack, charlie or win, losses is the number of hands with result lose, bust or surrender, pushes is the number of hands with result push, blackjacks, busts and surrenders are the numbers of hands with result blackjack, bust and surrender respectively, doubles is the number of times DOUBLE was performed, and splits is the number of times SPLIT was performed (doubles and splits are counted at the time of the action; all the others are counted at settlement).
- The profits of side bets, insurance and each hand are added to the player's net at the time each of them is settled.
- The dealer's statistics are: rounds is the round number r, blackjacks is the number of rounds in which the dealer's hand was a blackjack at the peek, and busts is the number of rounds in which the dealer drew one or more cards in 6.(11) and went bust.

9. Recommended action and automatic play
The "recommended action" for the current hand h is determined as follows. Let u be the point value of the dealer's upcard (counting A as 11).
(1) If h is a split-ace hand: split if SPLIT is possible, otherwise stand.
(2) If h consists of 2 cards with equal point values, SPLIT is possible, and the following condition holds for that point value v, then split. The condition is: always if v is 1 (A) or 8; if v is 9, when u is none of 7, 10, 11; if v is 2, 3 or 7, when u <= 7; if v is 6, when u <= 6; if v is 4, when u is 5 or 6 (it never holds when v is 5 or 10).
(3) If neither (1) nor (2) applies, determine a symbol from the following table according to h's total t and whether h is soft or hard.
 Soft: if t >= 19, S. If t = 18: Ds when 3 <= u <= 6, S when u is 2, 7 or 8, H otherwise. If t = 17: D when 3 <= u <= 6, H otherwise. If t is 15 or 16: D when 4 <= u <= 6, H otherwise. If t is 13 or 14: D when u is 5 or 6, H otherwise. If t = 12, H.
 Hard: if t >= 17, S. If 13 <= t <= 16: S when u <= 6; otherwise R when t = 16 and u >= 9, or when t = 15 and u = 10; H otherwise. If t = 12: S when 4 <= u <= 6, H otherwise. If t = 11: D when u <= 10, H otherwise. If t = 10: D when u <= 9, H otherwise. If t = 9: D when 3 <= u <= 6, H otherwise. If t <= 8, H.
 The recommended action is determined from the symbol as follows. S is stand and H is hit. D is double if DOUBLE is possible, otherwise hit. Ds is double if DOUBLE is possible, otherwise stand. R is surrender if SURRENDER is possible, otherwise hit.
The recommended actions hit, stand, double, split and surrender correspond to the commands HIT, STAND, DOUBLE, SPLIT and SURRENDER respectively. The recommended action is always a possible action.
- HINT: print the recommended action for the current hand.
- AUTO name: while the state is play and the owner of the current hand is name, repeatedly perform the recommended action for the current hand exactly as if the corresponding command had been executed for name. The output is also the same as the output of those commands.

10. Setup and player commands
In the following, for a command that requires the idle state, the error when that state condition is not met is error round in progress.
- SHOE decks seed: decks is from 1 to 8 inclusive, and seed is from 1 to 2147483646 inclusive. Requires the idle state. Creates a new shoe of decks decks, initializes the generator with seed, and shuffles. The previous shoe is discarded.
- RULE name value: if name is none of the 12 rule names in section 3, error unknown rule; if value is invalid, error bad value. Requires the idle state. If MIN after the change would be greater than MAX after the change, error min above max. Otherwise, change the rule's value. Bets and side bet amounts that are already set are not changed by RULE.
- RULES: print the values of all rules.
- PLAYER name bankroll: if name is not a word of 1 to 8 characters consisting only of uppercase English letters (A-Z), error bad name. bankroll is from 1 to 1000000 inclusive. Requires the idle state. If a player with the same name is already seated, error player exists; if 7 players are seated, error table full. Otherwise, seat a player with bankroll bankroll, bet and side bet amount 0, and statistics and net 0, in the lowest-numbered empty seat.
- LEAVE name: requires the idle state. Removes the player from the table. All information about the player who left (including statistics) is discarded, and the seat becomes empty.
- REBUY name amount: amount is from 1 to 1000000 inclusive. Requires the idle state. Adds amount to the bankroll.
- BET name amount: amount is from 0 to 1000000 inclusive. Requires the idle state. If amount is 0, set both the bet and the side bet amount to 0. If amount is not 0: if amount is not between MIN and MAX inclusive, error bet out of limits; if the sum of amount and the side bet amount is greater than the bankroll, error insufficient funds; otherwise set the bet to amount.
- SIDE name amount: amount is from 0 to 1000000 inclusive. Requires the idle state. If amount is 0, set the side bet amount to 0. If amount is not 0: if the bet is 0, error no bet; if amount is greater than SIDEMAX, error side out of limits; if the sum of the bet and amount is greater than the bankroll, error insufficient funds; otherwise set the side bet amount to amount.
- DEAL: requires the idle state. If no SHOE command has succeeded yet, error no shoe; if no player has a nonzero bet, error no bets. Otherwise start a round by the procedure of section 6.

11. In-round and information commands
- INSURANCE name amount: amount is from 0 to 1000000 inclusive. If the state is not insurance, error no insurance; if name does not have the insurance turn, error waiting for. If amount is greater than that participant's bet divided by 2, rounded down, error insurance out of limits; if it is greater than the bankroll, error insufficient funds. Otherwise, pay amount from the bankroll as that participant's insurance amount, and pass the insurance turn to the next participant. When the last participant has decided, go to 6.(8).
- HIT name, STAND name, DOUBLE name, SPLIT name, SURRENDER name, AUTO name: if the state is idle, error no round; if it is insurance, error insurance pending; if the owner of the current hand is not name, error waiting for. After that, HIT through SURRENDER perform the checks and processing of section 7, and AUTO performs the processing of section 9.
- HINT: if the state is idle, error no round; if it is insurance, error insurance pending.
- STATUS: print the table state.
- COUNT: if no SHOE command has succeeded yet, error no shoe. Print the number of cards remaining in the shoe m = n - k, the running count R, and the true count. The true count is R * 52 / m written with 2 decimal places, computed as follows. Let v be |R| * 5200 divided by m, rounded down; write - if R is negative, then the quotient of v divided by 100, then ., then the remainder of v divided by 100 zero-padded to 2 digits (examples: R = 5, m = 214 gives v = 121 and 1.21; R = -3, m = 100 gives -1.56; R = 0 gives 0.00).
- STATS: if no player is seated, error no players. Print the statistics and net of the seated players and the dealer's statistics.

12. Errors
On an error, change nothing, print only the single error line, and move on to the next command. Each command is checked in the following order, and the first error that applies is reported.
(1) The command name is none of the 20 formats: unknown command.
(2) Examine the arguments from left to right. The name of PLAYER gives bad name; the name of any other command gives unknown player if no player with that name is seated. The name of RULE gives unknown rule. decks, seed, bankroll, amount and the value of RULE give bad value if invalid.
(3) State errors (round in progress, no insurance, no round, insurance pending).
(4) The errors specific to each command, checked in the order written in sections 10, 11 and 7.

[Output format]
For each command, print the following lines in this order. Words within a line are separated by single ASCII spaces, no line has trailing whitespace, and every line ends with a newline. Numbers are written in decimal without extra leading zeros. Parts enclosed in < > are replaced by values. The period at the end of each item is sentence punctuation and is not part of the output. <hand> is the hand display (section 4). <profit> and the net are written with + if 0 or more and with - if negative (for example +20, +0, -13). Any other number that is negative (the running count) is written with -.
- Error: only the single line error: <reason>. <reason> is one of the following.
 unknown command <command name>

- SHOE: shoe <decks> decks <n> cards cut <cut card position>.
- RULE: rule <name> <value>.
- RULES: rules DEALER <value> PEN <value> MIN <value> MAX <value> BJ <value> DAS <value> DOUBLE <value> HANDS <value> RSA <value> SURRENDER <value> CHARLIE <value> SIDEMAX <value>.
- PLAYER: <player> sits at seat <seat number> with <bankroll>.
- LEAVE: <player> leaves with <bankroll> net <net>.
- REBUY: <player> rebuys <amount> bankroll <bankroll after adding>.
- BET: <player> bet cleared if amount is 0, otherwise <player> bets <amount>.
- SIDE: <player> side cleared if amount is 0, otherwise <player> side <amount>.
- DEAL: the lines produced in section 6, in the order they are produced.

 followed by the lines produced by the peek, turns, the dealer's turn and settlement (below).
- INSURANCE: <player> declines insurance if amount is 0, otherwise <player> insures <amount>. When the last participant has decided, followed by the lines produced from the peek onward.
- Lines produced by the peek: dealer peeks: blackjack or dealer peeks: no blackjack, <player> insurance <profit> for each insurance, and, if the dealer's hand is a blackjack, dealer: <dealer hand> and the settlement lines.
- Lines produced by turns: <hand name>: <hand> when a card is dealt to a hand newly created by a split.
- Lines produced by the dealer's turn: dealer: <dealer hand>, dealer hits: <dealer hand> each time a card is drawn, followed by the settlement lines.
- Settlement lines: as in section 8, <hand name> <result> <profit> for each hand and <player> bankroll <bankroll> for each participant.
- HIT, STAND, DOUBLE, SPLIT, SURRENDER: the line of section 7, followed by the lines produced by turns, the dealer's turn and settlement.
- HINT: hint <current hand name>: <recommended action>.
- AUTO: the outputs of the executed commands in order.
- STATUS: the first line is table idle round <r> when idle, table insurance round <r> next <name of the player who has the insurance turn> when in insurance, and table play round <r> turn <current hand name> when in play. If not idle, it is followed by the single line dealer: <upcard> ??. Then, for each seated player in seat order, one line seat <seat number> <player> bankroll <bankroll> bet <bet> side <side bet amount>, and, if that player is a participant of the round in progress, one line <hand name>: <hand> bet <hand bet> for each of their hands in number order.
- COUNT: count running <R> true <true count> remaining <m>.
- STATS: for each seated player in seat order, one line stats <player> rounds <rounds> hands <hands> wins <wins> losses <losses> pushes <pushes> blackjacks <blackjacks> busts <busts> surrenders <surrenders> doubles <doubles> splits <splits> net <net>, and finally one line stats dealer rounds <rounds> blackjacks <blackjacks> busts <busts>.

[Constraints]
- 1 <= N <= 400.
- Each word in a line is a string of 1 to 12 printable ASCII characters other than space. Command names consist only of letters.
- Each command has the number of arguments given by its format.
- The number of cards remaining in the shoe right after a card is drawn, n - k, is always at least 1.
- The value of every integer word in the input is at most 2147483647.
- All values fit in integers greater than -2^31 and less than 2^31. However, the random number computation 48271 * x exceeds 2^31 (it stays below 2^47), so compute it with a type that represents integers in this range exactly, such as a 64-bit integer. Floating-point numbers are not needed.
