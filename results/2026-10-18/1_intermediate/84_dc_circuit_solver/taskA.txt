[Overview]
Write a program that analyzes DC circuits. The program reads from standard input, one line at a time up to the line ".END", a description of the elements that make up a circuit (a netlist) and analysis commands, processes them in the order read, and writes the results to standard output. The elements are resistors, independent voltage sources, independent current sources, and four kinds of controlled sources (voltage-controlled voltage source, voltage-controlled current source, current-controlled current source, current-controlled voltage source). The circuit is turned into a system of linear equations by modified nodal analysis and solved exactly, keeping rational numbers (fractions), by a Gauss-Jordan method with a fixed procedure. The analyses are: the operating point (node potentials and source currents), element currents and powers, verification of Kirchhoff's current law, Thevenin and Norton equivalent circuits, maximum power, transfer function, sensitivity, Z parameters of a two-port network, superposition, a sweep that varies an element's value, display of the circuit equations, the combined resistance between two nodes (by a method using a matrix and by a method repeating series and parallel replacements), and a check of the circuit structure. The program can also change element values, delete elements, and list nodes and elements.

[Input format]
The input consists of one or more lines, and the last line is a line consisting of just the four characters ".END". A line consisting of just ".END" appears only as the last line. Each line is one of the following three kinds.
- Comment line: a line whose first character is "*".
- Command line: a line whose first character is "." (excluding the final ".END" line).
- Element line: any other line.
Each line consists of one or more 'words' separated by single spaces. There is no whitespace at the beginning or end of a line, and there are no empty lines. A word consists of one or more ASCII characters with character codes 33 to 126 (printable characters other than space). The first word of an element line is one uppercase letter (A-Z) followed by between 0 and 7 (inclusive) uppercase letters or digits (0-9). Other words have no restrictions beyond those stated here (how invalid words are handled is defined in [Processing]).

The element line formats are the following 7 kinds. The first word is called the element name, and its first character gives the type of the element. xxx is the rest of the element name (0 or more characters).
Rxxx n1 n2 value
Vxxx n1 n2 value
Ixxx n1 n2 value
Exxx n1 n2 c1 c2 value
Gxxx n1 n2 c1 c2 value
Fxxx n1 n2 vname value
Hxxx n1 n2 vname value
Here n1, n2, c1, c2 are node names, vname is an element name, and value is a word that writes a number. How node names and numbers are written is defined in [Processing]. An element line in the input may also have a first character other than the 7 kinds above, or a number of words different from these formats.

The command line formats are the following 22 kinds. The first word is called the command name, and the words after it are called the arguments.
.OP
.CURRENT name
.VOLTAGE a b
.POWER
.KCL a
.THEVENIN a b
.NORTON a b
.MAXPOWER a b
.TF a name
.SENS a
.ZPARAM a b c d
.SUPERPOSITION a
.SWEEP name from to step a
.MATRIX
.REQ a b
.REDUCE a b
.CHECK
.ALTER name value
.DELETE name
.CLEAR
.NODES
.PRINT
Here a, b, c, d denote node names, name denotes an element name, and from, to, step, value denote words that write numbers. A command line in the input may also have a command name that is none of these, a number of arguments different from the format, or arguments that are names of nonexistent nodes or elements, or words that are not valid numbers.

[Processing]
== Overall flow ==
Process the input one line at a time starting from line 1, and stop on reaching the ".END" line (nothing is output for the ".END" line). Each line is given a line number starting from 1. Line numbers count comment lines too. A comment line does nothing and outputs nothing. The processing of element lines and command lines is defined below.

Below, a string enclosed in double quotes is a string that appears in the output exactly as written. However, a part inside it enclosed in < and >, such as <name> or <k>, is replaced by its value. One that encloses the name of an argument (<name>, <a>, etc.) is that argument word itself; any other one is a value defined in the description.

== Notation of rational numbers ==
All calculations are done exactly with rational numbers. When a rational number x is output, the following notations are used.
- Fraction notation: express x as a fraction p/q where p and q are coprime and q >= 1. If q is 1, write just p; otherwise write p, "/", q in sequence. p and q are written in decimal (when x is negative, p is negative, so a single "-" is prefixed). For example: 5, -3/4, 0, 27/4.
- Decimal notation: let h be the largest integer less than or equal to |x| * 1000000. If x is negative, write "-" (even if h is 0), then write the quotient of h divided by 1000000, ".", and the remainder of h divided by 1000000 as 6 digits (padded with leading zeros if it has fewer than 6 digits). In other words, the digits from the 7th decimal place onward are truncated. For example, 27/4 is 6.750000, -2/3 is -0.666666, -1/10000000 is -0.000000, and 0 is 0.000000.
- Value notation: fraction notation, one space, "(", decimal notation, ")" in sequence. For example, the value notation of -2/3 is "-2/3 (-0.666666)".
In the output descriptions below, a part written <val> is replaced by the value notation of the rational value defined in that description.

== How numbers are written ==
The words in the position of value in element lines and in the positions of from, to, step, value in commands are read as rational numbers by the following rules.
1. If the word ends with "meg", remove it and let the multiplier be 1000000. Otherwise, if it ends with "k", remove it and let the multiplier be 1000; if it ends with "m", remove it and let the multiplier be 1/1000; if it ends with "u", remove it and let the multiplier be 1/1000000. If none of these applies, the multiplier is 1.
2. If the remainder begins with "-", remove that one character and let the sign be negative. Otherwise the sign is positive.
3. Call the remaining part the mantissa. The mantissa must have one of the following three forms. Here a 'digit string' is a string of one or more characters consisting only of digits (0-9) (leading zeros are allowed).
  - Integer form: a digit string. Its value is the integer that the digit string represents in decimal.
  - Decimal form: a digit string, ".", a digit string, in sequence. Its value is the value obtained by reading it as a decimal fraction (for example, 2.50 is 5/2).
  - Fraction form: a digit string, "/", a digit string, in sequence. Its value is the integer represented by the first digit string divided by the integer represented by the second digit string. The integer represented by the second digit string must not be 0.
4. The value of the word is the value of the mantissa multiplied by the multiplier, and further multiplied by -1 if the sign is negative.
A word whose mantissa fits none of the forms in 3 is 'a word that is not a valid number'. For example, 10, -2.5m (-1/400), 1/3k (1000/3), 007 (7), -0 (0), and 2.2meg (2200000) are valid, and 1., .5, 1/0, 1e3, +5, 10K, --1, 1.5/2, k, and 5mm are not valid.

== Nodes ==
The words valid as node names are "0", and one lowercase letter (a-z) followed by between 0 and 7 (inclusive) lowercase letters or digits (1 to 8 characters in total). Node "0" is ground, and its potential is always 0.
Node names are compared in the following 'name order'. Compare the character codes (ASCII) one character at a time from the beginning; the one whose code is smaller at the first differing character comes first. When one is equal to the beginning part of the other, the shorter one comes first. Since digits come before lowercase letters, "0" comes before every other node name. For example, 0, a, a1, a10, a2, b are in this order.

== Circuit ==
The program holds one circuit. The circuit is a sequence of elements, and it is initially empty. An element added by an element line is appended to the end of the sequence, an element deleted by .DELETE is removed from the sequence, and .CLEAR makes the sequence empty. Changing a value with .ALTER or .SWEEP does not change the element's position in the sequence. Below, 'netlist order' means the order of this sequence.
Each element has an element name, a type (the first character of the element name), terminals, and a value; F and H elements additionally have a vname (the element name of the referenced voltage source). Two or more elements with the same name never exist at the same time.
R, V, I, F, H elements have the two terminals n1 and n2, and E and G elements have the four terminals n1, n2, c1, c2. n1 and n2 are called the 'main terminals', and c1 and c2 of E and G are called the 'control terminals'. Any of the terminals may be the same node.
Among the node names appearing at element terminals (main terminals and control terminals), those other than "0" are called 'circuit nodes'. A node that no longer appears at any terminal, for example because elements were deleted, is no longer a circuit node.

== Element voltage, current, and power ==
The potential of node x is written V(x) (V(0) = 0). With n1, n2 the main terminals of an element, the voltage of the element is u = V(n1) - V(n2), and the current i of the element is 'the current flowing from n1 through the element to n2' (if i is negative, the current actually flows in the opposite direction). With w the value of the element, each element expresses the following relation.
- R (resistor): w is the resistance (a positive number), and i = u / w.
- V (independent voltage source): u = w. i is determined by the circuit.
- I (independent current source): i = w.
- E (voltage-controlled voltage source): u = w * (V(c1) - V(c2)). i is determined by the circuit.
- G (voltage-controlled current source): i = w * (V(c1) - V(c2)).
- F (current-controlled current source): i = w * (the current of the element vname).
- H (current-controlled voltage source): u = w * (the current of the element vname). i is determined by the circuit.
For example, when a battery (a V element) whose positive terminal is n1 supplies power to the circuit, its current i is negative. The 'absorbed power' of an element is u * i.
V, E, H elements are called 'voltage-source-type elements', V and I elements are called 'independent sources', and E, G, F, H elements are called 'controlled sources'.

== Circuit equations ==
Let N be the number of circuit nodes, M the number of voltage-source-type elements, and n = N + M. The unknowns are n in total: the N potentials of the circuit nodes (in name order), followed by the M currents of the voltage-source-type elements (in netlist order). The unknown for the potential of node x is called "V(x)", and the unknown for the current of element s is called "I(s)".
There are also n equations, arranged in the same order as the unknowns. The equation corresponding to V(x) is the equation 'the sum of the currents flowing out of node x into the elements is 0' (Kirchhoff's current law), and the equation corresponding to I(s) is the relation on the voltage of element s. These are written in the form A * (the column of the unknowns in order) = b, using an n-by-n matrix A and a column b with n entries. These A and b are called the 'circuit equations'.
The circuit equations are built as follows. Initially all entries of A and b are 0; then, in netlist order, perform the additions and subtractions below for each element. Here, a row or column indexed by a node name x means the row or column corresponding to V(x), and a row or column indexed by an element name s means the row or column corresponding to I(s) (for example, A[x][s] is the entry in the row corresponding to V(x) and in the column corresponding to I(s)). Additions and subtractions whose row or column index is node "0" are not performed. n1, n2, c1, c2 are the terminals of the element, w is the value of the element, s is the element's own name, and v is the vname of the element.
- R: with g = 1 / w, add g to A[n1][n1] and A[n2][n2], and subtract g from A[n1][n2] and A[n2][n1].
- I: subtract w from b[n1], and add w to b[n2].
- G: add w to A[n1][c1] and A[n2][c2], and subtract w from A[n1][c2] and A[n2][c1].
- F: add w to A[n1][v], and subtract w from A[n2][v].
- V, E, H: first, add 1 to A[n1][s] and A[s][n1], and subtract 1 from A[n2][s] and A[s][n2]. Then, for V add w to b[s]; for E subtract w from A[s][c1] and add w to A[s][c2]; for H subtract w from A[s][v].
For example, an R element whose n1 and n2 are the same node does not change A, because the additions and subtractions cancel each other. A is determined only by the values of R elements and the values of controlled sources, and does not depend on the values of independent sources. b is determined only by the values of independent sources.

== Solving a system of linear equations ==
For an n-by-n matrix A and a column b of n entries, 'solving A y = b' means performing the following procedure (the Gauss-Jordan method). Form the n-by-(n+1) matrix with b placed as one column to the right of A, and call its rows, from the top, row 1, row 2, ..., row n. For k = 1, 2, ..., n in this order, perform steps 1 to 4 below.
1. Among rows k through n, let row r be the first row whose entry in column k is not 0. If there is no such row, A is 'singular' and the procedure ends.
2. If r differs from k, swap row r and row k.
3. Divide every entry of row k by the entry of row k in column k.
4. For each i other than k (1 <= i <= n), if the entry f of row i in column k is not 0, subtract f * (the entry of row k in column j) from the entry of row i in each column j (1 <= j <= n+1).
When the procedure finishes to the end without becoming singular, the entries of column n+1 listed from top to bottom are the solution y. Whether A becomes singular does not depend on b.

== Structure check ==
The following three checks are called the 'structure check', and they are performed in this order.
Check 1. There are no circuit nodes: MESSAGE is "no nodes".
Check 2. There is a node not connected to ground: for each R, V, E, H element, consider a line joining its main terminals n1 and n2 (I, G, F elements and control terminals are not considered). If there are circuit nodes that cannot be reached from node "0" by following only these lines, let x be the first of them in name order; MESSAGE is "floating node <x>".
Check 3. There is a loop of voltage-source-type elements: examine the voltage-source-type elements one at a time in netlist order. When n1 and n2 of the element being examined are the same node, or n2 can be reached from n1 by following only lines joining the main terminals of the voltage-source-type elements examined before it, let s be the name of that element; MESSAGE is "voltage source loop at <s>".
Even for a circuit that passes the structure check, A of its circuit equations can be singular (when there are controlled sources).

== Errors ==
When a line results in an error, output only the one line "error: line <k>: <MESSAGE>" (<k> is the line number of that line), and do not change the circuit at all. A line that results in an error outputs nothing else. In the descriptions below, the error conditions are listed in the order in which they are checked, and the MESSAGE of the first condition that applies is used. MESSAGE is shown in double quotes. When the structure check results in an error, the MESSAGE of the first of checks 1 to 3 above that applies is used.

== Processing of element lines ==
For an element line, check the following conditions in order. <name> is the element name.
1. The first character of the element name is none of R, V, I, E, G, F, H: "unknown element type <name>"
2. The number of words (including the element name) is not the required number (4 for R, V, I; 6 for E and G; 5 for F and H): "wrong field count for <name>"
3. An element with the same name already exists: "duplicate element <name>"
4. Among the words in the node-name positions (n1, n2, and additionally c1, c2 for E and G; checked in this order) there is a word that is not valid as a node name: with x the first such word, "invalid node <x>"
5. For F and H, vname is not the name of an existing V element (it is a nonexistent name, or the name of an element of a type other than V): "unknown voltage source <vname>"
6. value is not a valid number: "invalid value <value>"
7. For R, the value of value is 0 or less: "nonpositive resistance <name>"
If none of these applies, append the element (whose value is the value of value) to the end of the netlist. Nothing is output in this case.

== Processing of command lines ==
For a command line, first check the following conditions in order. <cmd> is the first word.
1. The first word is none of the 22 command names: "unknown command <cmd>" (uppercase and lowercase are distinguished; for example, .op is not a command name)
2. The number of arguments differs from the format: "wrong argument count for <cmd>"
Then perform the checks given in the description of each command, and then perform the processing of that command. The descriptions of the commands use the following terms.
- node check: if the argument is neither "0" nor the name of a circuit node, it is an error ("unknown node <x>", where <x> is that argument).
- element check: if the argument is not the name of an existing element, it is an error ("unknown element <x>").
- number check: if the argument is not a valid number, it is an error ("invalid value <x>").
When several arguments are checked, they are checked starting from the leftmost argument unless stated otherwise.

== Analysis commands and auxiliary solutions ==
The 12 commands .OP, .CURRENT, .VOLTAGE, .POWER, .KCL, .THEVENIN, .NORTON, .MAXPOWER, .TF, .SENS, .ZPARAM, .SUPERPOSITION are called 'analysis commands'. For an analysis command, after the argument checks given in the description of the command, perform the structure check, and then solve the circuit equations A y = b of the current circuit. If A is singular, it is an error ("singular matrix"). If there is no error, this solution is called the 'operating point', and the processing of the command is performed. Below, V(x) and I(s) of the operating-point solution are written simply as V(x), I(s).
The current i of an element at the operating point, with w the value of the element, is as follows: for R, (V(n1) - V(n2)) / w; for V, E, H, I(s) (s is the name of that element); for I, w; for G, w * (V(c1) - V(c2)); for F, w * I(vname).

An analysis command may solve A y = b with A kept the same as for the operating point and only b replaced by a different column (since A is not singular, it can always be solved). Such a solution is called an 'auxiliary solution', and it is named as follows according to how the replacing column is built. For auxiliary solutions too, V(x) (0 if x is "0") and I(s) are used in the same way.
- 'injection solution from x to y' (x, y are nodes): use the column obtained by starting from a column whose entries are all 0, adding 1 to the row of x, and subtracting 1 from the row of y (additions and subtractions to the row of node "0" are not performed; if x and y are the same, the column stays 0). This is the solution when, in the circuit with the values of all independent sources set to 0, a current of 1 is fed into x from outside and taken out from y.
- 'solution of s alone' (s is an independent source): use the column built as b by the construction of the circuit equations, keeping the value of s as it is and regarding the values of the independent sources other than s as 0.
- 'solution of s alone set to 1' (s is an independent source): similarly, use the column built by regarding the value of s as 1 and the values of the independent sources other than s as 0.

== Processing of each command ==
.OP
There are no checks (only the common processing of analysis commands). For each circuit node x in name order, output "V(<x>) = <val>" (the value is V(x)); then, for each voltage-source-type element s in netlist order, output "I(<s>) = <val>" (the value is I(s)).

.CURRENT name
Perform the element check of name. For the current i of the element name, output "I(<name>) = <val>" (the value is i).

.VOLTAGE a b
Perform the node checks of a and b. Output "V(<a>,<b>) = <val>" (the value is V(a) - V(b)).

.POWER
For each element s in netlist order, output "P(<s>) = <val>" (the value is the absorbed power of s, p = (V(n1) - V(n2)) * i). Then output the three lines "absorbed = <val>", "delivered = <val>", "total = <val>". absorbed is the sum of the positive p, delivered is the sum of the negative p with their signs changed, and total is the sum of all p. Each sum starts from 0 and adds in netlist order (total is always 0).

.KCL a
Perform the node check of a. For each element s at least one of whose main terminals n1 and n2 is a, in netlist order, output "I(<s>) leaving <a> = <val>", and finally output "sum = <val>". The value of each line is the current flowing out of node a into element s: with i the current of s, it is 0 if both n1 and n2 are a, i if only n1 is a, and -i if only n2 is a. sum is the sum of these values (starting from 0 and adding in netlist order). Elements of which only a control terminal is a are not included.

.THEVENIN a b
Perform the node checks of a and b. Let Vth = V(a) - V(b), and let Rth be V(a) - V(b) of the injection solution from a to b. Output the two lines "Vth = <val>" (the value is Vth) and "Rth = <val>" (the value is Rth). a and b may be the same node.

.NORTON a b
Perform the node checks of a and b. Obtain Vth and Rth in the same way as .THEVENIN. If Rth is 0, it is an error ("zero thevenin resistance"). Otherwise, output the two lines "In = <val>" (the value is Vth / Rth) and "Rn = <val>" (the value is Rth).

.MAXPOWER a b
Perform the node checks of a and b. Obtain Vth and Rth in the same way as .THEVENIN. If Rth is 0 or less, it is an error ("nonpositive thevenin resistance"). Otherwise, output the two lines "RL = <val>" (the value is Rth) and "Pmax = <val>" (the value is (Vth * Vth) / (4 * Rth)).

.TF a name
Check, in this order: the node check of a, the element check of name, and the error when the element name is not an independent source (neither V nor I) ("not an independent source <name>"). Let z be the solution of name alone set to 1, and output the following three lines.
Line 1: "gain = <val>". The value is V(a) of z.
Line 2: the input resistance. If name is a V element, let j be I(name) of z; if j is 0, output "input resistance = INFINITE", otherwise output "input resistance = <val>" (the value is -1 / j). If name is an I element, output "input resistance = <val>", where the value is V(n2) - V(n1) of z, with n1, n2 the main terminals of name.
Line 3: "output resistance = <val>". The value is V(a) of the injection solution from a to 0.

.SENS a
Perform the node check of a. For each element s in netlist order, output "dV(<a>)/d<s> = <val>". The value is the derivative with respect to w of V(a) at the operating point when only the value w of s is changed, without changing the values of the other elements. It is obtained as follows. Starting from a column d of n entries that are all 0, perform the additions and subtractions below according to the type of s (additions and subtractions to the row of node "0" are not performed), solve A y = d, and take V(a) of that solution (0 if a is "0") as the value. n1, n2, c1, c2, v are the terminals and the vname of s, respectively.
- R: with t = i / w (i is the current of s), add t to d[n1], and subtract t from d[n2].
- I: subtract 1 from d[n1], and add 1 to d[n2].
- G: with t = V(c1) - V(c2), subtract t from d[n1], and add t to d[n2].
- F: with t = I(v), subtract t from d[n1], and add t to d[n2].
- V: add 1 to d[s].
- E: add V(c1) - V(c2) to d[s].
- H: add I(v) to d[s].

.ZPARAM a b c d
Perform the node checks of a, b, c, d. Let z1 be the injection solution from a to b and z2 the injection solution from c to d, and output the following four lines.
"z11 = <val>" (the value is V(a) - V(b) of z1)
"z12 = <val>" (the value is V(a) - V(b) of z2)
"z21 = <val>" (the value is V(c) - V(d) of z1)
"z22 = <val>" (the value is V(c) - V(d) of z2)

.SUPERPOSITION a
Perform the node check of a. For each independent source s in netlist order, output "<s>: V(<a>) = <val>" (the value is V(a) of the solution of s alone), and finally output "total: V(<a>) = <val>". The value of total is the sum of the values of those lines (starting from 0 and adding in netlist order), and it is 0 if there are no independent sources.

.SWEEP name from to step a
Check the following conditions in order.
1. The element check of name
2. The number checks of from, to, step (in this order)
3. The node check of a
4. The value of step is 0 or less: "invalid sweep step"
5. The value of from is greater than the value of to: "invalid sweep range"
6. With K the number obtained by adding 1 to 'the largest integer less than or equal to (to - from) / step', K is greater than 20: "too many sweep points"
7. The element name is an R element and the value of from is 0 or less: "nonpositive resistance <name>"
8. The structure check
If there is no error, for k = 0, 1, ..., K-1 in this order, let x = from + k * step, solve the circuit equations A y = b of the circuit in which the value of the element name is temporarily set to x, and output "<name> = <X>: V(<a>) = <val>" (<X> is the fraction notation of x, and the value is V(a) of that solution). If A is singular, do not treat it as an error; instead of that line, output "<name> = <X>: singular matrix" and continue. Finally, restore the value of the element name to the original value. This command does not change the circuit.

.MATRIX
Perform the structure check (the circuit equations are not solved; the output is produced even if A is singular). Build the circuit equations of the current circuit, and first output a line consisting of "unknowns: " followed by the names of the unknowns (in the form V(x) or I(s)) in the order of the unknowns, separated by single spaces. Then, for each row r (in the order of the unknowns), output a line consisting of "<L>: " followed by the fraction notations of the n entries of row r of A separated by single spaces, followed by " | " and the fraction notation of the r-th entry of b. <L> is the node name x if the row corresponds to V(x), and the element name s if it corresponds to I(s).

.REQ a b
Perform the node checks of a and b (the structure check is not performed). This command obtains the combined resistance between nodes a and b in the resistor-only circuit obtained by replacing every V element with a wire (regardless of its value) and removing every element other than R. The procedure is as follows.
1. Divide node "0" and the circuit nodes into several 'groups' by putting together the nodes connected by lines joining the main terminals n1 and n2 of V elements (a node not connected to any V element forms a group by itself). The 'representative' of each group is the first node of the group in name order.
2. If a and b belong to the same group, output "Req = 0 (0.000000)" and finish.
3. Each R element whose two end nodes belong to different groups is an 'edge' joining those two groups; with w the value of that element, the conductance of the edge is 1 / w. R elements whose two ends belong to the same group are not used.
4. Let S be the set of groups that can be reached from the group of a by following edges (including the group of a). If the group of b is not contained in S, output "Req = INFINITE" and finish.
5. Arrange the groups of S excluding the group of b in name order of their representatives, and let m be their number. Prepare an m-by-m matrix G and a column e of m entries, with all entries 0, and for each edge whose two ends are both in S (if one end of an edge is in S, the other end is also in S), in netlist order, with P, Q the groups at its two ends and g its conductance, add g to G[P][P] and G[Q][Q], and subtract g from G[P][Q] and G[Q][P]. However, additions and subtractions whose index is the group of b are not performed. Set the entry of e for the group of a to 1. Solve G y = e (G is never singular), let Req be the value of the entry of the solution for the group of a, and output "Req = <val>".

.REDUCE a b
Perform the node checks of a and b (the structure check is not performed). This command obtains the combined resistance between nodes a and b, by repeating series and parallel replacements, in the resistor-only circuit obtained by removing every element other than R (unlike .REQ, V elements are also removed instead of being made wires). The procedure is as follows.
1. If a and b are the same, output "Req = 0 (0.000000)" and finish.
2. Let the resistor list L be the R elements arranged in netlist order. Each entry of L has a name, two ends, and a resistance (initially the element name, n1 and n2, and the value of the element). Let C be the set of nodes that can be reached from a (including a) by following only lines joining the two ends of the resistors in L. If b is not contained in C, output "Req = INFINITE" and finish. Otherwise, remove from L every resistor whose ends are not contained in C (for each resistor, either both of its ends are contained in C or neither is; nothing is output on removal).
3. Repeat the following until none of them applies: check whether (i) to (iv) below apply, in this order, and perform only the first one that applies. Here the 'degree' of a node is the number of ends of resistors in L that are that node (a resistor whose two ends are both that node counts as 2), and an 'internal node' is a node appearing as an end of a resistor in L, other than a and b. New resistors are named "#1", "#2", ... in the order they are created within this command.
(i) L has a resistor whose two ends are the same node: remove the first such resistor in L from L, and output "remove <rname>" (<rname> is the name of the removed resistor).
(ii) There is an internal node of degree 1: remove the only resistor of the first such node in name order from L, and output "remove <rname>".
(iii) There are two resistors whose pairs of end nodes (unordered) are the same: let X be the first resistor in L that has such a partner after it, and let Y be the first of the partners of X located after X. With x, y the resistances of X and Y, create a new resistor with the same ends as X and resistance (x * y) / (x + y). Remove X and Y from L, append the new resistor to the end of L, and output "<newname> = <Xname> || <Yname> = <val>" (<newname> is the name of the new resistor, <Xname> and <Yname> are the names of X and Y, and the value is the new resistance).
(iv) There is an internal node of degree 2: let p be the first such node in name order, and of the two resistors having p as an end, let X be the one earlier in L and Y the one later in L. With u the end of X that is not p, v the end of Y that is not p, and x, y the resistances of X and Y, create a new resistor with ends u and v and resistance x + y. Remove X and Y from L, append the new resistor to the end of L, and output "<newname> = <Xname> + <Yname> = <val>" (the value is the new resistance).
4. If exactly one resistor remains in L, output "Req = <val>" (the value is the resistance of that resistor); otherwise output "not series-parallel: <m> resistors remain" (<m> is the number of resistors remaining in L).

.CHECK
If there are no circuit nodes, output "no nodes" and finish (this is not an error). Otherwise, output the problems found by 1 to 3 below, one per line, in this order.
1. For each circuit node x in name order, if the number of element main terminals that are x (counted over elements of all types; if both n1 and n2 are x, count 2) is less than 2: "dangling node <x>".
2. For each circuit node x that cannot be reached from node "0" in check 2 of the structure check, in name order: "floating node <x>".
3. For each voltage-source-type element s that satisfies the condition of check 3 of the structure check, in netlist order: "voltage source loop at <s>" (after one is found, continue examining the remaining elements in the same way).
If no problem was found by 1 to 3, solve the circuit equations A y = b, and if A is singular, output "singular matrix". If nothing was output, output "ok".

.ALTER name value
Check, in this order: the element check of name, the number check of value, and the error when the element name is an R element and the value of value is 0 or less ("nonpositive resistance <name>"). If there is no error, output "altered <name>: <A> -> <B>" (<A> is the value before the change and <B> is the value of value, each in fraction notation), and change the value of the element name to the value of value.

.DELETE name
Perform the element check of name. Next, if there are F or H elements whose vname is name, let f be the first of them in netlist order; it is an error ("<name> is referenced by <f>"). If there is no error, delete the element name from the netlist and output "deleted <name>".

.CLEAR
Output "cleared <k> elements" (<k> is the number of elements before the deletion; write elements even if <k> is 0 or 1), and make the netlist empty. This command has no checks other than the check of the number of arguments.

.NODES
Arrange the node names appearing at element terminals (main terminals and control terminals) in name order (including "0" if it appears at any terminal), and for each node x output one line "<x>: <S>". <S> is the names of the elements any of whose terminals is x, in netlist order, without duplicates, separated by single spaces. If there are no elements, output "no nodes".

.PRINT
For each element in netlist order, output one line writing that element in the element line format. That is, "<name> <n1> <n2> <w>" for R, V, I elements, "<name> <n1> <n2> <c1> <c2> <w>" for E and G elements, and "<name> <n1> <n2> <vname> <w>" for F and H elements. <name> is the element name, <n1> etc. are the node names of the terminals, <vname> is the vname, and <w> is the fraction notation of the current value. If there are no elements, output "empty netlist".

[Output format]
The output consists only of the lines defined in [Processing], output in the order of the input lines. When the processing of one line outputs several lines, they are output in the order described in [Processing]. A command line that does not result in an error outputs one or more lines, and an element line that does not result in an error and a comment line output nothing.
All output consists of ASCII characters, and each line ends with a newline (LF). No whitespace is added at the end of a line, and no empty lines are output. Unless specified otherwise, the separator within a line is a single space.
Integers are written in decimal without extra leading zeros, except for the fractional part of decimal notation.

[Constraints]
- The number of input lines (including the ".END" line) is between 1 and 1000 inclusive, and each line is at most 100 characters long.
- At most 40 elements exist at the same time, and there are at most 20 circuit nodes.
- The words in number positions (value in element lines, and from, to, step, value in commands) contain at most 7 digits (0-9) in total, whether the word is valid or not.
- When computed exactly following the procedures and formulas in [Processing], every rational number that appears (values read from number words and their intermediate values, entries of the circuit equations, all entries appearing during the Gauss-Jordan method, values computed by each command, intermediate values of sums, values of sweep points, etc.), written as a fraction p/q with p and q coprime and q >= 1, satisfies |p| < 2^26 (= 67108864) and q < 2^26. Therefore, even if addition, subtraction, multiplication, division, and comparison of two rational numbers are computed by naively multiplying numerators and denominators, the absolute values of the integers appearing on the way are less than 2^53. Note that |x| * 1000000 used when building decimal notation is not subject to this condition, but |p| * 1000000 is also less than 2^53.
