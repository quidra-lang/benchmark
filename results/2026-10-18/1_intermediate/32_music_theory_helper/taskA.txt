[Overview]
Write a program that is a music theory calculator working with pitch names and pitches. It reads a sequence of commands from standard input, executes them one at a time from the first, and writes the results to standard output. It covers conversion between MIDI numbers and frequencies, naming and inverting intervals, transposition, building scales and chords, identifying chords, key signatures and relationships between keys, building and analyzing chord progressions written with Roman numerals, analyzing the intervals of a melody, and so on.
This task distinguishes the "spelling" of a note (which letter it is written with and which accidental is attached). For example, F#4 and Gb4 are notes of the same pitch but are spelled differently, and the results of intervals and transpositions also depend on the spelling.

[Input format]
The first line contains the number of commands N, and each of the following N lines contains one command. The input consists of exactly these N+1 lines.
A command line is a command name followed by zero or more arguments; the command name and the arguments are separated by single spaces. There are no spaces at the beginning or end of a line, and there are no empty lines. The command name and the arguments (collectively called "words") are strings of one or more printable ASCII characters other than the space.
The valid forms of command names and arguments are defined in [Processing]. The input may contain lines with invalid command names or arguments; how they are handled is also defined in [Processing].

[Processing]
== Overall flow ==
Execute the commands in order from the first line, printing for each command the one or more lines defined in [Processing].
The only state the program keeps is the "reference frequency" A (in hertz), whose initial value is 440. Only the TUNING command changes A.
In this statement, a mod b denotes the remainder of dividing a by b that is at least 0 and less than b, and floor(x) denotes the largest integer less than or equal to x. String comparisons are case-sensitive.

There are the following 24 command forms. [ ] denotes an optional argument, and "..." means that any number of further arguments of the same kind as the one just before may follow.
  MIDI note
  NOTE number
  FREQ note
  TUNING frequency
  PITCH frequency
  INTERVAL note note
  INVERT interval
  TRANSPOSE note interval direction
  SCALE pitch scale
  CHORD pitch quality [inversion]
  VOICE note quality [inversion]
  IDENTIFY note note ...
  MELODY note note ...
  ENHARMONIC note
  KEYSIG key
  RELATIVE key
  CIRCLE mode
  DIATONIC key
  PROGRESSION key numeral ...
  ANALYZE key symbol ...
  FINDKEY pitch ...
  DEGREE key pitch
  SPELL number key
  KEYDIST key key
Here "pitch" means a pitch name, "scale" a scale name, "numeral" a Roman numeral and "symbol" a chord symbol. A "key" stands for the two arguments "tonic mode". Therefore, for example, KEYSIG takes exactly 2 arguments, KEYDIST exactly 4, SPELL exactly 3, PROGRESSION and ANALYZE 3 or more, IDENTIFY and MELODY 2 or more, FINDKEY 1 or more, and CHORD and VOICE 2 or 3.

Each command is checked in the following order. When an error is found, print exactly one error line for the first error found and do nothing else for that command (the reference frequency does not change either).
(1) If the command name matches none of the 24 above, the error is "ERROR UNKNOWN COMMAND <command name>".
(2) If the number of arguments does not match the form, the error is "ERROR ARGUMENT COUNT".
(3) Examine the arguments one by one from left to right; if an argument does not match the form required at its position, the error is the one defined in "== Argument types ==".
(4) Perform the checks given in the description of each command, in the order written.
In error lines, <command name> and <word> are replaced by the string exactly as written in the input.

== Pitch names and notes ==
There are 7 letters, C, D, E, F, G, A and B, which are given "letter numbers" 0 to 6 in this order. The "natural value" of a letter is 0 for C, 2 for D, 4 for E, 5 for F, 7 for G, 9 for A and 11 for B.
There are the following 5 accidentals; the value in parentheses is called the "alteration".
  bb (-2), b (-1), none (0), # (+1), x (+2)
A "pitch name" is one uppercase letter followed by an accidental (when the accidental is "none", it is just the letter). For example, C, F#, Bb, Ebb and Cx are pitch names. The "pitch class" of a pitch name is (natural value + alteration) mod 12. For example, the pitch class of Cb is 11 and the pitch class of B# is 0.
A "note" is a pitch name followed by an octave number. The octave number is an integer from -1 to 9, written as one of the strings -1, 0, 1, ..., 9. For example, C4, F#3, Bb-1 and Cx9 are notes. The following values are defined for a note.
  MIDI number = 12 * (octave number + 1) + natural value + alteration
  position = 7 * octave number + letter number
For example, the MIDI number of C4 is 60, of A4 is 69, of B#3 is 60 and of Cb4 is 59. Because the octave number belongs to the letter, B#3 and C4 are notes of the same pitch (notes with equal MIDI numbers). The position represents the height in terms of letters; the position of C4 is 28 and the position of B#3 is 27.
A "valid note" is a note whose octave number is from -1 to 9 and whose MIDI number is from 0 to 127.
To make a note from a pitch name X and a MIDI number t, use X as the pitch name and (t - (natural value of X) - (alteration of X)) / 12 - 1 as the octave number (in this statement this is used only when the division is always exact).
The "sharp spelling" and the "flat spelling" of a MIDI number t are the notes formed by the pitch name corresponding to the pitch class t mod 12 in the table below, followed by the octave number floor(t/12)-1.
  Sharp-spelling pitch names (pitch classes 0 to 11 in order): C C# D D# E F F# G G# A A# B
  Flat-spelling pitch names (pitch classes 0 to 11 in order): C Db D Eb E F Gb G Ab A Bb B
For example, the sharp spelling of MIDI number 61 is C#4 and its flat spelling is Db4.

== Argument types ==
- note: matches the form of a note in "== Pitch names and notes ==" and is a valid note. Otherwise the error is "ERROR BAD NOTE <word>". For example, c4, H4, C##4, Cbbb4, C10, C, 4, Cb-1 (MIDI number -1) and G#9 (MIDI number 128) are invalid.
- pitch: matches the form of a pitch name in "== Pitch names and notes ==". Otherwise the error is "ERROR BAD PITCH <word>". A string with an octave number attached, such as C4, is also invalid.
- number: an integer from 0 to 127 written in decimal without extra leading zeros. Otherwise the error is "ERROR BAD NUMBER <word>" (examples: 128, 060, -1).
- frequency: a string of 1 to 5 digits (0 to 9), optionally followed by "." and a string of 1 or 2 digits. Leading zeros are allowed. Its value is the number that this decimal represents. If it does not match the format or its value is out of range, the error is "ERROR BAD FREQUENCY <word>". The range is from 400 to 480 inclusive for TUNING, and greater than 0 for PITCH. For example, "440.", ".5", "440.123", "1e3" and "123456" do not match the format.
- interval: matches the form in "== Intervals ==". Otherwise the error is "ERROR BAD INTERVAL <word>".
- direction: UP or DOWN. Otherwise the error is "ERROR BAD DIRECTION <word>".
- scale: one of the 15 names in "== Scale table ==". Otherwise the error is "ERROR BAD SCALE <word>".
- quality: one of the 16 quality names in "== Chord table ==". Otherwise the error is "ERROR BAD QUALITY <word>".
- inversion: an integer from 0 to "(the number of chord tones of that command's quality) - 1", written in decimal without extra leading zeros. Otherwise the error is "ERROR BAD INVERSION <word>".
- mode: one of the 9 mode names in "== Keys ==". Otherwise the error is "ERROR BAD MODE <word>".
- key: the two arguments tonic (a pitch name) and mode. The tonic and then the mode are examined; if both are valid, then before the following arguments are examined, check whether it is a theoretical key ("== Keys =="). If it is a theoretical key, the error is "ERROR THEORETICAL KEY".
- numeral: matches the form in "== Roman numerals ==". Otherwise the error is "ERROR BAD NUMERAL <word>".
- symbol: matches the form in "== Chord symbols ==". Otherwise the error is "ERROR BAD SYMBOL <word>".

== Intervals ==
An interval is expressed by an "interval quality" and an "interval number", written as the string for the interval quality followed by the interval number (examples: M3, P5, A4, d7, M10, AA1).
- There are 7 interval qualities: P (perfect), M (major), m (minor), A (augmented), d (diminished), AA (doubly augmented) and dd (doubly diminished).
- The interval number is an integer from 1 to 99, written in decimal without extra leading zeros.
For an interval with interval number n, s = n-1 is called the "letter distance"; let k be the quotient and r the remainder of dividing s by 7. Interval numbers with r equal to 0, 3 or 4 (1, 4, 5, 8, 11, 12, 15, ...) are called "perfect-type", and those with r equal to 1, 2, 5 or 6 are called "major/minor-type". The "base semitone count" is 12 * k + b, where b is 0, 2, 4, 5, 7, 9, 11 for r = 0, 1, 2, 3, 4, 5, 6 respectively. The "semitone count" of an interval is the base semitone count plus the following difference, depending on the interval quality.
  perfect-type: dd is -2, d is -1, P is 0, A is +1, AA is +2
  major/minor-type: dd is -3, d is -2, m is -1, M is 0, A is +1, AA is +2
M and m cannot be used with perfect-type interval numbers, and P cannot be used with major/minor-type interval numbers. Also, d1 and dd1 are not accepted as intervals. Anything that falls under these cases, anything whose interval quality is none of the 7, and anything whose interval number is not written correctly is not a valid interval (examples: P3, M4, d1, Q3, M0, M03, m100, 3M, M).
For example, P1 is 0, m2 is 1, M3 is 4, P4 is 5, A4 and d5 are 6, P5 is 7, m7 is 10, P8 is 12, M9 is 14, M10 is 16 and P15 is 24 semitones.
The "simple interval" of an interval is as follows: if its interval number n is 9 or more, it is the interval with the same interval quality and the interval number obtained by repeatedly subtracting 7 from n until n is 8 or less. If n is 8 or less, it is the interval itself. For example, the simple interval of M10 is M3, of P15 is P8, of M9 is M2, and of P8 is P8.
To determine the interval from a pair of a letter distance s (0 or more) and a semitone count h, use s+1 as the interval number, and choose from the tables above the interval quality corresponding to the difference h minus the base semitone count. If there is no corresponding interval quality, that pair is said to "have no name".

== Raising a pitch name by an interval ==
Raising a pitch name X (letter number a, alteration v) by an interval with letter distance s and semitone count h gives the pitch name formed by the letter with letter number (a+s) mod 7 and the alteration
  w = (natural value of the letter with letter number a) + v + h - (natural value of the letter with letter number (a+s) mod 7) - 12 * floor((a+s)/7)
If w is not from -2 to 2, that pitch name cannot be written. This is called "unspellable".
For example, raising C by M3 gives E, raising A by m3 gives C, and raising B by A4 gives E#. Raising Fb by d7 gives w = -3, which is unspellable.

== Scale table ==
A scale is determined by a root (a pitch name) and a scale name. The notes of the scale are the pitch names obtained by raising the root by each interval in the following table, in the order of the table.
  major: P1 M2 M3 P4 P5 M6 M7
  natural_minor: P1 M2 m3 P4 P5 m6 m7
  harmonic_minor: P1 M2 m3 P4 P5 m6 M7
  melodic_minor: P1 M2 m3 P4 P5 M6 M7
  ionian: P1 M2 M3 P4 P5 M6 M7
  dorian: P1 M2 m3 P4 P5 M6 m7
  phrygian: P1 m2 m3 P4 P5 m6 m7
  lydian: P1 M2 M3 A4 P5 M6 M7
  mixolydian: P1 M2 M3 P4 P5 M6 m7
  aeolian: P1 M2 m3 P4 P5 m6 m7
  locrian: P1 m2 m3 P4 d5 m6 m7
  major_pentatonic: P1 M2 M3 P5 M6
  minor_pentatonic: P1 m3 P4 P5 m7
  blues: P1 m3 P4 A4 P5 m7
  whole_tone: P1 M2 M3 A4 A5 A6

== Chord table ==
A chord is determined by a root (a pitch name) and a quality. The "chord tones" of a chord are the pitch names obtained by raising the root by each interval in the chord intervals column of the following table, in the order of the table. From the first, they are called chord tone 0, chord tone 1, and so on. The "chord symbol" of a chord is the root's pitch name followed by the suffix in the table (the suffix of maj is the empty string). The "numeral example" column is the chord of that quality on the 1st scale degree written as a Roman numeral, and is used in "== Roman numerals ==".
  quality | chord intervals | suffix | numeral example
  maj | P1 M3 P5 | (empty) | I
  min | P1 m3 P5 | m | i
  dim | P1 m3 d5 | dim | io
  aug | P1 M3 A5 | aug | I+
  sus2 | P1 M2 P5 | sus2 | Isus2
  sus4 | P1 P4 P5 | sus4 | Isus4
  6 | P1 M3 P5 M6 | 6 | I6
  m6 | P1 m3 P5 M6 | m6 | i6
  7 | P1 M3 P5 m7 | 7 | I7
  maj7 | P1 M3 P5 M7 | maj7 | Imaj7
  m7 | P1 m3 P5 m7 | m7 | i7
  mMaj7 | P1 m3 P5 M7 | mMaj7 | imaj7
  m7b5 | P1 m3 d5 m7 | m7b5 | ih7
  dim7 | P1 m3 d5 d7 | dim7 | io7
  9 | P1 M3 P5 m7 M9 | 9 | I9
  add9 | P1 M3 P5 M9 | add9 | Iadd9
For example, the chord tones of the chord with root C and quality maj7 are C, E, G, B, and its chord symbol is Cmaj7. The chord symbol of the chord with root A and quality min is Am.
In a numeral example, the I or i is called the "numeral part", and the part after it (which may be empty) is called the "numeral suffix".

== Keys ==
A "key" is a pair of a tonic (a pitch name) and a mode, written as the two arguments "tonic mode". There are the following 9 modes, each with a fixed scale name and "offset".
  major: scale name major, offset 0
  minor: scale name natural_minor, offset -3
  ionian: scale name ionian, offset 0
  dorian: scale name dorian, offset -2
  phrygian: scale name phrygian, offset -4
  lydian: scale name lydian, offset +1
  mixolydian: scale name mixolydian, offset -1
  aeolian: scale name aeolian, offset -3
  locrian: scale name locrian, offset -5
The "fifths number" of a key is (fifths value of the tonic's letter) + 7 * (alteration of the tonic) + (offset of the mode). The fifths value of a letter is -1 for F, 0 for C, 1 for G, 2 for D, 3 for A, 4 for E and 5 for B. A key whose fifths number is not from -7 to 7 is called a "theoretical key".
For example, the fifths number of C major is 0, of A minor is 0, of D major is 2, of Bb major is -2, of F# minor is 3, and of D dorian is 0. G# major (8) and Fb major (-8) are theoretical keys.
The "scale" of a key is the 7 pitch names of the scale built with the tonic as the root and the mode's scale name. From the first, they are called the 1st scale degree, the 2nd scale degree, ..., the 7th scale degree. In a key that is not a theoretical key, the pitch name of every scale degree has an alteration from -1 to 1. The set of pitch classes of the 7 pitch names of a key's scale is called the "pitch-class set of the key".
The "pitch name with fifths number q" is the pitch name whose letter is the one at index (q+1) mod 7 in the string FCGDAEB (counting from the first, with the leading F as index 0) and whose alteration is floor((q+1)/7). For example, it is C for q = 0, A for 3, F# for 6, C# for 7, F for -1, and Cb for -7. The tonic of the key of mode m whose fifths number is p is the pitch name with fifths number p-(offset of m). For example, the tonic of the major key with fifths number 0 is C, and the tonic of the minor key is A.

== Roman numerals ==
A Roman numeral argument consists of a prefix, a numeral part and a suffix, in this order.
- The prefix is the first character of the argument if it is b or #; otherwise it is "none" (the empty string).
- The numeral part starts right after the prefix and is the longest part consisting only of the characters I, V, i and v (it may be empty). The numeral part must be one of I, II, III, IV, V, VI, VII or their lowercase forms i, ii, iii, iv, v, vi, vii. These denote the 1st to 7th scale degrees, in this order.
- The suffix is the remaining part after the numeral part (it may be empty).
It is valid if the pair (whether the numeral part is uppercase or lowercase, suffix) matches the pair (whether the numeral part is uppercase or lowercase, numeral suffix) of the numeral example of some quality in "== Chord table =="; that quality is the quality of the chord of this Roman numeral. For example, the quality of V7 is 7, of ii7 is m7, of viio is dim, of viih7 is m7b5, and of bVII is maj. IIII, iI, Io, i+, Vh7, bbII, VIII and # are invalid.
The root of the chord of a Roman numeral in a given key is the pitch name of the corresponding scale degree of that key with -1 added to its alteration if the prefix is b, or +1 if it is # (if there is no prefix, it is the pitch name of the scale degree itself).
To make a Roman numeral from a scale degree d (1 to 7) and a quality, take the I, II, III, IV, V, VI, VII corresponding to d, keep it as is if the numeral part of that quality's numeral example is uppercase or make it lowercase if it is lowercase, and append the numeral suffix. This is called the "Roman numeral notation" of the scale degree d and the quality. For example, the Roman numeral notation of the 2nd scale degree and m7 is ii7, and of the 7th scale degree and m7b5 is viih7.

== Chord symbols ==
A chord symbol argument is a pitch name followed by one of the suffixes in "== Chord table ==" (including the empty suffix of maj). Since no suffix starts with b, # or x, there is only one way to split it. The pitch name is the root of the chord, and the quality of the suffix is the quality of the chord. For example, Dm has root D and quality min, Bbm7b5 has root Bb and quality m7b5, and F# has root F# and quality maj. Cmaj, C/E and Hm are invalid.

== Degree labels ==
For a key and a pitch name X, the "degree label" of X is defined as follows. Let i = (letter number of X - letter number of the tonic) mod 7, and let e = (alteration of X) - (alteration of the pitch name of the (i+1)-th scale degree of the key). The degree label is -e copies of b if e is negative, or e copies of # if e is positive, followed by i+1 (if e = 0, it is just i+1).
For example, the degree label of F# in C major is #4, of G# in A minor is #7, of Bx in C major is ##7, of Cbb in C# major is bbb1, and of B in D dorian is 6.

== Commands ==
Below, a part shown by an argument type, such as <note> or <pitch>, is replaced by that argument exactly as written in the input.

MIDI note
Print "MIDI <note> <MIDI number>".

NOTE number
Let the number be the MIDI number t, and print "NOTE <t> <sharp spelling of t> <flat spelling of t>".

FREQ note
Let t be the MIDI number of the note, compute the frequency f = A * 2^((t-69)/12), and print "FREQ <note> <f>". f is rounded half up at the third decimal place and written with two decimals.

TUNING frequency
Change the reference frequency A to the value of the frequency, and print "TUNING <A>". A is written with two decimals.

PITCH frequency
Let f be the value of the frequency, and compute x = 69 + 12 * log2(f / A). Let n be the integer nearest to x.
Check: if n is not from 0 to 127, the error is "ERROR OUT OF RANGE".
Processing: let c be the integer nearest to 100 * (x - n), and print "PITCH <f> <sharp spelling of n> <c>". <f> is f written with two decimals. <c> is written with a leading "+" if c is 0 or more, or a leading "-" if it is negative (c = 0 is written as +0).

INTERVAL note note
Let N1 be the first note and N2 the second note, and let d = (position of N2) - (position of N1) and h = (MIDI number of N2) - (MIDI number of N1). If d is negative, or d = 0 and h is negative, the direction is down and d and h are replaced by -d and -h respectively. Otherwise the direction is up.
Check: if the pair of letter distance d and semitone count h has no name, the error is "ERROR UNNAMEABLE INTERVAL".
Processing: determine the interval of that pair and print "INTERVAL <N1> <N2> <interval> <direction> semitones=<h> simple=<simple interval of the interval> class=<class>". The class is perfect if the simple interval is one of P1, P5, P8, imperfect if it is one of m3, M3, m6, M6, and dissonant otherwise.
h can also be negative. For example, with N1 = B#4 and N2 = Cb5, d = 1 and h = -1, so the interval is dd2 and semitones=-1.

INVERT interval
Let q be the interval quality and n the interval number of the simple interval of the interval. The "inverted interval" has interval number 9-n and the interval quality obtained from q as follows: P becomes P, M becomes m, m becomes M, A becomes d, d becomes A, AA becomes dd, and dd becomes AA.
Check: if the inverted interval is d1 or dd1, the error is "ERROR CANNOT INVERT".
Processing: print "INVERT <interval> <simple interval> <inverted interval>".

TRANSPOSE note interval direction
Let s be the letter distance and h the semitone count of the interval. If the direction is UP, let P = (position of the note) + s and t = (MIDI number of the note) + h; if DOWN, let P = (position of the note) - s and t = (MIDI number of the note) - h. The resulting note is the note with the letter of letter number P mod 7, octave number floor(P/7), and alteration t - (12 * (floor(P/7) + 1) + natural value of that letter).
Check: if the alteration of the resulting note is not from -2 to 2, the error is "ERROR CANNOT SPELL". Next, if the resulting note is not a valid note, the error is "ERROR OUT OF RANGE".
Processing: print "TRANSPOSE <note> <interval> <direction> <resulting note>".

SCALE pitch scale
Build the scale of the scale name with the pitch name as the root.
Check: if any note of the scale is unspellable, the error is "ERROR CANNOT SPELL".
Processing: print "SCALE <pitch> <scale> <notes of the scale> steps=<steps>". <notes of the scale> is the pitch names of the scale in order, separated by spaces. <steps> is, where h1, h2, ..., hk are the semitone counts of the intervals of that scale name in the table in order, the values h2-h1, h3-h2, ..., hk-h(k-1), 12-hk separated by "," (commas).

CHORD pitch quality [inversion]
Let k be the inversion (k = 0 when it is omitted). Build the chord tones of the chord of that quality with the pitch name as the root.
Check: if any chord tone is unspellable, the error is "ERROR CANNOT SPELL".
Processing: move the first k elements of the sequence of chord tones to the end of the sequence, keeping their order (the sequence then starts with chord tone k). Print "CHORD <symbol> <reordered chord tones>". <symbol> is the chord symbol if k = 0, or, if k > 0, the chord symbol followed by "/" and the first pitch name of the reordered sequence. <reordered chord tones> is the pitch names separated by spaces.

VOICE note quality [inversion]
With the pitch name of the note as the root and the inversion as k (0 when omitted), build and reorder the chord tones in the same way as CHORD.
Check: if any chord tone is unspellable, the error is "ERROR CANNOT SPELL".
Processing: turn each pitch name of the reordered sequence into a note, in order from the first, as follows.
- The first pitch name: if k = 0, it is the input note itself. If k > 0, it is the lowest note of that pitch name above the MIDI number of the input note.
- The second and later pitch names: the lowest note of that pitch name above the MIDI number of the previous note.
Here "the lowest note of pitch name X above MIDI number M" is the note made from pitch name X and MIDI number t, where t = M + ((pitch class of X - M) mod 12), and t is changed to M + 12 if t = M.
Check: if any of the notes made is not a valid note, the error is "ERROR OUT OF RANGE".
Processing: print "VOICE <symbol> <notes made> midi=<MIDI numbers>". <symbol> is the same as for CHORD. <notes made> is the notes in order separated by spaces, and <MIDI numbers> is their MIDI numbers in order separated by ",".

IDENTIFY note note ...
Identify a chord from the input notes.
(1) Let S be the set of the pitch classes (MIDI number mod 12) of the input notes.
(2) Sort the input notes in ascending order of MIDI number (in input order when MIDI numbers are equal), and remove every note that has a note of the same pitch class before it; the result is the "candidate sequence". The first note of the candidate sequence is called the "bass".
(3) Try the notes of the candidate sequence as the root in order from the first, and for each root try the qualities of "== Chord table ==" from top to bottom. The answer is the first root and quality for which the set of pitch classes of the values (MIDI number of the root plus the semitone count of each chord interval) equals S.
(4) If there is an answer, look at the chord intervals in the order of the table, let k be the index (counting from chord interval 0) of the chord interval for which the pitch class of the MIDI number of the root plus its semitone count equals the pitch class of the bass, and print "IDENTIFY <symbol> root=<pitch name of the root> quality=<quality> inversion=<k>". <symbol> is the root's pitch name followed by the quality's suffix, and, if k > 0, further followed by "/" and the bass's pitch name. Here the "pitch name" of a note is the note with its octave number removed.
If there is no answer, print "IDENTIFY UNKNOWN".
For example, E3 G3 C4 has root C, quality maj and k = 1, giving C/E; A3 C4 E4 G4 is Am7, and C4 E4 G4 A4 is C6.

MELODY note note ...
Let n be the number of notes and N1, N2, ..., Nn the input notes in order.
- low is the first in input order among the notes with the smallest MIDI number, and high is the first in input order among the notes with the largest MIDI number.
- range is the interval obtained in the same way as INTERVAL low high.
- steps is, for i = 1, ..., n-1, the interval obtained in the same way as INTERVAL Ni N(i+1), preceded by "+" if the direction is up or "-" if it is down, listed in order separated by ",".
- leaps is the number of pairs of adjacent notes Ni, N(i+1) whose MIDI numbers differ by 3 or more in absolute value.
Check: if a pair with no name occurs while computing range or steps, the error is "ERROR UNNAMEABLE INTERVAL".
Processing: print "MELODY n=<n> low=<low> high=<high> range=<range> leaps=<leaps> steps=<steps>".

ENHARMONIC note
Print "ENHARMONIC <note> <enharmonic list>". <enharmonic list> is all valid notes whose MIDI number equals that of the input note (with any of the 5 accidentals, including the input note itself), in ascending order of position, separated by spaces. For example, the enharmonic list of C4 is B#3 C4 Dbb4.

KEYSIG key
Let p be the fifths number of the key. If p = 0, print "KEYSIG <tonic> <mode> none"; if p > 0, print "KEYSIG <tonic> <mode> sharps=<p> <list>"; if p < 0, print "KEYSIG <tonic> <mode> flats=<-p> <list>". <list> is the first p of F# C# G# D# A# E# B# if p > 0, or the first -p of Bb Eb Ab Db Gb Cb Fb if p < 0, in this order, separated by spaces.

RELATIVE key
Let p be the fifths number of the key, and print "RELATIVE <tonic> <mode> major=<tonic of the major key with fifths number p> minor=<tonic of the minor key with fifths number p>".

CIRCLE mode
Print "CIRCLE <mode> <list of tonics>". <list of tonics> is the 15 tonics of the keys of that mode with fifths numbers -7, -6, ..., 7, in this order, separated by spaces.

DIATONIC key
On each scale degree of the key's scale, build a triad and a seventh chord consisting only of notes of the scale. For scale degree i (1 to 7), the pitch names of scale degrees i, i+2, i+4 form the triad, and the pitch names of scale degrees i, i+2, i+4, i+6 form the seventh chord (if a scale degree number exceeds 7, subtract 7). In both, the pitch name of scale degree i is the root, and the quality is determined by the tuple of differences (mod 12) from the pitch class of the root to the pitch classes of the pitch names of scale degrees i+2, i+4 (and, for the seventh chord, also i+6), in this order.
  triads: (4,7) gives maj, (3,7) gives min, (3,6) gives dim
  seventh chords: (4,7,11) gives maj7, (4,7,10) gives 7, (3,7,10) gives m7, (3,6,10) gives m7b5
In keys of the 9 modes, no other tuple occurs.
Print the following 3 lines.
  "DIATONIC <tonic> <mode>"
  "TRIADS <item list>" (triads)
  "SEVENTHS <item list>" (seventh chords)
<item list> is "<Roman numeral notation of the scale degree and the quality>=<chord symbol>" for scale degrees 1 to 7 in order, separated by spaces.

PROGRESSION key numeral ...
Let m be the number of Roman numerals. For each Roman numeral, build the chord tones of the chord from its root and quality in that key.
Check: if there is a chord with an unspellable chord tone, the error is "ERROR CANNOT SPELL" (in this case no other lines are printed).
Processing: first print "PROGRESSION <tonic> <mode> <m>", then for each Roman numeral, in input order, print "<numeral> <chord symbol> <chord tones>", and finally print "CADENCE <cadence>". <chord tones> is the chord tones in order separated by spaces.
<cadence> is determined only by the prefixes and scale degrees of the last two Roman numerals (call the second-to-last X and the last Y); whether the numeral part is uppercase or lowercase and the suffix do not matter. If m = 1, it is none.
- If X is the 5th scale degree without prefix and Y is the 1st scale degree without prefix, it is authentic.
- If X is the 4th scale degree without prefix and Y is the 1st scale degree without prefix, it is plagal.
- If X is the 5th scale degree without prefix and Y is the 6th scale degree without prefix, it is deceptive.
- If none of the above applies and Y is the 5th scale degree without prefix, it is half.
- Otherwise it is none.

ANALYZE key symbol ...
For each chord symbol, find the degree label of the root in that key. Let the trailing digit of the degree label be the scale degree d, and the part before it (a run of b or # characters, possibly empty) the prefix part; the prefix part followed by the Roman numeral notation of the scale degree d and the chord's quality is the analysis result of that chord symbol. Print "ANALYZE <tonic> <mode> <analysis results>". <analysis results> is the analysis results in input order, separated by spaces.
For example, in C major, Bb is bVII and Gbdim7 is bvo7.

FINDKEY pitch ...
For fifths numbers p in the order -7, -6, ..., 7, and for each p, examine the major key with fifths number p and then the minor key with fifths number p, and select the keys whose scale's 7 pitch names contain all the argument pitch names (the pitch names must match including spelling). Let c be the number of selected keys; if c = 0, print "FINDKEY 0", and if c >= 1, print "FINDKEY <c> <list of keys>". <list of keys> is the selected keys, each in the form "<tonic> <mode>", in the order selected, separated by ", " (a comma and a space).

DEGREE key pitch
Print "DEGREE <tonic> <mode> <pitch> <degree label of the pitch name>".

SPELL number key
Let the number be the MIDI number t. If the pitch names of the key's scale include one whose pitch class is t mod 12, let it be X (there is at most one). If not, choose X as the pitch name with pitch class t mod 12 from the sharp-spelling pitch name table if the key's fifths number is 0 or more, or from the flat-spelling pitch name table if it is negative. Make a note from the pitch name X and the MIDI number t.
Check: if the note made is not a valid note, the error is "ERROR OUT OF RANGE".
Processing: print "SPELL <t> <tonic> <mode> <note made> <degree label of X>".

KEYDIST key key
Let p1 be the fifths number of the first key and p2 that of the second. Let r = (p2-p1) mod 12, and let f = r-12 if r > 6, otherwise f = r. Let c be the number of elements in the intersection of the pitch-class sets of the two keys. Determine the relation in the following order.
- If the two pitch-class sets are equal and the pitch classes of the tonics are also equal, it is same.
- If the two pitch-class sets are equal and the pitch classes of the tonics differ, it is relative.
- If the pitch-class sets differ and the pitch classes of the tonics are equal, it is parallel.
- If none of the above applies and f is 1 or -1, it is close.
- Otherwise it is distant.
Print "KEYDIST <tonic1> <mode1> <tonic2> <mode2> fifths=<f> common=<c> relation=<relation>". <f> is written with a leading "+" if positive, as 0 if 0, and with a leading "-" if negative.

[Output format]
- For each command, print only the lines defined in [Processing].
- Words within a line are separated as defined in [Processing] (all separators are a single space except the ", " of FINDKEY), with no spaces at the beginning or end of a line. Do not print empty lines. Every line ends with a newline (LF).
- Integers are written in decimal without extra leading zeros, and negative numbers have a leading "-" (except where [Processing] specifies a leading "+").
- Frequencies (f of FREQ, A of TUNING, f of PITCH) are written as the integer part in decimal without extra leading zeros (0 if less than 1), followed by "." and exactly two decimal digits. For example, write 8.18, 440.00, 12543.85. This does not depend on how the input is written; for example, the output for TUNING 0442 is TUNING 442.00.
- There are the following 19 error lines (the parts in < > are the strings exactly as written in the input).
  ERROR UNKNOWN COMMAND <command name>
  ERROR ARGUMENT COUNT
  ERROR BAD NOTE <word>
  ERROR BAD PITCH <word>
  ERROR BAD NUMBER <word>
  ERROR BAD FREQUENCY <word>
  ERROR BAD INTERVAL <word>
  ERROR BAD DIRECTION <word>
  ERROR BAD SCALE <word>
  ERROR BAD QUALITY <word>
  ERROR BAD INVERSION <word>
  ERROR BAD MODE <word>
  ERROR BAD NUMERAL <word>
  ERROR BAD SYMBOL <word>
  ERROR THEORETICAL KEY
  ERROR CANNOT SPELL
  ERROR CANNOT INVERT
  ERROR OUT OF RANGE
  ERROR UNNAMEABLE INTERVAL

[Constraints]
- 1 <= N <= 500
- The number of words on each line is from 1 to 16, and the length of each word is from 1 to 20.
- For FREQ in the test data, 100 * f computed exactly is at least 10^-6 away from every value of the form (integer + 0.5). For PITCH, x and 100 * (x - n) computed exactly are both at least 10^-6 away from every value of the form (integer + 0.5). Therefore, if the computation is done in double-precision floating point, small errors due to the order or method of computation do not affect the results.
- All other computations can be done with integers only.

[Example]
Input:
15
MIDI Cb4
NOTE 70
FREQ E4
PITCH 450
INTERVAL E4 C5
TRANSPOSE G4 M3 DOWN
SCALE D harmonic_minor
CHORD F 7 1
IDENTIFY G3 B3 E4
KEYSIG E major
PROGRESSION D major IV V7 I
ANALYZE G major Am7 D7 G
SPELL 63 E major
TRANSPOSE C4 M3 down
KEYSIG D# major

Output:
MIDI Cb4 59
NOTE 70 A#4 Bb4
FREQ E4 329.63
PITCH 450.00 A4 +39
INTERVAL E4 C5 m6 up semitones=8 simple=m6 class=imperfect
TRANSPOSE G4 M3 DOWN Eb4
SCALE D harmonic_minor D E F G A Bb C# steps=2,1,2,2,1,3,1
CHORD F7/A A C Eb F
IDENTIFY Em/G root=E quality=min inversion=1
KEYSIG E major sharps=4 F# C# G# D#
PROGRESSION D major 3
IV G G B D
V7 A7 A C# E G
I D D F# A
CADENCE authentic
ANALYZE G major ii7 V7 I
SPELL 63 E major D#4 7
ERROR BAD DIRECTION down
ERROR THEORETICAL KEY

In TRANSPOSE G4 M3 DOWN of this example, the position becomes that of E4, which is 2 less than that of G4, and the MIDI number is 67-4 = 63, so the result is Eb4 with alteration 63-64 = -1. In IDENTIFY G3 B3 E4, among the candidate sequence G3, B3, E4, no chord with root G or B matches, and min with root E matches. The pitch class of the bass G3 corresponds to chord interval 1 (m3), so inversion=1. In SPELL 63 E major, the pitch class of D# in the E major scale E F# G# A B C# D# is 3, so the note is D#4, and its degree label is 7. The fifths number of KEYSIG D# major is 2+7+0 = 9.
