[Overview]
Write a program that simulates paged virtual memory. It reads a sequence of commands from standard input and, for the memory accesses issued by several processes, simulates address translation through a TLB and page tables, frame allocation and page replacement on page faults, and write-back of dirty pages together with management of a swap area. There are 10 replacement policies, FIFO, LRU, LFU, NRU, AGING, CLOCK, ECLOCK (enhanced clock), WSCLOCK, RANDOM and OPT, and you can also choose whether the frames are shared by all processes (GLOBAL) or allocated per process (LOCAL). The program writes state dumps, various statistics, and comparisons that re-run the same access sequence with another policy or another number of frames to standard output.

[Input format]
The first line contains the number N of lines that follow. Each of the following N lines contains one command. Each line consists of one or more words separated by a single ASCII space; there are no spaces at the beginning or end of a line, and there are no empty lines. The command formats are as follows (< > denotes a value, and A|B denotes either A or B).

  SYSTEM <key>=<value> ...       (zero or more "key=value" pairs)
  PROCESS <pid> <page count>
  EXIT <pid>
  PROTECT <pid> <first> <last> RO|RW
  LOCK <pid> <first> <last>
  UNLOCK <pid> <first> <last>
  <pid> R|W <address>          (access line; R is a read, W is a write)
  LOOP <pid> R|W <start address> <interval> <length> <repeats>
  RAND <pid> <lower address> <upper address> <count> <seed> <write rate>
  TRACE ON|OFF
  SUMMARY
  FRAMES
  PAGETABLE <pid>
  TLB
  SWAP
  CLEAN
  COMPARE
  CURVE <policy name> <lo> <hi>
  EAT <a> <b> <c>
  TIMELINE <w>
  WSET <pid> <w>
  HOT <pid> <k>

A line that begins with a digit is an access line. Below, the R|W part of an access line and of LOOP is written <op>. An address (<address>, <start address>, <lower address>, <upper address>) is "0x" followed by 1 to 6 hexadecimal digits (0-9 and uppercase A-F), and it may have leading zeros, as in "0x0040". All other numbers are unsigned decimal integers without extra leading zeros. The range of each value is given in [Constraints].

[Processing]
== Notation ==
a div b is the quotient of a divided by b (the fractional part truncated), and a mod b is its remainder. This task uses them only with a >= 0 and b > 0. The "time" is an integer kept per simulation; it increases by 1 on every valid access.

== Overall flow ==
Process the commands in order from the first. A "simulation" starts with a valid SYSTEM line and lasts until just before the next SYSTEM line (whether valid or not) or until the end of the input. There is no simulation before the first valid SYSTEM line, nor from an invalid SYSTEM line up to the next valid SYSTEM line. When there is no simulation, every command other than SYSTEM (including each access line generated by LOOP and RAND, one line each) only outputs the single line "ERROR no system" and does nothing else.

== LOOP and RAND ==
A LOOP line or a RAND line is treated exactly as if the access lines it generates were written in order at its position. The generated lines do not depend on the state of the simulation and are determined as follows.
- LOOP <pid> <op> <start address s> <interval d> <length n> <repeats r>: generates the n access lines "<pid> <op> <address>" whose addresses are s, s + d, s + 2*d, ..., s + (n - 1)*d, in this order, and repeats that r times (n*r lines in total).
- RAND <pid> <lower lo> <upper hi> <count c> <seed x> <write rate w>: while updating the value x by "x <- (48271*x) mod 2147483647", repeats the following steps c times to generate c access lines. First update x once and let the address be lo + (x mod (hi - lo)). Then update x once more; the op is W if x mod 100 < w, and R otherwise.

== SYSTEM ==
A SYSTEM line ends the current simulation, if any, and specifies the settings of a new simulation. The keys, their valid values and their values when omitted are as follows.
  page    Page size (bytes). A power of 2 from 16 to 4096 inclusive. Default 256.
  frames  Number of frames of physical memory. From 1 to 16 inclusive. Default 4.
  tlb     Number of TLB entries. From 1 to 8 inclusive. Default 4.
  sets    Number of TLB sets. From 1 to 8 inclusive. Default 1.
  policy  Replacement policy. One of FIFO, LRU, LFU, NRU, AGING, CLOCK, ECLOCK, WSCLOCK, RANDOM, OPT. Default FIFO.
  scope   Scope of frame allocation. GLOBAL or LOCAL. Default GLOBAL.
  asid    Whether TLB entries are distinguished per process. ON or OFF. Default OFF.
  tick    Interval of timer interrupts (in number of valid accesses). From 0 to 1000 inclusive; 0 means no timer interrupts. Default 0.
  tau     Width of the WSCLOCK working-set window. From 1 to 1000 inclusive. Default 8.
  seed    Initial value of the random number generator of the RANDOM policy. From 1 to 2147483646 inclusive. Default 1.
Examine the pairs from left to right, checking each pair in the following order, and for the first error found output the corresponding line below.
- The key is not one of the 10 keys above: "ERROR unknown key <key>"
- The key was already specified earlier on the same line: "ERROR duplicate key <key>"
- The value is not one of the valid values above: "ERROR invalid <key>"
If no pair has an error, fill in the default values for the omitted keys. Then, if tlb is not divisible by sets, output "ERROR invalid sets". If any of the errors above occurred, no new simulation starts.
If there is no error, start a new simulation and output the values of all keys in the format of the SYSTEM line in [Output format]. The initial state is as follows: there are no processes, all frames are free, the TLB and the swap area are empty, the time and all counters are 0, the trace is OFF, all clock hands are 0, and the state of the RANDOM generator is the value of seed.

== Processes ==
PROCESS <pid> <page count> declares a process. The virtual address space of the process consists of the addresses from 0 up to but not including "page count*page", and the page numbers run from 0 to "page count - 1". Right after declaration, none of the process's pages is in memory, none has a swap slot, their protection is RW, and they are not locked. All statistics of the process (number of valid accesses, faults, writebacks, segfaults, protfaults, peak) are 0. Check the following in order, output the first error that applies, and do not declare the process.
1. In this simulation, at least one access line (including access lines that resulted in an error) has already been processed: "ERROR processes are fixed"
2. pid has already been declared in this simulation (including processes that have exited): "ERROR duplicate process <pid>"
3. The page count is not between 1 and 256 inclusive: "ERROR invalid page count"
4. There are already 8 declared processes (including processes that have exited), or scope is LOCAL and the number of declared processes is already equal to frames: "ERROR too many processes"
When the declaration succeeds, nothing is output.

For the commands that specify a process (access lines, EXIT, PROTECT, LOCK, UNLOCK, PAGETABLE, WSET, HOT), check pid before any other check. If pid has not been declared in this simulation, output "ERROR unknown process <pid>"; if the process has exited, output "ERROR process <pid> exited"; and finish processing that line.

EXIT <pid> terminates the process. All frames that held pages of the process become free (nothing is written back even if M is 1), the TLB entries for those pages are deleted, and all swap slots held by pages of the process become free. The statistics are kept. The output is the EXIT line of [Output format].

PROTECT <pid> <first> <last> RO|RW, LOCK <pid> <first> <last> and UNLOCK <pid> <first> <last> change the attributes of the process's pages first through last (both inclusive). If first > last, or last >= the page count of the process, output "ERROR invalid page range" and change nothing. PROTECT sets the protection to RO (read-only) or RW (read-write), LOCK locks the pages, and UNLOCK unlocks them. These can also be applied to pages that are not in memory. Locking affects only how candidates are chosen for the replacement policy (described later). On success, nothing is output.

== Page attributes ==
Each page has the following attributes: whether it is in memory and, if so, its frame number; its swap slot (none, or a slot number); its protection; whether it is locked; the reference bit R; the modified bit M; load (the time it was loaded into memory); last (the time it was last used); uses (the number of times it has been used since it was loaded into memory); age (a counter from 0 to 255 inclusive); and whether it has ever received a valid access. The initial values of R, M, load, last, uses and age are 0.

== Access lines ==
For an access line "<pid> <op> <address>", after the pid check, check the following in order.
- address >= page count*page: output "SEGFAULT P<pid> <address>" and increase the process's segfaults by 1.
- op is W and the protection of the page with page number (address div page) is RO: output "PROTFAULT P<pid> <address>" and increase the process's protfaults by 1.
An access line that results in an error outputs this one error line even when the trace is OFF, and none of the following processing is done (the time does not advance, and the line is not used in deciding a process switch as described next). An access that did not result in an error is called a "valid access" and is processed by the following steps.
1. Increase the time by 1. The value after the increase is the time t of this access.
2. If the valid access processed immediately before in this simulation belongs to a different process, this is a process switch: increase switches by 1, and if asid is OFF, delete all TLB entries (if asid is ON, do not delete them).
3. Let the page number p = address div page and the offset = address mod page.
4. Look up the TLB. The TLB consists of sets sets (numbered from 0), and each set holds up to tlb div sets entries. An entry maps (process number, page number) to a frame number, and the entry for page number p is placed in set p mod sets. Within each set, the order in which the entries were used is maintained.
  (a) If the set has an entry for (pid, p), it is a TLB hit. Increase tlbhits by 1 and make that entry the most recently used one.
  (b) Otherwise it is a TLB miss. If the page is in memory, it is a page table hit. Otherwise it is a page fault, handled as described later. In either case, finally add the entry for (pid, p) to the set as the most recently used one. If the set is full before adding, delete the least recently used entry in the set.
5. Set the page's R to 1, set M to 1 if op is W, set last to t, increase uses by 1, and record that the page has received a valid access. The physical address is "frame number*page + offset".
6. If tick > 0 and t is divisible by tick, perform a timer interrupt: for every page in memory, replace age with "age div 2 + 128*R" and set R to 0.

== Page faults ==
On a page fault, increase the process's faults by 1. If the page has a swap slot, it is a SWAPIN (read from the swap area); otherwise it is a ZERO (allocation of a zero-filled page); increase the corresponding count by 1. Next, decide the frame to load the page into as follows.
- When scope is GLOBAL: if there is a free frame, use the free frame with the smallest number. Otherwise, choose one frame with the replacement policy, taking all frames as candidates.
- When scope is LOCAL: each process has an allocation quota. Let n be the number of declared processes (including processes that have exited), q = frames div n and r = frames mod n; then the first r processes in increasing order of pid have quota q + 1, and the remaining processes have quota q. If the number of pages the faulting process has in memory is less than its quota, use the free frame with the smallest number (in this case a free frame always exists). If it is at least the quota, choose one frame with the replacement policy, taking as candidates only the frames that hold pages of that process.
Before passing the candidates to the replacement policy, remove from them the frames that hold locked pages. However, if removing them would leave no candidates, do not remove them and pass all the candidates.
When the replacement policy has chosen a frame, evict the page loaded there (the victim page). The victim page is now not in memory, and its TLB entry, if any, is deleted. If the victim page's M is 1, write it back (described later).
Finally, load the page into the decided frame and set load to t and uses, M and age to 0 (R, M, last and uses are updated in step 5 that follows). If the number of pages the process has in memory exceeds peak, set peak to that number.

== Write-back and the swap area ==
The swap area is a sequence of slots numbered from 0, with no upper limit on the number of slots. When a page is written back, increase by 1 both the writebacks of the process that owns the page and the number of write-backs of the whole simulation, and set the page's M to 0. If the page does not have a swap slot, assign it the unused slot with the smallest number. The page keeps the assigned slot until its process exits (even if the page is later read back into memory).
Write-backs happen only in these 3 cases: when a victim page whose M is 1 is evicted, in the WSCLOCK scan, and in CLEAN.

== Replacement policies ==
Choose one of the candidate frames by the following rules. Below, the attributes of a frame mean the attributes of the page loaded in it.
- FIFO: the one with the smallest load.
- LRU: the one with the smallest last.
(For FIFO and LRU, no two candidates ever have the same value.)
- LFU: the one with the smallest uses. If several are tied, the one among them with the smallest load.
- NRU: the one with the smallest 2*R + M. If several are tied, the one among them with the smallest frame number.
- AGING: the one with the smallest age. If several are tied, the one among them with the smallest load.
- RANDOM: update the random state x once by "x <- (48271*x) mod 2147483647", and take the (x mod number of candidates)-th candidate (the first one being the 0th) when the candidates are sorted in increasing order of frame number. The random state carries over within the simulation.
- OPT: the one whose page (matching both the process number and the page number) first appears farthest away in the reference sequence described later, after the current access line. A page that does not appear afterwards is considered farther than any position. If several are tied, the one among them with the smallest frame number.
- CLOCK, ECLOCK and WSCLOCK use a "clock hand". A hand holds a frame number as its value; if scope is GLOBAL there is one hand for the whole simulation, and if LOCAL there is one hand per process (all initially 0); with LOCAL, the hand of the faulting process is used. With h the value of the hand, the sequence of the candidates sorted in increasing order of (frame number - h + frames) mod frames is called the "circular order". When frame v is chosen, set the value of the hand used to (v + 1) mod frames. A hand moves only when a frame is chosen by one of these 3 policies.
  CLOCK: examine the frames in circular order; if R is 1, set R to 0 and move on to the next; if R is 0, choose it. If none has been chosen after examining all of them, examine them again in the same way from the start of the circular order.
  ECLOCK: (1) Examine in circular order; if there is one with R 0 and M 0, choose the first such one. No bits are changed in this stage. (2) Otherwise examine in circular order; if R is 0 and M is 1, choose it; otherwise set R to 0 and move on to the next. (3) If none has been chosen after examining all of them in (2), start again from (1).
  WSCLOCK: examine the frames in circular order exactly once. If R is 1, set R to 0, set last to t, and move on to the next. If R is 0 and t - last > tau: if M is 0, choose it and stop examining; if M is 1, write the page back (without evicting it) and move on to the next. Otherwise move on to the next. If none has been chosen after examining all of them, choose the first one in circular order whose M is 0 (including those written back during this scan), and if there is none, choose the first one in circular order.

== OPT reference sequence ==
In normal processing, the reference sequence is all access lines belonging to the simulation (including lines generated by LOOP and RAND, and including lines that result in an error), in input order. The page referenced by each line is (pid, address div page). The reference sequence in a re-run is described in the next item.

== Re-runs (COMPARE and CURVE) ==
COMPARE and CURVE take the sequence of the "valid accesses", "successful EXITs", "CLEANs" and "successful LOCKs and UNLOCKs" that have occurred so far in the current simulation, in the order they occurred, re-execute it from the beginning in a separate new simulation, and compute statistics. That simulation has the same settings as the current one (page, tlb, sets, scope, asid, tick, tau, seed) except that the replacement policy and the number of frames are changed to the specified ones, and it starts in the state where all processes declared in the current simulation have been declared with the same page counts. All re-executed accesses are valid, so protection has no effect. The OPT reference sequence in a re-run is just the re-executed valid accesses in order. Therefore, when the current policy is OPT and access lines still remain later in the input, the OPT result of COMPARE may differ from SUMMARY. A re-run outputs nothing and does not change the state of the current simulation at all.

== Display and analysis commands ==
- TRACE ON|OFF: turns the trace ON or OFF. Outputs nothing. While it is ON, one trace line is output for each valid access, followed by one timer line if a timer interrupt occurred.
- SUMMARY, FRAMES, PAGETABLE <pid>, TLB, SWAP: output the current state as described in [Output format].
- CLEAN: in increasing order of frame number, writes back every page in memory whose M is 1 (without evicting it).
- COMPARE: re-runs with each of the 10 policies, with the number of frames equal to the current frames.
- CURVE <policy name> <lo> <hi>: if the policy name is not one of the 10 policies, output "ERROR unknown policy". Otherwise, if 1 <= lo <= hi <= 16 does not hold, or scope is LOCAL and lo is less than the number of declared processes (including processes that have exited), output "ERROR invalid frame range". Otherwise, re-run with the specified policy for each number of frames lo, lo + 1, ..., hi.
- EAT <a> <b> <c>: computes the effective access time. a is the time to look up the TLB, b is the time for one memory read, and c is the time for one disk read or write. With A the number of valid accesses, H the tlbhits, S the number of SWAPINs and W the number of write-backs (all of them values for the whole simulation), the total time is T = a*A + b*(2*A - H) + c*(S + W).
- TIMELINE <w>: if w < 1, output "ERROR invalid window". Otherwise, divide the valid accesses, in order from time 1, into intervals of w accesses each, and for each interval count the accesses that were page faults. The last interval may contain fewer than w accesses.
- WSET <pid> <w>: if w < 1, output "ERROR invalid window". Otherwise, take the page numbers referenced by the last w valid accesses of the process (all of them if there are fewer than w), remove duplicates, and sort them in increasing order.
- HOT <pid> <k>: if k < 1, output "ERROR invalid count". Otherwise, sort the pages referenced by the process's valid accesses in decreasing order of the number of references (ties in increasing order of page number), and take the first k of them at most.

[Output format]
All output consists of ASCII characters, with no spaces at the end of any line, and every line ends with a newline. No empty lines are output. In the formats below, replace the < > parts with values and output all other characters as they are.
- Integers are written in decimal without extra leading zeros.
- Addresses (including physical addresses) are written as "0x" followed by uppercase hexadecimal without extra leading zeros (0 is "0x0"). Even if an input address has leading zeros, they are not written in the output.
- A ratio X/Y is written, if Y > 0, as "<V div 100>.<V mod 100 in 2 digits>%" with V = (10000*X) div Y, and if Y = 0, as "0.00%" (for example, 2/3 is "66.66%" and 1/2000 is "0.05%"). "In 2 digits" means that a value less than 10 is written as 2 characters with one 0 in front (the same applies to EAT).

The output of each command is as follows.
- SYSTEM (on success): "SYSTEM page=<page> frames=<frames> tlb=<tlb> sets=<sets> policy=<policy> scope=<scope> asid=<asid> tick=<tick> tau=<tau> seed=<seed>"
- Trace line: "t=<t> P<pid> <op> <address> page=<p> frame=<frame number> phys=<physical address> <result>". <result> is "TLBHIT" for a TLB hit, "HIT" for a page table hit, and "FAULT ZERO" or "FAULT SWAPIN" for a page fault. When a page fault evicted a victim page, append " evict=P<process number of the victim page>:<page number of the victim page>", and if the victim page was also written back when it was evicted (its M was 1 at eviction; a write-back during the WSCLOCK scan does not count), append " writeback" after that. If a process switch occurred on this access, append " switch" at the end of the line.
- Timer line: "t=<t> tick"
- EXIT: "EXIT P<pid> freed=<number of frames freed> slots=<number of slots freed>"
- SUMMARY: outputs two or more lines.
  Line 1: "SUMMARY policy=<policy> scope=<scope> time=<current time>"
  Line 2: "total faults=<number of page faults> zero=<number of ZEROs> swapin=<number of SWAPINs> faultrate=<ratio of number of page faults/time> tlbhits=<tlbhits> tlbrate=<ratio of tlbhits/time> writebacks=<number of write-backs> switches=<switches> segfaults=<sum of the segfaults of all processes> protfaults=<sum of the protfaults of all processes>"
  Then, one line for each declared process (including processes that have exited) in increasing order of pid: "P<pid> accesses=<number of valid accesses of the process> faults=<faults> writebacks=<writebacks> segfaults=<segfaults> protfaults=<protfaults> resident=<number of pages in memory> peak=<peak>". If scope is LOCAL, append " quota=<quota>" at the end of the line, and if the process has exited, further append " exited" at the end of the line.
- FRAMES: the first line is "FRAMES used=<number of frames holding a page>/<frames>". Then one line per frame in increasing order of frame number: "<frame number> free" if it is free, otherwise "<frame number> P<pid>:<p> R=<R> M=<M> load=<load> last=<last> uses=<uses> age=<age>" (with " locked" at the end of the line if the page is locked). Only when policy is CLOCK, ECLOCK or WSCLOCK, output one more line at the end: "hand=<hand value>" if scope is GLOBAL, and if LOCAL, a line consisting of "hand" followed by " P<pid>=<hand value>" for each declared process (including processes that have exited) in increasing order of pid.
- PAGETABLE: the first line is "PAGETABLE P<pid> pages=<page count> resident=<number of pages in memory>". Then, one line for each page that has ever received a valid access, in increasing order of page number: "<p> frame=<frame number> R=<R> M=<M>" if it is in memory, "<p> swap=<slot number>" if it is not in memory and has a swap slot, and "<p> zero" otherwise. If the protection is RO, append " RO" at the end of the line, and if the page is locked, further append " locked" at the end of the line.
- TLB: the first line is "TLB used=<total number of entries over all sets>/<tlb> sets=<sets>". Then one line per set in increasing order of set number: "set <set number>:" followed by the entries of that set, from the most recently used, each in the form " P<pid>:<p>-><frame number>" (if the set has no entries, the line is just "set <set number>:").
- SWAP: the first line is "SWAP used=<number of slots in use>". Then one line for each slot in use, in increasing order of slot number: "<slot number> P<pid>:<p>".
- CLEAN: "CLEAN written=<number of pages written back>"
- COMPARE: the first line is "COMPARE accesses=<number of valid accesses> frames=<frames>". Then one line per policy in the order FIFO, LRU, LFU, NRU, AGING, CLOCK, ECLOCK, WSCLOCK, RANDOM, OPT: "<policy name> faults=<number of page faults> writebacks=<number of write-backs> tlbhits=<tlbhits>" (all of them results of the re-run with that policy). Finally, output a line consisting of "ranking" followed by the 10 policy names, sorted in increasing order of the number of page faults, ties in increasing order of the number of write-backs, and remaining ties in the order listed above, each preceded by a single space.
- CURVE: the first line is "CURVE <policy name> frames=<lo>..<hi>". Then one line for each number of frames k = lo, ..., hi in this order: "F=<k> faults=<number of page faults>". If k > lo and the number of page faults is greater than that of the previous line (number of frames k - 1), append " ANOMALY" at the end of the line.
- EAT: if A > 0, "EAT accesses=<A> total=<T> average=<V div 100>.<V mod 100 in 2 digits>" (where V = (100*T) div A); if A = 0, "EAT accesses=0".
- TIMELINE: one line consisting of "TIMELINE window=<w>" followed by the number of page faults of each interval, in interval order, each preceded by a single space. If there are no valid accesses, the line is just "TIMELINE window=<w>".
- WSET: one line consisting of "WSET P<pid> window=<w> size=<number of pages>" followed by the page numbers in increasing order, each preceded by a single space.
- HOT: one line consisting of "HOT P<pid>" followed by " <page number>:<number of references>" for each page found, in order.
- PROCESS, PROTECT, LOCK, UNLOCK (on success) and TRACE output nothing.
- An error outputs the one line "ERROR ...", "SEGFAULT ..." or "PROTFAULT ..." given in [Processing].

[Constraints]
- 1 <= N <= 500. The total number of access lines after expanding LOOP and RAND is at most 3000.
- Each pair on a SYSTEM line has the form "key=value" and contains exactly one "=". A key consists of 1 to 10 lowercase English letters. The values of page, frames, tlb, sets, tick, tau and seed are decimal integers of 1 to 10 digits, and the values of policy, scope, asid and of unknown keys consist of 1 to 10 uppercase English letters or digits.
- The pid of PROCESS is from 1 to 99 inclusive, and the page count is from 0 to 999 inclusive. The pid of the other commands is from 1 to 99 inclusive.
- first and last of PROTECT, LOCK and UNLOCK are from 0 to 999 inclusive.
- The interval of LOOP is from 0 to 4096 inclusive, the length and repeats are at least 1, and length*repeats <= 500. The generated addresses are at most 0xFFFFFF.
- For RAND, lo < hi <= 0xFFFFFF, 1 <= count <= 500, 1 <= seed <= 2147483646, and 0 <= write rate <= 100.
- The policy name of CURVE consists of 1 to 10 uppercase English letters, and lo and hi are from 0 to 99 inclusive.
- For EAT, 1 <= a <= 1000, 1 <= b <= 1000, and 1 <= c <= 100000.
- w and k of TIMELINE, WSET and HOT are from 0 to 10000 inclusive.
- There are no lines of any form other than those described here. Every integer that appears during computation is less than 2^53.
