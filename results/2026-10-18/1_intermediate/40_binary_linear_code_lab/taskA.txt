[Overview]
Write an experimental program that works with linear block codes over the binary field GF(2) (hereafter simply called codes). The program reads a sequence of commands from standard input, executes them in order, and writes the results to standard output. The commands define codes by generator matrices or parity-check matrices; generate Hamming codes, simplex codes, repetition codes, parity-check codes, Reed-Muller codes and cyclic codes; construct new codes by dual, extension, puncturing, shortening and so on; compute properties such as the minimum distance, the weight distribution, the covering radius, the strength against burst errors and the number of trellis states; convert to systematic form; encode; decode by syndromes; correct erasures; run interleaving experiments; compute and check CRCs; factor x^n - 1; transform weight distributions by the MacWilliams identity; and compute code bounds.

[Input format]
The input consists of the following lines in this order.
- The first line is the number of commands N.
- Then N commands follow, one per line.
A command line consists of one or more words separated by single ASCII spaces, with no whitespace at the start or end of the line. The first word is the command name and the remaining words are its arguments. There are the following 41 command formats (everything other than the command name is the name of an argument).

HAMMING name r
SIMPLEX name r
REPETITION name n
PARITY name n

AUGMENT name a
EXPURGATE name a
PERMUTE name a q...
DIRECTSUM name a b
UUV name a b

LIST

SHOW a
INFO a
SYSTEMATIC a

An argument written with a trailing ... in the format (v..., q..., u..., c...) stands for one or more arguments of that form. The maximum number of them is 24 for v... of GEN and PCHECK and for q... of PERMUTE, 8 for u... of INTERLEAVE, and 25 for c... of MACWILLIAMS. For example, PERMUTE has at least 3 and at most 26 arguments, and the third and all later ones are of the form q.
Arguments are written as follows.
- name, a and b are code names. A code name is a string of 1 to 8 characters that starts with a letter (A-Z, a-z) and consists only of letters and digits (0-9). Uppercase and lowercase letters are distinguished (H7 and h7 are different code names).
- r, n, m, i, t, s, l, d, q and c are number words. A number word is a string of 1 to 4 characters consisting only of digits, whose first character is not 0 when it has 2 or more characters. Its value is the value read as a decimal number. For example, 0, 7 and 2576 are number words, and 07, -1, +3 and 10000 are not.
- v, g, u and w are bit-string words. A bit-string word is a string of 1 to 30 characters consisting only of 0 and 1.
- x is an erasure word. An erasure word is a string of 1 to 30 characters consisting only of 0, 1 and ? (the ASCII question mark).

[Processing]
Process the commands one at a time in input order, writing the output of each immediately. In the descriptions below, a part of an output line such as <n> is replaced by its value, and every other part is written exactly as shown.

1. Notation and terms
- A bit string of length n is treated as a vector of length n. The j-th bit of a bit string is its j-th character from the left (counting from 1), and the j-th bit of a vector v is written v_j. The length of a bit string v is written |v|.
- The sum u + v of two vectors u and v of the same length is the vector whose j-th bit, for each j, is the exclusive OR of u_j and v_j (0 if they are equal, 1 if they differ). The vector whose bits are all 0 is called the zero vector, and the sum of no vectors (an empty sum) is the zero vector.
- The weight wt(v) of a vector v is the number of 1s in v.
- The inner product of two vectors u and v of the same length is the remainder (0 or 1) of dividing by 2 the number of j for which u_j and v_j are both 1.
- For two bit strings of the same length, compare them from the start; the one whose first differing character is 0 is the smaller. This order is called lexicographic order (it is the same as the order of their values read as binary numbers).
- The space spanned by a sequence of vectors is the set of all vectors obtained by choosing some (possibly none) of the vectors in the sequence and adding them.
- A matrix is treated as a sequence of vectors (rows) of the same length arranged from top to bottom. The j-th bit of row i is called the (i, j) entry, and the j-th bits of the rows arranged from top to bottom are called column j.
- A bit string b_1 b_2 ... b_m represents the polynomial b_1 x^(m-1) + b_2 x^(m-2) + ... + b_m with coefficients 0 or 1 (the leftmost bit is the highest-degree coefficient). The degree of a polynomial is the largest exponent of a term whose coefficient is 1. The sum of polynomials is the coefficient-wise exclusive OR, and the product is the ordinary polynomial product with each coefficient replaced by its remainder modulo 2. In this arithmetic, x^n - 1 and x^n + 1 are the same polynomial.
- The remainder a(x) mod g(x) of dividing a polynomial a(x) by a polynomial g(x) of degree d (d >= 1) is the polynomial r(x) of degree less than d (it may be 0) such that a(x) = q(x)g(x) + r(x) for some polynomial q(x); this q(x) is called the quotient. The remainder can be obtained by repeatedly adding g(x)*x^(e - d) to a(x) (where e is the degree of a(x)) as long as the degree of a(x) is d or more. The remainder is written as a bit string of length d, including leading 0s.
- The binomial coefficient C(x, y) is the number of ways to choose y items out of x when 0 <= y <= x, and 0 when y < 0 or y > x. floor(x) is the largest integer not greater than x, and ceil(x) is the smallest integer not less than x.

2. Codes and the registry
- A code is a tuple of a length n, a dimension k, a generator matrix G, a parity-check matrix H and an encoding method. G is a matrix of k rows and H is a matrix of n - k rows, and every row has length n. The elements of the space spanned by the rows of G are called codewords. For the codes created by the commands below, there are exactly 2^k codewords, and they are exactly the vectors of length n whose inner product with every row of H is 0.
- The encoding method is matrix or polynomial. A polynomial code has a generator polynomial g(x).
- The length and dimension of a code always satisfy 1 <= k <= 12 and 1 <= n - k <= 12 (hence 2 <= n <= 24).
- The program keeps as its state a collection of pairs of a code name and a code (hereafter the registry). Initially the registry is empty. A code name in the registry is called "defined", and the code with that name is referred to simply by the name (for example "code a"). The length, dimension, generator matrix and parity-check matrix of code a are written n_a, k_a, G_a and H_a. In the description of a command that targets code a, they are also written simply n, k, G and H.

3. Basic procedures
(a) Extracting a basis: examine the sequence of vectors v(1), v(2), ..., v(m) from the front, and keep only those that are not in the space spanned by the vectors kept so far (the zero vector is never kept). The kept vectors in their original order are written B(v(1), ..., v(m)). For example, B(1100, 0110, 1010, 0000) is 1100, 0110.
(b) Reduced row echelon form: from a sequence of vectors of length n, obtain a sequence of rows R(1), ..., R(rho) and column numbers c(1) < c(2) < ... < c(rho) by the following procedure. rho is called the rank of the sequence. First take the whole sequence as the working matrix and let p = 1. For column numbers c = 1, 2, ..., n in this order, find the first row at or after row p whose c-th bit is 1. If there is none, go to the next column. If there is one, swap that row with row p, add row p to every row other than row p whose c-th bit is 1, set c(p) = c, and increase p by 1. After reaching the end, let rho = p - 1, and let rows 1 to rho of the working matrix be R(1), ..., R(rho).
(c) Basis of the null space: apply (b) to a sequence of vectors of length n, and call the column numbers that are none of c(1), ..., c(rho) free columns. For each free column f, build the vector whose f-th bit is 1, whose c(q)-th bit equals the f-th bit of R(q) for each q = 1, ..., rho, and whose other bits are 0. The sequence of these n - rho vectors in increasing order of f is written N(original sequence). The space spanned by N(original sequence) is the set of all vectors whose inner product with every vector of the original sequence is 0.

4. Command checks and errors
For each command, check (1) to (5) below in order and handle the first one that applies. A command that outputs an error does not change the registry at all and outputs only the single error line.
(1) The command name is not in the formats (uppercase and lowercase letters are distinguished): error: unknown command <command name>
(2) The number of arguments differs from the format, or an argument does not follow the rules in [Input format]: error: bad arguments
(3) A code name that is not defined appears in a position a or b of the format: with the code name of the earliest such argument as <code name>, error: no code <code name>. Whether name in the format is defined does not matter.
(4) Perform the value checks given in the description of each command in 5. to 9., in the order of the description, and output the first error that applies.
(5) Process the command as described in 5. to 9.
The error lines used in the value checks are as follows.
- error: bad parameter: a numeric value or a polynomial is outside the allowed range.
- error: bad length: the length of a bit string or the number of values does not match.
- error: bad position: a position is out of range.
- error: bad permutation: not a valid permutation.
- error: not a divisor: the generator polynomial does not divide x^n - 1.
- error: bad dimension <n> <k>: the length n and dimension k of the code to be created fail to satisfy at least one of 1 <= k <= 12 and 1 <= n - k <= 12.
- error: too large: the standard array is too large.
- error: bad burst: the range of the burst error is invalid.

5. Commands that define codes
Each of the 18 commands from GEN to PRODUCT builds one code from its arguments and puts it into the registry under the name name. Determine the length n and G as given in the description of each command (the number of rows of G is k), and after the value checks given in the description, perform the dimension check (if 1 <= k <= 12 and 1 <= n - k <= 12 are not both satisfied, error: bad dimension <n> <k>). If the checks pass and name is already defined, replace that code with the new code and output redefined <name> n <n> k <k>; otherwise output defined <name> n <n> k <k>. The new code is built from the codes as they were before the registry is changed (for example, DUAL A A replaces code A with its dual code).
For commands whose description does not mention H, H = N(G), and for commands whose description does not mention the encoding method, the encoding method is matrix. For DIRECTSUM, UUV and PRODUCT, k is k_a + k_b, k_a + k_b and k_a * k_b respectively (the dimension check may be done with n and k alone before building G).
- GEN name v...: if the lengths of v... are not all equal, error: bad length. Let n be that length, and G = B(v...).
- PCHECK name v...: if the lengths of v... are not all equal, error: bad length. Let n be that length, H = B(v...) and G = N(H).
- HAMMING name r: if r < 2 or r > 4, error: bad parameter. Let n = 2^r - 1. For i = 1, ..., r, let h(i) be the vector whose j-th bit, for each j = 1, ..., n, is the i-th digit from the left when j is written as an r-digit binary number (including leading 0s). H is the matrix of h(1), ..., h(r) in this order, and G = N(H). For example, for r = 2, h(1) = 011 and h(2) = 101.
- SIMPLEX name r: if r < 2 or r > 4, error: bad parameter. Let n = 2^r - 1, and G is the matrix of h(1), ..., h(r) (the same as in HAMMING) in this order.
- REPETITION name n: if n < 2 or n > 24, error: bad parameter. G is a single row of n 1s.
- PARITY name n: if n < 2 or n > 24, error: bad parameter. G has n - 1 rows, and row i (i = 1, ..., n - 1) has 1 in bit i and bit n and 0 in the other bits.
- RM name r m: if m < 1, m > 4 or r > m, error: bad parameter. n = 2^m and G = M(r, m). Here M(x, y) (0 <= x <= y) is a sequence of vectors of length 2^y defined as follows. If x = 0, it is a single row of 2^y 1s. If x >= 1, it consists first of, for each row z of M(min(x, y - 1), y - 1) in order, the row z followed by z, and then, for each row z of M(x - 1, y - 1) in order, the row of 2^(y-1) 0s followed by z.
- CYCLIC name n g: if n < 2, n > 24, the first character of g is 0, |g| < 2 or |g| > n, error: bad parameter. Let g(x) be the polynomial represented by g and d = |g| - 1 its degree. If (x^n + 1) mod g(x) is not 0, error: not a divisor. Let k = n - d. G has k rows, and row i is the concatenation of i - 1 0s, g and k - i 0s in this order. H has d rows, and its column j (j = 1, ..., n), read from top to bottom, is the bit string of length d representing x^(n-j) mod g(x). The encoding method is polynomial and the generator polynomial is g(x).
- DUAL name a: n = n_a, G = H_a and H = G_a.
- EXTEND name a: let n = n_a + 1. G is G_a with a 1 appended to each row whose weight is odd and a 0 appended to each row whose weight is even.
- PUNCTURE name a i: if i < 1 or i > n_a, error: bad position. Let n = n_a - 1, and G = B(the sequence of the rows of G_a with bit i removed from each).
- SHORTEN name a i: if i < 1 or i > n_a, error: bad position. Let n = n_a - 1. If G_a has rows whose i-th bit is 1, remove the topmost such row z, and add z to each remaining row whose i-th bit is 1 (the order of the rows is unchanged). If there is no such row, keep G_a as it is. G is the resulting sequence with bit i removed from each row.
- AUGMENT name a: n = n_a and G = B(the rows of G_a, the vector whose bits are all 1).
- EXPURGATE name a: let n = n_a. If G_a has rows of odd weight, G is obtained by removing the topmost such row z and adding z to each remaining row of odd weight (the order of the rows is unchanged). If there is no such row, G = G_a.
- PERMUTE name a q...: let q(1), ..., q(t) be the values of q... from the front. If t != n_a, or q(1), ..., q(t) is not an arrangement of 1, ..., n_a with each appearing exactly once, error: bad permutation. Let n = n_a. G is G_a with each row z replaced by the vector whose j-th bit is the q(j)-th bit of z (j = 1, ..., n).
- DIRECTSUM name a b: let n = n_a + n_b. G consists first of each row of G_a followed by n_b 0s, in order, and then of n_a 0s followed by each row of G_b, in order.
- UUV name a b: if n_a != n_b, error: bad length. Let n = 2 * n_a. G consists first of, for each row z of G_a in order, z followed by z, and then of n_a 0s followed by each row of G_b, in order.
- PRODUCT name a b: let n = n_a * n_b. G consists of, for every pair of a row x of G_a and a row y of G_b, the row whose bit (i - 1) * n_b + j (1 <= i <= n_a, 1 <= j <= n_b) is "1 if x_i and y_j are both 1, otherwise 0". The rows are arranged so that pairs whose x is higher in G_a come first, and for the same x, pairs whose y is higher in G_b come first.

6. Registry operations and display
- LIST: output codes <number of defined code names> on the first line, and then one line <code name> n <n> k <k> encoder <encoding method> for each defined code name. The code names are sorted in ASCII lexicographic order (compare character by character by ASCII code from the start; when one is a prefix of the other, the shorter comes first).
- DELETE a: remove code a from the registry and output deleted <a>.
- SHOW a: output code <a> n <n> k <k> encoder <encoding method> on the first line. If the encoding method is polynomial, then output poly g <generator polynomial> h <check polynomial>. The generator polynomial is the bit string of length n - k + 1 representing g(x), and the check polynomial is the bit string of length k + 1 representing the quotient of x^n + 1 divided by g(x). Then output each row of G from top to bottom as G <row>, and each row of H from top to bottom as H <row>, one per line.

7. Commands that examine code properties
- INFO a: output info <a> n <n> k <k> rate <p>/<q> d <d> t <t> perfect <yes or no> mds <yes or no> cyclic <c>.
  - p/q is k/n as a reduced fraction.
  - d is the minimum distance (the minimum weight of a codeword other than the zero vector), and t = floor((d - 1)/2).
  - perfect is yes if C(n, 0) + C(n, 1) + ... + C(n, t) = 2^(n-k).
  - mds is yes if d = n - k + 1.
  - If, for every row z of G, the vector z_2 z_3 ... z_n z_1 obtained by moving the first bit of z to the end is a codeword (in this case the same holds for every codeword, and the code is a cyclic code), c is the bit string obtained by removing all leading 0s from the codeword other than the zero vector that has the largest number of leading 0s (it is uniquely determined). Otherwise c is no.
- SYSTEMATIC a: transform G into systematic form by elimination with column swaps. Let the working matrix M be a copy of G, and let the column arrangement pi = (pi(1), ..., pi(n)) be (1, 2, ..., n). For r = 1, 2, ..., k in this order, do (i) to (iii) below.
  (i) If the r-th bit is 0 in every row from row r to row k of M, choose the smallest c (c > r) such that the c-th bit of some row among rows r to k is 1, swap the r-th bit and the c-th bit in every row of M, and swap pi(r) and pi(c) (such a c always exists).
  (ii) Swap the first row at or after row r of M whose r-th bit is 1 with row r.
  (iii) Add row r to every row of M other than row r whose r-th bit is 1.
  At the end, bits 1 to k of row i of M have a 1 only in bit i. pi(j) tells which column of G the transformed column j was. Output systematic <a> perm <pi(1)> <pi(2)> ... <pi(n)> on the first line, and then each row of M from top to bottom as G <row>. Then, for j = 1, ..., n - k in this order, output as H <row> the bit string of length k obtained by reading column k + j of M from top to bottom, followed by the vector of length n - k whose only 1 is bit j.
- WEIGHTS a: compute, for i = 0, 1, ..., n, the weight distribution A_i of the code (the number of codewords of weight i) and the weight distribution B_i of the dual code (the number of vectors of weight i in the space spanned by the rows of H). B_i can also be computed by the MacWilliams identity B_i = (A_0 K_i(0) + A_1 K_i(1) + ... + A_n K_i(n)) / 2^k (the division is always exact). Here K_i(x) is the value of the Krawtchouk polynomial K_i(x) = sum_{y=0}^{i} (-1)^y C(x, y) C(n - x, i - y). Output the following 3 lines.
  weights <a> <list of A items>
  dual <a> <list of B items>
  duality <a> self-orthogonal <yes or no> self-dual <yes or no> formally-self-dual <yes or no>
  The list of A items consists of i:A_i (for example 3:7) for each i with A_i not 0, in increasing order of i, separated by single ASCII spaces. The list of B items is formed in the same way. self-orthogonal is yes if the inner product of every two rows of G (including a row with itself) is 0; self-dual is yes if self-orthogonal is yes and n = 2 * k; formally-self-dual is yes if A_i = B_i for every i.
- COVERING a: compute the covering radius rho (the maximum weight of the coset leaders over all syndromes; see 8.), let c_w be the number of syndromes whose coset leader has weight w for w = 0, 1, ..., rho, and output covering <a> radius <rho> leaders 0:<c_0> 1:<c_1> ... <rho>:<c_rho>.
- BURST a: for a vector v other than the zero vector, let j1 be the smallest j with v_j = 1 and j2 the largest such j; v is then called a burst of length j2 - j1 + 1. Compute D and E below and output burst <a> detect <D> correct <E>.
  - D is the largest integer D (D >= 0) such that no burst of length D or less is a codeword (its syndrome is not the zero vector). This is the minimum length of a codeword other than the zero vector viewed as a burst, minus 1.
  - E is the largest integer E (E >= 0) such that the syndromes (see 8.) of the zero vector and of all bursts of length E or less are pairwise distinct.
- TRELLIS a: for i = 0, 1, ..., n, let rho1 be the rank of the sequence of vectors of length i obtained by taking bits 1 to i of each row of G, and rho2 the rank of the sequence of vectors of length n - i obtained by taking bits i + 1 to n of each row of G (the rank of a sequence of vectors of length 0 is 0), and let s_i = rho1 + rho2 - k. s_i means that the minimal trellis has 2^(s_i) states at depth i. Output trellis <a> profile <s_0> <s_1> ... <s_n> max <maximum of s_0, ..., s_n>.
- STDARRAY a: if n - k > 6 or k > 4, error: too large. Otherwise output stdarray <a> rows <2^(n-k)> columns <2^k> on the first line. Then sort all bit strings s of length n - k (syndromes) in increasing order of the weight of the coset leader L(s) (see 8.), and for equal weights in lexicographic order of L(s), and output one line for each s in that order. The line is <s>: followed by L(s) + c(1), L(s) + c(2), ..., L(s) + c(2^k), each preceded by a single ASCII space, where c(1), c(2), ..., c(2^k) are all codewords in lexicographic order (c(1) is the zero vector, so the first vector is L(s)).
- EQUAL a b: if n_a != n_b, output equal <a> <b> no lengths <n_a> <n_b>. Otherwise, let rho be the rank of the sequence of the rows of G_a followed by the rows of G_b, compute c = k_a + k_b - rho (the dimension of the set of codewords common to both codes), and output equal <a> <b> <e> intersection <c>. e is yes if k_a = k_b = c (the sets of codewords are equal), and no otherwise.

8. Encoding and decoding
- Encoding: convert a bit string u of length k (a message) into a codeword. If the encoding method is matrix, the codeword is the sum of row i of G over all i with u_i = 1. If it is polynomial, the codeword is u followed by the bit string of length n - k (u(x)*x^(n-k)) mod g(x) (u(x) is the polynomial represented by u). With either method, different messages are converted into different codewords, and every codeword is obtained from exactly one message. The message that is converted into a codeword c is called the message of c.
- Syndrome: the syndrome S(w) of a vector w of length n is the bit string of length n - k whose i-th bit is the inner product of row i of H and w. S(w) is the zero vector if and only if w is a codeword.
- Coset leader: for each bit string s of length n - k, the vector e of length n with S(e) = s that has the minimum weight (if there are several, the lexicographically smallest of them) is called the coset leader L(s) of s.
- Syndrome decoding: for a received word w, let e = L(S(w)) and c = w + e. c is a codeword. e is called the error pattern, c the decoded codeword, and the message of c the decoded message.
The commands are as follows.
- ENCODE a u: if |u| != k, error: bad length. Output encode <a> message <u> codeword <codeword obtained by encoding u>.
- SYNDROME a w: if |w| != n, error: bad length. Output syndrome <a> <S(w)> codeword <yes or no>. The last value is yes if w is a codeword.
- DECODE a w: if |w| != n, error: bad length. Decode w by syndrome decoding and output decode <a> codeword <c> message <message of c> error <e> weight <wt(e)>.
- BOUNDED a t w: if |w| != n, error: bad length. Decode w by syndrome decoding; if wt(e) <= t, output bounded <a> codeword <c> message <message of c> error <e> weight <wt(e)>, and if wt(e) > t, output bounded <a> fail weight <wt(e)>.
- COSET a w: if |w| != n, error: bad length. Let s = S(w), and output coset <a> syndrome <s> leader <L(s)> weights <list of items>. With N_i the number of vectors of weight i among w + c over all codewords c, the list of items consists of i:N_i for each i with N_i not 0, in increasing order of i, separated by single ASCII spaces.
- ERASURE a x: if |x| != n, error: bad length. Let z be the number of ? in x, and call a codeword a candidate if, at every position j where the character of x is not ?, its j-th bit equals the j-th character of x. If there is exactly one candidate, output erasure <a> erased <z> candidates 1 codeword <candidate> message <message of the candidate>; otherwise output erasure <a> erased <z> candidates <number of candidates>.
- INTERLEAVE a s l u...: let u(1), ..., u(D) be u... from the front. If any of them has a length other than k, error: bad length. Next, if s < 1, l < 1 or s + l - 1 > D * n, error: bad burst. Otherwise, do (i) to (iv) below.
  (i) For i = 1, ..., D, let c(i) be the codeword obtained by encoding u(i).
  (ii) The transmitted sequence T is the bit string of length D * n whose bit (j - 1) * D + i is the j-th bit of c(i) (1 <= i <= D, 1 <= j <= n).
  (iii) The received sequence R is T with each bit from bit s to bit s + l - 1 inverted (0 to 1, 1 to 0).
  (iv) For i = 1, ..., D, let r(i) be the bit string of bits (j - 1) * D + i of R arranged in the order j = 1, ..., n, and decode r(i) by syndrome decoding.
  The output is interleave <a> depth <D> burst <s> <l> on the first line, sent <T> on the second line and recv <R> on the third line, followed by row <i> errors <x> corrected <y> message <m> <ok or wrong> for i = 1, ..., D in this order, and finally result ok <number of ok rows> wrong <number of wrong rows>. x is the number of bits in which r(i) and c(i) differ, y is the weight of the error pattern of r(i), m is the decoded message of r(i), and the row is ok if m = u(i) and wrong otherwise.

9. Commands that do not use codes
- CRC g u: if the first character of g is 0, |g| < 2 or |g| > 17, error: bad parameter. Let d = |g| - 1; if |u| + d > 30, error: bad length. With g(x) the polynomial represented by g and u(x) the polynomial represented by u, compute r = (u(x)*x^d) mod g(x) (a bit string of length d) and output crc remainder <r> frame <the bit string u followed by r>.
- CRCCHECK g w: perform the same check on g as in CRC (error: bad parameter). Let d = |g| - 1, compute r = w(x) mod g(x) (a bit string of length d; w(x) is the polynomial represented by w), and output crccheck ok remainder <r> if r is the zero vector, or crccheck error remainder <r> otherwise.
- FACTOR n: if n < 1 or n > 24, error: bad parameter. Factor x^n + 1 into a product of irreducible polynomials. An irreducible polynomial is a polynomial of degree 1 or more that cannot be written as the product of two polynomials of degree 1 or more; this factorization is unique up to the order of the factors. Let f(1), ..., f(t) be the distinct irreducible polynomials appearing in the factorization, ordered by the length of the bit string representing them (whose first character is 1), shortest first, and lexicographically for equal lengths, and let e(i) be the number of times f(i) appears in the factorization. Output factor <n> <f(1)>^<e(1)> <f(2)>^<e(2)> ... <f(t)>^<e(t)> divisors <v>. v = (e(1) + 1) * (e(2) + 1) * ... * (e(t) + 1) is the number of polynomials that divide x^n + 1.
- MACWILLIAMS n c...: if n < 1 or n > 24, error: bad parameter; if the number of values c... is not n + 1, error: bad length; if the first value of c... is not 1, error: bad parameter. Let A_0, A_1, ..., A_n be the values of c... from the front and S = A_0 + A_1 + ... + A_n, and for j = 0, 1, ..., n compute B_j = (A_0 K_j(0) + A_1 K_j(1) + ... + A_n K_j(n)) / S as a rational number (K_j(x) is the same as in WEIGHTS). Output the following 3 lines.
  macwilliams n <n> size <S>
  dual <B_0> <B_1> ... <B_n>
  feasible <yes or no>
  B_j is written as a reduced fraction: if it is an integer, write that integer; otherwise write p/q with numerator p and denominator q (q >= 2), and prefix a - if it is negative (for example 0, 3, -2, 4/3, -1/2). feasible is yes if S is a power of 2 (1, 2, 4, 8, ...) and every B_j is an integer of 0 or more, and no otherwise.
- BOUNDS n d: if d < 1, d > n or n > 24, error: bad parameter. Output bounds n <n> d <d> singleton <x> hamming <y> griesmer <z>. x = n - d + 1. With V = C(n, 0) + C(n, 1) + ... + C(n, floor((d - 1)/2)), y is the largest integer k (0 <= k <= n) satisfying 2^k * V <= 2^n. z is the largest integer k (1 <= k <= n) satisfying ceil(d/2^0) + ceil(d/2^1) + ... + ceil(d/2^(k-1)) <= n.

[Output format]
- For each command, output the lines described in [Processing] in that order. Unless otherwise specified, each command outputs one line.
- Words in a line are separated by single ASCII spaces, no line has trailing whitespace, and every line ends with a newline.
- Numbers are written in decimal without extra leading 0s. Bit strings are written with the lengths defined in [Processing], including leading 0s.
- In the descriptions in [Processing], the period at the end of each item is sentence punctuation and is not part of the output.

[Constraints]
- 1 <= N <= 500.
- Each line has at most 1000 characters, and each word of a command line is a string of one or more printable ASCII characters other than space (from ! to ~).
- The codes targeted by DECODE, BOUNDED, COSET, INTERLEAVE, COVERING and STDARRAY satisfy C(n, 0) + C(n, 1) + ... + C(n, rho) <= 2 * 10^4, where rho is the covering radius.
