[Overview]
Write a program that plays the dice game "Yahtzee" for 1 to 6 players. It reads a sequence of commands from standard input, executes operations such as rolling the dice, choosing the dice to hold, and entering a score in a category of the scorecard one at a time, and reports any operation that violates the rules as an error. In addition, it displays the candidate score of each category, computes exactly the expected score after a reroll, advises the best way to hold, plays automatically as a computer (bot), undoes and redoes entries, displays scorecards and statistics, keeps records across games, and simulates games played only by bots. The faces of the dice are determined only by the specified random number generator and the "loaded faces" given in the input, so the results are fully determined.

[Input format]
The first line of standard input is the number of commands N. Each of the following N lines contains one command. Each line consists of a command name followed by zero or more arguments, separated by single spaces, with no whitespace at the beginning or end of the line. The command formats are the following 25 kinds.

RULE rule value
GAME seed p1 p2 ... pk
BOT p strategy
LOAD v1 v2 ... vk
ROLL
HOLD pattern
KEEP v1 v2 ... vk
SCORE category
WHATIF category
UNDO
REDO
SUGGEST
ODDS pattern
ADVISE
AUTO count
STATUS
CARD
BONUS
STATS
LOG
FACES
STANDINGS
END
RECORDS
SIM seed count s1 s2 ... sk

rule is a rule name, value is a rule value, p, p1, p2, etc. are player names, strategy and s1, s2, etc. are bot strategy names, category is a category name, and pattern is a word that represents a hold pattern. seed, count, v1, v2, etc. are words that represent integers. KEEP may have zero arguments. How these words are written and what they mean is explained in [Processing]. The input may contain words that are not valid as these words; in that case an error is reported.

[Processing]
Execute the commands in order from the first line, and print the result of each according to [Output format].

1. Word syntax
- Integer words: a word that consists of an optional single leading -, followed by one or more digits (0 to 9), whose first digit is not 0 when it has two or more digits, and which is not -0, is called a "decimal integer word". seed, count, v1, v2, etc., and the value of RULE ROLLS are valid only when they are decimal integer words and their values are within the range stated for each command.
- Player names: only words of 1 to 8 characters consisting solely of uppercase English letters (A to Z) are valid.
- Hold patterns (pattern): only words of 5 characters consisting solely of 0 and 1 are valid. The i-th character from the left corresponds to die i (section 2); 1 means "hold" and 0 means "do not hold".
- Category names (category): only one of the 13 names in section 3 is valid.
- Strategy names (strategy, s1, s2, etc.): only one of the 4 names in section 7 is valid.

2. Dice and random numbers
- There are 5 dice, called dice 1, 2, 3, 4, 5 from the left. Each shows a "face", an integer from 1 to 6.
- The random number generator has a state x (an integer from 1 to 2147483646). Each time one random number is drawn, x is updated to (48271 * x) mod 2147483647, and the updated x is the random number.
- The generator of the table game (section 5) is initialized with the seed of GAME (x = seed), and keeps its state until that game ends with END.
- The table game has a "loaded queue" (a sequence of face values). It is empty when the game starts, values can be appended to its end with LOAD, and it is discarded when the game ends with END.
- To roll one die: if the loaded queue is not empty, remove its first value from the queue and use it as the face of that die, without drawing a random number. If it is empty, draw one random number r and use (r mod 6) + 1 as the face.
- To roll several dice, roll them one at a time in increasing order of die number.

3. Categories and scores
- The scorecard has boxes for the following 13 "categories", and this order is called the "category order": ONES, TWOS, THREES, FOURS, FIVES, SIXES, THREEKIND, FOURKIND, FULLHOUSE, SMALL, LARGE, YAHTZEE, CHANCE.
- The first 6 are called "upper categories" and the remaining 7 "lower categories". ONES, TWOS, THREES, FOURS, FIVES, SIXES correspond to faces 1, 2, 3, 4, 5, 6 respectively, and the upper category corresponding to face f is called "the upper category of f".
- Each box is initially empty. A box in which a score has been entered becomes "used", and stays so unless the entry is undone by UNDO (section 8). A category whose box is empty is called an "open category".
- All 5 dice showing the same face is called a "Yahtzee".
- The "normal score" of each category for 5 faces is as follows.
 The upper category of f: f * c, where c is the number of dice showing face f.
 THREEKIND: the sum of the 5 faces if 3 or more dice show the same face, otherwise 0.
 FOURKIND: the sum of the 5 faces if 4 or more dice show the same face, otherwise 0.
 FULLHOUSE: 25 if there are exactly 2 distinct faces, with 3 dice showing one face and 2 dice showing the other, otherwise 0 (a Yahtzee also gives 0).
 SMALL: 30 if the set of faces that appear contains one of {1, 2, 3, 4}, {2, 3, 4, 5}, {3, 4, 5, 6}, otherwise 0.
 LARGE: 40 if the set of faces that appear is {1, 2, 3, 4, 5} or {2, 3, 4, 5, 6}, otherwise 0.
 YAHTZEE: 50 if it is a Yahtzee, otherwise 0.
 CHANCE: the sum of the 5 faces.
- For each player the following values are defined. The "upper subtotal" is the sum of the scores of the used upper categories. The "upper bonus" is 35 if the upper subtotal is 63 or more, otherwise 0. The "Yahtzee bonus" is the sum of the values added in section 4, initially 0. The "total" is the sum of the scores of all used categories, the upper bonus, and the Yahtzee bonus.

4. Rules and jokers
- There are the following 2 rules, both initially at their default values. They can be changed with RULE, and a change lasts until the end of the input. The rules apply to both the table game and SIM (section 11).
 ROLLS: an integer from 1 to 4, default 3. It is the maximum number of times the dice can be rolled in one turn.
 JOKER: one of FORCED, FREE, OFF, default FORCED.
- Below, consider a player entering a score with 5 faces d. The situation in which JOKER is not OFF, d is a Yahtzee, and that player's YAHTZEE box is used (whether its score is 50 or 0) is called the "joker situation".
- "Allowed categories": when it is not the joker situation, or when JOKER is FREE, all open categories. When JOKER is FORCED and it is the joker situation, letting f be the face of d: (a) if the upper category of f is open, only that category; (b) otherwise, if there is an open lower category, all open lower categories; (c) if neither, all open categories.
- The "points to enter" for category c: in the joker situation, if c is FULLHOUSE, SMALL, or LARGE, they are 25, 30, 40 respectively. Otherwise, they are the normal score of c for d.
- Yahtzee bonus: if d is a Yahtzee and 50 has been entered in that player's YAHTZEE box immediately before the entry, add 100 to that player's Yahtzee bonus, whichever category the entry is made in (regardless of the value of JOKER).

5. Games and turns
- The "table" holds at most one game at a time. Initially there is no game (this state is called "no game"); GAME starts a game, and END returns to no game.
- Players take seats 1, 2, ..., k in the order p1, p2, ..., pk of GAME. This order is called the "seat order". At the start of the game, every player's scorecard is entirely empty, the Yahtzee bonus is 0, and the bot strategy (section 7) is KIND.
- A game is a repetition of "turns". The first turn belongs to the player in seat 1, and each time a turn ends, it becomes the turn of the next player in seat order (seat 1 comes after seat k).
- The turn state consists of the turn player, the number of times the dice have been rolled in that turn (hereafter the "roll count"), the faces of the 5 dice, and a "hold" mark for each of the 5 dice. At the beginning of a turn, the roll count is 0, there are no faces, and no die has a hold mark.
- To roll the dice (ROLL): if the roll count is 0, roll all 5 dice; if it is 1 or more, roll only the dice without a hold mark (section 2); then add 1 to the roll count. The faces of dice with a hold mark do not change. Hold marks change only through HOLD and KEEP (including bot operations) and through UNDO and REDO (section 8), and they remain until the turn ends (rolling does not clear them).
- When the roll count is 1 or more, the turn player can enter a score in a category (SCORE), and making the entry ends that turn.
- Each player's "round" is the number of that player's used categories plus 1.
- When all 13 categories of all players are used, the game is "finished". A finished game has no turn. A finished game remains until END is executed.
- Ranking: players are ranked 1st, 2nd, ... in decreasing order of total. Among players with equal totals, the one earlier in seat order ranks higher.

6. Candidate scores and the best category
For the turn player's current scorecard and 5 faces d, the following are defined.
- The "candidate score" of an open category c is its points to enter if c is an allowed category, otherwise 0.
- Among the open categories, the one with the largest candidate score (if there are several, the earliest in category order) is called the "best category", and its candidate score is called the "best score". The best category is always an allowed category.
- Candidate scores and the best score do not include the upper bonus or the Yahtzee bonus.
When ODDS and ADVISE consider faces d different from the actual faces, these are defined in the same way using the turn player's current scorecard.

7. Bots
- There are 4 bot strategies: KIND, STRAIGHT, HIGH, UPPER.
- "One bot turn" is performed as follows, using the strategy set for the turn player.
(1) If the roll count is 0, roll the dice in the same way as ROLL.
(2) While the roll count is less than ROLLS, repeat the following. From the current faces, decide which dice to hold by the rule below. If all 5 dice are to be held, end the repetition. Otherwise, set that hold pattern in the same way as HOLD, and roll the dice in the same way as ROLL.
(3) Decide the category by the rule below, and make the entry in that category in the same way as SCORE.
- Rule for the dice to hold. Here the "most frequent face" is the face, among the current faces, shown by the largest number of dice (if the numbers are equal, the larger face).
 KIND, UPPER: hold all dice showing the most frequent face, and do not hold the others.
 STRAIGHT: when the consecutive integers a, a+1, ..., b (a <= b) all appear among the current faces, they are called a "run" of length b-a+1. If the length of the longest run (if there are several of the same length, the one with the larger a) is 3 or more, then for each value of that run, hold one die, namely the leftmost of the dice showing that value, and do not hold the others. If the length is 2 or less, hold by the same rule as KIND.
 HIGH: hold all dice whose face is 5 or 6, and do not hold the others (if there are none, hold nothing).
- Rule for the category to enter.
 UPPER: let f be the most frequent face. If 3 or more dice show face f and the upper category of f is an allowed category, make the entry in that category. Otherwise, make the entry in the best category.
 KIND, STRAIGHT, HIGH: make the entry in the best category.

8. Undo and redo
- Each time a score is entered, the table game creates a "score entry" and stores the score entries in order of entry. A score entry consists of the player, the category, the points entered, the Yahtzee bonus added at that time (100 or 0), whether it was the joker situation, and the 5 faces, the hold marks, and the roll count at the time of the entry.
- The game also has a "redo list", which is empty when the game starts.
- UNDO removes the last score entry, returns the box of its category to empty, and subtracts the Yahtzee bonus added at that time. At this point, it appends to the end of the redo list a pair consisting of the state immediately before executing UNDO (the turn state, or the fact that the game is finished) and the removed score entry. Then it sets the state to the turn of the score entry's player, with the faces, hold marks, and roll count as recorded in the score entry (it also returns to this state if the game was finished).
- REDO removes the pair at the end of the redo list, enters the same points in the box of that score entry's category, adds the same Yahtzee bonus, and puts that score entry back at the end of the sequence of score entries. Then it restores the state saved in the pair (the turn state, or the fact that the game is finished).
- When any of ROLL, HOLD, KEEP, SCORE, AUTO is executed without an error, the redo list becomes empty. Other commands do not change the redo list.
- UNDO and REDO do not restore the random number generator, the loaded queue, or the FACES counts (section 10).

9. Records
- The program keeps a "record" (games, wins, best score, sum of totals) for each player name, initially none. Records last until the end of the input.
- When a finished game is ended with END, for each player of that game, in the record for that name (if there is none, create a record with all zeros), add 1 to games, add 1 to wins if the rank is 1st, add that game's total to the sum of totals, and set the best score to the larger of itself and that game's total. When a game that is not finished is ended with END, the records do not change.

10. Commands
Each command checks for errors in the order written in its description, and reports the first one that applies (section 12). The check procedures used below are defined as follows.
"Turn check": (a) no game if there is no game, (b) game over if the game is finished.
"Rolled check": the turn check, followed by (c) not rolled if the roll count is 0.
"Rolls-left check": the rolled check, followed by (d) no rolls left if the roll count equals ROLLS.

- RULE rule value: unknown rule if rule is neither ROLLS nor JOKER, bad value if value is not one of the values given in section 4 (for ROLLS, a decimal integer word from 1 to 4; for JOKER, one of FORCED, FREE, OFF), game in progress if the state is not no game. Set the value of the rule rule to value.
- GAME seed p1 ... pk: the range of seed is 1 to 2147483646. bad value if seed is not valid; next, examining p1, p2, ... from the left, if there is an invalid player name, bad name for the first such name; too many players if k is 7 or more; game in progress if the state is not no game; duplicate name if the same name appears two or more times (for the first name, looking from the left, that has the same name somewhere to its left). Start a new game, and make it the turn of the player in seat 1.
- BOT p strategy: bad name if p is not valid, bad strategy if strategy is not valid, no game if there is no game, no player if the game has no player named p. Set the strategy of player p to strategy (this can be executed even if the game is finished).
- LOAD v1 ... vk: the range of each vi is 1 to 6. Examining from the left, if there is an invalid word, bad value for the first such word; no game if there is no game. Append v1, ..., vk in this order to the end of the loaded queue.
- ROLL: the turn check, then no rolls left if the roll count equals ROLLS, all dice held if all 5 dice have a hold mark. Roll the dice (section 5).
- HOLD pattern: bad pattern if pattern is not valid, then the rolls-left check. Set the hold marks of the 5 dice according to pattern.
- KEEP v1 ... vk: the range of each vi is 1 to 6. Examining from the left, if there is an invalid word, bad value for the first such word; then the rolls-left check. After that, for v1, v2, ..., vk in this order, select one die each: the leftmost die not yet selected among the dice showing that value. If there is a value for which no die can be selected, not showing for the first such value vi. Put a hold mark only on the selected dice, and clear the other marks (if k = 0, all marks are cleared).
- SCORE category: bad category if category is not valid, then the rolled check, already used if the category is used, joker requires if it is not an allowed category (in case (a) of section 4, joker requires <the upper category of f>; in case (b), joker requires lower box). Enter in the category the points to enter for it with the current faces, add the Yahtzee bonus (section 4), and store the score entry. If this finishes the game, the game is finished; otherwise start the turn of the next player.
- WHATIF category: checks the same errors in the same order as SCORE. Prints the content of the first line (the score line) that would be printed if SCORE category were executed, without changing anything.
- UNDO: no game if there is no game, nothing to undo if there is no score entry. Undo as described in section 8.
- REDO: no game if there is no game, nothing to redo if the redo list is empty. Redo as described in section 8.
- SUGGEST: the rolled check. For the current faces, print the candidate score of each open category, and the best category and the best score.
- ODDS pattern: bad pattern if pattern is not valid, then the rolls-left check. Of the current faces, keep the faces of the dice that are 1 in pattern unchanged, and assume that the 6^k possible face combinations (choices of a face for each of the 0 dice) that can result from rolling only the 0 dice (k of them) once more all occur with equal probability. For each open category, compute the expected value of the candidate score and the probability that the candidate score is greater than 0, and also compute the expected value of the best score. The current hold marks are not used. Nothing is changed, including the random number generator and the loaded queue.
- ADVISE: the rolls-left check. Let L = ROLLS - roll count (L >= 1). For 5 faces d and an integer j >= 0, the value W_j(d) is defined as follows. W_0(d) is the best score of d. For j >= 1, for each of the 32 hold patterns h, let E_h(d, j) be the average of W_{j-1}(d') over the 6^k face combinations d' (with equal probability, as in ODDS) obtained by rerolling only the dice of d that are 0 in h (k of them), and let W_j(d) be the maximum of these 32 values. The hold pattern 11111 is the case where no die is rerolled, and the only face combination is d itself. For the current faces d, find the hold pattern h that maximizes E_h(d, L), and print h and E_h(d, L). If several hold patterns attain the maximum, choose the earliest one in lexicographic order of the 5-character pattern strings (0 comes before 1). Nothing is changed.
- AUTO count: the range of count is 1 to 100. bad value if count is not valid, then the turn check. Perform one bot turn (section 7) count times in succession. If the game becomes finished partway, stop there. If the first turn is already partly in progress (the roll count is 1 or more), perform the procedure of section 7 from that state.
- STATUS: no game if there is no game. Print the turn state.
- CARD: no game if there is no game. Print the scorecards of all players.
- BONUS: no game if there is no game. For each player, print the upper subtotal; need, the points still needed for the upper bonus (the larger of 63 - upper subtotal and 0); max, the maximum possible upper subtotal (the upper subtotal plus 5 * f for each open upper category, where f is the face of that category); and the status of the upper bonus (made if the upper subtotal is 63 or more; otherwise lost if max is less than 63; otherwise open).
- STATS: no game if there is no game. For each player, from that player's score entries among the current score entries, compute and print turns (the number of score entries), rolls (the sum of the roll counts), zeros (the number of entries whose points entered are 0), yahtzees (the number of entries whose faces were a Yahtzee), and average (the average of the sum of the points entered; the count is turns).
- LOG: no game if there is no game. Print the current score entries in order of entry.
- FACES: no game if there is no game. Over all dice faces rolled in that game (including faces taken from the loaded queue and faces rolled by bots, and excluding faces rolled in SIM; the counts do not decrease on UNDO), compute the numbers of times faces 1, 2, ..., 6 appeared, c1, c2, ..., c6, and the total n = c1 + ... + c6. Also compute chi2 = (6 * (c1^2 + c2^2 + ... + c6^2) - n^2) / n if n >= 1, and chi2 = 0 if n = 0.
- STANDINGS: no game if there is no game. Print the ranking by the current totals and the difference from the total of the 1st-place player.
- END: no game if there is no game. Print the ranking by the current totals, record the records (section 9) if the game is finished, and set the state to no game.
- RECORDS: there are no errors. Print the records.
- SIM seed count s1 ... sk: the range of seed is 1 to 2147483646, and the range of count is 1 to 50. Examine seed, count, s1, s2, ... in this order, and for the first invalid word, bad value (when it is seed or count) or bad strategy (when it is an si). Next, too many players if k is 7 or more. Run the simulation (section 11).

11. Simulation
- Separately from the table, SIM plays count games in succession, each a k-player game in which bots with strategies s1, s2, ..., sk sit in seats 1, 2, ..., k. The current rules are used.
- The random number generator is initialized with seed only once; in the second and later games, random numbers continue to be drawn from the state at the end of the previous game. Loaded faces are not used.
- Each game starts with all scorecards empty and all Yahtzee bonuses 0, from the turn of seat 1, and repeats one bot turn (section 7) of the turn player's bot until the game is finished.
- SIM changes neither the table game (including its generator, its loaded queue, and its FACES counts) nor the records. Lines for bot operations are not printed.
- For each seat, the following values are aggregated. wins is the number of games in which the seat's rank was 1st, average is the average of the total at the end of the game (the count is count), best is the maximum of the total at the end of the game, bonus is the number of games in which the upper bonus was 35 at the end of the game, and yahtzee is the number of games in which 50 had been entered in the YAHTZEE box at the end of the game.

12. Order of error checks
On an error, change nothing and print only the single error line. For each command, first, unknown command if the command name is none of the 25 kinds in the formats. After that, check in the order written in the description of each command in section 10, and report the first error that applies.

[Output format]
For each command, print the following lines in this order. Words in a line are separated by single spaces, no line has trailing whitespace, and every line ends with a newline (the CARD table aligns its columns with spaces as described below). Numbers are written in decimal without extra leading zeros. Parts enclosed in < > are replaced by values. The period at the end of each item is a sentence delimiter and is not part of the output. Values are written as follows.
- Face list: the faces listed from the leftmost die in order, separated by single spaces. If there are no faces to list, write -.
- Hold pattern: the hold marks of the 5 dice written from the left as 5 characters, each 1 (hold) or 0 (do not hold).
- Fraction: a nonnegative rational number reduced to an irreducible fraction a/b (b >= 1), written as just a if b = 1, otherwise as a, /, b written consecutively (examples: 0, 1, 7/3).
- Average: for a sum s of nonnegative integers and a count n, if n >= 1, let v = (100 * s) / n (where / is integer division that discards the fractional part), and write v / 100, ., and v mod 100 zero-padded to 2 digits, consecutively in this order (examples: s = 159, n = 9 gives 17.66; s = 1001, n = 20 gives 50.05). If n = 0, write 0.00.

- Error: only the single line error: <reason>. <reason> is one of the following.
 unknown command <command name>
 unknown rule <rule>
 bad value <invalid word>
 bad name <invalid word>
 bad pattern <invalid word>
 bad category <invalid word>
 bad strategy <invalid word>
 too many players
 game in progress
 duplicate name <name>
 no game
 no player <p>
 game over
 not rolled
 no rolls left
 all dice held
 not showing <value>
 <category> already used
 joker requires <category>
 joker requires lower box
 nothing to undo
 nothing to redo
- RULE: rule <rule> <value>.
- GAME: one line game seed <seed> players <p1> <p2> ... <pk> and one line turn 1 <p1>.
- BOT: bot <p> <strategy>.
- LOAD: loaded <length of the loaded queue after appending>.
- ROLL: <turn player> roll <roll count after rolling>: <face list of the 5 dice>.
- HOLD, KEEP: <turn player> holds <hold pattern that was set>: <face list of the dice with a hold mark>.
- SCORE: first print the "score line". The score line is <player> scores <points entered> in <category>, followed, in this order, by joker if it is the joker situation, ybonus 100 if 100 was added to the Yahtzee bonus, and ubonus 35 if this entry changed the upper bonus from 0 to 35, and finally by total <total after the entry>. Then print one line: game over if the game became finished, otherwise turn <round of the next turn player> <next turn player>.
- WHATIF: one line, the score line with scores replaced by would score (example: ANN would score 0 in FULLHOUSE ybonus 100 total 168).
- UNDO: undo <player> <category> <points entered> (the content of the removed score entry).
- REDO: redo <player> <category> <points entered> (the content of the restored score entry). No turn line or other lines are printed.
- SUGGEST: one line consisting of suggest, followed by <category> <candidate score> for each open category in category order, and finally best <best category> <best score>.
- ODDS: one line odds <pattern> outcomes <value of 6^k>, a line <category> expect <expected candidate score as a fraction> chance <probability that the candidate score is greater than 0 as a fraction> for each open category in category order, and finally one line best expect <expected best score as a fraction>.
- ADVISE: advise <chosen hold pattern>: <face list of the dice held by that pattern> expect <E_h(d, L) as a fraction>.
- AUTO: for each bot operation, the same lines as when ROLL, HOLD, SCORE are executed, in the order in which they occur.
- STATUS: status game over if the game is finished. Otherwise status round <round of the turn player> player <turn player> rolls <roll count> dice <face list> holds <hold pattern> (if the roll count is 0, the face list is -).
- CARD: the following 18-line table. Each line consists of the heading written left-aligned in width 9 (padded with trailing spaces as needed), followed, for each player in seat order, by a single space and that player's cell string written right-aligned in width w (padded with leading spaces as needed). w is the larger of the number of characters in that player's name and 4. The 1st line has the heading CATEGORY, and its cells are the player names. The next 13 lines, in category order, have the category name as the heading, and their cells are the points entered (- if open). The next 4 lines have the headings UPPER, BONUS, YBONUS, TOTAL, and their cells are the upper subtotal, the upper bonus, the Yahtzee bonus, and the total, respectively.
- BONUS: for each player in seat order, bonus <name> upper <upper subtotal> need <need> max <max> <one of made, open, lost>.
- STATS: for each player in seat order, stats <name> turns <turns> rolls <rolls> zeros <zeros> yahtzees <yahtzees> average <average as an average>.
- LOG: for each score entry, in order of entry, log <number counted from 1> <player> <face list at the time of the entry> <category> <points entered>, followed, in this order, by joker if the entry was the joker situation and ybonus 100 if the entry added the Yahtzee bonus. If there are no score entries, one line no scores.
- FACES: faces <c1> <c2> <c3> <c4> <c5> <c6> total <n> chi2 <chi2 as a fraction>.
- STANDINGS: for each player in ranking order, standing <rank> <name> <total> behind <total of the 1st-place player - total of that player>.
- END: one line end final if the game is finished, otherwise end abandoned, and for each player in ranking order rank <rank> <name> <total>.
- RECORDS: for each record, record <name> games <games> wins <wins> best <best score> average <average of the sum of totals (the count is games)>. The order is more wins first; for equal wins, higher best score first; if those are also equal, lexicographic order of names (character code order). If there are no records, one line no records.
- SIM: one line sim seed <seed> games <count> players <k>, and for each seat in seat order seat <seat number> <strategy name> wins <wins> average <average as an average> best <best> bonus <bonus> yahtzee <yahtzee>.

[Constraints]
- 1 <= N <= 400.
- Each word in a line is a string of 1 to 12 printable ASCII characters (other than space).
- The number of arguments is as in the formats. However, the arguments of GAME are seed and 1 to 8 names, the arguments of LOAD are 1 to 20, the arguments of KEEP are 0 to 8, and the arguments of SIM are seed, count, and 1 to 8 strategy names.
- The number of games played by SIM is at most 200 in total over the whole input, and the number of times ADVISE is executed is at most 20 in total.
- W_j(d) of ADVISE does not depend on the order of the faces of d, only on the combination of faces (how many dice show each face). Similarly, E_h(d, j) depends only on the combination of the faces of the dice of d held by h. A naive enumeration for ADVISE requires a very large amount of computation, so use techniques such as reusing results for the same combination.
- The expected values of ADVISE are fractions whose denominators divide 7776^L.
