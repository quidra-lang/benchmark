[Overview]
Write a program that manages and checks a layout, such as a building floor plan or an integrated-circuit layout, as a collection of named rectangles. The program reads a sequence of commands from standard input, executes them one at a time from the first, and writes the results to standard output. The sides of the rectangles are parallel to the coordinate axes, and all coordinates are integers. Each rectangle belongs to exactly one layer. Besides adding, copying, moving, resizing, splitting, changing the layer of, and deleting rectangles and undoing operations, the program lists overlaps, computes the area and perimeter of a union, computes the area covered k or more times, determines the intersection, adjacency and containment of two rectangles, searches for rectangles containing a point, finds groups connected by contact (nets) and paths within them, finds the nearest rectangle, checks spacing, reports the bounding box and density, reports the density per tile, draws with characters, finds the largest empty rectangle, lists holes, decomposes into non-overlapping rectangles, and checks all registered rules at once.

[Input format]
The first line contains N, the number of commands, and each of the following N lines contains one command. Each line consists of a command name followed by zero or more arguments, separated by a single space. There is no whitespace at the start or end of a line, and there are no empty lines. There are the following 34 command forms (the parts other than the command name are argument names; however, SPACING, WIDTH and ENCLOSE directly after RULE are written literally as those strings).
ADD name layer x1 y1 x2 y2
COPY name new dx dy
MOVE name dx dy
RESIZE name w h
SPLIT name axis pos new
LAYER name layer
DELETE name
UNDO

INFO name

The arguments are written as follows.
- name, new, a and b are rectangle names. A rectangle name is a string of 1 to 8 characters that starts with an uppercase letter (A to Z) and consists only of uppercase letters and digits (0 to 9).
- layer, inner and outer are layer names. A layer name is a string of 1 to 8 characters that starts with a lowercase letter (a to z) and consists only of lowercase letters and digits.
- axis is either x or y.
- The other arguments (x1, y1, x2, y2, dx, dy, w, h, pos, x, y, k, s, m) are integers. A negative number is written with a leading "-", and a number 0 or greater has no sign.
All integers are written in decimal, and nonzero numbers have no leading zeros. It is guaranteed that every line follows these formats and the [Constraints].

[Processing]
Process the commands one at a time in input order, and write the output of each command immediately. Below, a string enclosed in double quotes is a string that appears in the output exactly as written. However, a part enclosed in < and >, such as <name> or <A>, is replaced by its value. A part that encloses the name of an argument of that command (such as <name> and <layer> in the description of ADD) is that argument's string; any other such part is a value defined in the description.

== Name order ==
Rectangle names are compared with each other, and layer names with each other, in the following order. Compare the character codes (ASCII) one character at a time from the beginning; the string whose character code is smaller at the first differing character comes first. If one string equals the beginning of the other, the shorter one comes first. Digits come before letters. For example, the rectangle names B2, BIG, S1, S10, S2 and the layer names m1, m10, m2, metal are each in this order. Below, "name order" means this order. A "name list" is the string obtained by arranging some names in name order and joining them with a single space between them.

== Rectangles and state ==
A rectangle has a name, a layer name, and integer coordinates x1, y1, x2, y2 (x1 < x2, y1 < y2). This rectangle represents the set of all points (x, y) in the plane with x1 <= x <= x2 and y1 <= y <= y2 (the boundary is included). x1, y1, x2 and y2 are called the left end, bottom end, right end and top end of the rectangle, respectively; x2-x1 is called the width, y2-y1 the height, and width * height the area. Two or more rectangles with the same name never exist at the same time (even if their layers differ). A rectangle whose layer name is L is called "a rectangle on layer L". For every rectangle, all four coordinates are between -10000 and 10000 inclusive (an operation that would go outside this range is an error).

The state consists of the set of existing rectangles, the set of rules, and the undo history, all of which are initially empty. The set of rectangles is changed only by ADD, COPY, MOVE, RESIZE, SPLIT, LAYER and DELETE (below, these seven are called "modifying commands") and UNDO. The set of rules is changed only by RULE, and the undo history is changed only by modifying commands and UNDO. All other commands do not change the state.

== Notation ==
- Rectangle notation: the rectangle with left end x1, bottom end y1, right end x2 and top end y2 is written as "(<x1>,<y1>)-(<x2>,<y2>)" (example: (0,-3)-(4,5)). No spaces are inserted. Shared edges, windows, tiles and so on, described later, are written in the same form.
- Point notation: the point (x, y) is written as "(<x>,<y>)" (example: (21,-1)).
- Two-decimal notation: for a rational number r >= 0, let h = floor(100r); the notation is the quotient of h divided by 100, then ".", then the remainder of h divided by 100 written with 2 digits (with a leading 0 if it has 1 digit). In other words, digits from the third decimal place on are truncated (examples: 25.46 if r is 382/15, 64.00 if r is 64, 0.00 if r is 0). Compute r exactly as a fraction.

== Relation between two rectangles ==
For two different rectangles A and B, let X1 be the larger of the left ends of A and B, X2 the smaller of the right ends of A and B, Y1 the larger of the bottom ends of A and B, and Y2 the smaller of the top ends of A and B, and let ox = X2-X1 and oy = Y2-Y1. The relation between A and B is exactly one of the following four.
- "Overlapping": when ox > 0 and oy > 0. The common part of A and B is the rectangle (X1,Y1)-(X2,Y2), which is called the "common rectangle". Its area is ox*oy.
- "Touching at an edge": when ox >= 0 and oy >= 0 and exactly one of ox and oy is 0. The common part is the segment of length ox+oy joining the point (X1, Y1) and the point (X2, Y2), which is called the "shared edge". The notation of the shared edge is "(<X1>,<Y1>)-(<X2>,<Y2>)".
- "Touching at a corner": when ox = 0 and oy = 0. The common part is only the point (X1, Y1).
- "Separated": when ox < 0 or oy < 0. There is no common part.
The "gap" between A and B is the largest of 0, -ox and -oy. The gap is 1 or more when they are separated and 0 otherwise. When they are separated, the "direction" is x if ox < 0 and oy >= 0, y if oy < 0 and ox >= 0, and diagonal if ox < 0 and oy < 0. The relation, common rectangle, shared edge, gap and direction do not change when A and B are swapped. They are defined in the same way even when A and B are on different layers.

When left end of A <= left end of B, bottom end of A <= bottom end of B, right end of B <= right end of A, and top end of B <= top end of A all hold, we say "A contains B". Two rectangles with the same coordinates contain each other.

Two rectangles on the same layer are "connected" when their relation is "overlapping" or "touching at an edge". Two rectangles that only touch at a corner are not connected.

== Unit squares and coverage ==
For integers i and j, the square with i <= x <= i+1 and j <= y <= j+1 is called the unit square [i, j]. The unit squares [i, j] and [i+1, j], and [i, j] and [i, j+1], are called "neighboring" (that is, two unit squares that share a side are neighboring). The rectangle (x1,y1)-(x2,y2) is said to "cover" the unit squares [i, j] with x1 <= i < x2 and y1 <= j < y2 (the unit squares contained in that rectangle).

For a set S of rectangles, the number of rectangles of S that cover the unit square [i, j] is called its coverage count, and a unit square whose coverage count is 1 or more is said to be "covered by S". The number of unit squares covered by S is called "the area of S" (it equals the area of the union of the rectangles of S). Unless stated otherwise, the coverage count and coverage for layer L are those with S being all the rectangles on layer L, and that area is called "the area of layer L". Because the coordinate range is wide, examining the unit squares one by one may take too much time.

The bounding box of a set S containing one or more rectangles is the rectangle whose left end, bottom end, right end and top end are, respectively, the minimum of the left ends, the minimum of the bottom ends, the maximum of the right ends and the maximum of the top ends of the rectangles of S.

== Errors ==
When a command results in an error, output only the single line "error: <MESSAGE>" and do not change the state at all (the undo history does not change either). In the description of each command, the error conditions are listed in the order in which they are checked, and the MESSAGE of the first condition that applies is used. The following three conditions are used often, so they are given names.
- unknown rectangle: no rectangle named x exists. The MESSAGE is "unknown rectangle <x>". For a command that takes two rectangle names a and b as arguments, a is checked first, then b.
- no rectangles: there is no rectangle on layer layer. The MESSAGE is "no rectangles on <layer>".
- out of bounds: after performing the operation, the absolute value of one or more of the four coordinates of the rectangle would be greater than 10000. The MESSAGE is "out of bounds".

== Processing of each command ==
ADD name layer x1 y1 x2 y2
The error conditions, in order, are: a rectangle named name already exists ("duplicate rectangle <name>"), x1 >= x2 or y1 >= y2 ("invalid rectangle"), and out of bounds (for the rectangle to be added). If there is no error, add the rectangle name on layer layer with coordinates x1, y1, x2, y2, and output "added <name> <layer> <R>" (<R> is the notation of the added rectangle).

COPY name new dx dy
Let x1, y1, x2, y2 be the coordinates of name. The error conditions, in order, are: unknown rectangle (for name), a rectangle named new already exists ("duplicate rectangle <new>"; this also applies when new is the same as name), and out of bounds (for the rectangle produced by the copy). If there is no error, add the rectangle new (x1+dx,y1+dy)-(x2+dx,y2+dy) on the same layer as name, and output "copied <name> to <new> <R>" (<R> is the notation of new). name does not change.

MOVE name dx dy
The error conditions, in order, are: unknown rectangle, and out of bounds (for name after the move). Add dx to the left end and right end of name and dy to its bottom end and top end, and output "moved <name> to <R>" (<R> is the notation of name after the move). Even when dx and dy are both 0, this is not an error, and it is also added to the undo history.

RESIZE name w h
The error conditions, in order, are: unknown rectangle, w <= 0 or h <= 0 ("invalid size"), and out of bounds (for name after the change). Without changing the left end and bottom end of name, change its right end to "left end + w" and its top end to "bottom end + h", and output "resized <name> to <R>" (<R> is the notation of name after the change).

SPLIT name axis pos new
Let x1, y1, x2, y2 be the coordinates of name. The error conditions, in order, are: unknown rectangle (for name), a rectangle named new already exists ("duplicate rectangle <new>"; this also applies when new is the same as name), and x1 < pos < x2 does not hold when axis is x, or y1 < pos < y2 does not hold when axis is y ("cut outside <name>"). If there is no error: if axis is x, change name to (x1,y1)-(pos,y2) and add the rectangle new (pos,y1)-(x2,y2) on the same layer as name; if axis is y, change name to (x1,y1)-(x2,pos) and add the rectangle new (x1,pos)-(x2,y2) on the same layer as name. Then output "split <name> at <axis>=<pos>: <name> <R1>, <new> <R2>" (<R1> is the notation of name after the change, and <R2> is the notation of new).

LAYER name layer
The error conditions, in order, are: unknown rectangle, and the layer name of name is already layer ("already on <layer>"). Change the layer name of name to layer, and output "layer <name> <old> -> <layer>" (<old> is the layer name before the change).

DELETE name
The error condition is unknown rectangle. Delete name, and output "deleted <name>".

UNDO
The undo history is a sequence of pairs of "a state of the set of rectangles" and "a command line". Each time a modifying command is executed without an error, the pair of the state of the set of rectangles immediately before that execution (the names, layer names and coordinates of all rectangles) and that command's line (the string exactly as the input line) is appended to the end of the history.
UNDO is an error ("nothing to undo") if the history is empty. Otherwise, remove the last pair from the history, restore the set of rectangles to that pair's state, and output "undo: <C>" (<C> is that pair's command line). Thus, executing UNDO repeatedly undoes the executed modifying commands one at a time, newest first. UNDO itself is not added to the history, and there is no way to redo an undone operation. The set of rules is not changed by UNDO.

LIST
Output "rectangles: <n>" (<n> is the number of rectangles), then, for every rectangle in name order, one line "<t> <L> <R> <w>x<h>". <t> is the rectangle name, <L> is the layer name, <R> is the notation of the rectangle, <w> is the width, and <h> is the height.

INFO name
The error condition is unknown rectangle. Output the following 6 lines. In lines 2 to 6, <T> is the name list of the rectangles (excluding name itself) that satisfy the condition stated there, and "none" if no rectangle satisfies it.
Line 1: "<name> <L> <R> <w>x<h> area <a>". <L> is the layer name of name, <R> is the notation of name, and <w>, <h>, <a> are the width, height and area of name.
Line 2: "overlaps: <T>". The rectangles on the same layer as name whose relation to name is "overlapping".
Line 3: "touches: <T>". The rectangles on the same layer as name whose relation to name is "touching at an edge".
Line 4: "corners: <T>". The rectangles on the same layer as name whose relation to name is "touching at a corner".
Line 5: "encloses: <T>". The rectangles on all layers that name contains.
Line 6: "enclosed by: <T>". The rectangles on all layers that contain name.

LAYERS
Let m be the number of layer names that appear as the layer name of some rectangle, and output "layers: <m>", then, for each of those layers L in name order, one line "<L>: <n> rectangles, area <A>, nets <k>". <n> is the number of rectangles on layer L, <A> is the area of layer L, and <k> is the number of nets of layer L (see NETS). Write "rectangles" even when <n> is 1.

OVERLAPS
OVERLAPS layer
A pair of two rectangles on the same layer whose relation is "overlapping" is called an "overlapping pair". Of the two rectangles of a pair, call the one that comes first in name order A and the other B.
When layer is absent, the overlapping pairs of all layers are considered. Let k be their number, and output "overlaps all layers: <k>", then output the overlapping pairs one per line as "<L> <A> <B> <R> area <s>", sorted by layer name order, then (for the same layer) by name order of A, then (for the same A) by name order of B. <L> is the layer name, <R> is the notation of the common rectangle, and <s> is its area. When layer is absent, there is no error.
When layer is present, the error condition is no rectangles. Only the overlapping pairs of layer layer are considered; let k be their number, and output "overlaps <layer>: <k>", then, in name order of A, and for the same A in name order of B, one pair per line as "<A> <B> <R> area <s>".

AREA layer
The error condition is no rectangles. Output "area <layer>: <A>" (<A> is the area of layer layer).

COVER k layer
The error condition is no rectangles. Let A be the number of unit squares whose coverage count for layer layer is k or more, and output "cover <layer> >= <k>: <A>".

PERIMETER layer
The error condition is no rectangles. Let P be the number of pairs of neighboring unit squares of which exactly one is covered by layer layer, and output "perimeter <layer>: <P>". P is the length of the boundary of the covered part (including the boundaries of holes).

INTERSECT a b
The error conditions, in order, are: unknown rectangle, and a and b are the same ("same rectangle <a>"). a and b may be on different layers. Depending on the relation between a and b, output one of the following lines.
- Overlapping: "intersect <a> <b>: <R> area <s>". <R> is the notation of the common rectangle, and <s> is its area.
- Touching at an edge: "intersect <a> <b>: segment <E> length <l>". <E> is the notation of the shared edge, and <l> is its length ox+oy.
- Touching at a corner: "intersect <a> <b>: point <P>". <P> is the notation of the point (X1, Y1).
- Separated: "intersect <a> <b>: none, gap <g>". <g> is the gap.

ADJACENT a b
The error conditions are the same as for INTERSECT. Depending on the relation between a and b, output one of the following lines.
- Overlapping: "adjacent <a> <b>: overlapping"
- Touching at an edge: "adjacent <a> <b>: <a> is <D> of <b>, edge <E>, length <l>". <E> and <l> are the same as for INTERSECT. When ox is 0, <D> is west if the right end of a equals X1, and east otherwise. When oy is 0, <D> is south if the top end of a equals Y1, and north otherwise.
- Touching at a corner: "adjacent <a> <b>: corner only at <P>". <P> is the notation of the point (X1, Y1).
- Separated: "adjacent <a> <b>: not adjacent"

ENCLOSE a b
The error conditions are the same as for INTERSECT. Let "left end of b - left end of a", "bottom end of b - bottom end of a", "right end of a - right end of b" and "top end of a - top end of b" be the left, bottom, right and top margins, respectively (they can be negative), and let <M> be "margins left <p> bottom <q> right <r> top <t>" (<p>, <q>, <r>, <t> are the left, bottom, right and top margins in this order). If all four margins are 0 or more (that is, if a contains b), output "enclose <a> <b>: yes, <M>, min <v>" (<v> is the minimum of the four margins); otherwise output "enclose <a> <b>: no, <M>".

AT x y
Among the rectangles on all layers, arrange those that contain the point (x, y) (those with left end <= x <= right end and bottom end <= y <= top end) in name order, write each one in the form "<t> <L> <pos>" (<t> is the rectangle name and <L> is the layer name), join them with ", " (a comma and a single space) between them to form <T>, and output "at (<x>,<y>): <T>". <pos> is corner if x equals the left end or the right end and y equals the bottom end or the top end, edge if exactly one of x and y does so, and inside if neither does. If no rectangle contains the point (x, y), output "at (<x>,<y>): none". This command never results in an error.

NETS layer
The error condition is no rectangles. For the rectangles on layer layer, connect every two connected rectangles with a line; each group of rectangles that can reach one another by following lines (a connected component) is called a net. A rectangle that is connected to no other rectangle forms a net by itself. Let k be the number of nets, and output "nets <layer>: <k>", then arrange the nets in name order of "the first rectangle of the net in name order", and for the i-th net (i = 1, 2, ..., k) output one line "net <i>: <T> area <A>". <T> is the name list of the rectangles of that net, and <A> is the area of the set of all rectangles of that net.

PATH a b
The error conditions, in order, are: unknown rectangle, a and b are the same ("same rectangle <a>"), and a and b are on different layers ("different layers"). Let L be the layer of a and b. A sequence t0, t1, ..., tk (k >= 1) of rectangles on layer L in which t0 is a, tk is b, and ti and t(i+1) are connected for each i with 0 <= i < k is called a path, and k is its length. If there is no path, output "path <a> <b>: none". If there is a path, among the paths of minimum length choose the one that, comparing the rectangle names position by position from the beginning, has at the first differing position the name that comes first in name order, and output "path <a> <b>: <P> (<k> steps)". <P> is the names of t0, t1, ..., tk joined with " -> ", and <k> is its length. Write "steps" even when <k> is 1.

NEAREST name
The error condition is unknown rectangle. Among the rectangles other than name on the same layer as name, let t be the one with the smallest gap to name (if there are several, the first in name order), and output "nearest <name>: <t> gap <g>" (<g> is that gap). If there is no such rectangle, output "nearest <name>: none".

DRC layer s
The error condition is no rectangles. Among the pairs of two rectangles on layer layer (call the one that comes first in name order A and the other B), a pair whose relation is "touching at a corner", or whose relation is "separated" with a gap smaller than s, is called a "spacing violation". Let k be the number of spacing violations, and output "drc <layer> spacing <s>: <k> violations", then output the spacing violations one per line as "<A> <B> gap <g> <D>", sorted by gap in increasing order (for equal gaps, by name order of A; if that is also equal, by name order of B). <g> is the gap. <D> is corner for a pair touching at a corner, and the direction (one of x, y and diagonal) for a separated pair. Write "violations" even when <k> is 0 or 1.

BBOX layer
The error condition is no rectangles. Let B be the bounding box of all rectangles on layer layer, W and H its width and height, n the number of rectangles on layer layer, and A the area of layer layer, and output "bbox <layer>: <R> <W>x<H>, <n> rectangles, density <P>%". <R> is the notation of B, and <P> is the two-decimal notation of 100*A/(W*H). Write "rectangles" even when <n> is 1.

DENSITY layer w
Let (X1,Y1)-(X2,Y2) be the bounding box of all rectangles on layer layer, let c be the smallest integer >= (X2-X1)/w, and let r be the smallest integer >= (Y2-Y1)/w. The error conditions, in order, are: no rectangles, and c > 20 or r > 20 ("too many windows").
For each i and j with 0 <= i < c and 0 <= j < r, the square (X1+i*w,Y1+j*w)-(X1+(i+1)*w,Y1+(j+1)*w) is called tile (i, j) (a tile may extend beyond the bounding box). Let v(i, j) be the number of unit squares contained in tile (i, j) that are covered by layer layer.
First output "density <layer> window <w>: <c>x<r>". Then, for j = r-1, r-2, ..., 0 in this order, output one line in which floor(100*v(i, j)/(w*w)) for i = 0, 1, ..., c-1 in this order are separated by a single space (lines nearer the top are tiles with larger y).
Next, for the tile with the minimum v(i, j) (if there are several, the one with the smallest j; if there are still several, the one with the smallest i), output "min <P>% at <Q>". <P> is the two-decimal notation of 100*v(i, j)/(w*w), and <Q> is the notation of the lower-left point (X1+i*w, Y1+j*w) of that tile. Finally, for the tile with the maximum v(i, j) (if there are several, the one with the smallest j; if there are still several, the one with the smallest i), output "max <P>% at <Q>" in the same way.

RENDER layer x1 y1 x2 y2
The error conditions, in order, are: no rectangles, x1 >= x2 or y1 >= y2 ("invalid window"), and x2-x1 > 60 or y2-y1 > 40 ("window too large"). The rectangle (x1,y1)-(x2,y2) is called the window. First output "render <layer> <R>" (<R> is the notation of the window), then, for j = y2-1, y2-2, ..., y1 in this order, output one line of x2-x1 characters. The p-th character of the line (p = 1, 2, ..., x2-x1), with e being the coverage count for layer layer of the unit square [x1+p-1, j], is "." if e is 0, the single digit representing e if e is between 1 and 9, and "*" if e is 10 or more.

EMPTY layer
The error condition is no rectangles. Let (X1,Y1)-(X2,Y2) be the bounding box of all rectangles on layer layer. When integers x1, y1, x2, y2 satisfy X1 <= x1 < x2 <= X2 and Y1 <= y1 < y2 <= Y2 and the rectangle (x1,y1)-(x2,y2) covers no unit square that is covered by layer layer, this rectangle is called an empty rectangle (it is a rectangle whose relation to every rectangle on layer layer is not "overlapping"). Let E be the empty rectangle with the largest area (if there are several, the one with the smallest x1; if there are still several, the one with the smallest y1; if there are still several, the one with the smallest width), and output "empty <layer>: <R> area <a>" (<R> is the notation of E, and <a> is the area of E). If there is no empty rectangle, output "empty <layer>: none".

HOLES layer
The error condition is no rectangles. For the unit squares not covered by layer layer, connect every two neighboring ones with a line; among the groups of unit squares that can reach one another by following lines (connected components), each one containing a finite number of unit squares is called a hole. Among the unit squares [i, j] contained in a hole, the one with the smallest j, and among those the one with the smallest i, is the anchor of that hole. Let k be the number of holes, and output "holes <layer>: <k>", then arrange the holes by j of the anchor in increasing order (for equal j, by i of the anchor in increasing order), and for the q-th hole (q = 1, 2, ..., k) output one line "hole <q>: area <a>, bbox <R>". <a> is the number of unit squares contained in the hole. <R> is the notation of the rectangle (i1,j1)-(i2+1,j2+1), where i1 and i2 are the minimum and maximum of i, and j1 and j2 are the minimum and maximum of j, over the unit squares [i, j] contained in the hole.
Note that even between two rectangles that only touch at a corner, uncovered unit squares are not neighboring each other. For example, if the rectangles of the layer are the four (0,1)-(1,3), (1,0)-(3,1), (3,1)-(4,3), (1,3)-(3,4), the unit squares [1, 1], [2, 1], [1, 2], [2, 2] form a hole of area 4.

MERGE layer
The error condition is no rectangles. For an integer j and integers i < e, when the unit squares [i, j], [i+1, j], ..., [e-1, j] are all covered by layer layer and [i-1, j] and [e, j] are not covered, (i, e) is called "a run of row j". For integers l < r and y1 < y2, when (l, r) is a run of row j for every j with y1 <= j < y2, and (l, r) is neither a run of row y1-1 nor a run of row y2, the rectangle (l,y1)-(r,y2) is called a piece. Every covered unit square is covered by exactly one piece. Let k be the number of pieces, and output "merge <layer>: <k> pieces", then output the notation of the pieces one per line, sorted by bottom end in increasing order (for equal bottom ends, by left end in increasing order). Write "pieces" even when <k> is 1.

RULE SPACING layer s
RULE WIDTH layer w
RULE ENCLOSE inner outer m
There are the following three kinds of rules.
- Spacing rule (kind spacing): consists of a layer layer and a value s.
- Width rule (kind width): consists of a layer layer and a value w.
- Enclosure rule (kind enclose): consists of an inner layer inner, an outer layer outer, and a value m.
Rules are distinguished by kind and layer (for an enclosure rule, the ordered pair of inner and outer), and there is at most one rule with the same kind and layer. RULE adds a rule if there is no rule of that kind and layer, and replaces the value if there is one. The outputs are "rule spacing <layer> <s>", "rule width <layer> <w>" and "rule enclose <inner> <outer> <m>", respectively. A rule's layer may have no rectangles. The only error is RULE ENCLOSE with inner and outer being the same, and its MESSAGE is "same layer <inner>".

CHECK
The error condition is that there are no rules ("no rules"). Arrange all rules in order of kind (the order enclose, spacing, width), and for the same kind in layer name order (for enclosure rules, in name order of inner, and for the same inner in name order of outer), and for each rule output one heading line and the violation lines. <k> in a heading is the number of violations of that rule; write "violations" even when it is 0 or 1.
- Enclosure rule (inner layer I, outer layer O, value m): for each rectangle t on layer I, compute, for each rectangle u on layer O, the minimum of "left end of t - left end of u", "bottom end of t - bottom end of u", "right end of u - right end of t" and "top end of u - top end of t"; the maximum of those values is the best margin of t. A t is a violation if there is no rectangle on layer O or its best margin is smaller than m. The heading is "enclose <I> <O> <m>: <k> violations", and the violation lines are "<t> best margin <v>" in name order of the violating t. <v> is the best margin of t, or "none" if there is no rectangle on layer O.
- Spacing rule (layer L, value s): the violations are the same as the spacing violations of DRC L s. The heading is "spacing <L> <s>: <k> violations", and the violation lines are in the same form and the same order as for DRC.
- Width rule (layer L, value w): a rectangle on layer L is a violation if d, the smaller of its width and height, is smaller than w. The heading is "width <L> <w>: <k> violations", and the violation lines are "<t> width <d>" (<t> is the rectangle name) in name order of the violating rectangles.
If the rule's layer (for an enclosure rule, layer I) has no rectangles, the rule has 0 violations. Finally output "check: <T> violations in <r> rules" (<T> is the sum of the numbers of violations of all rules, and <r> is the number of rules). Write "violations" even when <T> is 0 or 1, and "rules" even when <r> is 1.

[Output format]
The output of each command consists of the lines defined in [Processing], and is output in command order. When one command outputs several lines, output them in the order described in [Processing].
The output consists only of ASCII characters, and every line ends with a newline (LF). Do not put whitespace at the start or end of a line, and do not output empty lines.
Write numbers in decimal, with a leading "-" for negative numbers. Except for the fractional part of the two-decimal notation, do not put extra leading zeros on numbers.
Unless otherwise specified, a space inside a string is a single space.

[Constraints]
- 1 <= N <= 1000
- At most 40 rectangles exist at the same time, and there are at most 20 rules.
- x1, y1, x2, y2 of ADD, dx, dy of COPY and MOVE, w, h of RESIZE, pos of SPLIT, x, y of AT, and x1, y1, x2, y2 of RENDER are between -30000 and 30000 inclusive.
- k of COVER is between 1 and 50 inclusive.
- s of DRC, w of DENSITY, s of RULE SPACING and w of RULE WIDTH are between 1 and 30000 inclusive, and m of RULE ENCLOSE is between 0 and 30000 inclusive.
- Values such as areas and perimeter lengths are less than 2^31, but in the density computations of BBOX and DENSITY, integers of 2^31 or more may appear along the way. Every integer that appears during a computation has an absolute value less than 2^53.
